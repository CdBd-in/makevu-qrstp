## 2. 이번 세션에 한 일

### 2-1. `2-2-4. 이미지` 신설 ⭐ (디자인 요소에 이미지 항목 추가)
리워드 페이지 등에 들어가는 **이미지 리소스**를 정의. 두 종류:

- **① 3D thiings 아이콘** — 리워드를 직관적으로 보여주는 입체 아이콘.
  - 소스 **thiings.co**, 한 이벤트 = 단일 톤.
  - 자리: 리워드 이미지 **275×172** · 시작 페이지 리워드 이미지 **275×120**.
  - 배치: 투명 PNG · **중앙 정렬** · 비율 유지한 채 **아이콘 세로 길이를 박스 높이에 맞춤**.
  - 리워드 정보 없으면 `#D9D9D9` placeholder.
- **② 배경 이미지** — **가독성 최우선**(콘텐츠보다 튀지 않게, 저채도, 텍스트 영역 비움).
  - 선정 기준 **3유형**: **① 일러스트**(예 청주시) · **② 그래픽**(예 송도·SK on) · **③ 그라데이션**(예 SIMTOS).
  - **모두 Google Labs Flow에서 생성**(프롬프트: `flat illustration` / `abstract graphic shapes` / `soft gradient background` · 공통 `no text, no logo`, 9:16, 중앙 여백).
  - 예시 5종 임베드 → `attachments/bg-ex-{유형}-{이벤트}.png` (illust-청주 · graphic-송도 · graphic-skon · gradient-심토스 · solid-글렌그란트).

### 2-2. `3. 워크플로우` 갱신 (리소스 **없을 때** 중심으로 정비)
- **인트로**: "이벤트명·설명에 맞춘 **커스텀 디자인이 목적**" 명시 → 모든 페이지는 **`2-1 페이지 구조` + `2-2 디자인 요소` 전체를 베이스**로 제작. 하위 8개 노트 링크 추가.
- **옛 번호 참조 교정**: stale `2-1`(=디자인 시스템) → **2-2-1**, `2-2~2-5` → **2-1-1~2-1-4**, 표 헤더 "2-1 정의" → "2-2-1 정의", 갱신 규칙 분리(정의=2-2-1 / 페이지 규칙=2-1-n).
- **실제 이벤트 예시 링크**: 민주평통 → **솥바위기운수사국 · 고양꽃박람회** 로 교체(3곳).
- **Step 2.5 B (리소스 없을 때) 전면 개편**: "빈 회색 박스로 두지 않는다" 원칙.
  - **1) 컬러·폰트 동시 제안** — 무드 추출 → **컬러(2-2-3 팔레트) + 폰트(2-2-2)** 를 한 세트로. 9무드 체계를 두 파일이 공유.
  - 빠른 힌트 표를 **역할 기반**으로 교체: 임의 hex → **2-2-3 검증 팔레트의 `배경`/`텍스트`/`버튼(=메인)` + 폰트(헤드라인/본문)**.
  - **2) 이미지 생성/소싱** — 배경=Flow(3유형), 리워드=thiings 3D 아이콘 (→ 2-2-4 연결).
  - **3) DS 폴백 템플릿** + **4) 최종 폴백**(정보 없는 자리만 `#D9D9D9`).

## 3. 핵심 결정 (이번 세션)

1. 디자인 요소에 **이미지 항목(2-2-4)** 을 별도 문서로 분리.
2. 배경 이미지 방향 = **실사 사진풍 ❌ → 일러스트·그래픽·그라데이션 3유형**(가독성 최우선), 생성 도구 = **Google Labs Flow**.
3. 리소스 없을 때도 **회색 placeholder로 방치하지 않고** 컬러·폰트 추론 + 이미지 생성으로 **완성형 폴백**.
4. 톤 제안 = **컬러와 폰트를 항상 함께**(같은 무드), 컬러는 2-2-3의 **배경·텍스트·버튼 한 쌍** 규칙 준수.
