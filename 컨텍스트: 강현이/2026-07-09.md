- **§6 인증 템플릿 기준 신설** — **디자인(입력 필드 스타일) 기준 2유형**: **밑줄형**(기본) / **박스 인풋형**(티쏘)
  - 명암(라이트/다크)·메인컬러는 **직교 축**, 이메일·방법선택·닉네임·언어선택은 **직교 슬롯(기능 옵션)** — 디자인 유형 아님
- **§7 룰렛 템플릿 기준** — 처음엔 `연출 형태(A 스핀휠 / B 가챠·캡슐)` 로 만들었으나, **B(가챠·캡슐)는 룰렛이 아니라 다른 리워드 방식**이라 판단 → **연출 형태 축 삭제**
  - §7을 **조각(섹터) 디자인 유형**으로 승격: **A1 색면 교차형**(기본) / **A2 화이트 플레이트형** / **A3 일러스트 보드형**
  - 연동 정리: §8-4 요약 트리 · §9 로드맵(P1 A1 / P2 A2·A3) · §10 원칙 요약

### 7-6. B 경로형 설계 결론 (⚠️ 문서화 대기)

> "개수별 템플릿을 만들까 vs 규칙을 만들까" 논의 결론.

- **개수별 템플릿 ❌** — 2-3 §3 원칙(**규모는 축이 아니라 파라미터**)과 충돌 + 유지보수 폭발
- **B를 2개로 쪼갠다**:

| | 만들 것 | n 확장 |
|---|---|---|
| **B-1 여정형(추상 경로)** | **행 유닛 컴포넌트 1개** + 배치 규칙 | 유닛 복제 = 자동 |
| **B-2 지도형(실지도)** | **부품 세트**(핀·번호배지·점선경로·라벨·상태)만 규격화 | 배치는 이벤트별 커스텀 (**규칙화 불가** — 핀 위치를 지리가 정함) |

- **B-1 행 유닛 variant**: `열수 = 2 | 3` × `방향 = 좌→우 | 우→좌`(스네이크 U턴)
- ⭐ **핀 가로 위치 = 균등분할 공식 하나로 커버** (327폭): `xₖ = (2k−1)/(2c) × 327` (c=열수)
  - 2열 → 81.75 · 245.25 / 3열 → 54.5 · 163.5 · 272.5 → **4열이 와도 같은 공식** = 열수별 템플릿 불필요
- **열 수 선택 규칙**: `n ≤ 6` 또는 라벨 김 → **2열** / `n ≥ 7` → **3열** / `n ≥ 12` → 3열 + 스크롤
- **잔여 행**: 진행 방향 시작쪽부터 채우고 나머지 비움

### 7-7. 설문 답변 면(surface) 색상 제안 (⚠️ 미확정)

대상: WORLD PASSPORT 설문 섹션 `6600:20354` (면처리형 실험 중, 현재 **올리브/카키**라 라임이 탁해짐)

- **문제**: 라임(`#B0F800`, 황록)을 네이비 배경 위에 반투명 오버레이 → **노랑×파랑 = 카키**. 웜그레이(`#3E3A38`)도 쿨 네이비와 온도 충돌.
- **최종 추천**: **답변 면 = 쿨 차콜 `#242A2C`** (채도 6%, hue≈190° → 회색으로 보이나 라임과 붙음)
  - 미선택 `#242A2C` / 호버 `#2C3335` / **선택 = `#313937` + 라임 테두리 1.5px + 라디오 중앙 채움**
  - 선택 표시는 **면 색이 아니라 테두리+라디오**로
- 보조 텍스트용 **중간색** 후보(미정): 틸그레이 `#6E8C8A` / 뮤트 블루그레이 `#8C98A9`
- ⛔ 금지: 올리브 `#3B4A1E` · 웜그레이 `#2E2B29`·`#3E3A38`

### 7-8. ⚠️ 재현 시 함정 (실제로 막혔던 것)

1. **폰트 이름 함정** — 파일의 씰/리본 텍스트는 **`Nanum Myeongjo`(공백 있음)** 로 지정돼 있는데 **플러그인 환경에 없어 `loadFontAsync` 실패 → 텍스트 편집 불가**.
   → **`NanumMyeongjo`(공백 없음, ExtraBold/Bold/Regular)** 로 `fontName`을 교체하면 동일 서체로 편집 가능.
2. **섹션 자식 좌표는 섹션 상대값** — 페이지 절대좌표로 `x/y`를 넣으면 섹션이 거대하게 늘어나며 요소가 멀리 배치됨. (실제로 한 번 겪음 → 재배치 + `resizeWithoutConstraints`로 복구)
3. **컴포넌트 재생성 시 인스턴스 오버라이드 소실** — 컴포넌트를 새로 만들면 기존 인스턴스의 텍스트 오버라이드(명소명)가 날아감 → **교체 후 명소 텍스트 재적용 필요**.
4. **텍스트 중앙정렬** — 씰/리본 텍스트는 `textAlignHorizontal='CENTER'` + **고정 폭**으로 두어야 글자 수가 바뀌어도 중앙 유지.
