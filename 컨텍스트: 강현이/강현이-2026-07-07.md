# 🧭 참조 이벤트 종합 매트릭스 — 컨텍스트 문서

> **작성: 강현 · 2026-06-31**
> 현재 [[큐알스탬프 솔루션/5. 참조 페이지]]에 축적된 **57개 참조 이벤트**를 자동화 관점에서 "가로 비교"하기 위한 종합 매트릭스 노트의 **목적·구성 설계안**.
> ⚠️ 이 파일은 컨텍스트(설계 근거) 문서이며, 실제 매트릭스 노트 본체는 아직 만들지 않았다.

---

## 1. 왜 이 노트가 필요한가

참조 페이지가 57개다. 개별 노트는 "한 이벤트를 깊게" 보는 데는 좋지만, 자동화할 때 실제로 필요한 건 **가로 비교(cross-comparison)** 다.

| 자동화 시 실제 질문 | 개별 노트 57개로는 | 매트릭스 노트가 있으면 |
|---|---|---|
| "인증 없는 3단계 축제형이 몇 개고 뭐가 표준이지?" | 57개를 다 열어봐야 함 | 한 표에서 필터 |
| "스탬프 5칸이면 배치를 어떻게들 했지?" | 기억/재조사 | 배치 유형별로 정렬됨 |
| "이 브리프엔 어떤 기존 이벤트가 제일 가깝지?" | 감으로 매칭 | 축(axis)으로 최근접 매칭 |
| "룰렛 보상은 어떻게 구성하지?" | 흩어져 있음 | 패턴 카드로 정리 |

**핵심 목적**: 새 이벤트 브리프가 들어왔을 때 → **① 최근접 참조 매칭 → ② 재현 규칙 즉시 적용**. [[큐알스탬프 솔루션/3. 워크플로우.md]]의 "가장 가까운 참조 이벤트 매칭" 단계를 실제로 작동시키는 조견표 역할.

## 2. 노트 구성(목차안)

```
0. 목적 & 사용법 (자동화 파이프라인에서 어디에 쓰는지)
1. 마스터 매트릭스 (57개 전수 표)   ← 핵심
2. 축(axis)별 분류 요약
   2-1. 단계 구조   2-2. 인증 유무   2-3. 스탬프 배치·칸수
   2-4. 리워드 방식   2-5. 폰트·통이미지 여부
3. 자동화 의사결정 트리 (브리프 → 최근접 참조)
4. 반복 패턴 라이브러리 (룰렛/설문·퀴즈/다국어/2단리워드/캐릭터IP)
5. 자동화 공통 리스크 & 규칙
```

### (B) 축별 분류 요약 — *예: 스탬프 배치 유형*

- **정형 격자** (2×2·2×3·2열스크롤): 경기수의·SIMTOS·넷마블·맥캘란·삼다수 …
- **지도/로드맵형**: 은평구·창대십리길·솥바위·롯데월드ESG·광주·청년정책넷·횡성
- **콜라주/스태거드**: MSI·삼양·울산옹기·세부에어·APPLIED
- **원형·특수**: TCTAP(도넛링)·ITZY(겹침)·쿠키런(1행)
- **스탬프 없음(미션/공유)**: 티쏘·불가리 포스트카드

### (C) 자동화 의사결정 트리 — *발췌*

```
브리프 입력
├ 인증 필요?  ── 없으면 → 언어선택으로 대체하나? (다국어면 삼양/송도/올리브영 참조)
├ 스탬프 칸수 N?
│   ├ N≤4  → 2×2 격자 (경기수의·넷마블·K.CRAFT)
│   ├ N=5  → 2-2-1 피라미드 (송도·APPLIED·제주관광)
│   ├ N≥12 → 지도/스크롤 대형 (강진·연천·경기수의67)
│   └ N=0  → 미션형 (티쏘) / 공유형 (불가리)
├ 보상 방식?
│   ├ 고정  → 리워드 화면 (WORLD PASSPORT)
│   ├ 추첨  → 룰렛 삽입 (다이슨·세부에어·수원화성)
│   └ 구간  → 2단 마일스톤 (연천·삼다수)
└ 콘텐츠 게이팅? → 퀴즈/설문 (롯데ESG·인터배터리·TGG)
```

### (D) 자동화 공통 리스크 & 규칙 — *예시*

1. **통이미지 경고**: 절반 이상이 CTA·타이틀·스탬프 라벨까지 이미지에 baked → **리컬러 불가, 이미지 자산 생성이 선행**.
2. **폰트 확정 선행**: Pretendard가 아닌 브랜드/전통 서체 케이스 다수(Gotham·윤고딕·수성혜정·DungGeunMo …).
3. **active/inactive 방식**: 별도 애셋 2벌 vs opacity — 케이스별로 다름.
4. **밝은 메인컬러**: 라임·옐로 위 텍스트는 다크로 (WORLD PASSPORT 교훈).
