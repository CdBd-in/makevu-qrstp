## 5. 제작 방식 (재현 규칙 · 하드런 교훈)

1. **복제 출발점**: 템플릿 섹션 `6600:18858`을 `.clone()`. ⚠️ **`clone()`은 `figma.currentPage`에 붙는다** → 반드시 **`await figma.setCurrentPageAsync(대상페이지)`를 같은 스크립트에서 먼저** 호출(안 하면 첫 페이지 `Cover`로 감). 2시안은 시안1을 다시 복제해 리테마가 효율적.
2. **리테마 = 직접 fill 교체** (이 템플릿은 색이 **변수가 아니라 직접 SOLID fill**). 트리 순회로 `fills`·`strokes`·**텍스트 segment** 모두 처리.
   - ⭐ **`.characters = ...` 통짜 교체는 글자별(segment) 서식을 초기화한다.** → "스탬프 4개→6개" 바꿀 때 숫자 강조색이 날아감. 숫자/강조어는 **`getStyledTextSegments`→`setRangeFills`**로 별도 복원(강조어=메인 컬러, 검수 §3).
   - 강조어 대상: **활성 버튼·강조어·스탬프 개수(N개)·스탬프 채움/라벨·타이틀** = 메인 컬러 통일.
3. **벡터 배경**(KV는 통이미지로 넣지 말고 "무드"만 차용):
   - 스트링 조명 = SVG 곡선 와이어(`Q` 패스) + 전구 ellipse(웜 골드 + DROP_SHADOW 글로우), 달 = ellipse + 글로우 레이어, 별 = 4포인트 star.
   - ⚠️ **절대배치 좌표는 "부모 프레임 기준 상대좌표"** (캔버스 좌표 아님). `layoutPositioning='ABSOLUTE'`는 **부모가 오토레이아웃일 때만** 가능 → 오토레이아웃 아닌 프레임은 `insertChild(0,node)` + 일반 x/y.
4. **스탬프(매번 커스텀)**: 4유형 후보 보드 제작(①텍스트만 ②이미지+텍스트 ③이미지만 ④이미지+하단리본) → **사용자 1개 선택** → **이벤트 전용 컴포넌트 세트(active/inactive)** 생성(공용 마스터 `6189:13747` 수정 금지) → 그리드 6칸(2×3) 재구성 → 인스턴스 상태별 배치. **후보 보드는 삭제하지 않고 보관**(검수 §5).
   - **시안별 다른 스탬프**: 컴포넌트를 각각 만들고 `instance.swapComponent(newComp)`로 스왑(상태별 active↔inactive 매칭). 시안2는 시안1(③) 인스턴스에 **퍼플 오버라이드**로 시작했다가, 시안1만 ①씰로 스왑해 분리함.
   - crescent 초승달 = `createNodeFromSvg`(색상은 SVG fill 문자열에 직접). ⚠️ createNodeFromSvg는 FRAME 반환 → 프레임 fills 비우고 벡터에만 색.
5. **로고 = 어두운 배경 흰색 녹아웃**(검수 §7). 크림 칩/프레임 ❌. PIL로 `alpha 유지 + RGB→흰색` 실루엣 생성 → 업로드 → 8개 로고 `fills=[IMAGE(FIT)]`, cornerRadius 0.
6. **리워드 이미지 = thiings 3D 아이콘**(비율유지 FIT). 리워드 페이지 카드의 메인 이미지 rect에 적용 + 기존 오버레이(항공기) 이미지 `visible=false`.
7. **플로우 라벨(캔버스 섹션 헤더/캡션)은 고정색** — 시안 테마로 물들이지 말 것(`#462CD9`/`#547CFF`). 배경 일괄 차콜화 시 375폭 라벨 프레임까지 덮이므로 **시안1 라벨색을 이름+x 매칭해 복원**.
