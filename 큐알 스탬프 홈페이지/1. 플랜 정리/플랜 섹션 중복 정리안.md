# 🎯 QR스탬프 "이용 안내 × 플랜" 중복 정리안

> 홈페이지 [www.qrstp.com](https://www.qrstp.com/) 분석 기반

---

## 1. 문제 정의

현재 홈페이지에서 **플랜 관련 콘텐츠가 두 곳에 중복**되어 있다.

- **이용 안내 섹션** 안에 플랜별 기능/가격 정보가 포함되어 있음
- **플랜 섹션**이 별도로 또 존재함

→ 같은 정보가 다른 옷을 입고 두 번 노출되어 **유지보수 부담**과 **사용자 혼란**을 초래.

---

## 2. 진단: 왜 중복이 생겼는가

이 사이트는 **케이스 스터디가 매우 강력**(롯데월드, 다이슨, MS, 현대, 강원관광재단 등 30+ 사례)해서 본 솔루션이 "어디까지 가능한지"가 자연스럽게 궁금해진다.

그래서 운영자는 **이용 안내 안에 "어떤 옵션이 가능한지(=플랜별 기능)"를 함께 보여주고 싶은 충동**이 생겼을 것이다. 동시에 가격/플랜 페이지의 표준 구색을 위해 **별도 플랜 섹션도 존재**하게 된다.

→ 결과: **"기능 가용 범위"라는 같은 정보가 두 곳에서 반복**된다.

---

## 3. 정리 원칙 (1줄)

> **"이용 안내 = 무엇을 만들 수 있나(WHAT)" / "플랜 = 얼마에 어디까지 받나(HOW MUCH)"**
> 가격·플랜별 ✓/✗는 **플랜 섹션에만 단일 원본(SSOT)**으로 둔다.

| 섹션 | 사용자 마음 상태 | 답해야 할 질문 | 퍼널 단계 |
|---|---|---|---|
| **이용 안내** | "이게 어떻게 동작하지?" | HOW · 기능 | 🟡 Consideration |
| **플랜** | "얼마이고, 뭘 받지?" | WHAT & HOW MUCH | 🔴 Decision |

---

## 4. 실제 정리 액션

### ✂️ "이용 안내"에서 제거할 것
- [ ] 플랜 이름이 표 헤더로 등장하는 모든 표 → **제거**
- [ ] "이 기능은 ○○ 플랜 이상" 같은 가격 결정 정보 → **배지 1개로 축약**
- [ ] 가격(₩, 만원 등) 표시 → **전부 제거** (가격은 플랜 섹션에만)

### ✅ "이용 안내"에 남기거나 강화할 것
- [ ] STEP 1~4 흐름 (캠페인 만들기 → QR 배포 → 적립 → 리워드)
- [ ] 핵심 **기능 카드**: 스탬프 미션 / 룰렛 리워드 / 커스텀 디자인 / 다국어 / 분석
- [ ] 각 기능 카드 우상단에 **작은 플랜 배지**: `[Basic+]`, `[Pro+]`
- [ ] 섹션 마지막에 단일 CTA: **"플랜 비교하기 →"** (플랜 섹션 앵커)

### ✅ "플랜" 섹션의 단독 책임
- [ ] **플랜별 기능 비교 매트릭스** (이 사이트의 단일 진실)
- [ ] 가격 또는 "문의" 표기
- [ ] 추천 사용 케이스 1줄 (예: "Basic — 1회성 팝업스토어용")
- [ ] 단일 CTA: **"상담 신청하기"**

---

## 5. 보너스: CTA 정리도 함께

현재 사이트에 6종의 CTA가 혼재:
> 상담신청 / 문의하기 / 소개서 받기 / 체험하기 / 스탬프 투어 상담하기 / 샵플랜

**제안 — 3개로 통일**

| 위치 | Primary CTA | 의도 |
|---|---|---|
| 헤더 고정 | **상담 신청하기** | 리드 확보 |
| 이용 안내 끝 | **소개서 받기** | 검토 단계 |
| 플랜 섹션 끝 | **상담 신청하기** | 구매 임박 |
| 케이스 카드 | **비슷한 사례로 상담하기** | 사례 기반 진입 |

→ "체험하기"는 별도 데모 URL로 분리, 헤더에서 제거.

## 6. Before / After 와이어프레임

### Before (현재 추정)
```
[이용 안내]
 ├ STEP 1~4
 ├ 기능 설명
 ├ 📊 플랜별 기능표 ◀ 중복!
 ├ ₩ 가격 일부      ◀ 중복!
 └ CTA: 상담/문의/체험 (혼재)

[플랜]
 ├ 📊 플랜별 기능표 ◀ 중복!
 ├ ₩ 가격
 ├ 사용방법 요약    ◀ 이용 안내와 충돌
 └ CTA: 상담/문의 (혼재)
```

### After
```
[이용 안내]  ← "WHAT을 만들 수 있나"
 ├ STEP 1~4
 ├ 기능 카드 × N (우상단 플랜 배지만)
 └ CTA 1개: "플랜 비교하기 →"

[플랜]  ← "HOW MUCH"
 ├ 📊 단일 매트릭스 (가격 + ✓/✗)  ◀ 원본 단일화
 ├ 플랜별 추천 사용 케이스
 ├ FAQ: "어떤 플랜이 필요한가요?"
 └ CTA 1개: "상담 신청하기"
```

## 8. 플랜 배지 디자인 가이드

옵션 A 성공은 "**이 기능, 어느 플랜에 있어요?**"를 알려주는 작은 배지의 가독성에 달려 있다.

```
권장:   [ Basic+ ]   ← "베이직 이상부터" 의미. 한 번에 이해됨
비권장: [ Basic, Pro, Enterprise ]  ← 너무 김
비권장: [ ●●● ]   ← 의미 추측 필요
```

색상은 플랜별 시그니처 컬러를 미세하게 반영하되, 본문 가독성을 해치지 않도록 채도는 낮게.
