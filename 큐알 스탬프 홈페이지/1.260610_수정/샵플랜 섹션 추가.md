# 🛒 샵플랜 섹션 추가

> QR 홈페이지에 샵플랜(QR 결제) 진입 섹션을 추가하고, 클릭 시 샵플랜 상세 페이지로 연결한다.

---

## 1. 샵플랜이란?

| 항목 | 내용 |
|---|---|
| **카테고리** | B2B QR 결제 솔루션 |
| **핵심 USP** | **단말기 없이 QR 하나로 시작하는 결제** |
| **타겟 상황** | 단기 행사 / 팝업스토어 / 부스 / 축제 |
| **지원 결제 수단** | 카드 · 간편결제 · 계좌이체 |
| **차별점** | 단말기 대여·설치 비용·과정 불필요 |
| **참고** | [샵플랜 랜딩페이지(Notion)](https://www.notion.so/37505577764f80c8ab97d900ff1b9fae) |

---

## 2. 연결 동선

```
QR 홈페이지 (qrstp.com)
   └─ 샵플랜 섹션 (진입 카드)
        └─ [샵플랜 자세히 보기 →]
             └─ 샵플랜 상세 페이지
```

→ 홈페이지의 **샵플랜 섹션은 디스커버리(인지) 역할만** 수행. 상세 정보는 분리된 페이지로 위임.

---

## 3. 배치 위치 결정 — 위치 ③

### 결정: **이용 안내 직후, 최종 CTA 직전**

```
1. Hero
2. 고객사 로고
3. "왜 메이크뷰 QR 솔루션을…"
4. 케이스 스터디 / 가치 제안
5. QR 플랜 안내
6. 이용 안내
7. ★ [샵플랜 진입 섹션] ★     ← 신규
8. "우리 브랜드에 딱 맞는 스탬프 투어" CTA
9. 하단 이미지
```

### 결정 이유

| # | 사유 |
|---|---|
| 1 | **메인 퍼널 보존** — Hero → 플랜 → 이용안내까지 QR 스탬프 메인 흐름을 끊지 않음 |
| 2 | **인지 흐름 자연스러움** — "QR 스탬프 다 봤다 → 다른 옵션도 있구나" 자연 전환 |
| 3 | **위계 명확** — 위쪽 = 메인(QR 스탬프), 아래쪽 = 보조(샵플랜) 시그널 |
| 4 | **상담 진입 직전 노출** — 결정 직전에 "둘 다 가능"을 보여줘 크로스셀 기회 확보 |

### 검토 후 탈락한 후보

| 후보 위치 | 탈락 이유 |
|---|---|
| Hero 직후 | "메인 제품이 뭐지?" 혼란 |
| QR 플랜 안내 직전 | 플랜 검토 흐름 단절 |
| 페이지 맨 하단 | 스크롤 도달률 낮아 클릭 손실 |

## 4. 진입 섹션 구성 컨셉

### 4-1. 톤 & 색상 차별화

| 영역 | QR 스탬프 (위) | 샵플랜 (이 섹션) |
|---|---|---|
| 배경 | 다크 (#0B0B10) | 웜 크림 (#FFF7F0) |
| 포인트 컬러 | 민트 (#00DBA1) | 웜 오렌지 (#FF6B35) 계열 |
| 분위기 | "참여·이벤트" | "결제·거래" |

→ 한눈에 "여기서부터 다른 제품" 인지 가능.

### 4-2. 카피 설계

**메인 헤드라인 (후보)**
> 1. "행사 결제는 단말기 없이, QR 하나로"
> 2. "단기 행사에 카드 단말기까지 빌리지 마세요"
> 3. "참여는 QR 스탬프, 결제는 샵플랜"  ← 크로스셀 명시

**서브 카피**
> "팝업스토어·부스·축제 — 단말기 대여 없이 카드·간편결제·계좌이체까지 받아보세요"

**핵심 가치 3가지**
| # | 라벨 | 디스크립션 |
|---|---|---|
| 1 | **단말기 0대** | 대여·설치 없이 즉시 시작 |
| 2 | **모든 결제 수단** | 카드 · 간편결제 · 계좌이체 |
| 3 | **단기 행사 최적** | 팝업·부스·축제 운영에 맞춤 |

**CTA (단일)**
> [샵플랜 자세히 보기 →]

→ 상세 페이지 진입에만 집중. 상담 신청은 상세 페이지에서.

### 4-3. 레이아웃 가이드

```
┌─────────────────────────────────────────────────┐
│  웜 크림 배경                                    │
│                                                  │
│        [BADGE: "다른 솔루션도 있어요"]           │
│                                                  │
│      "행사 결제는 단말기 없이, QR 하나로"        │
│                                                  │
│    "팝업·부스·축제 — 단말기 대여 없이…"          │
│                                                  │
│   ┌─────────┐ ┌─────────┐ ┌─────────┐            │
│   │ 단말기  │ │ 모든    │ │ 단기    │            │
│   │ 0대     │ │ 결제    │ │ 행사    │            │
│   │ ...     │ │ 수단    │ │ 최적    │            │
│   └─────────┘ └─────────┘ └─────────┘            │
│                                                  │
│         [샵플랜 자세히 보기 →]                   │
│                                                  │
└─────────────────────────────────────────────────┘
```

- **높이 가이드**: 800~1000px (1뷰포트 이내)
- **너비**: 1920px
- **패딩**: 상하 100px, 좌우 360px

## 6. 후속 검토 항목

### 6-1. 카피 톤 결정 필요
3개 헤드라인 후보 중 어느 톤이 적합한지 — **사용자(QR스탬프 운영진)와 협의** 필요.

### 6-2. 크로스셀 메시지 강도
- 강하게: "참여는 QR스탬프, 결제는 샵플랜" (두 제품 직접 연결)
- 부드럽게: "결제도 필요하시다면" (선택지로 제시)

### 6-3. 진입 섹션의 정보 깊이
- 현재 안: 3가지 가치 청크만
- 대안: 가격대 / 사용 사례 / 신뢰 지표 일부 노출 → 길이 증가

### 6-4. 향후 메인 승격 가능성
샵플랜이 성장 제품으로 전략적 우선순위가 된다면, 위치 ③(보조) → 위치 ②(QR 플랜 직전, 동등 노출) 승격 검토.
