# 🛒 샵플랜 섹션 추가

> QR 홈페이지에 샵플랜(QR 결제) 진입 섹션을 추가하고, 클릭 시 샵플랜 상세 페이지로 연결한다.

---

## 1. 샵플랜이란?

| 항목 | 내용 |
|---|---|
| **카테고리** | B2B QR 결제 솔루션 |
| **핵심 USP** | **단말기 없이 QR 하나로 시작하는 결제** |
| **타겟 상황** | 단기 행사 / 팝업스토어 / 부스 / 축제 |
| **지원 결제 수단** | 카드 · 간편결제 · 계좌이체 |
| **차별점** | 단말기 대여·설치 비용·과정 불필요 |
| **참고** | [샵플랜 랜딩페이지(Notion)](https://www.notion.so/37505577764f80c8ab97d900ff1b9fae) |

---

## 2. 연결 동선

```
QR 홈페이지 (qrstp.com)
   └─ 샵플랜 섹션 (진입 카드)
        └─ [샵플랜 자세히 보기 →]
             └─ 샵플랜 상세 페이지
```

→ 홈페이지의 **샵플랜 섹션은 디스커버리(인지) 역할만** 수행. 상세 정보는 분리된 페이지로 위임.

---

## 3. 배치 위치 결정 — 위치 ③

### 결정: **이용 안내 직후, 최종 CTA 직전**

```
1. Hero
2. 고객사 로고
3. "왜 메이크뷰 QR 솔루션을…"
4. 케이스 스터디 / 가치 제안
5. QR 플랜 안내
6. 이용 안내
7. ★ [샵플랜 진입 섹션] ★     ← 신규
8. "우리 브랜드에 딱 맞는 스탬프 투어" CTA
9. 하단 이미지
```

### 결정 이유

| # | 사유 |
|---|---|
| 1 | **메인 퍼널 보존** — Hero → 플랜 → 이용안내까지 QR 스탬프 메인 흐름을 끊지 않음 |
| 2 | **인지 흐름 자연스러움** — "QR 스탬프 다 봤다 → 다른 옵션도 있구나" 자연 전환 |
| 3 | **위계 명확** — 위쪽 = 메인(QR 스탬프), 아래쪽 = 보조(샵플랜) 시그널 |
| 4 | **상담 진입 직전 노출** — 결정 직전에 "둘 다 가능"을 보여줘 크로스셀 기회 확보 |

### 검토 후 탈락한 후보

| 후보 위치       | 탈락 이유            |
| ----------- | ---------------- |
| Hero 직후     | "메인 제품이 뭐지?" 혼란  |
| QR 플랜 안내 직전 | 플랜 검토 흐름 단절      |
| 페이지 맨 하단    | 스크롤 도달률 낮아 클릭 손실 |

## 5. 후속 검토 항목

### 5-1. 카피 톤 결정 필요
3개 헤드라인 후보 중 어느 톤이 적합한지 — **사용자(QR스탬프 운영진)와 협의** 필요.

### 5-2. 크로스셀 메시지 강도
- 강하게: "참여는 QR스탬프, 결제는 샵플랜" (두 제품 직접 연결)
- 부드럽게: "결제도 필요하시다면" (선택지로 제시)

### 5-3. 진입 섹션의 정보 깊이
- 현재 안: 3가지 가치 청크만
- 대안: 가격대 / 사용 사례 / 신뢰 지표 일부 노출 → 길이 증가

### 5-4. 향후 메인 승격 가능성
샵플랜이 성장 제품으로 전략적 우선순위가 된다면, 위치 ③(보조) → 위치 ②(QR 플랜 직전, 동등 노출) 승격 검토.
