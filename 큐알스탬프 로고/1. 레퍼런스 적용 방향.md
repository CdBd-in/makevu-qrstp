# 🔖 1. 로고 레퍼런스 적용 방향 — QRSTAMP / 큐알스탬프

> Figma 섹션 **「로고 레퍼런스」**(`9238:497`)에 모은 레퍼런스 6장을 **로고의 어디에, 어떻게 쓸지** 정리한 문서다. 시안 제작 **전에** 이 문서로 방향을 먼저 맞춘다.
> 🎨 **같은 내용의 Figma 프레임** = 「로고」 페이지 **「큐알스탬프 로고 레퍼런스 적용 방향 (2026-10-19)」**(`9241:2`, 레퍼런스 섹션 오른쪽). 한쪽을 고치면 다른 쪽도 같이 고친다.
> 색·서체·점선 계승은 같은 페이지의 리서치 프레임 「큐알스탬프 리브랜딩 리서치 (2026-10-15)」(`9200:15000`)를 따른다.

## 0. 만들 로고

| 구분 | 표기 | 구조 |
|---|---|---|
| **영문** | `QRSTAMP` | `QR` + `STAMP` — 7자, 대문자 |
| **국문** | `큐알스탬프` | `큐알` + `스탬프` — 5음절 |

- 두 이름 모두 **「QR(인증 기술)」 + 「STAMP(모으는 경험)」 두 단어가 붙은 합성어**다. 로고가 할 일도 이 두 의미를 **한 덩어리로 묶는 것**이다.
- **서비스 핵심**: 종이 스탬프를 대체하는 **QR 방문 인증 → 스탬프 적립 → 리워드**(→ [[큐알스탬프 솔루션/0. 정의.md]]).
- 따라서 로고의 키워드 = **① QR(사각 모듈·스캔) ② 도장(원·잉크·찍힘) ③ 완료/인증(체크) ④ 투어(동선·여러 곳 방문) ⑤ 점선(메이크뷰 로고의 점선 프레임 계승 → 스탬프 칸 점선 · 스캔 프레임, 리서치 결론)**.

## 1. 레퍼런스별로 가져올 것 / 버릴 것

> 🔑 레퍼런스는 **형태를 베끼지 않고 원리만 가져온다.** 아래 「가져올 것」은 원리, 「적용」은 그 원리를 QRSTAMP에 옮긴 모습이다.

### ① QLINK — 모듈 조합 심볼 + 음각 체크

![[큐알스탬프 로고/attachments/logo-ref-1-qlink.png]]

| | 내용 |
|---|---|
| **특징** | 원 4개를 잘라 정사각형으로 모은 심볼 · 가운데 **빈 공간(음각)이 체크(✓)** 모양 · Q의 꼬리를 길게 뺀 기하학 산세리프 |
| **가져올 것** | **같은 도형을 반복·조합해 하나의 심볼**을 만드는 방식 · **음각(네거티브 스페이스)으로 두 번째 의미**를 숨기는 방식 |
| **적용** | **심볼** — QR 모서리의 **파인더 패턴(□ 3개)**을 **원(도장)** 모양으로 바꿔 조합하고, 비어 있는 네 번째 칸이나 가운데 음각에 **체크 = 「인증 완료」**를 넣는다. **영문** — `QRSTAMP`의 `Q` 꼬리 처리에 참고 |
| **버릴 것** | 원 4개를 정사각형으로 모은 구도 그대로 쓰기(QLINK와 같아 보임) |

### ② 구미래 OLD FUTURE — 직선 분절 한글 + 국·영 조합 + 괄호 프레임

![[큐알스탬프 로고/attachments/logo-ref-2-oldfuture.png]]

| | 내용 |
|---|---|
| **특징** | 직선 획을 **끊어서(스텐실 컷)** 만든 한글 · 큰 한글 옆에 영문 2줄 + 자간 넓힌 소문구 · 양끝을 감싸는 **대괄호 `[ ]`** |
| **가져올 것** | **획 사이의 끊김**(고무도장·스텐실 느낌) · **국문 크게 + 영문 작게 쌓는 이중 언어 조합** · **양끝 프레임** |
| **적용** | **국문** — `큐알스탬프`를 직선 모듈로 짜고 획 이음부를 끊어 **도장을 찍은 듯한 틈**을 만든다. **조합형** — `큐알스탬프` 옆에 `QRSTAMP`를 작게 붙이는 국·영 병기 버전. **프레임** — 대괄호를 **QR 스캔 화면의 모서리 가이드 `⌜ ⌟`**로 바꿔 「스캔한다」는 행동을 보여준다 |
| **버릴 것** | 레트로·플리마켓 분위기 · 지나치게 좁은 자폭(작은 크기에서 뭉개짐) |

### ③ 미쳤대도 여자야구 — 블록 한글 + 잉크 질감 + 글자 속 상징

![[큐알스탬프 로고/attachments/logo-ref-3-womens-baseball.png]]

| | 내용 |
|---|---|
| **특징** | 굵은 블록 한글 2줄 쌓기 · 전체에 **잉크·그런지 질감** · `ㅇ` 하나를 **야구공 실밥**으로 바꿔 주제를 심음 |
| **가져올 것** | **자모 하나를 상징으로 치환** · **찍힌 잉크 질감** · **2줄 쌓기(정방형 덩어리)** |
| **적용** | **국문** — `큐알스탬프`에서 유일한 원형 자모인 **`알`의 `ㅇ`을 도장(원) 또는 QR 파인더 패턴으로 치환**한다. **세로형** — `큐알 / 스탬프` 2줄 쌓기 버전. **질감** — 서비스 스탬프 화면에 쓰는 **그런지 브러시**(→ [[큐알스탬프 솔루션/2. 작업 가이드/2-1. 페이지 구조/2-1-3. 스탬프.md]] §2-6 ①)와 같은 질감을 **캠페인·굿즈용 변형**에만 입힌다 |
| **버릴 것** | 질감을 **기본 로고에 넣는 것** — 작은 크기·인쇄·QR 중앙 삽입에서 깨진다. 기본 로고는 **단색 면**으로 |

### ④ qrcollie — 2톤 워드마크 + QR 픽셀 심볼

![[큐알스탬프 로고/attachments/logo-ref-4-qrcollie.png]]

| | 내용 |
|---|---|
| **특징** | `qr`은 회색, `collie`는 검정 — **합성어를 색으로 나눔** · 심볼은 **QR 모듈(정사각 픽셀)**로 그린 개 |
| **가져올 것** | **합성어 경계를 색(명도)으로 구분** · **QR 모듈 단위로만 그리는 픽셀 심볼** |
| **적용** | **영문** — `QR` / `STAMP`를 **명도나 색으로 나눠** 두 단어가 바로 읽히게 한다(국문은 `큐알` / `스탬프`). **심볼** — QR 모듈 격자 위에서만 그려 **도장·체크·핀**을 표현(파비콘·앱 아이콘에 강함) |
| **버릴 것** | 소문자 표기(`QRSTAMP` 대문자로 확정) · 실제 QR처럼 보이는 무작위 모듈(**스캔되는 코드로 오인**) |

### ⑤ spinefold — 얇은 선 심볼 + 단 하나의 채운 점

![[큐알스탬프 로고/attachments/logo-ref-5-spinefold.png]]

| | 내용 |
|---|---|
| **특징** | 세리프 워드마크 · 아주 얇은 선으로 그린 행성 궤도 + **채운 마름모 하나**만 강조 · 워드마크와 심볼을 **떼어 써도 각각 완결** |
| **가져올 것** | **선(외곽선) 위에 채운 점 하나** = 시선이 한 곳에 꽂히는 대비 · **심볼·워드마크 분리 사용 체계** |
| **적용** | **심볼 보조안** — **점선(메이크뷰에서 계승한 스탬프 칸 점선)**으로 그린 **동선(투어 경로)** 위에 채운 점 하나 = **「지금 찍은 한 곳」**. **체계** — 심볼 단독 / 워드마크 단독 / 조합형을 모두 완결되게 설계 |
| **버릴 것** | 세리프·헤어라인 굵기 — 모바일 소형 표시에서 사라진다. 선은 **작은 크기에서도 보이는 굵기**로 |

### ⑥ HACHI HACHI — 원형 엠블럼 + 좌우 대칭 조합 + 태그라인

![[큐알스탬프 로고/attachments/logo-ref-6-hachihachi.png]]

| | 내용 |
|---|---|
| **특징** | **원형 엠블럼** 안에 두 의미(벌 + 국수 그릇)를 **한 선으로 합친** 라인 아이콘 · 엠블럼 좌우에 자간 넓은 워드마크 · 아래에 태그라인 · 단색 + 어두운 배경 |
| **가져올 것** | **원형 테두리 = 도장 인면(印面)** · **두 상징을 하나의 선으로 합치기** · **태그라인 자리** · **어두운 배경용 단색 버전** |
| **적용** | **심볼** — 원형(점선) 도장 테두리 안에 **QR 파인더 + 체크**를 한 선으로 합친다. 리서치 추천 「점선 원 스탬프 칸」과 같은 계열. **엠블럼형 조합** — 원형 심볼 + `QRSTAMP` + 태그라인(예: `MOBILE STAMP TOUR`) — 현장 배너·굿즈·스티커용. **색** — 단색 1도로도 완결 → 어두운 배경은 **흰색 녹아웃**(볼트 상시 규칙) |
| **버릴 것** | 좌우 대칭 분할(`HACHI ◯ HACHI`) — `QRSTAMP`는 반복 단어가 아니라 그대로 쓰면 어색 |

| 로고 요소 | 주 레퍼런스 | 적용 한 줄 |

| **심볼 형태** | ① QLINK · ④ qrcollie · ⑥ HACHI | QR 파인더 패턴 + 원(도장) 조합 · 음각 체크 · 모듈 격자 기반 |
| **심볼 의미** | ①(체크) · ⑤(점 하나) · ⑥(두 의미 합치기) | **QR + 도장 + 인증 완료**를 한 형태에 |
| **영문 워드마크 `QRSTAMP`** | ① QLINK · ④ qrcollie | 기하학 산세리프 대문자 · `Q` 꼬리 처리 · `QR`/`STAMP` 2톤 |
| **국문 워드마크 `큐알스탬프`** | ② 구미래 · ③ 여자야구 | 직선 모듈 한글 · 획 끊김(도장 틈) · `알`의 `ㅇ` 치환 |

| **프레임** | ② 구미래 | 대괄호 → **QR 스캔 모서리 `⌜ ⌟`** (선택 요소) |
| **질감** | ③ 여자야구 | 잉크 그런지 = **캠페인·굿즈용 변형만** · 기본 로고 ❌ |
| **색** | ④ qrcollie · ⑥ HACHI | 단색 1도로 완결 + 2톤 구분 · 사이트 팔레트(퍼플 `#AE1FFF` · 그린 `#00F392`) · 어두운 배경 흰색 녹아웃 |

## 3. 시안 방향 3가지 (레퍼런스 조합)

> 시안은 아래 3방향으로 **각 1안씩** 먼저 그려 비교한다. 어느 방향이든 리서치 추천인 **「점선 원(스탬프 칸)」**을 심볼에 얹을 수 있다.

| 방향 | 조합 | 심볼 | 영문 `QRSTAMP` | 국문 `큐알스탬프` | 인상 |
|---|---|---|---|---|---|
| **A. 모듈 심볼형** | ① + ④ | QR 파인더 □ 3개를 원으로 바꾸고 빈 칸에 음각 체크 | 기하학 산세리프 · `QR` 회색/포인트색 + `STAMP` 검정 | 산세리프 모듈 한글 | 깔끔·테크·확장 쉬움 |
| **B. 도장 레터링형** | ② + ③ | 심볼 없이 글자 자체가 로고 (`알`의 `ㅇ` = 도장) | 스텐실 컷 대문자 | **직선 분절 + 획 끊김** · 2줄 쌓기 가능 | 찍는 손맛·이벤트 현장감 |
| **C. 엠블럼형** | ⑥ + ⑤ | 원형 도장 테두리 안에 QR + 체크(또는 동선 + 점 하나)를 한 선으로 | 자간 넓은 대문자 + 태그라인 | 엠블럼 하단 병기 | 공식 인증 마크·굿즈 친화 |
