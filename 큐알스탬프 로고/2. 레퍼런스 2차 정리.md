# 🔖 2. 로고 레퍼런스 2차 정리 — 심볼 · 워드마크

> Figma 「로고 레퍼런스」 섹션(`9333:2441`)의 **36장**을 **표현 원리 5갈래**로 묶고, 지금 시안에 어디에 쓸지 정리했다.
> 지금 시안 = [[큐알스탬프 로고/1. 레퍼런스 적용 방향.md]] 이후 만든 Figma 「큐알스탬프 로고 제안 2」(`9282:3`)의 **A 도장 국문 · B 찍힌 칸(QRSTAMP + 원 엠블럼) · C 이어지는 칸(QRSTAMP) · 파비콘**.
> 🔑 레퍼런스는 **형태를 베끼지 않고 원리만 가져온다.** Square · norton · asana · TIDAL · android 등은 실제 상표라 비슷하게 그리면 안 된다.
> 이름이 없는 심볼(아래쪽 작은 이미지)은 「출처 미표기」로 적었다.

## ① 사각 · 프레임 — 칸 · QR 모서리

![[큐알스탬프 로고/attachments/logo-ref2-1-frame.png]]

> 순서: 위 줄 Square · Extensis · Reform Collective · Quixel · 끊긴 사각 프레임(출처 미표기) / 아래 줄 LUDWIG ARAUJO · KILO

| 레퍼런스 | 특징 | 가져올 것 | 어디에 |
|---|---|---|---|
| **Square** | 둥근 사각 테두리 안에 작은 사각 하나 | 「칸 안에 찍힌 것 하나」 — QR 위치 표시 사각형(□ 안 ■)과 같은 구조 | 파비콘 · B안 칸 하나만 떼어 쓰는 심볼 |
| **Extensis** | 사각 안을 꺾인 선으로 나눠 미로처럼 | 사각 프레임 안에서 선이 이어지는 길 | C안(이어지는 칸)의 심볼 버전 |
| **Reform Collective** | 사각 칸 반쪽만 채움 + 굵은 와이드 글자 | 칸을 「반만 채운」 상태 = 진행 중 | B안 색 변형(일부 칸만 채우기)의 근거 |
| **Quixel** | Q를 접힌 육각 면으로 | Q 한 글자를 심볼로 | Q 파비콘을 다시 그릴 때 |
| **끊긴 사각 프레임** (출처 미표기) | 굵은 사각 테두리를 4조각으로 끊음 | 끊긴 모서리 = **QR 스캔 모서리 + 열린 선** | **C안 파비콘**과 가장 가까움 — 굵기 · 끊는 위치 비교용 |
| **LUDWIG ARAUJO** | L 블록 + 작은 사각 + 2줄 condensed 글자 | 블록 심볼과 좁은 대문자 워드마크의 무게 맞춤 | B안(condensed QRSTAMP) 옆에 심볼을 둘 때 |
| **KILO** | 사각 테두리 안에 픽셀 글자 2×2 | **칸 안에 글자를 넣은 스탬프 판** | B · C안의 세로형 · 정사각형 버전(QR / ST / AMP를 칸에) |

## ② 픽셀 · 모듈 — QR 연상

![[큐알스탬프 로고/attachments/logo-ref2-2-module.png]]

> 순서: 위 줄 Prove · Hudson · Flecto · neara · TIDAL / 아래 줄 픽셀 N · 픽셀 Q · 모듈 체크 · 체커 패턴 · 점 연결 패턴 (아래 줄 모두 출처 미표기)

| 레퍼런스 | 특징 | 가져올 것 | 어디에 |
|---|---|---|---|
| **Prove** | 점 3×3 격자(한 점 빠짐) | 점 격자 = QR 모듈 · 빠진 점 하나가 포인트 | 「모으는 중」(찍힌 점 / 빈 점) 표현 |
| **Hudson** | 막대 모듈로 십자(+) | 같은 모듈 반복으로 심볼 | — (의료 · 십자 연상 주의) |
| **Flecto** | 블록이 계단처럼 이어진 F | 모듈이 이어져 한 글자가 됨 | C안 「이어짐」을 모듈로 표현할 때 |
| **neara** | 사각 안에 N을 사선으로 깎음 | 칸을 깎아 글자를 만드는 방식 | B안 칸 안 글자(뚫린 글자)와 같은 원리 |
| **TIDAL** | 다이아몬드 4개 + 넓은 자간 워드마크 | 작은 심볼 + 자간 넓은 대문자 | C안 워드마크 자간 참고 |
| **픽셀 N** | 픽셀 블록으로 그린 N | 모듈 단위 글자 | — |
| **픽셀 Q** | 정사각 모듈로 그린 **Q** | **QR 모듈로 그린 Q** — 바로 QR이 떠오름 | **파비콘 후보**(Q 한 글자) |
| **모듈 체크** | 사각 모듈 계단으로 ✓ | 모듈 = QR, ✓ = 인증 완료 | 파비콘 · 적립 완료 아이콘 |
| **체커 패턴** | 흑백 체크무늬를 원형으로 | 모듈이 모여 하나의 도장 모양 | 굿즈 · 패턴 그래픽 |
| **점 연결 패턴** | 점들이 이어져 꽃 모양 | 점(스탬프)이 이어져 하나가 됨 | C안 「이어짐」 그래픽 |

> ⚠ 실제 QR 코드처럼 무작위로 모듈을 흩뿌리면 **스캔되는 코드로 오인**된다 → 위 레퍼런스처럼 **규칙 있는 모듈**만 쓴다.

## 7. 공통 원리 — 36장에서 반복되는 것

1. **심볼 하나 + 산세리프 워드마크** — 심볼은 정사각 안에서 완결되고, 워드마크와 높이 · 굵기를 맞춘다.
2. **단색 워드마크 + 포인트 하나** — 색은 심볼이나 글자 한 곳에만(stc · android · neara). 지금 시안의 「QR만 그린」과 같은 방향.
3. **같은 단위의 반복** — 모듈 · 점 · 칸을 반복해 심볼을 만든다(Prove · Flecto · 픽셀 Q). 큐알스탬프의 「칸 = 스탬프」와 잘 맞는다.
4. **비움으로 의미 만들기** — 끊긴 틈 · 빠진 점 · 반만 채운 칸이 두 번째 의미를 만든다(끊긴 프레임 · Prove · Reform).

## 8. 다음 단계

1. 후보별 1순위 레퍼런스로 **정사각 · 세로형 버전**(특히 B안 KILO형)과 **심볼 단독**을 그려 본다.
2. 파비콘은 「끊긴 사각 프레임」 · 「픽셀 Q」 · 「MUSEU(칸 안 원)」를 기존 A · C안 파비콘과 나란히 비교한다.
3. 결과는 Figma 「큐알스탬프 로고 제안 2」(`9282:3`)에 반영하고 이 문서에 기록한다.
