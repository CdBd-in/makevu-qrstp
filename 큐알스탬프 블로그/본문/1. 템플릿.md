## 3. 유형 선택 기준
- **한 문장 강조** → ① 핵심 메시지
- **숫자/성과** → ② 수치 강조
- **순서·방법** → ③ 단계/프로세스
- **선택지 비교** → ④ 비교표
- **시간에 따른 변화** → ⑤ 타임라인
- **개념·순환 관계** → ⑥ 개념도/순환도
- **팁·요약 리스트** → ⑦ 체크리스트
- **실제 제품 화면** → ⑧ 앱 목업(코드/생성 ❌ · 실제 캡처 삽입)

## 4. 작업 규칙
- **유형 프레임을 복제** → 텍스트만 교체(폰트·크기·행간·자간 유지). **원본 `본문템플릿_*` 수정 ❌.**
- **④ 비교표**: 강조 열(파란 테두리·틴트)은 **자사(QR)용** — 강조 위치 유지.
- **⑧ 앱 목업 규칙** (2가지)
  1. **이미지 삽입 위치 고정** — 캡처한 **QR 스탬프 화면 이미지는 폰 목업의 화면 슬롯 프레임에 넣어서** 만든다(임의 위치·크기로 얹기 ❌ · 코드/생성 ❌, 실제 화면 캡처만).
     - 슬롯: **`목업1개` = `Frame 8`(`2689:13`)** · **`목업2개` = `Frame 8`(`2687:229`) + `Frame 9`(`2687:230`)**.
  2. **1개용 / 2개용 상황 선택** — 목업 템플릿 2종(각 **1000×1000**): **`목업1개`(`2689:10`)** · **`목업2개`(`2681:27`)**. 보여줄 화면 수에 맞춰 **상황 보면서 골라 사용**한다.
- 텍스트 길이 다르면 **폰트 크기·줄바꿈 자동 맞춤 → 스크린샷 검수**(1~2회).

## 5. 참고 — 넓은 폭(16:10) 활용
> 1920×1200은 기존 4:3보다 가로가 넓다. **좌정렬 유형(③·④·⑦)**은 우측 여백이 생길 수 있으니, 필요 시 **우측에 비주얼/2열 배치**로 채운다(선택).

## 6. Export·배치
- **PNG export**(1920×1200, 레티나면 2x) · 파일명 `qrstp_NN_slug.png`(본문 순서).
- **Wix**: `UploadImageToWixSite` → 본문 해당 위치 `IMAGE` 노드 · **한국어 alt 필수**.
