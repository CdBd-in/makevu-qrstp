# 🖼 본문 템플릿 가이드

> 블로그 **본문에 삽입하는 이미지**. **5대분류 → 세부유형** 체계로 정리돼 있고, 콘텐츠 형태에 맞는 세부유형을 **복제해 텍스트만 교체**한다.

## 1. 위치·규격

| 항목 | 값 |
|---|---|
| 파일 | `kmX87Vd85aCYKYrIp9jsC2` |
| 템플릿 페이지 | `AI 블로그 이미지 템플릿` (`2672:39`) → 섹션 `템플릿`(`2687:233`) |

| 폰트·배경 | Pretendard · **배경 `#F6F6F6`**(라이트) |
| 브랜드 색 | 액센트 `#5AA2F2`·`#FDAD13`·`#A994E6` + 보조 그린 `#349869` · 본문 `#161717` · 서브 `#6C7585` |

## 2. 유형 체계 (5대분류 → 세부유형)

> 템플릿 페이지에 **`H5` 대분류 헤더** + **`#세부유형` 헤더**로 분류돼 있다. 세부유형은 계속 추가될 수 있다.

| 대분류 | 세부유형 | 프레임(노드) | 크기 | 언제 쓰나 |
|---|---|---|---|---|
| **① 기본** | `#핵심메시지` | `본문템플릿_핵심메시지` (`2676:6`) | 1920×1200 | 섹션의 한 문장 강조 |
| | `#핵심메시지+목업` | `본문템플릿_핵심메시지+목업` (`2720:169`) | 1920×1200 | 한 문장 강조 + **제품 화면(목업)** 나란히 |
| **② 강조** | `#수치강조` | `본문템플릿_수치강조` (`2676:11`) | 1920×1200 | 큰 숫자 임팩트("2,000명") |
| **③ 비교** | `#비교표` | `본문템플릿_비교표` (`2678:6`) | 1920×1200 | A vs B vs C 대조(각 열 **3D 아이콘 + 항목 3줄**, 카드형) |
| | `#비교매트릭스` ⏳ | (신규 · 3편 인스턴스 `2722:5` 참조) | 1920×가변 | **다항목(행) × 3방식(열)** 정면 표 · **승자 열 틴트 강조**. 카드형으로 담기엔 항목이 많을 때 |
| **④ 나열** | `#목업` | `목업1개`(`2689:10`) / `목업2개`(`2681:27`) | 1000×1000 | 제품 화면 예시 |
| | `#체크리스트` | `본문템플릿_체크리스트` (`2681:6`) | 1920×1141 | "3가지 조언" 등 항목 정리 |
| **⑤ 프로세스** | `#단계프로세스` | `본문템플릿_단계프로세스` (`2677:6`) | 1920×1402 | 순서·방법(화살표 연결 단계) |
| | `#타임라인` | `본문템플릿_타임라인` (`2679:6`) | 1920×1200 | 시간축 변화(연도+이미지) |
| | `#개념도순환도` | `본문템플릿_개념도순환도` (`2680:6`) | 1920×1200 | 관계·순환 |

> ⏳ **세부유형 확장 예정** — 각 대분류 안에서 세부유형이 더 쪼개질 수 있다. 새 세부유형이 추가되면 이 표에 `#유형명`·노드ID·용도를 덧붙인다.

### 2-1. 세부유형별 구성 요소 (교체 포인트)

| 세부유형 | 구성 | 교체 요소 |
|---|---|---|
| `#핵심메시지` | KEY POINT 라벨 · 큰 문장 · 강조 바 | 라벨 · 문장 |
| `#핵심메시지+목업` | 좌: KEY POINT 라벨 + 큰 문장 · 우: **폰 목업**(`Frame 8` `2720:178` > 슬롯 `Frame 10` `2720:179`) | 라벨 · 문장 · **`Frame 10`에 화면 캡처** |
| `#수치강조` | 상단 라벨 · 큰 숫자+단위 · 캡션 | 라벨 · 숫자·단위 · 캡션 |
| `#비교표` | 3열(각 **3D 아이콘 200×200 + 제목 + 항목 3줄**) | 제목 · 열 아이콘·제목·항목 |
| `#비교매트릭스` | 제목 · 헤더행(항목·3방식) · **그룹헤더** · N행(항목 + 방식별 셀) · **QR/승자 열 틴트+볼드 강조** | 제목 · 항목명 · 셀 값 |
| `#목업` | 폰 목업(1개/2개) | **각 폰 안 `Frame 10`에 화면 캡처** |
| `#체크리스트` | 제목 · ✓ 항목(제목+설명) × N | 제목 · 항목 제목·설명 |
| `#단계프로세스` | 제목 · 단계(제목+설명) + **화살표 연결** | 제목 · 단계 제목·설명 |
| `#타임라인` | 제목 + **서브타이틀** · 연도 노드 3 + **연도별 3D 아이콘 200×200** | 제목·서브 · 연도 · 라벨 · 연도 아이콘(thiings) |
| `#개념도순환도` | 제목 · 4노드 + 중앙 라벨 + 화살표 | 제목 · 노드 라벨 · 중앙 라벨 |

## 3. 유형 선택 기준
- **한 문장 강조** → ① 기본 `#핵심메시지`
- **한 문장 + 제품 화면** → ① 기본 `#핵심메시지+목업`
- **숫자/성과** → ② 강조 `#수치강조`
- **핵심 3가지 카드 비교**(아이콘+요점) → ③ 비교 `#비교표`
- **다항목 표 비교**(행 5개 이상 · 비용·참여·데이터 등) → ③ 비교 `#비교매트릭스`
- **제품 화면** → ④ 나열 `#목업`
- **팁·요약 리스트** → ④ 나열 `#체크리스트`
- **순서·방법** → ⑤ 프로세스 `#단계프로세스`
- **시간 변화** → ⑤ 프로세스 `#타임라인`
- **개념·순환 관계** → ⑤ 프로세스 `#개념도순환도`

## 4. 작업 규칙
- **제작 위치** — 이미지는 「**AI 블로그 이미지 제작**」 페이지(`2697:7`)에 **글 제목으로 섹션을 만들어** 그 안에 넣는다(썸네일+본문 한 섹션). 템플릿 원본 페이지(`2672:39`)에서는 **복제만**.
- **세부유형 프레임을 복제** → 텍스트만 교체(폰트·크기·행간·자간 유지). **원본 `본문템플릿_*` 수정 ❌.**
- **③ 비교**: 각 열 상단 **3D 아이콘(200×200)** + 제목 + 항목 3줄. 열 순서·강조는 원본 따름.
- **⑤ 타임라인**: 제목/서브 + 연도 노드 + **연도별 3D 아이콘 슬롯(200×200)**.
- **🎨 3D 아이콘 소스 규칙** (타임라인·비교표 등 아이콘 슬롯 공통)
  - **[thiings.co](https://www.thiings.co)에서 해당 내용을 영어로 검색 → PNG 다운로드 → 슬롯에 삽입**한다.
  - 예) 종이 스탬프 → `paper` / `notebook` · 종이+앱 → `laptop` · QR → `qr code`.
  - 슬롯에 삽입 시 `FILL`(또는 원본 슬롯 설정) 유지 · 내용과 무관한 임의 아이콘 ❌. (3D 아이콘 정의 → [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-4. 이미지.md]])
- **⑧ 목업 규칙** (2가지)
  1. **이미지 삽입 위치 = `Frame 10`** — 캡처한 **QR 스탬프 화면 이미지는 각 폰 안의 `Frame 10`(화면 슬롯)에 넣어서** 만든다(임의 위치·크기 ❌ · 코드/생성 ❌, 실제 캡처만).
     - 구조: `폰(Frame 8)` > **`Frame 10`(화면=이미지 슬롯)**. `Frame 8`(폰 프레임 그래픽)은 건드리지 않는다.
     - **목업1개** = `Frame 10` 1개 · **목업2개** = 좌우 폰 각각 안에 `Frame 10` → 2개.
  2. **1개용 / 2개용 상황 선택** — 보여줄 화면 수에 맞춰 `목업1개`/`목업2개` 중 골라 사용.
- 텍스트 길이 다르면 **폰트 크기·줄바꿈 자동 맞춤 → 스크린샷 검수**(1~2회).
