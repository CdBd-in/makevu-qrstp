# 🖼 블로그 이미지 제작 가이드

> qrstp.com 블로그 글에 들어가는 이미지를 **매번 같은 품질·같은 브랜드로 찍어내기 위한 규격 문서**. 손으로 그리지 않고 **HTML/CSS 템플릿 → 헤드리스 렌더 → PNG → Wix 업로드** 파이프라인으로 생산한다.
> 근거: 실제 발행글 「QR 스탬프투어 트렌드와 앞으로의 방향」(개념 총정리 시리즈 5편)의 이미지 5종을 역분석해 규격·색상을 추출.

> [!note] 브랜드 층위
> 이 이미지들은 **MAKEVU(메이크뷰) 코퍼레이트/블로그 브랜드**를 쓴다. 이벤트 페이지의 **이벤트별 메인 컬러 스킨**(→ [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]])과는 **다른 팔레트**다. 폰트만 공통(**Pretendard**).

## 1. 이미지 3유형 (역할·규격)

| 유형 | 규격(px) | 비율 | 용도 | 제작 방식 |
|---|---|---|---|---|
| **① 커버(히어로)** | **1200 × 630** | 1.91:1 | 글 최상단 + **OG/트위터 카드**(featured) | HTML/CSS 렌더 |
| **② 인포그래픽** | **1200 × 1200** | 1:1 | 본문 중간 개념도·타임라인·순환도 | HTML/CSS 렌더 |
| **③ 앱 목업(제품 화면)** | **가변**(예 393 × 858) | 폰 비율 | 큐알스탬프 실제 화면 예시 | **제품 스크린샷/Figma export** (코드 렌더 ❌) |

- **커버는 항상 1장 · OG 이미지 겸용**(글의 `og:image`·`twitter:image`로 지정).
- **인포그래픽은 섹션당 0~1장** — 개념을 그림으로 요약할 수 있을 때만. 텍스트 반복 금지.
- **앱 목업**은 코드로 만들지 않는다. 실제 이벤트 페이지(Figma 시안 또는 배포 화면)를 캡처해 **폰 비율 그대로** 넣는다.

## 2. 브랜드 토큰 (실측값)

> 발행 이미지에서 픽셀 샘플링으로 추출한 **실제 사용값**. 이 표가 블로그 이미지 색의 단일 출처.

### 2-1. 컬러

| 토큰 | HEX | 용도 |
|---|---|---|
| **커버 배경(다크)** | `#0D1E2B` → `#0D2E3A` (세로 그라데이션) | 히어로 배경. 볼트 다크 토큰 `#0E1A2B`과 동계열 |
| **시안 액센트** ⭐ | `#00BFD3` | MAKEVU 포인트색 · 로고 "VU" · 강조 라인·배지·번호칩 |
| **본문 텍스트(다크)** | `#171C26` | 인포그래픽 제목·본문 |
| **서브 텍스트(그레이)** | `#6C7585` | 부제·캡션·푸터 |
| **헤어라인/보더** | `#DEE3EA` | 카드 외곽선·구분선 |
| **뉴트럴 배경 틴트** | `#FAFBFD` | 카드 옅은 바탕 |
| **시안 배경 틴트** | `#F0FDFF` | 강조 카드 바탕 |
| **웜 배경 틴트** | `#FDF7F0` | 보조 카드 바탕 |
| **카테고리 · 오렌지** | `#DA8A27` | 분류/단계 색 2 |
| **카테고리 · 그린** | `#349869` | 분류/단계 색 3 |

- **커버 = 다크 / 인포그래픽 = 라이트**. 두 무드를 섞지 않는다.
- 카테고리 3색(**시안 `#00BFD3` · 오렌지 `#DA8A27` · 그린 `#349869`**)은 **타임라인/순환도에서 항목을 구분**할 때만. 남발 금지.

### 2-2. 타이포 (Pretendard 고정)

| 역할 | 폰트 · 크기(1200 캔버스 기준) | 색 |
|---|---|---|
| 커버 타이틀 | Pretendard **Bold ~64px** · 2줄 이내 · leading 1.2 | `#FFFFFF` |
| 커버 서브 | Pretendard **Medium ~24px** | `#FFFFFF` 80% 또는 시안 |
| 커버 배지(우상단) | Pretendard **SemiBold ~18px** | `#FFFFFF`/그레이 |
| 인포 타이틀 | Pretendard **Bold ~40px** | `#171C26` |
| 인포 서브 | Pretendard **Medium ~20px** | `#6C7585` |
| 카드 제목 | Pretendard **Bold ~24px** | `#171C26` |
| 카드 본문 | Pretendard **Medium ~18px** | `#6C7585` |
| 푸터 | Pretendard **Medium ~18px** | `#6C7585` |

> **본문·UI는 Pretendard 고정** (→ [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-2. 폰트.md]]). 영문 로고 "MAKEVU"만 브랜드 자산.

## 3. 레이아웃 해부

### 3-1. 커버(히어로) — 1200×630

```
┌────────────────────────────────────────────┐
│ [MAKEVU 로고]            개념·총정리 시리즈 · N편 · 완결 │  ← 상단 바 (좌 로고 / 우 배지)
│                                            │
│        (다크 네이비 + QR 그리드 점 패턴 배경)      │
│                                            │
│  타이틀 (Bold 64 · 2줄)                      │  ← 좌하단 정렬
│  서브텍스트 (Medium 24)                      │
└────────────────────────────────────────────┘
```
- **좌우 패딩 64** · 하단 타이틀 블록은 **좌하단 앵커**.
- **로고**: 점선 대괄호 `[ ]` + `MAKE`(흰색) + `VU`(시안 `#00BFD3`).
- **배경 패턴**: 다크 네이비 세로 그라데이션 위 **아주 낮은 대비의 QR 그리드**(작은 사각 + 세로 헤어라인). 텍스트 가독성 우선 — 패턴은 우측/가장자리로.
- **배지**(우상단): `개념·총정리 시리즈 · 5편 · 완결` 형식.

### 3-2. 인포그래픽 — 1200×1200

```
┌────────────────────────────────────────────┐
│ 타이틀 (Bold 40)                             │  ← 좌상단
│ 서브 (Medium 20)                             │
│                                            │
│            [다이어그램: 타임라인 / 순환도]         │  ← 중앙
│            (카드 + 번호칩 + 커넥터)              │
│                                            │
│ ──────────────────────────────────────     │  ← 헤어라인
│ 큐알스탬프 · 개념 총정리 시리즈 N편              │  ← 푸터(좌)
└────────────────────────────────────────────┘
```
- **흰 배경** · 패딩 ~56–64.
- **카드**: radius ~16 · 1px `#DEE3EA` 보더(또는 카테고리색 보더) · 제목 Bold + 본문 그레이.
- **번호칩**: 카테고리색 채운 원 + 흰 숫자(①②③④).
- **커넥터**: 타임라인 = 가로 라인 + 노드 원 / 순환도 = 원형 배치 + 시안 삼각 화살표.
- **푸터**: 헤어라인 위 `큐알스탬프 · 개념 총정리 시리즈 N편` (그레이).

### 3-3. 앱 목업
- 실제 제품 화면을 **폰 비율 그대로**. 별도 프레임/그림자 없이 화면 자체를 넣거나, 필요 시 옅은 라운드만.

## 4. 제작 파이프라인

> **HTML/CSS 1장 = 이미지 1장.** 자체 완결 HTML을 헤드리스 브라우저로 정확한 px에 렌더한다.

1. **HTML/CSS 작성** — §5 템플릿 복제. 캔버스 크기 고정(`width/height`), Pretendard 웹폰트 로드, §2 토큰 인라인.
2. **헤드리스 렌더 → PNG 캡처**
   - 뷰포트 = 캔버스 크기(1200×630 또는 1200×1200), **`deviceScaleFactor: 2`**(레티나 선명도 → 실제 파일은 2400×1260 등으로 나오면 1200 규격으로 다운스케일하거나 그대로 업로드).
   - 요소 스크린샷(`clip`)으로 **여백 없이** 캔버스만.
   - 도구: 프로젝트 헤드리스 브라우저(`/browse`·`connect-chrome`) 또는 임의 Chromium 스크린샷.
3. **파일명 규칙** (아래 §6) 로 저장.
4. **Wix 업로드** — `UploadImageToWixSite`(Wix MCP)로 사이트 미디어에 올려 **media id** 획득.
5. **배치**
   - 본문: 해당 위치에 `IMAGE` 노드로 삽입(리치 콘텐츠).
   - 커버: **글 featured 이미지 + `og:image`/`twitter:image`** 로 지정.
6. **alt 텍스트 필수 작성**(§7).

## 6. 파일명 규칙

```
qrstp_NN_slug.png
```
- `NN` = 글 내 등장 순서(2자리, `00`=커버). 예) `qrstp_00_hero.png` · `qrstp_01_timeline.png` · `qrstp_02_datacycle.png`.
- `slug` = 내용 요약 영문 소문자.
- 커버는 항상 `00_hero`.

## 7. alt 텍스트 · SEO 규칙 (필수)

- **모든 이미지에 한국어 alt** 작성. "이미지1" 같은 무의미값 ❌.
- alt = **이미지가 전달하는 개념을 한 문장으로**. 핵심 키워드 자연 포함.
  - 예(커버): `데이터가 남는 오프라인 이벤트로 진화하는 QR 스탬프투어의 앞으로의 방향을 정리한 커버`
  - 예(인포): `종이 스탬프 랠리에서 데이터가 남는 QR 스탬프투어로 넘어온 5년의 변화를 정리한 개념도`
- **커버 = OG/트위터 이미지**로 지정하고, `og:image:alt`도 채운다.
- 키워드는 글 SEO 세팅의 메인 키워드와 결이 같게.

## 8. 제작 체크리스트

- [ ] 커버 **1200×630** · 다크 네이비 + QR 그리드 + MAKEVU 로고 + 시안 액센트
- [ ] 커버를 **featured + og:image + twitter:image**로 지정 (+ `og:image:alt`)
- [ ] 인포그래픽 **1200×1200** · 라이트 · Pretendard · §2 토큰만 사용
- [ ] 카테고리 3색(시안/오렌지/그린) **구분 목적일 때만**, 남발 ❌
- [ ] 앱 목업은 **실제 제품 화면 캡처**(코드 렌더 ❌) · 폰 비율 유지
- [ ] `deviceScaleFactor 2`로 선명하게 렌더 · 캔버스 여백 없이 clip
- [ ] 파일명 `qrstp_NN_slug.png` 규칙
- [ ] **모든 이미지 한국어 alt** 작성 · 키워드 정합
- [ ] 텍스트 대비 확보(커버 흰 텍스트 위 패턴 저대비 · 인포 `#171C26` 본문)

## 9. 원칙 요약
- **커버=다크(1200×630) / 인포=라이트(1200×1200) / 목업=제품 캡처**. 무드 혼용 ❌.
- **팔레트 = MAKEVU 브랜드**(시안 `#00BFD3` + 다크 네이비) — 이벤트 스킨과 별개 · **폰트만 Pretendard 공통**.
- **코드로 찍는다**: HTML/CSS → 헤드리스 2x 렌더 → PNG → Wix 업로드 → 배치.
- **커버는 OG 겸용 · 모든 이미지 alt 필수**.
- 색·규격 단일 출처 = 이 문서 §2. 새 시리즈도 같은 토큰으로 재현.
