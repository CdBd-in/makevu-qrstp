# 🖼 블로그 이미지 제작 가이드

> qrstp.com 블로그 이미지는 **손으로 새로 그리지 않는다.** Figma **「QRSTP 블로그 템플릿」** 파일의 정해진 템플릿 프레임을 **복제 → 안의 텍스트·이미지·액센트색만 교체**해서 만든다. 이렇게 해야 자간·행간·간격이 튀지 않고 브랜드가 일정하게 유지된다.
> Figma 파일: `kmX87Vd85aCYKYrIp9jsC2` (「QRSTP 블로그 템플릿」)

> [!warning] 왜 "그려서 넣는다"인가
> AI가 타이포를 맨바닥에서 레이아웃하면 **자간·행간·광학 정렬이 불안정**하다. 템플릿은 폰트·크기·행간·자간·패딩·정렬을 **이미 고정**해 두므로, **텍스트만 교체**하면 그 안정성이 그대로 유지된다. 간격을 "새로 잡는" 게 아니라 "템플릿이 잡아둔 걸 안 건드리는" 것이 핵심.

---

## 1. 제작 방식 — 템플릿 복제 (기본)

1. Figma 파일 `kmX87Vd85aCYKYrIp9jsC2` 열기 → **템플릿 프레임 복제**(§2).
2. **텍스트만 교체** — 서식(폰트·크기·행간·자간)은 건드리지 않는다. 텍스트 통짜 교체 시 서식이 초기화되면 원본 스타일로 복원.
3. **썸네일은 액센트색 로테이션**(§3) 적용.
4. **본문 이미지는 `이미지 프레임`에 콘텐츠 배치**(§4).
5. **길이 안 맞으면 자동 맞춤 + 스크린샷 검수**(§5).
6. **PNG export → Wix 업로드 → 배치**(§6) · **alt 필수**(§7).

> `use_figma` 호출 전 **figma-use 스킬 선로드** 필수 · 복제 프레임은 **템플릿 페이지에 두지 말고** 작업 위치를 명확히(→ [[CLAUDE.md]] Figma 규칙).

## 3. ⭐ 썸네일 액센트색 3색 로테이션 (조건)

> **썸네일을 만들 때마다 액센트색을 3색 중 하나로 번갈아 적용한다.** 템플릿에서 `#5AA2F2`로 칠해진 부분을 아래 순서로 순환.

**로테이션 색상**

| 순번 | HEX | 색 |
|---|---|---|
| ① | `#FDAD13` | 주황 |
| ② | `#A994E6` | 보라 |
| ③ | `#5AA2F2` | 파랑 (템플릿 기본값) |

- **적용 대상 = 템플릿에서 `#5AA2F2`인 부분** = **① 큰 타이틀 텍스트(`2672:7`)** + **② 화살표 버튼(`Group 2` `2672:10`)**.
- **순서 = 발행 순서대로 `#FDAD13 → #A994E6 → #5AA2F2` 반복** 후 다시 처음으로.
- 상단 3색 스와치(`2672:35~37`)는 **3색을 모두 보여주는 데코라 고정**(로테이션 대상 아님).

> [!note] 확인 필요
> "번갈아"의 기준 = **직전 발행글의 액센트색 다음 색**. 새 글 만들 때 **직전 썸네일 색을 확인해 다음 색**을 고른다. (현재 시퀀스 위치가 헷갈리면 최근 발행글 썸네일 색을 먼저 확인.)

## 4. 본문 이미지

- `AI 블로그 이미지 템플릿`(`2672:39`)의 **`이미지 프레임`** 을 복제해 콘텐츠 배치.
- **개념도·타임라인·순환도 등**은 이 프레임 규격(600×450 / 600×315) 안에서 그린다.
- **앱 목업(제품 화면)** 은 코드/생성으로 만들지 말고 **실제 이벤트 페이지(Figma 시안·배포 화면)를 캡처**해 넣는다.
- 색·폰트는 썸네일과 동일 브랜드(Pretendard · §8 토큰).

## 5. 텍스트 길이 자동 맞춤 + 검수 루프

> 제목 길이가 템플릿 원본과 다르면 **넘치거나 빈다.** 아래 순서로 맞춘다.

1. **텍스트 교체** 후 서식 유지 확인(폰트·크기·행간·자간 그대로).
2. **박스(520px)·줄 수(2~3줄) 초과 여부 판정** → 넘치면 **폰트 크기 단계적 축소**, 짧으면 원본 크기 유지.
3. **줄바꿈 균형** — 어절 단위로 위/아래 줄 길이가 비슷하게.
4. **스크린샷으로 실제 반영 재확인**(해시·코드만 믿지 말 것 → [[CLAUDE.md]]). 잘림·겹침·간격 튐 확인.
5. 어긋나면 2~3 반복. **한 방이 아니라 1~2회 검수 반복**이 정상.

> ⚠️ 광학적 자간·시각 균형은 **스크린샷 검수 없이 한 번에 완벽히는 어렵다.** 반드시 눈으로 확인 후 미세 조정.

## 6. Export · 업로드 · 배치

1. 프레임 **PNG export**(레티나면 2x).
2. **파일명**: `qrstp_NN_slug.png` — `00`=썸네일, 이후 본문 순서. 예 `qrstp_00_hero.png`.
3. **Wix 업로드**: `UploadImageToWixSite`(Wix MCP) → media id 획득.
4. **배치**:
   - 썸네일 → 글 **featured 이미지 + `og:image`/`twitter:image`**.
   - 본문 → 해당 위치 `IMAGE` 노드.

---

## 7. alt 텍스트 · SEO (필수)

- **모든 이미지에 한국어 alt** — 이미지가 전달하는 개념을 한 문장, 핵심 키워드 자연 포함.
- 썸네일 = OG/트위터 이미지로 지정하고 `og:image:alt`도 채운다.
- 키워드는 글 SEO 메인 키워드와 정합.

## 10. 원칙 요약
- **그리지 않는다 — 템플릿을 복제해 텍스트만 바꾼다.** 간격 안정성의 근원.
- **썸네일 액센트 = 3색 로테이션**(`#FDAD13`→`#A994E6`→`#5AA2F2`), 대상 = 타이틀 + 화살표 버튼.
- **길이 안 맞으면 폰트 크기·줄바꿈 자동 맞춤 + 스크린샷 검수**(한 방 ❌, 1~2회 반복).
