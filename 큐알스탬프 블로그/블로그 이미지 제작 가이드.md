# 🖼 블로그 이미지 제작 가이드 (INDEX)

> qrstp.com 블로그 이미지는 **손으로 새로 그리지 않는다.** Figma **「QRSTP 블로그 템플릿」**(`kmX87Vd85aCYKYrIp9jsC2`)의 정해진 템플릿 프레임을 **복제 → 텍스트·이미지·색만 교체**해서 만든다. 이래야 자간·행간·간격이 튀지 않고 브랜드가 일정하다.

## ⭐ 이미지 생성 요청 워크플로우 (요청 받으면 이 순서대로)

> "블로그 이미지 만들어줘 / 썸네일 뽑아줘 / 이 글에 이미지 넣어줘" 류 요청 = 아래 순서 준수. **곧바로 그리기 ❌.**

### Step 1 — 파악 (질문 먼저)
- **어떤 글인가** — 제목·본문·타깃 키워드. (Wix 초안이면 Draft Posts API로 내용 확보)
- **무엇을 만드나** — 썸네일 / 본문 이미지 / 둘 다 · **몇 장**.
- **본문이면 각 이미지가 전달할 내용** → 8종 중 어떤 유형인지 매핑(§ 본문 가이드).

### Step 2 — 유형·색 결정
- **썸네일**: `Cover-1-1` 사용 · **액센트 3색 로테이션**에서 **직전 발행글 다음 색** 선택 → 최근 발행 썸네일 색을 먼저 확인.
- **본문**: 콘텐츠 형태에 맞는 템플릿 유형 선택(핵심메시지·수치·단계·비교표·타임라인·개념도·체크리스트·앱목업).

### Step 3 — 템플릿 복제 (그리지 않음)
- **`use_figma` 호출 전 `figma-use` 스킬 선로드 필수**(→ [[CLAUDE.md]]).
- 해당 **템플릿 프레임을 `clone()`** → 작업용 위치로 이동. **템플릿 원본(`2672:*`·`본문템플릿_*`)은 절대 수정하지 않는다.**
- `clone()`은 `figma.currentPage`에 붙으므로, 다른 페이지 대상이면 **`setCurrentPageAsync` 먼저**.

### Step 4 — 텍스트·색 교체 (서식 유지)
- **텍스트만 교체.** 폰트·크기·행간·자간은 건드리지 않는다.
- 통짜 교체로 **강조 서식이 초기화되면** `getStyledTextSegments`+`setRangeFills`로 복원(→ [[CLAUDE.md]]).
- **썸네일**: 로테이션 색을 **타이틀 텍스트 + 화살표 버튼**에 적용.

### Step 5 — 길이 맞춤 + 검수 (1~2회 반복)
- 제목 길이가 원본과 다르면 **박스·줄 수 초과 여부 판정 → 폰트 크기 단계 축소 / 줄바꿈 균형**.
- **`screenshot()`로 실제 반영 재확인** — 잘림·겹침·간격 튐 확인(해시·코드만 믿지 말 것).
- 어긋나면 반복. **"한 방"이 아니라 검수 루프가 정상.**

### Step 6 — Export · Wix 업로드 · 배치
- 프레임 **PNG export**(썸네일 600×450 · 본문 1920×1200 · 레티나면 2x).
- **파일명** `qrstp_NN_slug.png` (`00`=썸네일).
- **`UploadImageToWixSite`**(Wix MCP) → media id 획득.
- **배치**: 썸네일 → 글 **featured + `og:image`/`twitter:image`** · 본문 → 해당 위치 `IMAGE` 노드.

### Step 7 — alt 텍스트 (필수)
- **모든 이미지에 한국어 alt** — 개념을 한 문장, 핵심 키워드 자연 포함 · 썸네일은 `og:image:alt`도.

## 원칙 요약
- **그리지 않는다 — 템플릿 복제 + 텍스트/색 교체.** 간격 안정성의 근원.
- **썸네일 600×450 · 본문 1920×1200.** 규격 고정.
- **썸네일 액센트 = 3색 로테이션**(`#FDAD13`→`#A994E6`→`#5AA2F2`).
- **길이 맞춤 후 스크린샷 검수**(1~2회) · **모든 이미지 alt 필수**.
- Figma: figma-use 선로드 · 템플릿 원본 보존 · 복제본은 작업 위치로.
