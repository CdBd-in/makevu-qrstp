# 🖼 썸네일 템플릿 가이드

## 3. ⭐ 액센트색 3색 로테이션 (핵심 규칙)

> 썸네일을 만들 때마다 **`#5AA2F2`로 칠해진 부분**(타이틀 `2672:7` + 화살표 버튼 `2672:10`)을 아래 순서로 번갈아 적용.

| 순번 | HEX | 색 |
|---|---|---|
| ① | `#FDAD13` | 주황 |
| ② | `#A994E6` | 보라 |
| ③ | `#5AA2F2` | 파랑 (템플릿 기본) |

- **순서 = 발행 순서대로 `#FDAD13 → #A994E6 → #5AA2F2` 반복.**
- **기준 = 직전 발행글 다음 색** → 새 썸네일 만들 때 **최근 발행 썸네일 색 먼저 확인**.
- 상단 3색 스와치는 **고정**(세 색을 모두 보여주는 데코).

## 4. 텍스트 규칙
- **서브타이틀**(`2672:15`) + **타이틀**(`2672:7`) 두 줄 구조. 폰트·크기·행간은 **건드리지 않는다**.
- 타이틀이 길면 **줄바꿈 균형** 맞추고, 박스(520px)·줄 수 초과 시 **폰트 크기 단계 축소**.
- 교체 후 **스크린샷 검수**로 잘림·간격 확인(1~2회).

## 5. 제작 위치 · Export·배치
- **제작 위치** — 썸네일도 Figma 「**AI 블로그 이미지 제작**」 페이지(`2697:7`)의 **글별 섹션 안**에 넣는다(본문 이미지와 같은 섹션). 템플릿 원본 페이지(`2672:5`)에서는 **복제만**.
- **PNG export**(600×450, 레티나면 2x) · 파일명 `qrstp_00_hero.png`.
- **Wix**: `UploadImageToWixSite` → **글 featured + `og:image`/`twitter:image`** 지정 · `og:image:alt` 작성.
