## 4. 고객 사례 요약 (3p → 1p)

카테고리별 대표 1건씩 선정 — 인지도 + 기능 어필을 함께 고려.

| 카테고리 | 선정 | 이유 |
|---|---|---|
| 팝업 · 브랜드 | **올리브영 X 망그러진 곰 팝업** | 인지도 최상 + 다국어·미션 기능 동시 어필 |
| 지역 축제 · 관광 | **수원화성 어드벤처** | 인지도 + 미션·룰렛·단계별 보상 어필 |
| 컨퍼런스 · 박람회 | **마이크로소프트 AI 투어 서울** | 글로벌 브랜드 + **부스 방문율 2배** 정량 성과 |

> 탈락 6건(더 글렌그란트 / 스타필드 X 땡겨요랜드 / 실레마을 / 김포 로컬푸드 / SK ON / LS전선)은 본디자인 단계에서 **로고 스트립**으로 노출하는 안 검토 가능.
