## 2. 참고 소개서 3종의 공통 골격

```
메인(표지) → 스테이트먼트 → 목차 → [챕터 간지 → 내용] × N → 랜딩(CTA) → 백커버
```

세 소개서 모두 **① 챕터 간지(디바이더)로 리듬을 끊고**, **② 목차에 페이지 번호를 명시**하며,
**③ 마지막을 CTA·연락처 랜딩으로 닫는다**. 기존 QR 소개서에는 ①·③이 없었다.

## 5. 핵심 설계 판단 5가지

1. **가격·사양의 단일 원본(SSOT)은 p18 한 곳** — [[큐알스탬프 홈페이지/수정/1. 260610/2. 플랜 및 이용안내 정리.md]]에서 정리한 원칙을 소개서에도 그대로 적용. 이용 안내 페이지(p09~12)에는 가격을 넣지 않는다.
2. **기존 소개서의 "본인인증/룰렛/설문" 3개 페이지 → 기능 옵션 1페이지로 압축** — 홈페이지가 이미 옵션을 평평한 카드 그리드로 정리했고, 페이지 수를 4p 절약해 신규 섹션(어드민·샵플랜·FAQ)에 배분.
3. **챕터 간지 도입** — 참고 3종의 공통점. 25p 분량에서 독자가 위치를 잃지 않게 하는 최소 장치. 간지에 해당 챕터의 하위 항목을 미리 노출.
4. **랜딩 페이지 신설(p24)** — 기존 소개서는 고객사 로고로 끝나 액션이 없었음. QR 스캔 → 샘플 체험 동선을 지면에 심는다.
5. **사례는 "무엇을 하려고 → 어떻게 운영" 문장 구조 유지** — 홈페이지 카피를 그대로 사용(검증된 문장 재활용).

## 6. 확인이 필요한 항목 (와이어프레임에 가안 반영)

- [ ] **데일리 플랜 사용 기간** — 와이어프레임엔 `90일~`으로 표기. 기존 소개서 PDF는 `7일`, 정리 노트는 `90일이 데일리 차별점`. **최신 기준 확정 필요**
- [ ] **표기 통일** — 스탬프 `개` / `회` 혼용 → 소개서는 `회`로 통일(정리 노트 원칙)
- [ ] 지표 `500+ 도입 브랜드`는 (주)엠카(메이크뷰 전체) 기준 → QR 솔루션 단독 지표와 혼동 여지. 각주 필요
- [ ] 판형 A4 가로 유지 vs 16:9 전환 — 현재는 **A4 가로 유지**로 진행
- [ ] 로고 24개 리스트 최종 확정 (홈페이지 슬라이더 기준 + 사용 승인 여부)
