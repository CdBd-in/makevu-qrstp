## 4. 플랜 사양 — 홈페이지 원문 확정본

| | 이지 플랜 | 리드 플랜 | 데일리 플랜 |
|---|---|---|---|
| 티저 | 참여율이 가장 중요할 때 / 본인인증 없이 참여하는 | 이벤트 참여자의 / 개인 정보 수집이 가능한 | 출석 체크 방식으로 / 재방문을 유도하는 |
| **가격** | 100만원~ | 200만원~ | 200만원~ |
| 본인 인증 | 없음 | 휴대폰/이메일 | 휴대폰/이메일 |
| 사용 기간 | 7일~ | 7일~ | **90일~** |
| 스탬프 | 5회~ | 5회~ | 10회~ |
| 추천 | 지역축제 · 대규모 박람회 | 신제품 팝업 · 기업 세미나 | 항공사 · 백화점 · F&B 매장 |
