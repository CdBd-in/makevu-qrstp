## 2. 순서 — 홈페이지 DOM 검증 결과

홈페이지 실제 섹션 순서(HTML 위치 기준):

```
Hero → 고객사 → 차별점 → 고객사례 → 플랜 → 이용안내(참여프로세스·적립방식·기능옵션·유연한운영)
     → 어드민 → 제작프로세스 → 샵플랜 → 모바일페이지 → FAQ → 푸터
```

**v2에서 틀렸던 부분** — 차별점을 고객사보다 앞에, 이용 안내를 고객 사례보다 앞에, 플랜을 사례 뒤가 아닌 더 뒤에 두고 있었음 → v3에서 전부 홈페이지 순서로 정렬.

| | v2 (틀림) | v3 (수정) |
|---|---|---|
| 아이콘 영역 | 388 × 190 **가로 배너 박스** | **112 × 112 정사각** |
