# 📌 큐알스탬프 솔루션 디자인

> 메이크뷰 QR 스탬프(QR Stamp) 솔루션의 **정의**와 **이벤트 진행 프로세스**를 정의하는 문서

---

## 1. 큐알스탬프란? (정의)

**메이크뷰 QR 스탬프**는 모바일 스탬프 투어를 통해 **이벤트·프로모션 운영을 간편화하고 고객 참여를 극대화하는 이벤트 서비스**입니다.

종이 기반의 번거로운 스탬프 시스템을 대체하여, **QR 기술 기반의 빠르고 간단한 방문 인증 및 보상 지급 체계**를 제공합니다.

### 핵심 가치

| 구분 | 내용 |
|---|---|
| **운영 효율성** | 종이 스탬프의 복잡함 제거 · 빠른 인증과 간편한 리워드 운영 |
| **유연한 가격 모델** | 참여자 무제한, 기능 단위 과금 — 10명이든 10만 명이든 추가 비용 없음 |
| **커스터마이징** | 행사 목적과 규모에 맞춘 맞춤 설계 |

### 활용 분야

- 팝업 스토어
- 지역 축제 및 박람회
- 컨퍼런스 및 세미나
- 테마파크 이벤트

### 진입 장벽 최소화

앱 설치 · 회원가입 · SNS 로그인이 **모두 불필요**하며, QR 스캔 후 시작만으로 참여가 가능합니다.

---

## 2. 이벤트 진행 프로세스 (4단계)

> 원본 가이드는 **3단계**(시작 → 스탬프 적립 → 리워드 신청)로 안내하지만,
> 본 솔루션 디자인에서는 **본인 인증** 단계를 추가하여 **4단계**로 재정의한다.

```
1. 시작  →  (2. 본인 인증)  →  3. 스탬프 적립  →  4. 리워드 신청
                 ⌃ 선택 단계 (이벤트별 유무)
```

> [!note] **2단계(본인 인증)는 선택 단계**
> 본인 인증은 **모든 이벤트에 필수가 아니며**, QR스탬프 이벤트 **담당자의 요청에 따라 포함하거나 생략**한다.
> - **포함 시** → 4단계: `시작 → 본인 인증 → 스탬프 → 리워드`
> - **생략 시** → 3단계: `시작 → 스탬프 → 리워드`

### 1단계 — 시작

매장 또는 행사 부스에 부착된 **QR 코드를 스마트폰 카메라로 스캔**하면, 이벤트 시작 페이지로 랜딩하며 스탬프 투어가 시작됩니다.

- 앱 설치·회원가입 없이 즉시 진입
- 시작 버튼 클릭으로 참여 개시

### 2단계 — 본인 인증 *(선택)*

참여자 식별 및 리워드 지급의 신뢰성을 위해 **본인 인증**을 진행합니다.

- 중복 참여·부정 적립 방지
- 리워드 지급 대상의 정확한 식별
- *(인증 방식은 행사 정책에 따라 설계 — 예: 휴대폰 번호, 간편 인증 등)*
- **이벤트 담당자 요청에 따라 이 단계 자체를 생략할 수 있음** → 생략 시 시작 후 바로 3단계로 진입

### 3단계 — 스탬프 적립

각 QR 스캔 포인트마다 **스탬프가 쌓이며**, 참여자는 현재 진행 상황을 실시간으로 확인할 수 있습니다.

- 게임처럼 직관적으로 설계되어 완주의 재미 제공
- 진행률 실시간 표시

### 4단계 — 리워드 신청

정해진 기준에 맞게 스탬프를 모으면 **즉시 리워드 신청**이 가능해집니다.

- 버튼 하나로 신청
- 온라인 / 오프라인 방식으로 보상 수령
