# 🚩 1-2. 시작

> 4단계 중 **1단계**. 참여자가 처음 진입하는 지점.
> 관련: [[큐알스탬프 솔루션/0. 정의.md]] · [[큐알스탬프 솔루션/2. 디자인 가이드/1-1. 공통 디자인 시스템.md]]

---

## 1. 정의

매장·행사 부스의 **QR 코드를 스캔**하거나 **랜딩 페이지로 접속**하여 이벤트가 시작되는 단계.
앱 설치·회원가입 없이 **시작 버튼 클릭**만으로 참여가 개시된다.

---

## 2. 진입 분기 (Flow)

```
[진입로1] QR URL 접속 ─┐
                       ├─→ 인증 여부 판단
[진입로2] 랜딩 페이지 ─┘     ├─ 미인증(NO) → 2. 본인 인증 (Login)
                            └─ 인증됨(YES) → 3. 스탬프 (적립현황)
```

- **진입로1 — QR URL 접속**: QR 스캔으로 직접 진입
- **진입로2 — 랜딩 페이지 접속**: 이벤트 소개 랜딩에서 진입

## 4. 무엇이 들어가는가 (구성 요소)

**랜딩 페이지 (begin-LandingPage)**
1. **이벤트 배너 비주얼** — "QR 스탬프 / 리워드 이벤트" (현재 `Event 1` 이미지로 베이크됨)
2. **이벤트 설명** — 적립 방식 + 리워드 안내 (`Input Text`)
3. **상품권/Voucher 미리보기** 이미지 (예: ₩10,000 상품권)
4. **유의사항 리스트** (`Tip`)
   - 중복·부정 참여 시 리워드 지급 취소
   - 동일 인증 건으로 중복 참여 불가
   - 이미 스캔한 QR로 중복 적립 불가
   - 리워드 상품권 부분 사용·환불 불가
   - 기한 내 미수령 시 지급 취소
5. **CTA 버튼** — "이벤트 참여하기" (`Button / Enabled`, 하단 고정)

### 4-1. 배너 비주얼을 "텍스트"로 넣을 때 — Pretendard 타입 스케일

> 현재 배너는 통이미지(`Event 1`)지만, **텍스트(라이브 텍스트)로 구현할 경우** 아래 정의를 따른다.
> (375 폭 기준 · 폰트 **Pretendard** · 좌우 여백 24)

| 텍스트 역할 | 예시 | weight / size / line-height | 컬러 |
|---|---|---|---|
| **Eyebrow**(강조 한 줄) | "스탬프 4개 모으고 상품권 받으세요!" | SemiBold(600) · **16** · 24 | primary `#4B73FF` |
| **메인 타이틀**(Hero) | "QR 스탬프" | Bold(700)~ExtraBold(800) · **48** · 56 | primary `#4B73FF` |
| **서브 타이틀** | "리워드 이벤트" | Bold(700) · **32** · 42 | text `#212529` |
| **본문 설명** | "행사장 내 QR 코드를 스캔하면…" | Medium(500) · **16** · 26 | text `#212529` |
| └ 본문 강조어 | "**10,000원 상품권**" | SemiBold(600) · 16 · 26 | text `#212529` |
| **유의사항** | "· 중복 및 부정 참여 시…" | Regular(400) · **12** · 20 | text-sub `#737D87` |

> 위 사이즈는 배너 이미지(375×776)의 텍스트 비율을 측정해 도출한 **권장 정의값**이다. 기존 디자인 시스템(`Title_L` 28 등)보다 큰 **배너 전용 디스플레이 스케일**로 취급한다.
