# 🎁 1-5. 리워드

> 4단계 중 **4단계**. 스탬프 조건 충족 후 리워드를 신청·수령.
> 관련: [[큐알스탬프 솔루션/0. 정의.md]] · [[큐알스탬프 솔루션/2. 디자인 가이드/1-1. 공통 디자인 시스템.md]]

---

## 1. 정의

정해진 기준만큼 스탬프를 모으면 **즉시 리워드 신청**이 가능해지고, 버튼 하나로
**온라인/오프라인 방식**의 보상을 수령하는 단계.

---

## 2. 화면 목록

| 화면(frame) | 설명 |
|---|---|
| `(reward)` | 리워드 신청/수령 안내 화면 ("축하드려요!") |
| `(reward_applied)` | 리워드 신청 완료 상태 |

> 리워드 상세는 **세로로 긴 페이지(≈ 375 × 1054)** — 스크롤하며 안내·지도까지 확인.

---

## 3. 무엇이 들어가는가 (구성 요소)

1. **축하 헤드라인** — "축하드려요!" (`Title_L`, primary 강조) + Close Icon(우상단)
2. **리워드 안내 문구** — "지금 바로 리워드를 신청하고 즉시 사용 가능한 {금액} 상품권을 받으세요!"
3. **상품권/Voucher 이미지** — 리워드 미리보기 (예: ₩10,000 상품권)
4. **리워드 수령 안내** (`Title_L` 소제목 + 본문)
   - **장소** — 예: 서울 서초구 강남대로 373
   - **기한** — 예: 2024년 2월 10일까지
5. **지도** — 오프라인 수령 위치 (Reward 이미지에 포함)
6. **CTA 버튼** — [리워드 받기] / [리워드 신청하기] (`Button`, 하단 고정)

---

## 4. 상태 흐름

```
스탬프 조건 충족 → (reward) "리워드 받기"
        → 신청 → (reward_applied) 신청 완료
        → 스탬프 화면 Done 상태로 동기화
```

- 신청 전: [리워드 받기] **활성**
- 신청 후: 완료 표시 + 스탬프 단계의 `Done` 상태와 일관성 유지

---

## 5. 사용 리소스 (디자인 시스템)

| 요소 | 토큰/컴포넌트 |
|---|---|
| 축하 헤드라인 | `Title_L` · primary `#4B73FF` 강조 |
| 안내 본문 | `Input Text` / `Tip` · text-sub `#737D87` |
| 장소·기한 라벨 | `Title_S` (라벨) + `Input Text`(값) |
| 상품권/지도 | 이미지 에셋 (Voucher, Reward 이미지) |
| 닫기 | **Close Icon** (27×27) |
| CTA | **Button** (Enabled) |
| 레이아웃 | 375 폭 · 세로 스크롤(≈1054) · 하단 고정 CTA |

---

## 6. 디자인 시 체크포인트
- [ ] 신청 가능/완료 상태가 명확히 구분되는가
- [ ] 수령 장소·기한이 누락 없이 노출되는가 (오프라인 시 지도 포함)
- [ ] 상품권 미리보기가 신뢰감 있게 표현되는가
- [ ] 스탬프 단계의 완료(Done) 상태와 메시지가 일관적인가
