## 1. 레이아웃 기준

| 항목 | 값 |
|---|---|
| 화면(아트보드) | **375 × 812** (모바일 세로) |
| 좌우 여백 | **24px** |
| 콘텐츠 폭 | **326~327px** (여백 제외) |
| 기본 정렬 | 좌측 정렬(텍스트), 하단 고정 CTA |

---

## 2. 컬러 토큰

| 토큰 | HEX | 용도 |
|---|---|---|
| **primary** (`selected` / `light blue`) | `#4B73FF` | 활성 버튼, 강조 텍스트, 스탬프, 선택 탭 |
| **primary-tint** | `#4B73FF` @ 흐림 (≈ `#C9D5FF`) | 비활성 버튼 배경, empty 스탬프 |
| **text** (`black`) | `#212529` | 기본 본문/제목 텍스트 |
| **text-sub** (`dark gray`) | `#737D87` | 보조 텍스트, 필드 라벨 |
| **placeholder** (`gray`) | `#C0C0C0` | placeholder, 비활성 텍스트, 언더라인 |
| **white** | `#FFFFFF` | 배경, 버튼 위 텍스트 |

## 3. 타이포그래피 (Pretendard)

| 스타일명 | weight / size / line-height / spacing | 용도 |
|---|---|---|
| **Title_L** | SemiBold · 28 · 44 · 0 | 페이지 메인 헤드라인 |
| **Title_S** | Medium · 14 · 26 · -0.2 | 라벨 · 소제목 |
| **Field txt_L** | Medium · 22 · 26 · 0 | 입력 필드 입력값(큰 텍스트) |
| **Input Text** | Medium · 14 · 26 · -0.2 | 본문 · 동의 문구 |
| **Button Text** | SemiBold · 20 · 26 · -0.2 | 버튼 라벨 |
| **link_ul** | Regular · 14 · 22 · -0.1 · underline | 링크("자세히", "문자가 오지 않을 때") |
| **Tip** | Regular · 12 · 26 · 0 | 팁 · 보조 안내 |

> 폰트 패밀리: **Pretendard** 고정.

## 4. 공통 컴포넌트

| 컴포넌트 | 사양 | 상태(variant) |
|---|---|---|
| **Button** (Primary CTA) | 326 × 50, rounded, 하단 고정 | `Enabled`(배경 #4B73FF / 흰 텍스트) · `Disabled`(primary-tint / 회색 텍스트) |
| **Input Field** | 326 폭, 라벨(Title_S, text-sub) + 입력(Field txt_L) + 하단 언더라인 | `Default` · `Focus` · `Filled` · `Error`(에러 피드백 텍스트) |
| **Checkbox** | 18 × 18 + 라벨(Input Text) + "자세히"(link_ul) | `Off` · `On`(primary) |
| **Stamp** | 100 × 100, 2열 그리드(점선 구분선) | `Stamped`(primary 도장) · `Empty`(번호 01~05 고스트) · `Stamp_Multi`(리워드 경계) |
| **Tab** (리워드 A/B/C) | pill 형태 가로 분할 | `Selected`(primary) · `Default`(gray) |
| **Close Icon** | 27 × 27, 우상단 | — |
| **Popup / Modal** | 풀스크린 시트, 우상단 Close Icon + 제목 + 본문 | — |

### 이미지/에셋 리소스
- **이벤트 배너**(Event 1) — 랜딩 상단 비주얼
- **상품권/Voucher** — 리워드 미리보기 이미지
- **Reward 이미지**(375 × 1054) — 리워드 상세(스크롤), 지도 포함
- **Stamp 아이콘** — "stamp" 도장 그래픽

---

## 5. 사용 원칙

1. 모든 화면은 **375 폭 · 24 여백 · 하단 고정 CTA** 골격을 따른다.
2. 강조/활성은 **primary `#4B73FF`** 단일 색으로 통일한다.
3. 텍스트 위계: 헤드라인 `Title_L` → 본문 `Input Text` → 보조 `Tip`.
4. 모든 단계의 CTA는 **Button 컴포넌트 1개**를 상태만 바꿔 재사용한다.
