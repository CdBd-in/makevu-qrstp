# 🏷️ 2-1-3. 스탬프

> 4단계 중 **3단계**. QR 스캔 포인트마다 스탬프를 적립하고 진행 상황을 확인.
> 관련: [[큐알스탬프 솔루션/0. 정의.md]] · [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]]

---

## 1. 정의

각 QR 스캔 포인트에서 **스탬프가 적립**되며, 참여자는 **적립 현황**을 실시간으로 확인한다.
조건(전체 적립) 충족 시 리워드 신청으로 이어진다.

---

## 2. 표준 구조 (공통)

> 모든 스탬프 화면 공통 = **헤더 → 리워드 버튼 → 스탬프 그리드**. 상태에 따라 **헤더 문구 · 버튼 · 적립 개수**만 달라진다. (`n` = 전체 스탬프 수)

### 2-1. 세로 배치 & 간격
```
상단
 │ 52          ← 헤더 top
헤더 (개인화 + 상태 메시지)
 │ 25
리워드 버튼
 │ 25
스탬프 그리드
 │ 40
하단
```

### 2-2. 영역별 사양

| 영역 | 사양 | 폰트/컬러 |
|---|---|---|
| **헤더** (y=52, 좌측정렬) | 개인화 인사 + 상태 메시지 | **28px/44 SemiBold** · 기본 `#212529` · **강조어 = 이벤트 메인 컬러** |
| **리워드 버튼** (327×50 · radius 8) | 상태별 활성/비활성 | 활성 = **이벤트 메인 컬러** / 비활성 = **활성색 투명도 30%** · 텍스트 흰색 |
| **스탬프 그리드** | 2열 × `n/2`행 · 점선 구분선(세로1+가로) | 아래 2-3 참고 |

### 2-3. 스탬프 (컴포넌트)

- 스탬프 칸 = **`stamp` 컴포넌트** (`6189:13747`) 인스턴스를 사용한다.
- variant: **`active`(적립)** / **`inactive`(미적립)**.
- **색상은 이벤트 메인 컬러**로 적용 (inactive는 동일 컬러의 연한 버전).

#### 스탬프 라벨(내부 텍스트) 규칙

스탬프 컴포넌트 안의 텍스트는 **해당 스탬프의 이름**이다. 이름 유무에 따라 다음과 같이 표기한다.

| 구분 | 표기 | 예 |
|---|---|---|
| **이름 없음** | **순번 숫자**(`1`, `2`, `3`, `4` …)를 그리드 순서대로 표기 | `1` · `2` · `3` · `4` |
| **이름 있음** | **스탬프 이름**을 그대로 표기 | `아메리카노` · `라떼` · `디저트` |

- 기본값은 **순번 숫자**이며, 1부터 시작해 그리드 좌→우, 위→아래 순서로 증가한다.
- 스탬프별 이름이 지정된 경우 숫자 대신 **이름**을 표기한다. (한 이벤트 안에서 이름 있는 칸·없는 칸이 섞일 수 있으며, 이름이 없는 칸은 순번 숫자 규칙을 따른다.)
- `active`/`inactive` 어느 상태든 라벨 텍스트(숫자 또는 이름)는 동일하게 유지된다.

## 3. 4-상태 정의

> 강조어 = **이벤트 메인 컬러**.

| #       | 상태             | 헤더                                                  | 버튼                    | 스탬프           |
| ------- | -------------- | --------------------------------------------------- | --------------------- | ------------- |
| **3-1** | Default (수집 전) | "{이름}님, 스탬프 **{n}**개를 모으고 리워드를 받으세요!"               | "리워드 받기" · **비활성**    | 전부 `inactive` |
| **3-2** | 진행 (m개 적립)     | "{이름}님, 스탬프 **{n−m}**개를 모으고 리워드를 받으세요!" *(남은 수 강조)* | "리워드 받기" · **비활성**    | m개 `active`   |
| **3-3** | 완료·신청 (n/n)    | "{이름}님, **스탬프를 모두 모았어요!** 리워드를 신청하세요"               | "리워드 받기" · **활성**     | 전부 `active`   |
| **3-4** | 수령 후           | "{이름}님, **축하드려요!** 리워드 신청이 완료되었어요"                  | "리워드 수령 완료" · **비활성** | 전부 `active`   |

- 헤더의 숫자 = **남은 개수(n−적립수)**, 0이 되면 3-3 메시지로 전환.
- 버튼은 **n/n 적립 시에만 활성**, 수령 후 "리워드 수령 완료"(비활성).

---

## 4. ⭐ 개인화(이름) 규칙 — 본인인증 여부

| 본인인증 | 헤더 형태 | 예 |
|---|---|---|
| **완료(인증 O)** | "**{이름}님,** …" 접두 | "홍길동님, 스탬프 8개를 모으고 리워드를 받으세요!" |
| **미사용/미완료(인증 X)** | **이름 제거**, 상태 메시지만 | "스탬프 8개를 모으고 리워드를 받으세요!" |

> 본인인증이 없는 이벤트면 모든 스탬프 헤더에서 "{이름}님," 를 **반드시 뺀다.**

## 5. 사용 리소스

| 요소 | 토큰/컴포넌트 |
|---|---|
| 헤더 | `Title_L`(28/44 SemiBold) · text `#212529` / 강조 = 이벤트 메인 컬러 |
| 스탬프 | **`stamp` 컴포넌트**(`6189:13747`, active/inactive) · 색상 이벤트 메인 컬러 |
| 그리드 구분선 | 점선(dashed) `#C0C0C0` |
| 버튼 | **Button** · 활성=이벤트 메인 컬러 / 비활성=메인 컬러 30% |
| 레이아웃 | 375 폭 · 여백 24 · 2열 그리드 |

> **다중 리워드(Multi)** 변형: 리워드 A/B/C를 `Tab`으로 전환하는 형태. 선택 탭=메인 컬러, 탭별로 적립현황·남은 개수·신청 가능 여부가 즉시 반영. (기본 골격은 위와 동일)

## 6. 디자인 시 체크포인트
- [ ] 헤더 개인화: 인증 O → "{이름}님," / 인증 X → 이름 제거
- [ ] 강조어·스탬프·활성 버튼이 **이벤트 메인 컬러**로 통일됐는가
- [ ] 비활성 버튼 = 활성색 **투명도 30%** 인가
- [ ] 스탬프가 `stamp` 컴포넌트 active/inactive로 구성됐는가
- [ ] 간격 준수: 52 / 25 / 25 / 40
- [ ] 남은 개수/완료가 헤더에서 즉시 읽히는가
