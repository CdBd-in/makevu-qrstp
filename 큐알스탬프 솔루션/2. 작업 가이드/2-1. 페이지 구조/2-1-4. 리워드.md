## 1. 정의

스탬프를 모두 모으면 리워드를 신청·수령하는 단계. **받기 전 / 받은 후** 2개 화면으로 나뉘며 **레이아웃은 동일, CTA만 다르다.**

## 2. 표준 구조 (공통)

> 배경 = **이벤트 배경 컬러**(선택 팔레트의 `배경`색, 메인 컬러와 한 쌍 → [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-3. 색상팔레트.md]]) · 중앙 정렬 · 프레임 높이 가변(예 759).

### 2-1. 세로 배치 & 간격
```
상단
 │ 52          ← 상단 여백 (오토레이아웃 top)
로고 자리 (150 × 65.57 프레임 · 로고 contain · 중앙)
 │ 12
타이틀 (축하합니다!)
 │ 10
안내문
 │ 35
리워드 카드
 │ 35
CTA 버튼
 │ 52          ← 하단 여백 (오토레이아웃 bottom)
하단
```

> 🧩 **오토레이아웃**: 로고·타이틀·안내문·리워드 카드·CTA는 **327폭 세로 오토레이아웃 컨테이너(중앙 정렬 · 높이 hug)** 에 담긴다.
> - **위/아래 간격(고정) = 상단(top) 52 · 하단(bottom) 52.**
> - **로고 → 타이틀 = 12.** **콘텐츠 프레임 gap 35** (타이틀그룹 → 리워드 카드 → CTA). **타이틀그룹 내부 gap 10**(축하합니다! ↔ 안내문).
> 안내문 줄 수·리워드 카드 내용(구분선·핀 라벨)이 늘어도 간격이 유지되며 높이가 자동 조정된다. → 복제 후 콘텐츠만 교체.

### 2-3. 🪧 로고 적용 규칙

> 브랜드 로고를 **로고 자리(150 × 65.57 고정 프레임)** 에 넣을 때의 규칙. 로고가 있으면 적용, 없으면 `#EDEDED` placeholder 유지.
> ⭐ **새 로고를 새로 그리지 않는다** — **전달받은(기존) 로고 에셋을 아래 규칙에 맞춰 크기·마스크만 수정**해 넣는다.
> 📐 **로고 크기 정책(옵티컬) ⭐**: 프레임 = **150 × 65.57** — **구 167×73에서 축소**(프레임을 꽉 채우니 로고가 시각적으로 **커 보였기** 때문). **프레임은 최대 경계**이고, 로고는 비율유지 contain + **옵티컬(시각 균형)으로 프레임보다 작게** 둘 수 있다. 가장자리까지 꽉 채우지 말 것.

**1) 크기 맞춤 — 150×65.57 프레임 안에 비율 유지 contain + 중앙 정렬**
- **가로로 긴 로고** → 프레임 **너비(150)** 기준으로 맞춘다. (높이는 비율대로 따라가며 **65.57 이내**)
- **세로로 긴 로고** → 프레임 **높이(65.57)** 기준으로 맞춘다. (너비는 비율대로 따라가며 **150 이내**)
- **항상 원본 비율 유지** · 프레임 기준 **중앙 정렬** · **프레임(150×65.57)을 벗어나지 않게**(가득 채우지 않고 contain) — 로고가 길게 뻗은 방향을 프레임의 같은 방향 변에 맞춘다.

**2) 어두운 배경 → 흰색 마스크 (필수)**
- 배경이 어두우면(이번 BTS 다크 테마처럼) 컬러/검정 로고가 묻힌다. → **로고 이미지(알파)를 마스크로 사용하고 그 위에 `#FFFFFF` 사각형**을 깔아 **로고를 흰색으로 녹아웃**한다.
- 밝은 배경이면 **원본 로고 그대로** 적용(마스크 불필요).
- 구현: `[#FFFFFF 사각형]`을 `[로고 이미지]`로 **마스킹** → 로고 모양만 흰색으로 표시.

### 2-4. ✍️ 안내문 강조어 = 별도 텍스트 필드 (가로 오토레이아웃) ⭐

> 안내문의 **강조어(수령장소 등)** 는 한 텍스트 안에서 색만 바꾸지 말고, **강조어와 나머지 문장을 각각 별도 텍스트 필드로 분리**해 **가로 오토레이아웃(items-center)** 으로 나란히 배치한다.

- **구조**: `[가로 오토레이아웃 · items-center] = [강조 필드] + [일반 필드]`
  - **강조 필드**(예 "물빛광장 인포부스") = **Pretendard Bold · 메인 컬러**
  - **일반 필드**(예 "에서 리워드를 받아가세요!") = **Pretendard Medium · 흰색/기본색**
  - 두 필드 **같은 크기(14) · tracking · leading 1.4** 로 맞춰 한 문장처럼 보이게.
- **왜 분리하나 (중요)** ⭐: 한 텍스트 노드에 인라인 혼합 서식을 쓰면, 나중에 **`characters` 로 통짜 교체할 때 글자별 강조 서식(색·굵기)이 초기화**된다(→ CLAUDE.md 상시 규칙). **필드를 분리해 두면 이 문제가 원천 차단**되고, 강조어(장소)만 교체해도 서식이 유지된다. — 자동 제작 시 Claude가 헷갈리던 지점을 구조로 해결.
- **줄바꿈**: 가로 오토레이아웃은 기본 **한 줄(nowrap)**. **강조어를 문장 앞에 두어** 한 줄에 들어가는 문안으로 작성(예 "**{장소}**에서 리워드를 받아가세요!").
- 리워드뿐 아니라 **시작·룰렛 등 강조어가 필요한 모든 안내 텍스트**에 동일 적용.
- ⚠️ **오토레이아웃 프레임 배경 비우기**: `createAutoLayout`(또는 새 프레임)은 **기본 흰색 fill**이 들어간다 → 반드시 **fill 제거(투명)**. 안 그러면 다크 배경에서 **흰 박스가 생기고 흰색 텍스트가 묻힌다.**

## 3. 2-상태 정의 (CTA만 차이)

| # | 상태 | CTA |
|---|---|---|
| **4-1** | 리워드 받기 전 | "리워드 받기" · **활성**(이벤트 메인 컬러) |
| **4-2** | 리워드 받은 후 | "리워드 수령완료" · **비활성**(메인 컬러 30%) |

> 버튼 규칙은 스탬프와 동일 — 활성=이벤트 메인 컬러 / 비활성=활성 버튼 전체 **opacity 30%** · 텍스트 흰색.

> ⭐ **`4-2. REWARD-Done`은 `4-1. REWARD-Default`를 복제해 하단 CTA 상태만 바꾼 것**이다 — 로고·타이틀·안내문·리워드 카드·핀 라벨 등 **나머지는 100% 동일**. (별도 "수령 완료" 확인 화면을 새로 만들지 않는다.)

## 4. 🖼 리워드 이미지 규칙

- `#D9D9D9` 영역(275×172)은 **리워드 이미지 자리**.
- **리워드 정보가 주어지면**, Claude가 **[thiings.co](https://www.thiings.co/things)** 에서 적합한 이미지를 **다운로드해 적용**한다.
- 정보가 없으면 **회색(`#D9D9D9`) placeholder 유지**.

## 6. 디자인 시 체크포인트
- [ ] 받기 전(활성)/받은 후(비활성) **CTA 상태**만 다르고 레이아웃 동일한가
- [ ] 타이틀·강조어·활성 버튼·핀 라벨이 **이벤트 메인 컬러**로 통일됐는가
- [ ] 비활성 버튼 = 활성색 **투명도 30%** 인가
- [ ] **리워드명 ↔ 수령정보 사이 구분선**이 들어갔는가
- [ ] 수령장소·수령기한이 핀 라벨(**12 Bold**)+값(**13 SemiBold**)로 노출되는가
- [ ] 리워드 정보 있으면 thiings.co 이미지 적용, 없으면 회색 유지
- [ ] 간격 준수: **상단 52** / 로고→타이틀 12 / 타이틀→안내문 10 / 안내문→카드 35 / 카드→CTA 35 / **하단 52**
