# 🎁 2-1-4. 리워드

> 4단계 중 **4단계** *(본인인증 생략 시 −1단계 → 3단계)*. 스탬프 조건 충족 후 리워드를 신청·수령.
> 관련: [[큐알스탬프 솔루션/0. 정의.md]] · [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]]

---

## 1. 정의

스탬프를 모두 모으면 리워드를 신청·수령하는 단계. **받기 전 / 받은 후** 2개 화면으로 나뉘며 **레이아웃은 동일, CTA만 다르다.**

---

## 2. 표준 구조 (공통)

> 배경 = **이벤트 배경 컬러**(선택 팔레트의 `배경`색, 메인 컬러와 한 쌍 → [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-3. 색상팔레트.md]]) · 중앙 정렬 · 프레임 높이 가변(예 735).

### 2-1. 세로 배치 & 간격
```
상단
 │ 34          ← 로고 자리 top
로고 자리
 │ 15
타이틀 (축하합니다!)
 │ 10
안내문
 │ 30
리워드 카드
 │ 40
CTA 버튼
 │ 40          ← CTA 하단 여백
하단
```

### 2-2. 영역별 사양

| 영역 | 사양 | 폰트 / 컬러 |
|---|---|---|
| **로고 자리** | 167×73 · 상단 중앙 · `#EDEDED` placeholder | 브랜드 로고 자리(없으면 회색) |
| **타이틀** "축하합니다!" | 중앙 | **48px Bold** · **이벤트 메인 컬러** |
| **안내문** | "{수령장소}에 방문하여 해당화면을 보여주세요!" · **너비 327 고정 · 높이 hug** · 줄바꿈 = **어절 단위**(→ [[큐알스탬프 솔루션/2. 작업 가이드/2-1. 페이지 구조/2-1-1. 시작.md]] §4-4) | **14px Bold** · 기본 `#212529` · **장소 강조 = 메인 컬러** |
| **리워드 카드** | **너비 327** · radius **8** · 배경 **메인 컬러 10%** · 패딩 상하 30 | (아래 포함) |
| └ **리워드 이미지** | **275 × 172** · `#D9D9D9` | thiings.co 규칙(4절) |
| └ **리워드 명** | "스탬프 n개 리워드" + "{리워드명}" | 14 SemiBold · 라벨=메인 컬러 / 명=`#111111` |
| └ **수령장소** | 핀 라벨(메인 컬러 · radius 50 · 흰 12 SemiBold) + 값 | 예: 삼송역 3번출구, 아쿠아필드 루프탑 |
| └ **수령기한** | 핀 라벨 + 값 | 예: 2026년 5월 10일까지 |
| **CTA 버튼** | **327 × 50** · radius **8** | 상태별 (3절) |

---

## 3. 2-상태 정의 (CTA만 차이)

| # | 상태 | CTA |
|---|---|---|
| **4-1** | 리워드 받기 전 | "리워드 받기" · **활성**(이벤트 메인 컬러) |
| **4-2** | 리워드 받은 후 | "리워드 수령완료" · **비활성**(메인 컬러 30%) |

> 버튼 규칙은 스탬프와 동일 — 활성=이벤트 메인 컬러 / 비활성=활성 버튼 전체 **opacity 30%** · 텍스트 흰색.

> ⭐ **`4-2. REWARD-Done`은 `4-1. REWARD-Default`를 복제해 하단 CTA 상태만 바꾼 것**이다 — 로고·타이틀·안내문·리워드 카드·핀 라벨 등 **나머지는 100% 동일**. (별도 "수령 완료" 확인 화면을 새로 만들지 않는다.)

---

## 4. 🖼 리워드 이미지 규칙

- `#D9D9D9` 영역(275×172)은 **리워드 이미지 자리**.
- **리워드 정보가 주어지면**, Claude가 **[thiings.co](https://www.thiings.co/things)** 에서 적합한 이미지를 **다운로드해 적용**한다.
- 정보가 없으면 **회색(`#D9D9D9`) placeholder 유지**.

---

## 5. 사용 리소스

| 요소 | 토큰/컴포넌트 |
|---|---|
| 타이틀 | 48px Bold · 이벤트 메인 컬러 |
| 안내문 | 14px Bold · `#212529` / 장소 강조 = 메인 컬러 |
| 카드 | radius 8 · 배경 메인 컬러 10% |
| 핀 라벨(수령장소/기한) | radius 50 · 배경 메인 컬러 · 흰 12 SemiBold |
| 리워드 이미지 | `#D9D9D9` 275×172 (thiings.co) |
| CTA | **Button** · 활성=메인 컬러 / 비활성=메인 컬러 30% |
| 레이아웃 | 375 폭 · 여백 24 · 카드 327 |

---

## 6. 디자인 시 체크포인트
- [ ] 받기 전(활성)/받은 후(비활성) **CTA 상태**만 다르고 레이아웃 동일한가
- [ ] 타이틀·강조어·활성 버튼·핀 라벨이 **이벤트 메인 컬러**로 통일됐는가
- [ ] 비활성 버튼 = 활성색 **투명도 30%** 인가
- [ ] 수령장소·수령기한이 핀 라벨로 노출되는가
- [ ] 리워드 정보 있으면 thiings.co 이미지 적용, 없으면 회색 유지
- [ ] 간격 준수: 34 / 15 / 10 / 30 / 40 / 40
