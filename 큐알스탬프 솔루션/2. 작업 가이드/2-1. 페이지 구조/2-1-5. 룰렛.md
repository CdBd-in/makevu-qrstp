# 🎡 2-1-5. 룰렛

> **선택(옵션) 기능** — 기본 플로우에 추가되는 **리워드 룰렛** 모듈. Easy / Lead 플랜에 **필요에 따라 추가**하는 부가 기능.
> 관련: [[큐알스탬프 솔루션/0. 정의.md]] · [[큐알스탬프 솔루션/2. 작업 가이드/2-1. 페이지 구조/2-1-4. 리워드.md]] · [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]]

> [!note] 출처·범위 안내
> 이 문서는 [룰렛 가이드](https://qrstp.mintlify.app/features/roulette)에 **명시된 내용만** 정리한 것입니다. 화면 프레임·레이아웃 수치는 **아직 Figma 확정 전**이며, 별도 표기 없이 임의로 유추하지 않습니다. 디자인 시에는 공통 디자인 시스템(6절)을 따르고, Figma가 나오면 보강합니다.

---

## 1. 정의 (가이드 명시)

- 참여자가 스탬프를 적립하고 **룰렛(추첨) 기회**를 얻는 **추첨 기반 리워드 시스템**.
- 기본 **스탬프 적립형 리워드 지급 방식의 대안**으로 설계됨.

---

## 2. 핵심 — 실시간 확률·수량 조정 (가이드 명시)

- 관리자는 **행사 진행 중에도 당첨 확률과 최대 당첨 개수를 실시간 조정**할 수 있다.
- 사전에 고정된 방식이 아니라 **"동적(dynamic) 룰렛"** 으로 동작한다.

### 조정 시나리오

| 상황 | 조정 |
|---|---|
| 인기 리워드가 **너무 빨리 소진** | 확률을 낮추거나 최대 당첨 수를 늘려 행사 기간 전체로 분산 |
| 비인기 리워드가 **남음** | 해당 확률을 줄이고 인기 리워드 배정을 확대 |
| 참여가 **예상보다 저조** | 전체 당첨 확률을 높여 만족도 향상 |
| **추가 예산 확보** | 신규 리워드 추가 · 최대 당첨 수량 상향 |
| **특정 시간대 참여 집중** | 일시적으로 확률을 조정해 균형 유지 |

---

## 3. 룰렛 페이지 구성 (가이드 명시)

- **리워드 이미지 업로드**: 룰렛 이벤트 페이지 안에 리워드 이미지를 넣어 **참여자의 기대감과 명확성**을 높인다.

> 이미지 소스 규칙(정보 있으면 thiings.co 적용 / 없으면 `#D9D9D9` placeholder)은 리워드와 동일 → [[큐알스탬프 솔루션/2. 작업 가이드/2-1. 페이지 구조/2-1-4. 리워드.md]] §4.

---

## 4. 운영·데이터 (가이드 명시)

- **실시간 통계 대시보드**(관리자용): 리워드별 분포 · 잔여 재고 · 시간대별 참여 추이 · 개별 당첨자 내역 표시.
- **Excel 내보내기**: 행사 중·후 **언제든** 룰렛 데이터를 Excel로 내보낼 수 있다.
- **운영 대행 지원**: 메이크뷰가 운영자를 대신해 **모니터링·조정을 대행**하는 옵션 제공.

---

## 5. 제공 범위 (가이드 명시)

- **Easy 플랜 · Lead 플랜** 양쪽에 **필요 시 추가**할 수 있는 부가 기능.

## 6. 화면 디자인 규칙 (공통 디자인 시스템 적용)

> ⚠️ 룰렛 전용 Figma가 확정되기 전까지, 화면은 다른 페이지와 동일한 **공통 디자인 시스템**을 따른다. 아래는 룰렛만의 새로운 값이 아니라 **볼트 공통 규칙의 적용**이다.

- 배경 = **이벤트 배경 컬러** · 로고 자리 **167 × 73 프레임**(비율유지 contain, 없으면 `#EDEDED`) → [[큐알스탬프 솔루션/2. 작업 가이드/2-1. 페이지 구조/2-1-4. 리워드.md\|§2-3 로고 규칙]]
- 카드·CTA는 너비 **327 · radius 8** · 활성 = **이벤트 메인 컬러** / 비활성 = 활성 버튼 **opacity 30%** · 텍스트 흰색
- 다줄 텍스트 줄바꿈 = **어절 단위** → [[큐알스탬프 솔루션/2. 작업 가이드/2-1. 페이지 구조/2-1-1. 시작.md]] §4-4
- 상세 토큰·컴포넌트 → [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]]

## 7. 디자인 시 체크포인트

- [ ] 리워드 이미지가 룰렛 페이지에 노출되는가 (없으면 회색 유지)
- [ ] 공통 디자인 시스템(메인 컬러 · 327 · radius 8 · 버튼 opacity 30%)을 따랐는가
- [ ] (운영) 실시간 확률·수량 조정, 통계 대시보드, Excel 내보내기 흐름이 반영됐는가
