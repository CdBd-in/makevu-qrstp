# 🎡 2-1-5. 룰렛

> **선택(옵션) 기능** — 기본 플로우에 추가되는 **리워드 룰렛** 모듈. Easy / Lead 플랜에 **필요에 따라 추가**하는 부가 기능.
> 관련: [[큐알스탬프 솔루션/0. 정의.md]] · [[큐알스탬프 솔루션/2. 작업 가이드/2-1. 페이지 구조/2-1-4. 리워드.md]] · [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]]

## 1. 정의 (가이드 명시)

- 참여자가 스탬프를 적립하고 **룰렛(추첨) 기회**를 얻는 **추첨 기반 리워드 시스템**.
- 기본 **스탬프 적립형 리워드 지급 방식의 대안**으로 설계됨.

---

## 2. 핵심 — 실시간 확률·수량 조정 (가이드 명시)

- 관리자는 **행사 진행 중에도 당첨 확률과 최대 당첨 개수를 실시간 조정**할 수 있다.
- 사전에 고정된 방식이 아니라 **"동적(dynamic) 룰렛"** 으로 동작한다.

### 조정 시나리오

| 상황 | 조정 |
|---|---|
| 인기 리워드가 **너무 빨리 소진** | 확률을 낮추거나 최대 당첨 수를 늘려 행사 기간 전체로 분산 |
| 비인기 리워드가 **남음** | 해당 확률을 줄이고 인기 리워드 배정을 확대 |
| 참여가 **예상보다 저조** | 전체 당첨 확률을 높여 만족도 향상 |
| **추가 예산 확보** | 신규 리워드 추가 · 최대 당첨 수량 상향 |
| **특정 시간대 참여 집중** | 일시적으로 확률을 조정해 균형 유지 |

### 8-3. 🎡 룰렛 이미지 3종 (핵심)

> 룰렛은 **① 배경 디스크 + ② 휠(n등분) + ③ 핀** 3개 레이어를 겹쳐 구성한다.

| 레이어 | 이름 | 크기 | 설명 |
|---|---|---|---|
| **① 배경 이미지** | `roulette-bg` | **327 × 327** | 룰렛 원판 배경(테두리·바탕). 화면 배경과 별개. |
| **② 룰렛(휠) 이미지** | `Subtract` × N | 원판 지름 ≈ **316** · 배경디스크 안쪽 **5.64px** 여백 | **원을 리워드 개수 N으로 n등분**한 부채꼴 조각. 각 조각에 라벨·이미지. |
| └ 분할 내 리워드 | (라벨+이미지) | 각 조각 중앙 · 방사 방향 회전 | **리워드 라벨**(Pretendard SemiBold **15** · 다크 `#0E1A2B` · center · w91) + **리워드 이미지**(예 항공권 83.3×69.2). |
| **③ 핀 이미지** | `pin` | **25.84 × 17.38** | 휠 **상단 중앙** 포인터(당첨 지시). |

#### ⭐ n등분 규칙 (리워드 개수 = 분할 수) — **가변**

> 룰렛 이미지는 4개 고정이 아니다. **리워드 개수 N에 맞춰 원을 균등하게 n등분**한다.

- **조각 각도 = 360° ÷ N.** 예) **N=3 → 120°씩 3분할** · **N=4 → 90°씩 4분할** · **N=5 → 72°씩 5분할** …
- 각 조각(섹터) **중앙에 리워드 라벨 + 리워드 이미지**를 조각의 방사 방향에 맞춰 회전 배치한다.
- **리워드 개수가 바뀌면 휠 이미지·라벨·이미지·색을 모두 N 기준으로 다시 배치**하고, `4-2. Roulette-reward{N}` 리워드 페이지 수도 N에 맞춘다.
- 현재 템플릿 예시 = **4등분(90°)**, Reward1~4.

#### 🎨 조각 색상 규칙 (메인 색 투명도 단계)

> 각 조각은 **메인 색의 투명도(opacity) 단계**로 칠한다. **인접한 조각이 같은 색이 되지 않도록** 번갈아 적용하는 것이 핵심.

- **필요한 색 수 K** = 인접 조각 색 중복을 피하는 최소 수 → **N이 짝수면 2색 · 홀수면 3색**.
- **투명도 값** = 메인 색 기준, **최대 80%**에서 균등 분포:

  | 등분 수 N | 필요 색 수 K | 메인 색 투명도(%) |
  |---|---|---|
  | 3등분 | 2색 | **40 / 80** |
  | **4등분** | **2색** | **40 / 80** |
  | **5등분** | **3색** | **30 / 55 / 80** |
  | 6등분 | 2색 | 40 / 80 |
  | 7등분 | 3색 | 30 / 55 / 80 |

  > 규칙: **짝수 N → 2색(40 / 80)** · **홀수 N → 3색(30 / 55 / 80)**. (홀수는 원형 배열 특성상 2색이면 시작·끝 조각이 맞닿아 같은 색이 되므로 3색 사용)

- 조각에 **낮은 % → 높은 %** 순으로 번갈아 적용하고, **원형으로 한 바퀴 돌아 첫 조각과 맞닿는 마지막 조각도 다른 색**이 되도록 배치한다.
- 예) 4등분 = `40 · 80 · 40 · 80` / 5등분 = `30 · 55 · 80 · 30 · 55`.
- 라벨·리워드 이미지·텍스트는 조각 색과 무관하게 **다크**(`#0E1A2B`, 밝은 메인 위 가독성) 유지 → §8-2.

- 리워드 이미지 소스 규칙(정보 있으면 thiings.co / 없으면 `#D9D9D9`)은 리워드와 동일 → §3.
- **밝은 메인 컬러(라임 등)** 위 텍스트·라벨은 **다크**(`#0E1A2B`)로 — [[큐알스탬프 솔루션/5. 참조 페이지/5. WORLD PASSPORT (JINAIR).md]] 규칙.

## 9. 전환 플로우 (룰렛 관련) ⭐

### 9-1. 룰렛만 있을 경우

```
스탬프 [리워드 받기]
   → 4-1. Roulette-start
        └ [룰렛 돌리기] → (추첨) → 4-2. Roulette-reward{N}   ← 당첨 리워드 페이지
                                        └ [리워드 받기] → 수령 완료(Done)
```

| 순서 | 화면 | 전환 트리거 |
|---|---|---|
| 1 | `4-1. Roulette-start` (룰렛) | **[룰렛 돌리기]** → 추첨 실행 |
| 2 | `4-2. Roulette-reward{N}` (당첨 리워드) | **[리워드 받기]** → 수령 처리 |
| 3 | `Done` (수령 완료) | — |

- 룰렛을 돌리면 **당첨된 리워드 1종의 리워드 페이지**로 이동 → 그 페이지에서 바로 수령.
- 참조 섹션(Figma): 「룰렛」 `6600:19076`.

### 9-2. 룰렛 + 설문 (둘 다 켜졌을 경우)

> ⭐ **룰렛 → 설문 → 리워드 순**. 룰렛으로 뽑은 리워드를 받으려면 **설문을 먼저 거쳐야** 최종 수령된다.

```
스탬프 [리워드 받기]
   → 4-1. Roulette-start → [룰렛 돌리기] → 4-2. Roulette-reward{N}
        └ [리워드 받기] → (설문으로) → 5-1. Survey-Default → (응답) → 5-2. Survey-Filled
             └ [제출하기] → 5-3. Survey-Reward → [리워드 받기] → 5-4. Survey-Reward done (수령 완료)
```
