# 🎡 2-1-5. 룰렛

> **선택(옵션) 기능** — 기본 4단계 플로우에 추가되는 **리워드 룰렛** 모듈. Easy / Lead 플랜의 **부가 기능(Add-on)**.
> 관련: [[큐알스탬프 솔루션/0. 정의.md]] · [[큐알스탬프 솔루션/2. 작업 가이드/2-1. 페이지 구조/2-1-4. 리워드.md]] · [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]]

> [!important] 이 단계는 **선택(옵션) 기능**입니다.
> 룰렛은 **모든 이벤트에 필수가 아니며**, 이벤트 담당자의 요청에 따라 **포함될 수도, 생략될 수도** 있습니다.
> - **포함 시**: 스탬프 조건 충족 후 **리워드 즉시 지급 대신** 룰렛을 돌려 당첨을 결정 (`… → 스탬프 → 룰렛 → 리워드`)
> - **생략 시**: 기본 플로우 그대로 (`… → 스탬프 → 리워드`)
> 따라서 이 화면은 **이벤트별로 켜고 끌 수 있는 모듈**로 설계한다.

---

## 1. 정의

스탬프를 모두 모은 참여자에게 **룰렛(추첨) 기회를 제공**하여, 확률에 따라 리워드 당첨을 결정하는 단계.
단순 적립·지급이 아니라 **"돌려서 당첨"** 이라는 게임성을 더해 참여 재미와 몰입을 높인다.

> ⭐ **핵심 차별점 — 실시간 확률·수량 조정**
> 행사 시작 **후에도 당첨 확률·최대 당첨 개수를 실시간으로 조정**할 수 있다. 예상 참여와 실제 참여의 괴리를 운영 중에 바로 보정한다.

---

## 2. 실시간 조정 시나리오 (운영 가치)

| 상황 | 조정 |
|---|---|
| 특정 리워드가 **너무 빨리 소진** | 해당 리워드 당첨 확률을 낮춰 인기 분산 |
| 특정 리워드가 **남아돎(미소진)** | 해당 리워드 쪽으로 확률을 옮김 |
| 참여자가 **예상보다 적음** | 전체 당첨 확률을 상향 |
| **추가 예산·경품** 확보 | 신규 리워드·수량을 즉시 반영 |
| **특정 시간대 참여 집중** | 시간대별 당첨 수량·확률 조절 |

## 3. 화면/상태 목록

| 상태(frame) | 설명 |

| `ROULETTE / Default` | 룰렛 진입 — 돌리기 전 대기 (CTA "돌리기" 활성) |

## 4. 표준 구조 (Roulette)

> 배경 = **이벤트 배경 컬러**(선택 팔레트의 `배경`색, 메인 컬러와 한 쌍 → [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-3. 색상팔레트.md]]) · 중앙 정렬 · 좌우 여백 24. 로고·간격 규칙은 시작/리워드와 동일 계열로 맞춘다.

### 4-1. 세로 배치 & 간격 (위 → 아래)

```
상단
 │ 52          ← 상단 여백 (오토레이아웃 top)
로고 (167 × 73 프레임 · 비율유지 contain · 중앙)
 │ 12
타이틀 (룰렛을 돌려 리워드를 받으세요!)
 │ 10
안내문
 │ 35
룰렛 휠 (원형 · 리워드 조각 분할)
 │ 35
CTA 버튼 ("돌리기")
 │ 52          ← 하단 여백 (오토레이아웃 bottom)
하단
```

### 4-2. 영역별 사양

| 영역 | 사양 | 폰트 / 컬러 |
|---|---|---|
| **로고 자리** | **167 × 73 프레임** · 상단 중앙 · 비율유지 contain · 없으면 `#EDEDED` · 규칙 → [[큐알스탬프 솔루션/2. 작업 가이드/2-1. 페이지 구조/2-1-4. 리워드.md\|2-1-4 §2-3]] | — |
| **타이틀** | 중앙 · 줄바꿈 어절 단위 | **48px Bold** · **이벤트 메인 컬러** |
| **안내문** | "스탬프를 모두 모았어요! 룰렛을 돌려보세요." · 너비 327 · 높이 hug | **14px Bold** · `#212529` |
| **룰렛 휠** | 원형 휠 · **리워드 개수만큼 조각 분할** · 조각별 라벨/아이콘 · 중앙 포인터 | 조각 배경 = 메인 컬러/보조 톤 교차 · 라벨 흰 **12~13 Bold** |
| └ **리워드 이미지** | 각 조각 또는 결과 카드에 리워드 이미지 삽입 (참여자 흥미·명확성) | `#D9D9D9` placeholder → thiings.co 규칙 |
| **CTA 버튼** | **327 × 50** · radius **8** | 상태별 (5절) |
| **결과 카드**(Win) | 너비 327 · radius 8 · 배경 메인 컬러 10% · 당첨 리워드 이미지+명 | 리워드 화면(2-1-4)과 동일 톤 |

> 🧩 로고·타이틀·안내문·룰렛·CTA는 **327폭 세로 오토레이아웃 컨테이너(중앙 정렬 · 높이 hug)** 에 담고, 간격은 **상단 52 / 로고→타이틀 12 / 타이틀→안내문 10 / gap 35 / 하단 52**로 시작·리워드와 통일한다.

## 5. 상태별 CTA

| # | 상태 | CTA |
|---|---|---|
| **5-1** | 돌리기 전 (Default) | "돌리기" · **활성**(이벤트 메인 컬러) |
| **5-2** | 회전 중 (Spinning) | 비활성(메인 컬러 30%) · 회전 애니메이션 |
| **5-3** | 당첨 (Win) | "리워드 받기" · **활성** → 리워드 화면 이동 |
| **5-4** | 미당첨 (Lose) | "확인" · 재도전/종료 안내 *(꽝 구성 시)* |

> 버튼 규칙은 스탬프·리워드와 동일 — 활성 = 이벤트 메인 컬러 / 비활성 = 활성 버튼 전체 **opacity 30%** · 텍스트 흰색.

## 6. 🖼 리워드 이미지 규칙

- 룰렛 조각·결과 카드의 리워드 이미지 자리(`#D9D9D9`)는 **리워드 정보가 주어지면** [thiings.co](https://www.thiings.co/things)에서 적합한 이미지를 다운로드해 적용한다.
- 정보가 없으면 **회색(`#D9D9D9`) placeholder 유지**. (→ [[큐알스탬프 솔루션/2. 작업 가이드/2-1. 페이지 구조/2-1-4. 리워드.md]] §4)

## 7. 운영·데이터 (참고)

> 디자인 화면과 별개로, 룰렛은 **운영자용 실시간 통계**를 제공한다 — 디자인 시 결과/공유 화면 설계의 배경으로 참고.

- **실시간 통계 대시보드**: 리워드별 당첨 분포 · 재고(잔여 수량) · 시간대별 참여 추이 · 개별 당첨자 내역 → **Excel 다운로드**
- **운영 대행 지원**: 행사 중 확률·수량 모니터링 및 조정을 제공사가 대신 운영 가능

---

## 8. 디자인 시 체크포인트
- [ ] 룰렛은 **옵션 모듈** — 켜고 끌 수 있게 설계됐는가
- [ ] 돌리기 전 / 회전 중 / 당첨 / 미당첨 **상태별 CTA**가 구분되는가
- [ ] 타이틀·강조어·활성 버튼이 **이벤트 메인 컬러**로 통일됐는가
- [ ] 비활성 버튼 = 활성색 **투명도 30%** 인가
- [ ] 룰렛 조각이 **리워드 개수만큼** 분할되고 라벨/이미지가 명확한가
- [ ] 당첨(Win) 결과가 **리워드 화면(2-1-4)** 으로 자연스럽게 연결되는가
- [ ] 리워드 정보 있으면 thiings.co 이미지 적용, 없으면 회색 유지
- [ ] 간격 준수: **상단 52 / 로고→타이틀 12 / 타이틀→안내문 10 / gap 35 / 하단 52**
