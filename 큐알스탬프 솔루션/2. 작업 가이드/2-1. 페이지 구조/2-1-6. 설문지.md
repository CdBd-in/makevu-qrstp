# 📝 2-1-6. 설문지

> **선택(옵션) 기능** — 스탬프 적립 후 설문을 제시하고 응답을 조건으로 리워드/룰렛 기회를 제공하는 모듈. Easy / Lead 플랜에 **필요에 따라 추가**하는 부가 기능.
> 관련: [[큐알스탬프 솔루션/0. 정의.md]] · [[큐알스탬프 솔루션/2. 작업 가이드/2-1. 페이지 구조/2-1-5. 룰렛.md]] · [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]]

> [!note] 출처·범위 안내
> 1~5절은 [설문 가이드](https://qrstp.mintlify.app/features/survey)에 **명시된 내용**, 6절은 공통 디자인 시스템 적용이다.
> **8절(화면 스펙)·9절(전환 플로우)은 Figma 표준 템플릿(`WORLD PASSPORT` 캔버스 `6388:2`)이 확정되어 실제 수치를 반영한 확정본**이다(현재 예시는 2문항이며 **문항 수는 2·3·4개… 가변**).

---

## 1. 정의 (가이드 명시)

- **스탬프 적립 후** 설문을 제시하여, 응답을 완료하면 **리워드 또는 룰렛(추첨) 기회**를 제공하는 **조건부 리워드** 기능.
- 본인 인증만으로는 얻기 어려운 **상세 고객 정보를 수집** — 만족도 조사·소비자 경험 데이터 확보에 활용.

---

## 2. 질문 유형 & 설정 (가이드 명시)

- **주관식 · 객관식** 질문 가능.
- 객관식은 **여러 답변 동시 선택(다중 선택)** 지원.
- **필수 답변 설정**: 각 질문에 필수 설정을 적용하면 **반드시 답변을 완료해야 설문 제출 가능**.
- **질문 개수 제한 없음**.

---

## 3. 데이터·응답 관리 (가이드 명시)

- **실시간 응답 추적**: 행사 중 응답 수·완료율 확인, **이탈 지점 파악**.
- **Excel 즉시 다운로드** 가능(행사 진행 중에도).
- 객관식 응답은 **시각화**, 주관식 응답은 **별도 가공 없이 즉시 확인** 가능.
- **참여자 식별 연동**: **Lead 플랜** 적용 시 응답에 **이름·연락처를 매칭**.

---

## 4. 퀴즈와의 차이 (가이드 명시)

- **설문**: 모든 스탬프 적립 **이후 한 번** 진행하는 **종합형**.
- **퀴즈**: **각 스탬프 시점마다** 발생하는 응답형 기능.

---

## 5. 제공 범위 (가이드 명시)

- **이지 플랜 · 리드 플랜** 양쪽에 추가할 수 있는 부가 기능.

## 7. 디자인 시 체크포인트
- [ ] 설문은 **옵션 모듈** — 켜고 끌 수 있게 설계됐는가
- [ ] 주관식·객관식(다중 선택) 문항 유형이 컴포넌트로 구분되는가
- [ ] **필수 답변** 문항은 미완료 시 제출이 막히도록 표현됐는가
- [ ] 질문 개수 제한 없이 문항이 반복·확장 가능한 구조인가
- [ ] 공통 디자인 시스템(메인 컬러 · 327 · radius 8 · 버튼 opacity 30%)을 따랐는가
- [ ] (운영) 실시간 응답 추적·Excel 다운로드·Lead 연동 흐름이 반영됐는가

## 8. 화면 스펙 — `5-1. Survey-Default` (Figma 확정본) ⭐

> 표준 템플릿 `WORLD PASSPORT` 기준. 프레임 `5-1. Survey-Default`(`6672:2187`) / `5-2. Survey-Filled`(`6672:2249`). 아트보드 **375 폭 · 높이 가변**(현재 **1056** · 문항 늘면 증가) · **배경 = 풀블리드 이미지**(object-cover).
> ⚠️ **현재 예시 = 객관식 2문항(Q1·Q2) + 주관식 1문항(Q3)**. 문항 수·유형은 제한 없이 늘 수 있다(§2 · 아래 8-4). 문항 유형은 **① 객관식 ② 주관식** 2가지.
> 🆕 **필수 표시 도입**: 필수 문항은 Q번호 옆에 **빨간 `*`**(`#FF6767`)를 붙이고, 헤더 안내문 **"빨간색 * 표시는 필수 표시입니다."** 로 설명한다. (이전 헤더의 리워드 이미지는 제거되고 이 안내문으로 대체됨)
> 색상은 이벤트에 맞춰 치환 — 예시값은 WORLD PASSPORT(메인 라임 `#B0F800` · 다크 배경 · 밝은 메인 위 텍스트=다크 `#0E1A2B` · 필수 표시 `#FF6767`).

### 8-1. 세로 배치 & 간격 (오토레이아웃)

```
상단

[콘텐츠 컨테이너 · 327폭 · 세로 · 중앙정렬 · gap 56]
 ├ 헤더 그룹 (gap 8 · 281폭)
 │    타이틀 "간단한 만족도 조사 참여하고 / 리워드를 받으세요!"
 │     │ 8
 │    안내문 "빨간색 * 표시는 필수 표시입니다."   (회색)
 │ 56
 ├ 객관식 문항 컨테이너 (gap 24)
 │    [객관식 블록] (gap 20)
 │        질문 라벨 그룹 (gap 4):  "Q1." + 빨간 *   /   질문문
 │         │ 20
 │        보기 그룹 (gap 16):  ○ 보기 · ○ 보기 …   (원형 체크박스)
 │     │ 24
 │    [객관식 블록]  (Q2 · 보기 그룹 gap 14)
 │ 56
 ├ [주관식 블록] (gap 20)
 │        질문 라벨 그룹 (gap 4):  "Q3." + 빨간 *   /   질문문
 │         │ 20
 │        입력 그룹 (gap 10):  예시 placeholder(회색) + 밑줄 입력 필드

 └ CTA "제출하기" (327 × 50)
 │ 52            ← 하단 패딩
하단
```

- **패딩**: 좌우 **24** · 상하 **52**. **콘텐츠 gap 56**(헤더 ↔ 객관식 컨테이너 ↔ 주관식 블록 ↔ CTA).
- **헤더 gap 8**(타이틀 ↔ 안내문 · 폭 281). **객관식 문항 컨테이너 gap 24**(문항 ↔ 문항). **문항 내 gap 20**(질문 라벨 ↔ 응답영역). **질문 라벨 gap 4**(Q번호행 ↔ 질문문).
- **객관식**: 보기 gap **16(Q1)/14(Q2)** · 보기 행 내 gap **10**(체크박스 ↔ 라벨). **주관식**: 입력 그룹 gap **10**(예시 ↔ 밑줄 필드).
- ※ 주관식 블록은 객관식 컨테이너 밖 별도 블록으로 배치되어 상위 **gap 56** 간격을 받는다(문항을 한 그룹으로 묶고 싶으면 같은 컨테이너에 gap 24로 넣어도 됨).

### 8-3. 🔘 체크박스 선택 전 / 후 (상태 디자인)

> 보기 체크박스는 **선택 전(미선택)** 과 **선택 후(선택됨)** 두 상태가 있다. (Figma 애셋 실측)

| 상태 | 디자인 | 비고 |
|---|---|---|
| **선택 전(미선택)** | **18 × 18 원형 테두리**(메인 컬러 1.5px, radius 원형) · **내부 비어있음** | `5-1. Survey-Default`는 전부 미선택 |
| **선택 후(선택됨)** | 동일한 원형 테두리 + **중앙에 메인 컬러로 채워진 점**(지름 ≈ 10 / 반지름 5) | 라디오형 비주얼(테두리+중앙 점) |

- 밝은 메인 컬러(라임 등) 배경에서도 테두리·중앙 점 모두 **메인 컬러** 사용(WORLD PASSPORT: `#B0F800`).
- 가이드상 **객관식은 다중 선택 지원**(§2) — 비주얼은 원형이지만 **여러 개를 동시에 채울 수 있다**(라디오 단일선택 아님).
- 하나라도 필수 문항이 선택되면 → `5-2. Survey-Filled`로 전환되며 **제출하기 버튼이 활성**(비활성 opacity 30% → 100%)된다.

### 8-4. 문항 유형 — 객관식 / 주관식

> 문항은 **① 객관식(선택형)** 과 **② 주관식(서술형)** 2가지. 두 유형 모두 상단 **질문 라벨 그룹**(Q번호 17 + 필수면 빨간 `*` + 질문문 17 · gap 4)은 동일하고, 그 아래 **응답 영역만 다르다**(문항 블록 내부 gap 20).

#### ① 객관식 (선택형)

- 응답 영역 = **원형 체크박스 보기 목록** (보기 gap **16(Q1)/14(Q2)** · 보기 행 내 gap 10).
- 보기 행 = 체크박스 **18 × 18**(원형 테두리 메인 1.5px) + 라벨(**Pretendard Medium 16** · white).
- **선택 전/후 상태** = §8-3 (미선택 = 빈 원 / 선택 = 중앙 메인 점). **다중 선택 지원**(§2).
- 예시: **Q1** 만족도(매우 만족/만족/보통/불만족/매우 불만족) · **Q2** 가장 좋았던 점(도시 스탬프 모으는 재미/룰렛 추첨/리워드(경품)/여권 콘셉트 디자인/참여 간편함).

#### ② 주관식 (서술형)

- 응답 영역 = **예시(placeholder) 텍스트 + 밑줄 입력 필드** (입력 그룹 gap **10** · w327).
- **예시 텍스트**: "ex) …" 형식 · **Pretendard Regular 16 · 회색 `#9A9A9A`** · leading 22 (작성 가이드용, 실제 입력 시 대체됨).
- **입력 필드**: 하단 **밑줄(underline) 라인**(옅은 회색 `#C0C0C0` 계열) · 공통 디자인 시스템 입력 필드 사용(→ 2-2-1). 응답 텍스트는 밑줄 위에 표시.
- 예시: **Q3** "진에어 서비스에 바라는 점을 자유롭게 남겨주세요." + ex) 기내 서비스가 개선되었으면 좋겠다.

#### 문항 확장 (개수·유형 가변)

- ⭐ **문항 수·유형은 고정이 아니다** — **객관식·주관식을 자유롭게 섞어 2·3·4개…**로 늘릴 수 있다(가이드상 질문 개수 제한 없음, §2).
- **문항 추가** = 문항 블록(질문 라벨 그룹 + 응답 영역)을 복제해 아래에 붙인다(객관식 = gap 24 컨테이너 내 / 주관식 = 동일 패턴). 프레임 높이는 hug로 자동 증가.
- 현재 예시 = **객관식 2(Q1·Q2) + 주관식 1(Q3)**.

#### ✱ 필수(*) 표시 규칙 🆕

- **필수 문항**은 Q번호 오른쪽에 **빨간 별표 `*`**(**Pretendard Medium 13 · `#FF6767`**)를 붙인다. (Q번호행 = `Q1.` + `*`, 두 요소 나란히 · whitespace-nowrap)
- 화면 상단 헤더 **안내문**으로 의미를 설명한다 → **"빨간색 * 표시는 필수 표시입니다."**(Regular 14 · `#9A9A9A`).
- 선택 문항이면 `*`를 생략한다. 필수 문항이 모두 응답되어야 **제출하기**가 활성(§8-5).
- 현재 예시는 **Q1·Q2·Q3 모두 필수(*)**.

### 8-5. 상태(프레임) 구성

| 프레임 | 역할 | CTA "제출하기" |
|---|---|---|
| `5-1. Survey-Default` | 미응답 (체크박스 전부 미선택) | **비활성**(메인 opacity 30%) |
| `5-2. Survey-Filled` | 응답 완료 (선택된 보기 = 중앙 점 채움) | **활성**(메인 100%) |
| `5-3. Survey-Reward` | 리워드 페이지 | "리워드 받기"(활성) |
| `5-4. Survey-Reward done` | 수령 완료 | "리워드 수령완료"(비활성) |

> ⭐ **필수 문항 미완료 시 제출 비활성**(Default) → 응답 완료 시 활성(Filled). 리워드 페이지(5-3·5-4)는 표준 리워드(2-1-4)와 동일.
> 전환 순서는 아래 **9절** 참고.

## 9. 전환 플로우 (설문 관련) ⭐

> 스탬프를 다 모으고 `3-4. STAMP-RewardDone`의 **[리워드 받기]**를 누른 뒤의 화면 전환. **설문이 켜진 경우 2가지 경로**가 있다.
> (룰렛만 켜진 경로는 → [[큐알스탬프 솔루션/2. 작업 가이드/2-1. 페이지 구조/2-1-5. 룰렛.md]] §9)

![[큐알스탬프 솔루션/attachments/reward-flow-roulette-survey.png]]

### 9-1. 설문만 있을 경우

```
스탬프 [리워드 받기]
   → 5-1. Survey-Default (미응답 · 제출 비활성)
        └ 응답 → 5-2. Survey-Filled (제출 활성)
                    └ [제출하기] → 5-3. Survey-Reward   ← 리워드 페이지
                                       └ [리워드 받기] → 5-4. Survey-Reward done (수령 완료)
```

| 순서 | 화면 | 전환 트리거 |
|---|---|---|
| 1 | `5-1. Survey-Default` (미응답) | 필수 문항 응답 시 → Filled |
| 2 | `5-2. Survey-Filled` (응답 완료) | **[제출하기]**(활성) → 제출 |
| 3 | `5-3. Survey-Reward` (리워드) | **[리워드 받기]** → 수령 처리 |
| 4 | `5-4. Survey-Reward done` (수령 완료) | — |

- 설문 응답을 완료해야 **제출하기**가 활성화된다(비활성 = 메인 opacity 30%). 제출 후 리워드 페이지에서 수령.
- 참조 섹션(Figma): 「설문지」 `6600:20354`.

### 9-2. 룰렛 + 설문 (둘 다 켜졌을 경우)

> ⭐ **룰렛 → 설문 → 리워드 순**. 룰렛(→ [[큐알스탬프 솔루션/2. 작업 가이드/2-1. 페이지 구조/2-1-5. 룰렛.md]] §9)에서 리워드를 뽑고 **[리워드 받기]**를 누르면 설문으로 진입한다.

```
… 4-2. Roulette-reward{N} [리워드 받기]
   → 5-1. Survey-Default → (응답) → 5-2. Survey-Filled
        └ [제출하기] → 5-3. Survey-Reward   ← 리워드 페이지 복귀
                           └ [리워드 받기] → 5-4. Survey-Reward done (수령 완료)
```

- 설문 제출 후 **리워드 페이지로 되돌아와** 다시 **[리워드 받기]**를 눌러야 최종 수령된다(이 경로는 "리워드 받기"를 **2번** 누른다: 룰렛 당첨 후 → 설문 후).
- 참조 섹션(Figma): 「룰렛+설문지」 `6600:18858`.
