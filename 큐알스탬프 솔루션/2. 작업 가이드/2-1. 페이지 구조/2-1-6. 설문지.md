# 📝 2-1-6. 설문지

> **선택(옵션) 기능** — 참여자에게 설문을 제시하고 응답을 조건으로 리워드·추첨을 제공하는 모듈. Easy / Lead 플랜의 **부가 기능(Add-on)**.
> 관련: [[큐알스탬프 솔루션/0. 정의.md]] · [[큐알스탬프 솔루션/2. 작업 가이드/2-1. 페이지 구조/2-1-4. 리워드.md]] · [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]]

> [!important] 이 단계는 **선택(옵션) 기능**입니다.
> 설문지는 **모든 이벤트에 필수가 아니며**, 이벤트 담당자의 요청에 따라 **포함될 수도, 생략될 수도** 있습니다.
> - **포함 시**: 참여 마무리 단계에서 설문을 제시하고, 응답 완료를 조건으로 리워드/추첨 제공 (`… → 스탬프 → 설문 → 리워드`)
> - **생략 시**: 기본 플로우 그대로 (`… → 스탬프 → 리워드`)
> 따라서 이 화면은 **이벤트별로 켜고 끌 수 있는 모듈**로 설계한다.

> [!note] 퀴즈와의 차이
> **퀴즈**는 각 스탬프 적립 포인트에서 트리거되는 반면, **설문**은 참여를 마무리하며 진행하는 **종합 설문**이다. 두 기능은 한 이벤트 안에서 **동시에 운영**될 수 있다.

---

## 1. 정의

참여자에게 **설문(질문지)** 을 제시하여 고객 데이터를 수집하고, 응답을 조건으로 **리워드 지급·추첨 응모** 기회를 제공하는 단계.
수집된 응답은 마케팅·분석에 활용된다.

> ⭐ **핵심 가치 — 실시간 데이터 관리**
> 행사 종료 후 집계를 기다릴 필요 없이, **응답이 몰리는 시간대·이탈 지점을 즉시 파악**한다. 행사 진행 중 **Excel 즉시 다운로드**로 빠른 운영 조정이 가능하다.

---

## 2. 질문 유형 & 설정

| 유형 | 설명 |
|---|---|
| **객관식(단일 선택)** | 보기 중 하나 선택 |
| **객관식(다중 선택)** | 여러 보기 동시 선택 — 더 풍부한 응답 수집 |
| **주관식(서술형)** | 참여자 직접 입력 — 정성 피드백 확보 |

- **질문 개수 무제한** — 이벤트 필요에 따라 자유롭게 구성
- **필수 응답 설정** — 핵심 데이터는 반드시 받도록 필수 지정 가능

## 3. 화면/상태 목록

| 상태(frame) | 설명 |
|---|---|
| `SURVEY / Default` | 설문 진입 — 미응답 상태 |
| `SURVEY / Filled` | 응답 입력 완료 → 제출(CTA 활성) |
| `SURVEY / Error` | 필수 문항 미응답 상태에서 제출 → 해당 문항 Error |
| `SURVEY / Done` | 제출 완료 → 리워드/추첨 안내 연결 |

## 4. 표준 구조 (Survey)

> 배경 = **이벤트 배경 컬러**(→ [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-3. 색상팔레트.md]]) · 좌우 여백 24 · 문항 수에 따라 프레임 높이 **가변(스크롤)**. 입력 필드·체크박스·버튼은 **공통 디자인 시스템** 컴포넌트를 그대로 사용한다.

### 4-1. 세로 배치 & 간격 (위 → 아래)

```
상단
 │ 52          ← 상단 여백
로고 (167 × 73 프레임 · 비율유지 contain · 중앙)
 │ 12

 │ 10
안내문
 │ 35
[ 문항 카드 1 ]
 │ 20
[ 문항 카드 2 ]
 │ 20

 │ 35

 │ 52          ← 하단 여백
하단
```

### 4-2. 영역별 사양

| 영역 | 사양 | 폰트 / 컬러 |
|---|---|---|
| **로고 자리** | **167 × 73 프레임** · 상단 중앙 · 비율유지 contain · 없으면 `#EDEDED` · 규칙 → [[큐알스탬프 솔루션/2. 작업 가이드/2-1. 페이지 구조/2-1-4. 리워드.md\|2-1-4 §2-3]] | — |
| **타이틀** | 중앙 · 줄바꿈 어절 단위 | **48px Bold** · **이벤트 메인 컬러** |
| **안내문** | "간단한 설문에 응답하면 리워드 응모가 완료됩니다." · 너비 327 · 높이 hug | **14px Bold** · `#212529` |
| **문항 카드** | 너비 **327** · radius **8** · 패딩 상하 20 · 내부 gap 10 · 배경 **메인 컬러 10%** · 문항 수만큼 반복 | — |
| └ **질문 텍스트** | 카드 상단 · 필수 문항은 ***(필수)*** 표기 | **16px Bold** · `#212529` · 필수 강조 = 메인 컬러 |
| └ **객관식 보기** | 라디오(단일) / 체크박스(다중) + 라벨 | **14px Medium** · 선택 시 메인 컬러 |
| └ **주관식 입력** | 텍스트 필드(placeholder) · 높이 hug | 입력 `#212529` / placeholder `#9A9A9A` |
| **CTA 버튼** | **327 × 50** · radius **8** · 하단 | 상태별 (5절) |

> 🧩 문항이 늘어도 **세로 오토레이아웃 gap(20)** 으로 간격이 유지되며 높이가 자동 조정된다. 문항 카드를 복제 후 내용만 교체.

## 5. 상태별 CTA & 인터랙션

| # | 상태 | CTA |
|---|---|---|
| **5-1** | 미응답 (Default) | "제출하기" · **비활성**(메인 컬러 30%) |
| **5-2** | 응답 완료 (Filled) | "제출하기" · **활성**(이벤트 메인 컬러) |
| **5-3** | 제출 완료 (Done) | "확인" → 리워드/추첨 안내 이동 |

- **필수 문항 미응답 상태에서 [제출하기] 클릭** → 미응답 문항에 **Error 피드백** 노출.
- 모든 **필수 문항** 충족 시에만 **[제출하기] 활성**.
- 버튼 규칙은 공통 — 활성 = 이벤트 메인 컬러 / 비활성 = 활성 버튼 전체 **opacity 30%** · 텍스트 흰색.

## 6. 데이터 활용 (참고)

> 디자인 화면과 별개로, 설문은 **응답 데이터**를 실시간으로 축적한다 — 화면/연결 설계 배경으로 참고.

- **실시간 응답 관리**: 응답 시간대·이탈 지점 즉시 파악 · 행사 중 **Excel 즉시 다운로드**
- **참여자 식별 연동(Lead 플랜)**: 응답을 참여자 **이름·연락처와 매칭** → 후속 마케팅·분석에 활용
- **퀴즈와 동시 운영 가능** — 퀴즈(스탬프 포인트 트리거) + 설문(종합)

## 7. 디자인 시 체크포인트
- [ ] 설문은 **옵션 모듈** — 켜고 끌 수 있게 설계됐는가
- [ ] 객관식(단일/다중)·주관식 **문항 유형**이 컴포넌트로 구분되는가
- [ ] **필수 문항** 표기 및 미응답 시 Error 피드백이 명확한가
- [ ] 미응답(비활성)/응답완료(활성) **CTA 상태**가 구분되는가
- [ ] 타이틀·강조어·활성 버튼이 **이벤트 메인 컬러**로 통일됐는가
- [ ] 비활성 버튼 = 활성색 **투명도 30%** 인가
- [ ] 문항 수가 늘어도 **오토레이아웃 gap(20)** 으로 간격이 유지되는가
- [ ] 제출 완료(Done)가 리워드/추첨 안내로 자연스럽게 연결되는가
- [ ] 간격 준수: **상단 52 / 로고→타이틀 12 / 타이틀→안내문 10 / 문항 gap 20 / 하단 52**
