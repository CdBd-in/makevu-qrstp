# 🔀 2-1-7. 리워드 전환 플로우 (룰렛·설문 분기)

> **스탬프를 다 모은 뒤 "리워드 받기"를 누른 순간부터 최종 "수령 완료"까지의 화면 전환 규칙.**
> 옵션 모듈(룰렛·설문)이 **켜져 있는지에 따라 3가지 경로**로 갈린다. 이 문서는 각 경로의 **화면 순서·전환 트리거**를 정의한다.
> 관련: [[큐알스탬프 솔루션/2. 작업 가이드/2-1. 페이지 구조/2-1-4. 리워드.md]] · [[큐알스탬프 솔루션/2. 작업 가이드/2-1. 페이지 구조/2-1-5. 룰렛.md]] · [[큐알스탬프 솔루션/2. 작업 가이드/2-1. 페이지 구조/2-1-6. 설문지.md]]

- **Figma 표준 템플릿**: `WORLD PASSPORT` 캔버스(`6388:2`)에 **3가지 경로가 섹션으로 분리**되어 있다.
  - 섹션 **「룰렛」** (`6600:19076`) — 룰렛만
  - 섹션 **「설문지」** (`6600:20354`) — 설문만
  - 섹션 **「룰렛+설문지」** (`6600:18858`) — 둘 다

## 0. 공통 진입점

모든 경로의 시작은 동일하다.

```
… → 스탬프(3-4. STAMP-RewardDone) → [리워드 받기] 클릭 → (아래 경로로 분기)
```

- 스탬프를 조건만큼 모으면 `3-4. STAMP-RewardDone`의 하단 CTA **"리워드 받기"**가 활성화된다.
- 이 버튼을 누른 뒤의 흐름이 **룰렛/설문 옵션 조합**에 따라 달라진다.

---

## 1️⃣ 경로 A — 룰렛만 있을 경우

```
스탬프 [리워드 받기]
   → 4-1. Roulette-start
        └ [룰렛 돌리기] → (추첨) → 4-2. Roulette-reward{N}   ← 당첨 리워드 페이지
                                        └ [리워드 받기] → 수령 완료(Done)
```

| 순서 | 화면 | 전환 트리거 |
|---|---|---|
| 1 | `4-1. Roulette-start` (룰렛) | **[룰렛 돌리기]** → 추첨 실행 |
| 2 | `4-2. Roulette-reward{N}` (당첨 리워드) | **[리워드 받기]** → 수령 처리 |
| 3 | `Done` (수령 완료) | — |

- 룰렛을 돌리면 **당첨된 리워드 1종의 리워드 페이지**(`4-2. Roulette-reward1~N`)로 이동한다.
- 리워드 페이지 레이아웃은 표준 리워드 화면과 동일 → [[큐알스탬프 솔루션/2. 작업 가이드/2-1. 페이지 구조/2-1-4. 리워드.md]].
- 참조 프레임(「룰렛」 섹션): `4-1`(`6600:19384`) · `4-2 reward1~4`(`6600:19437`/`19470`/`19504`/`19538`) · `Done`(`6600:19233`).

---

## 2️⃣ 경로 B — 설문만 있을 경우

```
스탬프 [리워드 받기]
   → 5-1. Survey-Default (미응답 · 제출 비활성)
        └ 응답 → 5-2. Survey-Filled (제출 활성)
                    └ [제출하기] → 5-3. Survey-Reward   ← 리워드 페이지
                                       └ [리워드 받기] → 5-4. Survey-Reward done (수령 완료)
```

| 순서 | 화면 | 전환 트리거 |
|---|---|---|
| 1 | `5-1. Survey-Default` (설문·미응답) | 필수 문항 응답 시 → Filled |
| 2 | `5-2. Survey-Filled` (설문·응답완료) | **[제출하기]**(활성) → 제출 |
| 3 | `5-3. Survey-Reward` (리워드) | **[리워드 받기]** → 수령 처리 |
| 4 | `5-4. Survey-Reward done` (수령 완료) | — |

- 설문 응답을 완료해야 **제출하기** 버튼이 활성화(비활성 = 메인 컬러 opacity 30%)된다.
- 제출 후 리워드 페이지로 넘어가고, 거기서 리워드를 수령한다.
- 참조 프레임(「설문지」 섹션): `5-1`(`6600:20407`) · `5-2`(`6600:20458`) · `5-3`(`6600:20373`) · `5-4`(`6600:20511`).

---

## 3️⃣ 경로 C — 룰렛 + 설문 동시에 있을 경우

> ⭐ **룰렛 → 설문 → 리워드 순**. 룰렛으로 리워드를 뽑고, 그 리워드를 받으려면 **설문을 먼저 거쳐야** 최종 수령된다.

```
스탬프 [리워드 받기]
   → 4-1. Roulette-start
        └ [룰렛 돌리기] → 4-2. Roulette-reward{N}   ← 룰렛 당첨 리워드 페이지
                              └ [리워드 받기] → 5-1. Survey-Default
                                                    └ 응답 → 5-2. Survey-Filled
                                                                └ [제출하기] → 5-3. Survey-Reward   ← 리워드 페이지 복귀
                                                                                   └ [리워드 받기] → 5-4. Survey-Reward done (수령 완료)
```

| 순서 | 화면 | 전환 트리거 |
|---|---|---|
| 1 | `4-1. Roulette-start` (룰렛) | **[룰렛 돌리기]** → 추첨 |
| 2 | `4-2. Roulette-reward{N}` (룰렛 당첨) | **[리워드 받기]** → 설문으로 |
| 3 | `5-1. Survey-Default` (설문·미응답) | 필수 문항 응답 시 → Filled |
| 4 | `5-2. Survey-Filled` (설문·응답완료) | **[제출하기]** → 리워드로 |
| 5 | `5-3. Survey-Reward` (리워드 복귀) | **[리워드 받기]** → 수령 처리 |
| 6 | `5-4. Survey-Reward done` (수령 완료) | — |

- **핵심 차이**: 경로 A·B는 "리워드 받기" 한 번으로 수령이 끝나지만, 경로 C는 **룰렛 당첨 리워드 페이지의 "리워드 받기"가 곧바로 수령이 아니라 설문으로 연결**된다. 설문을 마친 뒤 **리워드 페이지로 되돌아와** 다시 "리워드 받기"를 눌러야 최종 수령된다.
- 참조 섹션(「룰렛+설문지」 `6600:18858`): 룰렛(`4-1`~`4-2 reward1~4`) → 설문조사(`5-1`~`5-4`).
