## 2. 컬러 토큰

> **메인 컬러는 이벤트별로 가변**(리소스 없을 때는 이벤트명·설명에서 추론 → [[큐알스탬프 솔루션/3. 워크플로우.md]]). 기본값은 `#4B73FF`.

| 토큰 | 값 | 용도 |
|---|---|---|
| **main** (이벤트 메인 컬러) | 이벤트별 지정/추론 · 기본 `#4B73FF` | 활성 버튼 · 강조어 · 스탬프 채움 · **스탬프 라벨(이름/번호)** · 핀 라벨 · 타이틀 |
| **main @ 30%** | 메인 컬러 투명도 30% | **비활성 버튼** |
| **main @ 10%** | 메인 컬러 투명도 10% | **카드 배경** |
| **text** | `#212529` / `#111111` | 기본 본문·제목 |
| **text-sub** | `#737D87` | 보조 텍스트·필드 라벨 |
| **placeholder** | `#C0C0C0` | 입력 placeholder · 그리드 점선 구분선 |
| **image-empty** | `#D9D9D9` | 리워드 이미지 placeholder |
| **logo-empty** | `#EDEDED` | 로고 자리 placeholder |
| **background** (페이지) | 팔레트 `배경`색 (이벤트별) | **페이지 전체 배경** — 메인 컬러와 **한 쌍**(→ 2-2-3). 흰색 고정 아님 |
| **white** | `#FFFFFF` | 버튼 위 텍스트 · 밝은 배경 |

## 4. 공통 컴포넌트

| 컴포넌트 | 사양 | 상태/비고 |
|---|---|---|
| **Button (CTA)** | **327 × 50** · radius **8** · 흰 텍스트(20 SemiBold) · 하단 고정 | **활성 = 메인 컬러** / **비활성 = 메인 컬러 30%** |
| **Card** | **327 너비** · radius **8** · 배경 **메인 컬러 10%** · 패딩 20~30 | 시작·리워드 |
| **핀 라벨 (Pill)** | radius **50** · 배경 메인 컬러 · 흰 12 SemiBold + 값 텍스트 | 수령장소·수령기한 등 |
| **리워드 이미지 영역** | `#D9D9D9` placeholder (시작 275×120 / 리워드 275×172) | **thiings.co 규칙**(아래 5절) |
| **로고 자리** | `#EDEDED` placeholder (예 167×73) | 브랜드 로고 없으면 회색 |

| **Checkbox** | 18 × 18 + 라벨 + "자세히"(link_ul) | `Off` · `On`(메인 컬러) |

## 5. 이벤트별 가변값 + 리소스 규칙

- **메인 컬러**: 이벤트별 지정/추론. 모든 버튼·강조·스탬프·핀라벨이 이 색으로 통일.
- **스탬프 칸 수(n)**: DS에서 정하지 않음 — 요청 시 함께 전달(예: 민주평통 16 · 솥바위 3 · 고양 6 · MS 4).
- **리워드 이미지**(`#D9D9D9`): 리워드 정보가 주어지면 **[thiings.co](https://www.thiings.co/things)** 에서 다운로드해 적용, 없으면 회색 유지.
- **로고/배경 비주얼**: 리소스 있으면 배치, 없으면 placeholder(`#EDEDED`)·메인 컬러 기반.

## 6. 사용 원칙

1. 모든 화면 = **375 폭 · 여백 24 · 콘텐츠 327** 골격.
   - 배경은 흰색 고정이 아니라 **선택 팔레트의 `배경`색**(메인 컬러와 한 쌍)을 적용 → 2-2-3.
2. 강조·활성·스탬프·핀라벨·타이틀은 **이벤트 메인 컬러 단일 테마**로 통일 (보조 버튼 포함).
3. **버튼은 327×50 컴포넌트 1개**를 상태만 바꿔 재사용 — 활성(메인) / 비활성(메인 30%).
4. **카드는 327·radius 8·메인 컬러 10%** 한 가지 규격을 재사용.
5. 색·타이포는 **토큰/변수로 적용**(하드코딩 금지).
6. 텍스트 위계: **Display(48) → Title_L(28) → Sub_L(18) → Body(14) → Caption(12)**.
7. **다줄 텍스트 줄바꿈 = 어절(띄어쓰기) 단위.** 어절 중간에서 끊지 않고, 어색하면 어절 경계에 수동 개행. 텍스트 박스는 너비 고정·높이 hug. (상세 → [[큐알스탬프 솔루션/2. 작업 가이드/2-1. 페이지 구조/2-1-1. 시작.md]] §4-4)
