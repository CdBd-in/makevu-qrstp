# ✍️ 2-2-2. 폰트 — 이벤트 컨셉별 선택 가이드

> **이벤트 컨셉에 맞는 폰트를 고를 때의 기준.**
> 적용 규칙(사이즈·위계)은 → [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] · 색상은 → [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-3. 색상팔레트.md]]

---

## 1. 원칙

1. **본문·UI 텍스트 = `Pretendard` 고정** (입력 필드·버튼·설명·라벨·핀 라벨 등). 바꾸지 않는다.
2. **디스플레이 텍스트(이벤트명·"축하합니다!" 등 48px급 큰 제목)만** 컨셉에 맞춰 교체 가능.
3. 디스플레이 폰트도 **한글 지원 · 가독성**을 최우선. **이벤트당 디스플레이 폰트 1종**으로 통일.
4. 리소스(브랜드 지정 폰트)가 있으면 그 폰트 우선.

---

## 2. 컨셉(무드) → 디스플레이 폰트 추천

| 컨셉 / 무드 | 느낌 | 추천 디스플레이 폰트(예) |
|---|---|---|
| 기본 · 모던 · 심플 | 깔끔 · 중립 | **Pretendard** (Bold / ExtraBold) |
| 축제 · 페스티벌 · 팝 | 활기 · 임팩트 | Gmarket Sans, Pretendard Black, 여기어때 잘난체 |
| 럭셔리 · 프리미엄 · 위스키 | 고급 · 우아 | 세리프(명조) — Noto Serif KR, Nanum Myeongjo |
| 전통 · 한국적 | 단아 · 붓 느낌 | 마루부리, 명조 계열 |
| 키즈 · 귀여움 | 친근 · 둥글 | 라운드 산세리프 — Jua, 배민 주아 |
| 레트로 · 빈티지 | 복고 | 슬랩세리프 · 둥근모/픽셀 |
| 자연 · 감성 | 부드러움 | 손글씨 · 명조 혼합 |

> 컨셉 매칭은 **색상 팔레트(2-2-3)의 무드 분류와 동일 기준**을 쓴다.

---

## 3. 선택 절차

1. **이벤트명 + 설명에서 무드 추출** (색상 가이드와 동일한 키워드 분석).
2. 위 표에서 **디스플레이 폰트 후보 1종** 선정 → 사용자 확인.
3. **본문·UI는 Pretendard 유지**.
4. 미정/판단 애매 → **Pretendard(Bold)** 기본 사용.

---

## 4. 체크포인트
- [ ] 본문·UI 텍스트는 Pretendard인가
- [ ] 디스플레이 폰트가 **한글 지원·가독성** OK인가
- [ ] 이벤트당 디스플레이 폰트 **1종**으로 통일됐는가
- [ ] 컨셉(무드)이 색상 팔레트와 일관되는가
