# 🎨 2-2-3. 색상 팔레트 — 이벤트 컨셉별 선택 가이드

> **이벤트 컨셉에 맞는 메인 컬러를 고를 때의 기준.**
> 컬러 토큰·파생·적용 규칙은 → [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] · 폰트는 → [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-2. 폰트.md]]

---

## 1. 원칙

1. 이벤트당 **메인 컬러 1개**를 정한다 (강조어 · 활성 버튼 · 스탬프 · 핀 라벨 · 타이틀에 통일 적용).
2. 파생값 (2-2-1):
   - **카드 배경 = 메인 컬러 10%**
   - **비활성 버튼 = 메인 컬러 30%**
3. **배경은 흰색 기본**, 메인 컬러는 포인트로 사용 (대비·가독성 확보).
4. **리소스(브랜드 컬러)가 있으면 그 값을 우선**, 없으면 아래 추론으로 제안.

---

## 2. 컨셉(무드) → 팔레트

> 이벤트명·설명에서 키워드/계절/무드를 뽑아 매칭. (입력 컬러가 없을 때 클로드가 추론·제안)

| 키워드 / 무드 | 추천 톤 | 예시 hex |
|---|---|---|
| 여름 · 바다 · 쿨 · 워터 | 시원한 블루 · 틸 | `#1E90FF` `#00B5C7` |
| 봄 · 벚꽃 · 플라워 | 핑크 · 라이트그린 | `#FF8FB1` `#8FD694` |
| 가을 · 단풍 | 오렌지 · 버건디 | `#E8743B` `#9B3B3B` |
| 겨울 · 크리스마스 | 레드 · 딥그린 / 아이스블루 | `#C0392B` `#1E6B52` |
| 럭셔리 · 프리미엄 · 위스키 | 딥레드 · 골드 · 블랙 | `#7B1E1E` `#C9A227` |
| 축제 · 페스티벌 · 네온 | 비비드 마젠타 · 퍼플 | `#B5179E` `#7209B7` |
| 미정 / 판단 애매 | DS 기본 | `#4B73FF` |

> 예) "2026 **SUMMER FESTIVAL** / 축제를 즐기고…" → *여름·축제* → 시원한 블루(`#1E90FF`).

---

## 3. 선택 절차

1. **이벤트명 + 설명에서 무드 추출**.
2. 위 표에서 **메인 컬러 후보**를 골라 **hex + 근거**와 함께 제안.
3. 사용자 **확인/수정** → 확정.
4. 확정 색으로 **메인 / 10% / 30%** 파생을 일관 적용 (2-2-1).

---

## 4. 체크포인트
- [ ] 이벤트당 **메인 컬러 1개** 확정됐는가
- [ ] 흰 배경 대비 **충분한 대비(가독성)** 인가
- [ ] 메인 / 카드 10% / 비활성 30% **파생이 일관 적용**됐는가
- [ ] 강조어 · 버튼 · 스탬프 · 핀 라벨 · 타이틀이 **메인 컬러로 통일**됐는가
