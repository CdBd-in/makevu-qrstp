## 0. QR스탬프 적용 규칙 (중요)

QR스탬프 페이지는 **흰 배경 + 이벤트 메인 컬러 포인트** 구조다(→ 2-2-1). 따라서:

1. 아래 팔레트에서 무드에 맞는 1개를 고른 뒤, **`버튼`(포인트) 색을 "이벤트 메인 컬러"로 채택**한다.
2. 채택한 메인 컬러로 **메인 / 10%(카드 배경) / 30%(비활성 버튼)** 파생을 적용(→ 2-2-1).
3. 페이지 배경은 **흰색 기본**. (팔레트의 `배경`색은 풀블리드 비주얼/리워드 카드 등 보조 용도로만 참고)
4. 강조어·활성 버튼·스탬프·핀 라벨·타이틀 = 메인 컬러로 통일.

---

## 1. 역할 매핑 규칙 (팔레트 → QR스탬프)

| 팔레트 색 | QR스탬프 역할 |
|---|---|
| `버튼`(포인트) | **이벤트 메인 컬러** (활성 버튼·강조·스탬프·핀라벨·타이틀) |
| `텍스트` | 본문 텍스트(보통 `#212529`/`#111`) — 흰 배경이면 그대로 |
| `배경` | 풀블리드 비주얼/카드 등 보조 (페이지 기본 배경은 흰색) |

> ⚠️ 보조 텍스트는 `텍스트색 × 60%/40%` 투명도로. AA-Large 등급(3.6~4.5)은 본문 14px 이하 비권장 → 헤드라인·CTA 위주.

## 4. 선택 절차 (QR스탬프)

1. **이벤트명 + 설명에서 무드 추출** (폰트 가이드와 동일 기준).
2. 해당 무드 표에서 **팔레트 1개** 선택 → 그 팔레트의 **`버튼`색을 메인 컬러로** 제안(hex + 근거).
3. 사용자 확인/수정 → 확정.
4. 메인 / 10% / 30% 파생을 일관 적용(→ 2-2-1).
5. 리소스(브랜드 컬러)가 있으면 그 값 우선.

> 미정/판단 애매 → **DS 기본 `#4B73FF`** (프로페셔널/모던 톤).

## 5. 체크포인트
- [ ] 메인 컬러 1개 확정 (팔레트 포인트색 채택)
- [ ] 흰 배경 대비 충분한 대비(가독성)
- [ ] 메인 / 카드 10% / 비활성 30% 파생 일관
- [ ] AA-Large 등급은 본문 14px 이하 비사용(헤드라인·CTA만)
