## 2. 🧊 3D thiings 아이콘

### 2-1. 정의
리워드를 직관적으로 보여주는 **3D 스타일 아이콘**. thiings.co의 일관된 입체 렌더 톤을 사용해 화면 전체의 비주얼 통일감을 유지한다.

### 2-2. 적용 규칙
- **리워드 정보가 주어지면**, Claude가 **[thiings.co](https://www.thiings.co/things)** 에서 주제에 맞는 아이콘을 **검색 → 다운로드 → 해당 영역에 적용**한다.
- 정보가 없거나 적합한 아이콘이 없으면 **회색(`#D9D9D9`) placeholder 유지**.
- 한 이벤트 = **동일 톤(thiings 단일 스타일)** 으로 통일 — 출처가 섞인 아이콘 혼용 ❌
- **단일 아이콘으로 의미가 안 살면 thiings 아이콘 2개 이상을 합성**한다(같은 thiings 톤끼리). 예) **포토카드** = `photo`(카메라) + `card`(카드)를 나란히 합성 → "포토카드" 의미를 명확히. (서로 다른 출처/스타일 혼합 ❌ — thiings끼리만)

### 2-3. 규격 (영역별)

| 적용 위치                 | 영역 크기         | placeholder | 비고              |
| --------------------- | ------------- | ----------- | --------------- |
| **리워드 이미지** (2-1-4)   | **275 × 172** | `#D9D9D9`   | 리워드 카드 내부 중앙    |
| **시작 페이지 리워드 이미지** (2-1-1) | **275 × 120** | `#D9D9D9`   | 이벤트 설명 카드 내부 중앙 |

- 배경 투명(PNG) 권장 — 카드 배경(메인 컬러 10%) 위에 자연스럽게 얹히도록.
- **중앙 정렬** · 아이콘 **비율은 유지한 채 아이콘의 세로 길이를 박스(영역) 높이에 맞춘다**(세로 기준 맞춤 · 가로는 비율대로 따라감).

### 2-4. 다운로드 → 적용 절차
1. 리워드/이벤트 키워드 추출(예: 커피, 케이크, 메달, 티켓).
2. thiings.co에서 검색 → 주제 적합 아이콘 선택.
3. 미디어 폴더로 다운로드(서술형 파일명).
4. 해당 이미지 자리(`#D9D9D9`)에 배치 → 회색 placeholder 대체.

## 3. 🌄 배경 이미지

### 3-1. 정의
페이지 전체에 깔리는 **배경 비주얼**. 흰색 고정이 아니라(→ 2-2-3) 이벤트 무드를 살리되, **텍스트·카드 가독성을 절대 해치지 않는** 은은한 배경으로 사용한다.

### 3-2. 가독성 최우선 원칙 (핵심) ⭐
> 배경의 첫째 조건은 "예쁨"이 아니라 **읽힘**이다. 아래 예시들은 모두 배경이 깔려 있어도 타이틀·본문·CTA가 또렷하게 읽힌다.

- 배경은 **주인공이 아니라 받침** — 타이틀·본문·CTA·핀 라벨이 항상 또렷해야 한다.
- **밝고 은은한 톤 · 낮은 채도** — 콘텐츠보다 튀지 않게.
- **텍스트가 놓이는 영역(중앙)은 비우거나 흐리게** — 패턴·디테일은 가장자리/코너로.
- 배경 위 텍스트 대비 **≥ 3.6:1**(→ 2-2-3). 부족하면 **단색 레이어/오버레이**로 보정.
- 로고·텍스트·워터마크가 배경에 박히지 않게.

### 3-3. 선정 기준 — 3가지 유형
이벤트명·내용에 어울리는 배경을 아래 **세 유형 중 하나**로 선택한다.

#### ① 일러스트 — 이벤트 소재를 묘사한 일러스트
- 전시·행사·장소 등 **이벤트 주제를 그린 평면/아이소메트릭 일러스트**(언덕·풍경·캐릭터 등).
- 채도를 낮춰 배경화 · 콘텐츠 영역은 비움.
- 예: 청주시 청소년의 날(하단 언덕·풀 일러스트 배경)

![[bg-ex-illust-청주.png]]

#### ② 그래픽 이미지 — 도형·라인·패턴 그래픽
- 곡선·물결·도형 등 **추상 그래픽 요소**를 코너/가장자리에 배치, 중앙은 비움.
- 메인 컬러 계열로 통일.
- 예: 송도해상케이블카(물결 라인) · SK on(코너 그래픽 블록)

![[bg-ex-graphic-송도.png]] ![[bg-ex-graphic-skon.png]]

#### ③ 그라데이션 이미지 — 메인 컬러 그라데이션
- 메인/배경 컬러의 **은은한 그라데이션**. 가장 안전(텍스트 가독성 최상).
- 위→아래 또는 코너 방사형 · 단색에 가까운 옅은 톤 권장.
- 예: SIMTOS 2026(초록→크림 그라데이션 배경 · 가운데 아이콘은 콘텐츠)

![[bg-ex-gradient-심토스.png]]

> 세 유형이 모두 애매하면 **③ 그라데이션** 또는 선택 팔레트의 **`배경`색 단색**(→ 2-2-3)이 가장 안전한 기본값.
> (참고: 글렌그란트 예시처럼 **거의 흰색에 가까운 옅은 단색**도 제품/실사 리워드가 주인공일 때 유효)

### 3-4. 공통 가드 (필수)
- 어느 유형이든 **밝고 은은하게** — 콘텐츠보다 튀지 않을 것.
- 3D 아이콘(§2)·메인 컬러와 **같은 무드(저채도)** 로 통일.
- 텍스트·CTA·핀 라벨 영역은 **깨끗하게 비우거나** 오버레이로 대비 확보.

### 3-5. 규격
| 항목 | 값 |
|---|---|
| 적용 폭 | **375**(모바일 세로) · 높이 콘텐츠 가변 |
| 형식 | 그라데이션·그래픽 = PNG / 일러스트 = PNG·SVG |
| 톤 | 선택 팔레트의 `배경`·메인 컬러와 동일 무드 · **저채도** |

### 3-6. 제작 도구 — Google Labs Flow
> 위 3가지 유형(일러스트·그래픽·그라데이션) 배경 이미지는 모두 **[Google Labs Flow](https://labs.google/fx/ko/tools/flow)** 에서 생성한다.

- **도구**: [Google Labs Flow](https://labs.google/fx/ko/tools/flow) — 프롬프트 기반 AI 이미지 생성. 이벤트명·내용을 자연어로 묘사해 배경 컷을 만든다.
- **유형 지정**: 프롬프트에 원하는 스타일을 명시.
  - 일러스트 → `flat illustration` / `isometric illustration`
  - 그래픽 → `abstract graphic shapes` / `wave lines`
  - 그라데이션 → `soft gradient background`
- **공통 필수**: **저채도·은은하게** · 모바일 세로(`9:16`) · **중앙(텍스트 영역) 여백 확보** · **로고·텍스트 배제**(`no text, no logo, no watermark`).
- **가용성**: Google 계정 로그인 필요 · 브라우저에서 생성·다운로드 후 파일명을 키워드로 변경. `/generate-flow-image` 스킬이 설치된 환경에서는 자동 생성 가능.

## 4. 리소스 관리
- 다운로드/생성 이미지는 **미디어 폴더**(`큐알스탬프 솔루션/attachments/`)에 **서술형 파일명**으로 저장.
  - 예: `reward-coffee-thiings.png` · `bg-summer-blue.png`
- 노트에는 Obsidian 임베드(`![[...]]`)로 참조.

## 5. 디자인 시 체크포인트
- [ ] 3D 아이콘은 **thiings.co 단일 톤**으로 통일했는가
- [ ] 리워드 정보 있으면 아이콘 적용, 없으면 `#D9D9D9` 유지
- [ ] 아이콘 영역 비율(리워드 275×172 / 시작 275×120) 준수 · 중앙 정렬
- [ ] 배경은 **일러스트 / 그래픽 / 그라데이션** 3유형 중 이벤트에 맞는 하나로 선택했는가
- [ ] 배경이 **밝고 은은(저채도)** 하며 콘텐츠보다 튀지 않는가
- [ ] 텍스트가 놓이는 영역은 비우거나 흐려 **가독성**을 확보했는가
- [ ] 배경 위 텍스트·CTA·핀 라벨 **대비 ≥ 3.6** 확보(필요 시 오버레이)
- [ ] 이미지는 미디어 폴더에 서술형 파일명으로 저장했는가
