## 2. 🧊 3D thiings 아이콘

### 2-1. 정의
리워드를 직관적으로 보여주는 **3D 스타일 아이콘**. thiings.co의 일관된 입체 렌더 톤을 사용해 화면 전체의 비주얼 통일감을 유지한다.

### 2-2. 적용 규칙
- **리워드 정보가 주어지면**, Claude가 **[thiings.co](https://www.thiings.co/things)** 에서 주제에 맞는 아이콘을 **검색 → 다운로드 → 해당 영역에 적용**한다.
- 정보가 없거나 적합한 아이콘이 없으면 **회색(`#D9D9D9`) placeholder 유지**.
- 한 이벤트 = **동일 톤(thiings 단일 스타일)** 으로 통일 — 출처가 섞인 아이콘 혼용 ❌

### 2-3. 규격 (영역별)

| 적용 위치                 | 영역 크기         | placeholder | 비고              |
| --------------------- | ------------- | ----------- | --------------- |
| **리워드 이미지** (2-1-4)   | **275 × 172** | `#D9D9D9`   | 리워드 카드 내부 중앙    |
| **시작 페이지 리워드 이미지** (2-1-1) | **275 × 120** | `#D9D9D9`   | 이벤트 설명 카드 내부 중앙 |

- 배경 투명(PNG) 권장 — 카드 배경(메인 컬러 10%) 위에 자연스럽게 얹히도록.
- **중앙 정렬** · 아이콘 **비율은 유지한 채 아이콘의 세로 길이를 박스(영역) 높이에 맞춘다**(세로 기준 맞춤 · 가로는 비율대로 따라감).

### 2-4. 다운로드 → 적용 절차
1. 리워드/이벤트 키워드 추출(예: 커피, 케이크, 메달, 티켓).
2. thiings.co에서 검색 → 주제 적합 아이콘 선택.
3. 미디어 폴더로 다운로드(서술형 파일명).
4. 해당 이미지 자리(`#D9D9D9`)에 배치 → 회색 placeholder 대체.

## 3. 🌄 배경 이미지

### 3-1. 정의
페이지 전체에 깔리는 **배경 비주얼**. 흰색 고정이 아니라(→ 2-2-3) 이벤트 무드를 살리는 배경으로 사용한다.

### 3-2. 적용 규칙 (우선순위)
1. **이벤트 배경 리소스 있음** → 그대로 배치(텍스트 가독성 확인).
2. **리소스 없음** → **Google Labs Flow로 실사 배경 이미지를 생성**한다(상세 규칙 → 아래 **3-5**). 단색만으로 충분하면 선택 팔레트의 **`배경`색**(2-2-3)을 그대로 사용.
3. 어느 경우든 **3D 아이콘 톤과 충돌하지 않게** 한다.

### 3-3. 가독성 가드 (필수)
- 배경 위 **본문·제목 텍스트 대비 ≥ 3.6:1** 유지(→ 2-2-3 기준).
- 배경이 복잡하면 카드(메인 컬러 10%)·텍스트 영역에 **단색 레이어/오버레이**로 가독성 확보.
- CTA·핀 라벨(메인 컬러)이 배경에 묻히지 않는지 확인.

### 3-4. 규격
| 항목 | 값 |
|---|---|
| 적용 폭 | **375**(모바일 세로) · 높이 콘텐츠 가변 |
| 형식 | 무손실 PNG / 패턴은 타일 가능하게 |
| 톤 | 선택 팔레트의 `배경`·메인 컬러와 동일 무드 |

### 3-5. 실사 배경 이미지 생성 규칙 — Google Labs Flow

> 배경 리소스가 없을 때 **실사 사진풍 배경**을 직접 생성하는 기준. (출처: cdbd-templates 「1-4. 이미지 → 📦 소스 ②」를 QR스탬프 배경용으로 정리)

**도구**: [Google Labs Flow](https://labs.google/fx/ko/tools/flow) — Veo 모델 기반 AI 이미지/영상 생성. 프롬프트 기반(자연어로 장면·피사체·분위기 묘사).

#### ⓐ 사용 컨텍스트
- ✅ 이벤트 무드를 살리는 **실사 사진풍 배경**(공간·풍경·질감 등)이 필요할 때.
- ✅ 자연광·평범한 환경의 **은은한 배경** — 텍스트·카드가 위에 얹혀도 가독성을 해치지 않는 컷.
- ❌ 상징적 메시지 전달(리워드 아이콘) → **thiings 3D 일러스트**(§2)로 처리. Flow는 배경/실사 전용.

#### ⓑ 선정 기준 (절대 규칙)
| ✅ 반드시 | ❌ 절대 금지 |
|---|---|
| **사실적인 실사** — 다큐/스냅사진 톤 | 연출샷·광고샷 — 인위적 포즈·세팅 |
| 자연광·평범한 환경 | 스튜디오 라이팅·화려한 배경 |
| 깨끗하고 여백 있는 구도(텍스트 얹을 공간) | **로고·텍스트·워터마크 (완전 배제)** |
| 피사체/장면에 집중 | 과장된 카메라 각도·필터 |

> ⚠️ **로고/텍스트 금지**: AI는 텍스트 렌더링이 부정확 → 글자가 들어간 컷은 모두 폐기. 간판·패키지 등에 글자가 보이면 다른 컷으로 교체.

#### ⓒ 프롬프트 작성 원칙
**목표**: "연출되지 않은, 우연히 찍힌 듯한 자연스러운 실사"

| 요소 | 작성 방향 |
|---|---|
| **사진 종류** | `documentary photo`, `candid shot`, `everyday photo` (NOT `professional studio shot`) |
| **광원** | `natural daylight`, `window light`, `overcast soft light` (NOT `dramatic lighting`) |
| **앵글** | `eye-level`, `slight angle`, `casual framing` (NOT `dramatic low angle`) |
| **배경** | `plain background`, `simple interior`, `blurred neutral background` (텍스트 얹을 여백 확보) |
| **무드** | `unposed`, `natural`, `realistic`, `not staged` |
| **비율** | 배경은 **모바일 세로(375 폭)** 에 맞춰 `9:16` 등 세로형 / 카드 내부용은 `1:1` |
| **금지어** | `no text`, `no logo`, `no watermark`, `no captions`, `blank surfaces` |

#### ⓓ 프롬프트 예시
**좋은 예시:**
```
An everyday, documentary-style photo of a softly blurred plain interior wall 
in warm natural daylight, lots of empty negative space, eye-level angle. 
Unposed, realistic, not staged. 9:16 vertical aspect ratio. 
No text, no logos, no watermarks anywhere.
```

**나쁜 예시 (피할 것):**
```
❌ Beautiful professional studio background with dramatic lighting
❌ Vibrant promotional poster with elegant gold logo and text
❌ Stylish staged scene with branded props
```

#### ⓔ 가용성 메모
- Flow는 **Google 계정 로그인 필요** · 자동화 어려움 → 브라우저에서 **수동 생성·다운로드** 후 파일명만 키워드로 변경.
- `/generate-flow-image` 스킬은 환경에 따라 미설치일 수 있음 — 설치된 워크스테이션에서만 자동 생성 가능.
- 대안(실사 fallback): 범용 라이프스타일은 [Unsplash](https://unsplash.com/) stock, 특수 컨텍스트는 OpenAI `gpt-image-1` 생성도 가능(cdbd-templates 1-4 참고).

## 4. 리소스 관리
- 다운로드/생성 이미지는 **미디어 폴더**(`큐알스탬프 솔루션/attachments/`)에 **서술형 파일명**으로 저장.
  - 예: `reward-coffee-thiings.png` · `bg-summer-blue.png`
- 노트에는 Obsidian 임베드(`![[...]]`)로 참조.

## 5. 디자인 시 체크포인트
- [ ] 3D 아이콘은 **thiings.co 단일 톤**으로 통일했는가
- [ ] 리워드 정보 있으면 아이콘 적용, 없으면 `#D9D9D9` 유지
- [ ] 아이콘 영역 비율(리워드 275×172 / 시작 275×120) 준수 · 중앙 정렬
- [ ] 배경은 흰색 고정이 아니라 **선택 팔레트 `배경`색/메인 컬러 기반**인가
- [ ] 배경 위 텍스트·CTA·핀 라벨 **대비 ≥ 3.6** 확보(필요 시 오버레이)
- [ ] 이미지는 미디어 폴더에 서술형 파일명으로 저장했는가
