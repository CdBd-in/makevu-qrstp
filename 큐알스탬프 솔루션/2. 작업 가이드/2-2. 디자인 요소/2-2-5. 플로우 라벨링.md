# 🏷️ 2-2-5. 플로우 라벨링

> 매 이벤트 제작 시, 각 화면 프레임 **위에 사각형 라벨**을 얹어 **어느 단계·어떤 상태인지 한눈에** 보이게 하는 정리용 주석 규칙.
> 관련: [[큐알스탬프 솔루션/2. 작업 가이드/2-1. 페이지 구조/2-1-1. 시작.md]] · [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]]

> [!important] 🤖 Claude 필수 규칙
> 큐알 이벤트 페이지를 **만들 때마다**, 각 화면 프레임 위에 아래 규칙대로 **플로우 라벨을 함께 생성**해야 한다. 라벨은 화면 구성요소가 아니라 **캔버스 정리·플로우 파악용 주석**이며, 실제 참여자에게 노출되지 않는다.
> 기준 캔버스: `WORLD PASSPORT` (`6388:2`).

![[큐알스탬프 솔루션/attachments/flow-labeling-spec.png]]

---

## 1. 구조 — 2단 라벨

라벨은 프레임 **위쪽에 2단(層)** 으로 쌓는다.

| 단(層) | 이름 | 역할 | 텍스트 | 폭 |
|---|---|---|---|---|
| **상단** | **단계 라벨**(보라) | 이 화면이 속한 **큰 단계(Step)** 표시 | 한글 단계명 (시작·인증·스탬프·룰렛·설문조사·리워드) | **단계 그룹 전체를 가로로 덮음** (그룹 첫 프레임 좌측 ~ 마지막 프레임 우측) |
| **하단** | **상태 라벨**(파랑) | 그 단계 안에서 이 화면의 **세부 상태(State)** 표시 | 상태명 (Default·Filled·1/n 적립·Reward1 등) | **프레임 1개 폭(375)** · 프레임과 좌우 정렬 |

> ⭐ 단계 라벨 1개가 **여러 상태 라벨을 위에서 덮는** 형태다. (예: `스탬프` 보라 라벨 하나 아래 `Default / 1/n 적립 / n/n 적립 / 리워드 Done` 파랑 라벨 4개)

---

## 2. 스타일 토큰 (고정)

> 색은 **라벨 전용 고정색**이다. 이벤트 메인 컬러로 바꾸지 않는다 (참여자 비노출 주석이므로).

### 2-1. 단계 라벨 (보라)
| 속성 | 값 |
|---|---|
| 배경 | **`#462CD9`** (보라) |
| radius | **20** |
| 패딩 | **좌우 48 · 상하 32** |
| 높이 | **148** (고정) |
| 폭 | 단계 그룹 전체 폭 (2절 3항) |
| 폰트 | **Pretendard Bold · 60px** · white · 중앙 정렬 · leading 1.4 |

### 2-2. 상태 라벨 (파랑)
| 속성 | 값 |
|---|---|
| 배경 | **`#547CFF`** (파랑) |
| radius | **20** |
| 패딩 | **좌우 40 · 상하 24** |
| 높이 | **104** (고정) |
| 폭 | **375** (프레임과 동일) |
| 폰트 | **Pretendard Bold · 40px** · white · 중앙 정렬 |

## 3. 배치 규칙 (좌표)

프레임을 `x`(좌측), `y=725`(상단) 기준으로 놓았을 때:

```
y=338  ┌───────────────── 단계 라벨 (보라 · 높이 148) ─────────────────┐
        │  그룹 전체 폭을 덮음 (첫 프레임 좌 ~ 마지막 프레임 우)          │
       └──────────────────────────────────────────────────────────────┘
          │ 40  (gap)
y=526  ┌── 상태 라벨 ──┐  ┌── 상태 라벨 ──┐  ┌── 상태 라벨 ──┐   (각 375 · 높이 104)
        │   Default    │  │  1/n 적립     │  │  n/n 적립     │  …
       └──────────────┘  └──────────────┘  └──────────────┘
          │ (프레임 상단 정렬)
y=725  ┌── 화면 프레임 ┐  ┌── 화면 프레임 ┐  ┌── 화면 프레임 ┐   (각 375)
```

- **단계 라벨 y = 338**, 높이 148 → 하단 486.
- **상태 라벨 y = 526**, 높이 104 → 단계 라벨과 **gap 40**.
- **화면 프레임 y = 725**.
- **프레임 간 가로 간격 = 100** (프레임 375 + gap 100). → 단계 라벨 폭 = `프레임수 × 375 + (프레임수−1) × 100`.
  - 예) 2프레임(인증) = 850 · 4프레임(스탬프) = 1800 · 5프레임(룰렛) = 2275.
- **상태 라벨 x = 대응 프레임 x** (완전 좌우 정렬).

### 3-1. 단계에 화면이 1개뿐일 때 (예: 시작)
- 상태 라벨을 **따로 두지 않고**, 단계 라벨(보라) **한 개만** 둔다.
- 이때 보라 박스 크기 = **375 × 292** (`y=338`, 두 단 높이를 합친 만큼) · 텍스트는 **세로 중앙**.
- 색·폰트는 단계 라벨과 동일(`#462CD9` · Pretendard Bold 60).

## 4. 라벨 텍스트 사전 (WORLD PASSPORT 기준)

> 프레임 레이어명의 **숫자 접두어(1·2-1·3-1…)** 와 라벨을 짝지어 쓴다. 상태 라벨 텍스트는 이벤트에 맞게 조정 가능하되, 아래를 기본으로 한다.

| 단계 라벨(보라) | 프레임(레이어명) | 상태 라벨(파랑) |
|---|---|---|
| **시작** | `1. Start` | *(단독 → 상태 라벨 없음)* |
| **인증** | `2-1. LOGIN-Default` | Default |
| | `2-2. LOGIN-Filled` | Filled |
| **스탬프** | `3-1. STAMP-Default` | Default |
| | `3-2. STAMP-1/n` | 1/n 적립 |
| | `3-3. STAMP-n/n` | n/n 적립 |
| | `3-4. STAMP-RewardDone` | 리워드 Done |
| **룰렛** | `4-1. Roulette-start` | Start |
| | `4-2. Roulette-reward1~4` | Reward1 · Reward2 · Reward3 · Reward4 |
| **설문조사** | `5-1. Survey-Default` | Survey-default |
| | `5-2. Survey-Filled` | Survey-filled |
| | `5-3. Survey-Reward` | Reward |
| | `5-4. Survey-Reward done` | Reward-Done |

> **단계 순서**는 이벤트 구성(옵션 포함/생략)에 따라 달라진다 — 인증·룰렛·설문은 선택. 포함된 단계만 왼쪽→오른쪽 순으로 라벨링한다.
> 리워드가 룰렛/설문과 분리된 별도 그룹일 땐 단계 라벨 **`리워드`** 를 추가로 쓴다(전환 플로우 → [[큐알스탬프 솔루션/2. 작업 가이드/2-1. 페이지 구조/2-1-5. 룰렛.md]] §9 · [[큐알스탬프 솔루션/2. 작업 가이드/2-1. 페이지 구조/2-1-6. 설문지.md]] §9).

## 5. 제작 순서 (Claude용)

1. 화면 프레임들을 **왼쪽→오른쪽, 플로우 순서**로 `y=725`에 나열(간격 100).
2. 같은 단계 프레임들을 묶어 **그 위(`y=338`)에 보라 단계 라벨** 1개를 그룹 폭만큼 배치.
3. 각 프레임 위(`y=526`)에 **파랑 상태 라벨**을 프레임과 좌우 정렬해 배치.
4. 화면이 1개뿐인 단계(시작 등)는 **3-1항**대로 보라 라벨만 375×292로.
5. 라벨 텍스트는 **4절 사전** 기준으로 채운다.

---

## 6. 체크포인트
- [ ] 모든 화면 프레임 위에 **단계(보라)+상태(파랑)** 라벨이 있는가
- [ ] 단계 라벨이 **그룹 전체 폭**을 덮고, 상태 라벨이 **프레임과 좌우 정렬**됐는가
- [ ] 색·radius·폰트가 고정값(보라 `#462CD9`/60px, 파랑 `#547CFF`/40px, radius 20)인가
- [ ] 화면 1개짜리 단계는 보라 라벨 **단독(375×292)** 으로 처리했는가
- [ ] 라벨색을 이벤트 메인 컬러로 **바꾸지 않았는가** (전용 고정색 유지)
- [ ] 포함된 단계만, 플로우 순서대로 라벨링됐는가
