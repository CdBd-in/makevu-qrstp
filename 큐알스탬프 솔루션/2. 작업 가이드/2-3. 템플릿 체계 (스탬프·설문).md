# 🧩 2-3. 템플릿 체계 (스탬프·설문)

> 이벤트마다 레이아웃을 **즉석 제작**하다 품질이 무너지는 문제(예: 여권도장 대비 **C안 루트맵 붕괴**)를 막기 위해, **검증된 레이아웃을 템플릿으로 규격화**하는 기준 문서.
> 관련: [[큐알스탬프 솔루션/2. 작업 가이드/2-1. 페이지 구조/2-1-3. 스탬프.md]] · [[큐알스탬프 솔루션/2. 작업 가이드/2-1. 페이지 구조/2-1-6. 설문지.md]] · [[큐알스탬프 솔루션/3. 워크플로우.md]] · 참조 종합 [[컨텍스트: 강현이/강현이-2026-07-07.md]]

> [!note] 이 문서의 위치
> **설계안(기준)** 문서다. 실제 Figma 템플릿 컴포넌트는 **아직 만들지 않았고**, 아래 로드맵(7절)에 따라 제작한다.

---

## 1. 배경 — 왜 템플릿을 늘리는가

- 현재 [[큐알스탬프 솔루션/2. 작업 가이드/2-1. 페이지 구조/2-1-3. 스탬프.md]]는 **2열 격자 골격 1종 + 칸(셀) 4유형**만 정의 → **3~8칸 격자만** 잘 커버.
- **격자로 안 풀리는 배치**(여정/지도·대형 10칸+·특수)는 **검증 템플릿이 없어 매번 즉석 제작** → **C안 루트맵처럼 품질 붕괴**.
- 해법: **"칸 비주얼은 커스텀, 레이아웃 골격은 템플릿"** 으로 분리하고, 빠진 레이아웃 아키타입을 **완성형 템플릿**으로 채운다.

---

## 2. 데이터 근거 (참조 이벤트 57개 집계)

### 스탬프 개수 분포 — 규모 파라미터(축2)의 분포

| 개수 | 3 | 4 | **5** | 6 | 7~8 | 10~14 | 17~67 | 0(미션) |
|---|---|---|---|---|---|---|---|---|
| 건수 | 6 | 10 | **16** | 7 | 4 | 6 | 3 | 2 |

- **3~6칸 = 39건(68%)** · 그중 **5칸 최다(16건)**.
- **10칸+ = 9건** — 지도·여정·스크롤형(강진·연천·청년정책넷·경기수의67 등).
- `stamp_type` **single 48/57(84%)** = 개별 칸형 압도적. 나머지(map-route·crossword·mission·image-card)는 소수 특수.
- `has_auth` **true 32 / false 24** → 인증은 on/off 모듈(기존 문서화).

## 3. 분류 원칙 — MECE ⭐

> [!important] MECE 점검으로 축 재정리 (2026-07-08)
> 이전 안은 **상호배타(ME) 위반**이 있었다 → 아래처럼 **직교 축**으로 재정리.
> - **스탬프 위반**: 개수 구간 겹침(n=5 → G·P·R 동시) + "정형 배열(G·P·S)"과 "경로 메타포(R)"라는 **다른 축을 한 줄에** 나열 + n=0·특수 누락(CE 미달).
> - **설문 위반**: 라인·면처리 = **보기(낱개) 배경** 축 / 카드 = **문항(묶음) 컨테이너** 축 → **레벨 불일치**(카드+면처리 동시 성립).

**공통 원칙**: **뼈대(배열/컨테이너)는 ME·CE 아키타입으로 · 비주얼(셀/보기 스타일)은 직교 스왑축으로 · 규모(개수·문항수)는 축이 아니라 파라미터로.**

| 역할 | 스탬프 | 설문 |
|---|---|---|
| **뼈대 축 (ME·CE)** | 배열 아키타입 (§4-1) | 문항 컨테이너 (§5-1) |
| **비주얼 축 (직교)** | 셀 4유형 (§4-3) | 답변 배경 (§5-2) |
| **파라미터 (축 아님)** | 개수 n → 행수·스크롤 | 문항 수·유형 |
| **조합 요소 (직교)** | — | 질문번호·필수·주관식필드·테마 (§5-3) |

→ `뼈대 아키타입 × 비주얼 스왑`으로 조립. 새 이벤트 = **골격 복제 + 비주얼만 교체**.

## 4. 스탬프 템플릿 기준 (MECE)

### 4-1. 축1 · 배열 아키타입 (ME·CE — 한 이벤트 = 정확히 하나)

| 아키타입 | 정의 | 규모/변형(축2) | 대표 참조 | 우선 |
|---|---|---|---|---|
| **A. 정형 배열형** | 규칙적 격자·대칭 배치 | 정렬(2열 좌측 / 중앙 대칭) × 규모(표준 hug / 대형 스크롤) | WORLD PASSPORT · 경기수의 · 송도 · 강진 | **P0** |
| **B. 경로형** | 여정 라인/지도 위 순번 배치 | 핀 수(4~10) · 경로 곡률 | 청년정책넷 · 은평구 · 횡성 | **P0** (C안 빈틈) |
| **C. 특수형** | 비정형(원형 링·1행·겹침·콜라주) | — | TCTAP · 쿠키런 · ITZY | P2 (가이드 커스텀) |
| **D. 무(無)스탬프** | 스탬프 그리드 없음(미션/공유) | — | 티쏘 · 불가리 포스트카드 | 해당 없음 |

> **A/B/C/D는 서로 겹치지 않고(ME) 모든 스탬프 페이지를 덮는다(CE).** 이전 **G·P·S = 전부 A의 변형**(정렬·규모 파라미터), **R = B**.

### 4-2. 축2 · 규모(개수 n) = 파라미터 (별도 템플릿 아님)
- A·B 안에서 **행수·스크롤·정렬**만 바꾸는 변수. n=3~8 표준 hug / n≥10 대형 스크롤 / 홀수 = 마지막행 좌측만 or 중앙 대칭.
- 규격: 2열 · 칸 100×100 · 열간격 63.5 · 행간격 40 · 점선 구분선 · 높이 hug (= [[큐알스탬프 솔루션/2. 작업 가이드/2-1. 페이지 구조/2-1-3. 스탬프.md]] §2-4).

### 4-3. 축3 · 셀(칸) 4유형 = 직교 스왑
- ①텍스트만 ②이미지+텍스트 ③이미지만 ④이미지+하단라벨 (→ 2-1-3 §2-6). **배열 아키타입과 무관하게 스왑.**
- ⚠️ 4유형은 {이미지 유무}×{텍스트 배치}의 **큐레이션 조합**이라 엄밀 MECE는 아님 — 실무 카탈로그로 취급(확장 가능).

### 4-4. 프리셋 (구 G·P·R·S 매핑)
| 프리셋 | 아키타입 | 파라미터 | 우선 |
|---|---|---|---|
| **G. 표준 격자** | A | 2열 좌측 · 표준 hug (n 3~8) | P0 (정형화) |
| **P. 중앙 피라미드** | A | 중앙 대칭 (n 3·5) | P1 |
| **S. 대형 스크롤/도감** | A | 2열 · 스크롤 (n≥10) | P1 |
| **R. 여정 루트** | B | 경로 (n 4~10) | **P0** |

> ⚠️ **R(경로형) 규격**: 다크/맵 패널 + 곡선 경로(점선) + 순번 핀 + 랜드마크 슬롯 + 진행 상태(inactive 회색 → active 메인). 핀·경로·라벨을 **규격 좌표로 고정**(C안 실패 교훈 — 즉석 배치 금지), 랜드마크는 셀 유형으로 스왑.

## 5. 설문 템플릿 기준 (MECE — 직교 2축)

> ⚠️ 설문 템플릿은 **문항 수가 아니라 디자인**으로 가른다. 단, 이전 안(라인/면처리/카드 1줄 나열)은 **레벨이 섞여** ME 위반이었다 → **직교 2축**으로 분리한다. (문항 수·유형은 파라미터)

### 5-1. 축1 · 문항 컨테이너 (ME — 문항 묶음을 어떻게 감싸나)

| | 정의 | 대표 |
|---|---|---|
| **플랫** | 문항별 컨테이너 없음 (질문+보기 나열) | 진에어 · 은평구 |
| **카드** | 문항별 화이트 카드 (radius 12 + drop-shadow) | 삼양 CRAVE LAB(퀴즈) |

### 5-2. 축2 · 답변(보기) 배경 (ME — 보기 낱개의 배경 처리)

| | 정의 | 대표 |
|---|---|---|
| **라인** | 배경 없음 · 원형 라디오 + 텍스트 | 진에어 · TGG |
| **면처리** | 채움 라운드 박스 (연한 톤 fill) | 은평구 감탄한바퀴 (`5876:2308`) |
| **아웃라인** | 테두리만 있는 박스 (fill 없음) | (카탈로그 확장 대상) |

> **축1 × 축2 는 직교** — "카드 + 면처리 보기"도 성립한다. 그래서 **이전 안의 '카드형'은 라인/면처리와 같은 레벨이 아니라** 다른 축(문항 컨테이너)이었다.

![[큐알스탬프 솔루션/attachments/survey-answer-styles.png]]
*(좌 진에어 = 플랫 × 라인 / 중 은평구 = 플랫 × 면처리 / 우 삼양 = 카드 × 라인)*

### 5-3. 축3 · 조합 요소 (직교 — 어느 조합에나 스왑)
- **질문 번호**: `Qn.` 텍스트(진에어·TGG) / **원형 뱃지 ①②③**(은평구).
- **필수 표시**: 빨간 `*`(`#FF6767`) + 헤더 안내문 (→ [[큐알스탬프 솔루션/2. 작업 가이드/2-1. 페이지 구조/2-1-6. 설문지.md]] §8-4).
- **주관식 필드**: 밑줄형(진에어) / 박스형(테두리).
- **테마**: 다크(라인 궁합) / 라이트(면처리·카드 궁합).

### 5-4. 프리셋 (문항 컨테이너 × 답변 배경)
| 프리셋 | 조합 | 대표 |
|---|---|---|
| **진에어형** | 플랫 × 라인 | WORLD PASSPORT |
| **은평구형** | 플랫 × 면처리 | 감탄한바퀴 |
| **삼양형** | 카드 × 라인 | CRAVE LAB(퀴즈) |

> **문항 블록 컴포넌트**(`객관식-단일`·`객관식-다중`·`주관식`)를 **축2(답변 배경)별 variant**로 두고, 문항 수·유형은 자유 조립(파라미터). 새 답변 스타일(칩/버튼·이미지 보기 등)은 축2에 값으로 추가(카탈로그 확장).

## 6. 선택 의사결정 트리

```
[스탬프] 배열 아키타입? (넷 중 하나 — ME)
 ├ 규칙 격자/대칭      → A 정형배열형 → 규모 n: 3~8 표준 · ≥10 스크롤 · 대칭이면 피라미드
 ├ 여정/지도 스토리    → B 경로형 → 핀 4~10
 ├ 비정형(원형/1행/겹침) → C 특수형 (가이드 커스텀)
 └ 스탬프 없음(미션/공유) → D 무스탬프
        → 셀 = 4유형 중 브랜드 모티프 (2-1-3 §2-6)

[설문] 두 축을 각각 선택 (직교)
 · 문항 컨테이너: 플랫 / 카드
 · 답변 배경:     라인 / 면처리 / 아웃라인
        → 조합요소(질문번호·필수·주관식필드·테마) + 문항 자유 조립

[공통 옵션] 인증(on/off) · 리워드 · 룰렛 · 설문
```

## 7. 제작 로드맵 (우선순위)

> 모두 **Figma 컴포넌트·variant**로 **"템플릿" 전용 페이지/섹션**에 보관 → 이벤트는 복제해 사용. **현재 상태 = 전부 미제작(설계안).**

> [!important] 우선순위 = "제작 순서"이지 "중요도/필요 여부"가 아니다
> **모든 아키타입·프리셋(A·B·C + 설문 조합)은 결국 다 만든다.** P0/P1/P2는 **어떤 순서로 만들지**를 정한 것일 뿐, P1·P2가 불필요하다는 뜻이 아니다. 순서는 아래 3기준으로 정했다:
> - **① 공백(gap)**: 지금 없어서 즉석 제작→붕괴하는 것부터 → **R(여정 루트)**. (C안 실패 지점)
> - **② 빈도(coverage)**: 가장 자주 쓰는 것 → **G(3~8칸, 68%)**. 단 이미 골격이 있어 **정형화(승격)만** 하면 됨(제작 부담 작음).
> - **③ ROI/대체가능성**: 다른 템플릿으로 임시 대체 가능하면 후순위. 예) **P(피라미드)**=G의 홀수처리로 부분 대체 가능 → P1 / **S(대형 10+, 9건·16%)**=빈도 낮음 → P1 / 특수(원형·1행·겹침, 1~2건)=희소 → P2.
>
> 즉 **R을 "먼저"** 라 한 건 *유일한 P0*이라서가 아니라(G·설문유형1도 P0), **없는 걸 새로 만들어야 하고 C안 재발 방지가 급해서**다.

- [ ] **P0 · B 경로형(R 여정 루트)** — C안 빈틈 대체. 규격 좌표·경로·핀·진행상태 확정 후 컴포넌트화.
- [ ] **P0 · A 정형배열형 기본(G 표준 격자) 정형화** — 2-1-3 §2-4를 템플릿 컴포넌트로 승격(홀수 처리 포함).
- [ ] **P0 · 설문 플랫 × 라인(진에어형)** + 문항 블록 3종 컴포넌트 (이미 존재 → 정형화).
- [ ] **P1 · A 변형(P 피라미드 · S 대형 스크롤) · 설문 플랫 × 면처리(은평구형)**.
- [ ] **P2 · 설문 카드 × 라인(삼양형) · C 특수형 가이드**(원형/1행/겹침 = 템플릿 없이 커스텀).

## 8. 원칙 요약 (MECE)
- **뼈대는 ME·CE 아키타입, 비주얼은 직교 스왑, 규모는 파라미터.** (§3)
- **스탬프 배열 = A/B/C/D 중 정확히 하나** (정형·경로·특수·무스탬프). G·P·S는 A 변형, R은 B.
- **설문 = 문항 컨테이너(플랫/카드) × 답변 배경(라인/면처리/아웃라인) 직교** — 카드는 라인/면처리와 다른 축.
- **여정은 경로형(B) 템플릿으로** — C안 같은 즉석 제작 재발 방지.
- 특수(C)·무스탬프(D)는 템플릿화 대신 **가이드 커스텀 / 해당 없음**.
