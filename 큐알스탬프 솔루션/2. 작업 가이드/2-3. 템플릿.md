# 🧩 2-3. 템플릿

> 이벤트마다 레이아웃을 **즉석 제작**하다 품질이 무너지는 문제를 막기 위해, 검증된 스킨을 **3개 템플릿 유형(기본형·박스형·라인형)으로 규격화**하고 **어드민에서 1택**해 4개 페이지(인증·스탬프·설문·룰렛)에 일관 적용한다.
> 관련: [[큐알스탬프 솔루션/2. 작업 가이드/2-1. 페이지 구조/2-1-3. 스탬프.md]] · [[큐알스탬프 솔루션/2. 작업 가이드/2-1. 페이지 구조/2-1-5. 룰렛.md]] · [[큐알스탬프 솔루션/2. 작업 가이드/2-1. 페이지 구조/2-1-6. 설문지.md]] · [[큐알스탬프 솔루션/3. 워크플로우.md]] · 단일 출처 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]]

> [!warning] ⚠️ 유형명 변경 · 이름 매핑 (혼동 주의)
> 유형 이름을 더 직관적으로 정리했다. **본 문서는 새 이름을 쓴다.** Figma 프레임명은 아직 기존 이름이므로 아래 매핑을 참고할 것.
>
> | 새 이름 (본 문서) | 기존 이름 · Figma 프레임 | 한 줄 성격 |
> |---|---|---|
> | **기본형** | 라인형 (Figma `A. 라인형_*`) | 원래 있던 기본 레이아웃 |
> | **박스형** | 박스형 (Figma `B. 박스형_*`) | 면이 들어간 유형 |
> | **라인형** | 테두리형 (Figma `C. 테두리형_*`) | 선(테두리)이 많이 쓰인 유형 |
>
> 🔴 **교차 주의**: Figma의 `A. 라인형`은 본 문서의 **기본형**이고, 본 문서의 **라인형**은 Figma `C. 테두리형`이다. "라인형"이라는 단어가 가리키는 대상이 Figma와 문서에서 서로 다르다.

> [!note] 이 문서의 위치
> Figma **「QR 템플릿」 페이지**(node `6814-37175`)에 실제 구성된 템플릿을 기준으로 정리한 **규격 문서**다. 페이지에는 `A / B / C` 세 섹션(현 Figma 프레임명 `A. 라인형 / B. 박스형 / C. 테두리형` = 본 문서의 **기본형 / 박스형 / 라인형**)이 각각 **인증·스탬프·설문·룰렛 프레임 세트**로 구성돼 있고, 우측에 **「어드민 추가」 섹션**(색상·배경 설정 UI)이 함께 있다. 공통 진입점 `1. Start` 프레임은 별도.

## 1. 핵심 개념 — 3유형 × 4페이지 상속

- 이벤트 스킨을 **정확히 3가지 템플릿 유형** 중 하나로 규격화한다: **기본형 · 박스형 · 라인형**.
- 어드민이 **이벤트 추가 시 유형을 1택**하면(➊), 그 유형이 **인증·스탬프·설문·룰렛 4페이지 전체에 상속**된다.
- 유형이 정하는 것 = **면/테두리 처리 방식 · 텍스트 정렬 · 필요한 어드민 색상 필드(보조 색상 활성 여부)**. 그 외(스탬프 개수·리워드 수·색·배경 이미지)는 파라미터.

```
어드민: 템플릿 유형 1택 (기본 / 박스 / 라인)
   └→ 인증 · 스탬프 · 설문 · 룰렛 4페이지에 동일 스킨 상속
        + 시작(Start) · 리워드는 톤만 일치
   └→ 유형에 따라 어드민 "보조 색상" 필드 활성/비활성 결정
```

---

## 2. 템플릿 3유형 정의 (Figma 섹션 A·B·C)

> 셋의 차이는 딱 하나 — **아무 처리도 안 하나(기본) · 면으로 채우나(박스) · 선으로 나누나(라인)**.

| 유형 | 컨셉 (한 줄) | 면/테두리 처리 | 텍스트 정렬 |
|---|---|---|---|
| **A. 기본형** (Figma `A. 라인형_*`) | 면도 테두리도 없이 **텍스트 위주**로 구성한 가장 단순한 기본 스킨 | 처리 없음 (텍스트 위주) | **좌정렬** (읽는 흐름 좌→우) |
| **B. 박스형** (Figma `B. 박스형_*`) | 요소를 **색 면(fill)으로 채워** 도장 하나하나를 또렷하게 | **면(fill) 채움** | **중앙정렬** |
| **C. 라인형** (Figma `C. 테두리형_*`) | **테두리 선(stroke)으로 구간을 나눠** 정보를 정리 | **테두리(stroke) 구획** | **중앙정렬** |

> 이 차이가 곧 **어드민에서 받아야 하는 색상 필드**(§5)와 **룰렛 색상 파생 방식**(§4-3)을 결정한다.

## 3. 유형 × 페이지 매핑

각 유형 섹션은 아래 페이지 프레임을 모두 포함한다.

| 페이지 | 기본형 | 박스형 | 라인형 |
|---|---|---|---|
| **시작 (Start)** | 공통 `1. Start` (톤만 일치) | 〃 | 〃 |
| **본인인증** | 좌정렬 · 텍스트 위주 폼 | 면 처리 폼 | 테두리 구획 폼 |
| **스탬프** | 좌정렬 · 기본 셀 | 채움 박스·원 셀 | 테두리 구획 셀 |
| └ 리워드 변형 | **리워드 1개 / 리워드 복수(여러개)** | 〃 | 〃 |
| └ 진행 상태 | **4단계 프레임**(§3-2) | 〃 | 〃 |
| **룰렛** | 기본 톤 · 조각색 = 흰100%+버튼10% | 면 톤 · 조각색 = 메인색 투명도 교차 | 테두리 톤 · 조각색 = 메인색 투명도 교차 |
| **설문** | 좌정렬 · 기본 보기 | 면 처리 보기 | 테두리 보기 |

> **스탬프는 리워드 수에 따라 2변형**(`리워드가 1개` · `리워드가 여러개`)이 각 유형마다 존재한다. 복수 리워드는 **디자인만 참고 · 플로우는 [복수 조건 UI 변경]과 동일**.

### 3-2. 스탬프 "리워드 1개" 4프레임 = 진행 상태 4단계

스탬프(리워드 1개)가 유형마다 **4프레임**인 이유 = **참여자 적립 진행 상태 단계**다(실측·스크린샷 확인 완료).

| 단계 | 헤드라인(예시) | 스탬프 상태 | CTA 버튼 |
|---|---|---|---|
| ① 적립 진행 중 | "홍길동님, 스탬프 **N개**를 모으고 리워드를 받으세요!" | 일부만 활성 · 나머지 비활성(`#C0C0C0`) | (비활성) 리워드 받기 |
| ② 적립 진행 중(근접) | 〃 | 활성 개수 증가 | 〃 |
| ③ 전체 적립 완료 | "홍길동님, 스탬프를 **모두 모았어요!** 리워드를 신청하세요!" | 전부 활성 | **활성** `리워드 받기`(메인색) |
| ④ 리워드 신청 완료 | "홍길동님, **축하드려요!** 리워드 신청이 완료되었어요" | 전부 활성 | `리워드 신청완료`(완료 표기) |

> **강조어**(개수 `N개` · `모두 모았어요` · `축하드려요`)에는 **메인 색상**을 적용한다. 텍스트 통짜 교체 시 강조색이 초기화되므로 [[CLAUDE.md]] 규칙대로 `getStyledTextSegments`+`setRangeFills`로 복원.

## 4. 템플릿별 페이지 규칙 (페이지 × 유형 매트릭스)

> 유형(스킨)이 페이지에 상속될 때 **각 페이지가 유형별로 어떻게 렌더되는지**를 정의한다. 공통 스펙(폼 필드·타이포·컴포넌트)은 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 단일 출처.

### 4-1. 본인인증

| 항목 | 기본형 | 박스형 | 라인형 |
|---|---|---|---|
| 정렬 | 좌정렬 | 중앙정렬 | 중앙정렬 |
| 컨테이너 | 텍스트 위주(면·테두리 없음) | 폼 블록을 **면(fill)** 처리 | 폼 블록을 **테두리(stroke)** 구획 |
| 제목 | — | — | 페이지 상단 제목 부여 |
| 상속 파라미터 | **본문 텍스트 색상 · 버튼 색상** | + **보조 색상**(면 fill) | + **메인 색상**(테두리) |

- DS 폼 구성요소는 고정. 유형 스킨은 **정렬·면/테두리**만 바꾼다.
- **배경 이미지**: `본인인증_보안` 하단에 배경 이미지 설정 항목이 붙는다(§5-3).

### 4-2. 스탬프

| 항목 | 기본형 | 박스형 | 라인형 |
|---|---|---|---|
| 정렬 | 좌정렬 | 중앙정렬 | 중앙정렬 |
| 셀 처리 | 기본 셀(텍스트 위주) | **채움 박스·원** 셀 | **테두리 구획** 셀 |
| 진행 상태 | 4단계(§3-2) | 4단계 | 4단계 |
| 리워드 변형 | 1개 / 복수 | 1개 / 복수 | 1개 / 복수 |

- **텍스트 규칙**: **한 줄 5글자**까지 · 띄어쓰기 시 다음 줄로 줄바꿈 · **최대 3줄**. (→ [[큐알스탬프 솔루션/2. 작업 가이드/2-1. 페이지 구조/2-1-3. 스탬프.md]] 상속)
- **스탬프 텍스트 사이즈 = 19px → 16px 로 축소**(Figma 확정 · "기존 19px → 16px"). 버튼 텍스트 대비 원 안 스탬프 텍스트가 커서 조정.
- **라인형 스탬프 사이 스트록 = `#C0C0C4` 고정**(= 비활성 스탬프 색상과 동일).
  > ⚠️ 스탬프 문서·CLAUDE 규칙의 비활성값은 `#C0C0C0`. Figma 주석은 `#C0C0C4` → **표기 불일치 확인 필요**(둘 중 하나로 통일).
- **비활성 스탬프 = `#C0C0C0`** 고정(활성 = 메인색). → 스탬프 §2-6 디테일 준수.
- **복수 리워드**: 디자인만 참고, 플로우는 [복수 조건 UI 변경]과 동일 (`수정전`/`수정후` `Stamp_Multi` 비교 참조).
- **배경 이미지**: 스탬프 페이지를 **`스탬프 목록` + `디자인` 섹션으로 분리**, `디자인` 섹션에 배경 이미지 설정 항목을 둔다(§5-3).

### 4-3. 룰렛 — 유형별 색상 파생이 다름

룰렛은 **버튼 색상에서 여러 요소 색을 파생**시킨다. 파생 방식이 유형마다 다르다.

| 파생 대상 | 기본형 | 박스형 | 라인형 |
|---|---|---|---|
| 핀 색상 | 버튼색 | 버튼색 | 버튼색 |
| 룰렛 배경 outline | 버튼색 | — | 버튼색(outline 색상) |
| 룰렛 배경색 | — | **보조색** | — |
| 조각(구간) 색상 | **흰색 100% + 버튼색 10%** | **메인색 투명도 단계 교차**(아래) | **메인색 투명도 단계 교차** |
| 조각 구분선 | 버튼색 | — | 버튼색 |
| 룰렛 글자 / 핀 안 동그라미 | 글자색 파생 | 글자색 파생 | 글자색 파생 |

**🎨 조각 색상 규칙 (박스형·라인형 공통)** — 메인 색 투명도 단계를 인접 조각끼리 겹치지 않게 번갈아 적용:
- **짝수 N → 2색** (투명도 **80 / 90**)
- **홀수 N → 3색** (투명도 **70 / 80 / 90**)
- **낮은% → 높은% 순 교차** · 한 바퀴 돌아 **첫·끝 조각도 다른 색**이 되게.
- 예) 4등분 `80·90·80·90` / 5등분 `70·80·90·70·80`

**기본형 조각 색상 규칙** — `흰색 100% + 버튼색 10%`(단순 톤). 기본형은 위 투명도 교차 규칙을 쓰지 않음.

- **⚠️ 버튼 색상이 흰색일 경우 = 예외 처리 필요**(흰색 10%·흰색 outline은 밝은 배경에서 사라짐 → 별도 fallback). → 조각 색상 상세 규칙 [[큐알스탬프 솔루션/2. 작업 가이드/2-1. 페이지 구조/2-1-5. 룰렛.md]] §8-3.
- 룰렛 배경 이미지는 **다른 페이지와 달리 별도 설정**(§5-3 근거).

### 4-4. 설문

| 항목 | 기본형 | 박스형 | 라인형 |
|---|---|---|---|
| 정렬 | 좌정렬 | 중앙정렬 | 중앙정렬 |
| 보기(답변) 배경 | 기본(라인 없음) | 면(fill) | 테두리(stroke) |
| 라디오 버튼 색 | **메인 색상**(공통) | 메인 색상 | 메인 색상 |

- **설문조사 라디오 버튼 색상 = 메인 색상**(유형 무관 공통). 어드민 `설문 버튼` 항목으로 지정.
- 답변 보기 배경은 유형 스킨을 따름. → [[큐알스탬프 솔루션/2. 작업 가이드/2-1. 페이지 구조/2-1-6. 설문지.md]]
- **배경 이미지**: 설문 `디자인` 하단에 배경 이미지 설정 항목이 붙는다(§5-3).

## 5. 어드민 규격 (Figma 「어드민 추가」 섹션)

> 어드민 이벤트 추가 흐름 = **➊ 템플릿 유형 설정 → ➋ 본문 텍스트·메인/보조 색상 설정 → 페이지별 배경 이미지 설정**.

### 5-1. ➊ 이벤트 추가 시 — 템플릿 유형 1택 (게이트)
- **기본형 / 박스형 / 라인형 중 하나 선택** = 최상위 선택. 이 선택이 **보조 색상 필드의 활성 여부를 결정**(조건부).

### 5-2. ➋ 페이지 공통 스타일 설정 — 색상 체계 (메인 / 보조)

어드민 색상 UI는 **본문 텍스트 색상 · 메인 색상 · 보조 색상** 3필드로 구성된다.

| 필드 | 활성 조건 | 필수 | 적용처 |
|---|---|---|---|
| **본문(텍스트 색상)** | 항상 | ✅ 필수 | 전 페이지 본문 텍스트 |
| **메인 색상** | 항상 | ✅ 필수 | 버튼·강조어 · **설문 라디오 버튼** · **라인형 테두리(stroke)** · 룰렛 조각(박스/라인형) |
| **보조 색상** | **박스형 선택 시만 활성** | 박스형일 때 필수 | **박스형 박스 fill** · 박스형 **룰렛 배경색** |

> **핵심**: 과거 "박스 면색 / 박스 테두리색"을 각각 받던 방식에서 → **메인 색상**(라인형 stroke까지 겸함) + **보조 색상**(박스형 fill 전용, 박스형일 때만 활성)으로 정리됨.

**유형별 "어드민에서 필요한 색상" 요약**

| 유형 | 본문 텍스트 | 메인 색상 | 보조 색상 |
|---|---|---|---|
| **기본형** | ✅ | ✅ | ⬜ 비활성 |
| **박스형** | ✅ | ✅ | ✅ **필수**(박스 fill·룰렛 배경) |
| **라인형** | ✅ | ✅(테두리 stroke 겸용) | ⬜ 비활성 |

> **각 유형에 맞는 상황일 때만 필드 활성화.** 기본형·라인형에서는 **보조 색상 입력 불가**(비활성) → 무의미한 입력·유령 데이터 방지.

### 5-3. 페이지별 배경 이미지 설정 (확정)

> **[변경 확정]** 과거 "인증·스탬프·설문 공통 배경 1개" 안에서 → **페이지별 개별 배경 이미지 설정**으로 확정됨. 각 페이지 어드민에 배경 이미지 항목을 개별 배치한다.

| 페이지 | 어드민 배치 |
|---|---|
| **본인인증** | `본인인증_보안` 하단에 **배경 이미지 설정 항목 추가** |
| **스탬프** | 스탬프 페이지를 **`스탬프 목록` / `디자인` 섹션으로 분리**, `디자인` 섹션에 **배경 이미지 설정 항목 적용** |
| **설문** | 설문 `디자인` 하단에 **배경 이미지 설정 항목 추가** (+ `설문 버튼` 색상 항목) |
| **룰렛** | **별도 배경**(이미 별도 설정으로 개발됨 · 아래 근거) |

**배경 이미지 설계 근거 (Figma 메모)**
- **룰렛만 배경 별도인 이유**: 룰렛은 정보 전달 구조가 아니라 **룰렛 자체가 주인공** → 강조 배경을 따로 두는 게 임팩트 있음 · **이미 배경 별도 설정으로 개발돼 있음**.
- 인증·스탬프·설문은 **각 페이지 하단/디자인 섹션에서 개별 배경**을 설정한다(페이지별 유연 대처 가능).

### 5-4. 어드민 화면
- **어드민_대시보드_디자인**: 템플릿 유형 · 본문 텍스트 · 메인/보조 색상 · 페이지별 배경 설정 화면.
- **어드민_설문_수정/삭제**: 설문 문항 수정·삭제 + `설문 버튼`(라디오 버튼) 색상 설정.

## 6. 원칙 요약
- **스킨 = 기본형 / 박스형 / 라인형 3유형 중 정확히 하나** (어드민 1택 → 4페이지 상속).
- **차이의 축 = 면/테두리 처리**: 기본(처리 없음·좌정렬) · 박스(면 fill·중앙) · 라인(테두리 stroke·중앙).
- **어드민 색상 = 본문 텍스트 + 메인 색상(필수) + 보조 색상(박스형일 때만 활성)**. 메인색이 라인형 stroke까지 겸함 · 보조색은 박스형 fill·룰렛 배경 전용.
- **배경 이미지 = 페이지별 개별 설정**(본인인증·스탬프·설문 각각) · **룰렛만 별도**.
- **스탬프**: 텍스트 5글자·3줄 · **19px→16px** · 비활성 `#C0C0C0`(라인형 사이 스트록 `#C0C0C4` 표기 통일 필요) · 리워드 1개/복수 2변형 · **진행 상태 4단계**.
- **룰렛**: 버튼색 → 핀·outline·구분선 파생 · 조각색 = **기본형(흰100%+버튼10%)** vs **박스·라인형(메인색 투명도 80/90 또는 70/80/90 교차)** · **흰색 버튼 예외** · 배경 별도.
- **설문**: 라디오 버튼 = 메인 색상(공통) · 답변 보기 배경은 유형 스킨을 따름.
- **⚠️ 유형명 매핑**: 기존 라인형 = **기본형** · 기존 테두리형 = **라인형**(Figma 프레임명은 기존 이름 유지). 상단 매핑 콜아웃 참조.
