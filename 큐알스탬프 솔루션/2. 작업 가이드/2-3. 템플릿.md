# 🧩 2-3. 템플릿

> 이벤트마다 레이아웃을 **즉석 제작**하다 품질이 무너지는 문제를 막기 위해, 검증된 스킨을 **3개 템플릿 유형(라인형·박스형·테두리형)으로 규격화**하고 **어드민에서 1택**해 4개 페이지(인증·스탬프·설문·룰렛)에 일관 적용한다.

> [!note] 이 문서의 위치
> Figma **「QR 템플릿」 페이지**(node `6814-37175`)에 실제 구성된 템플릿을 기준으로 정리한 **규격 문서**다. 페이지에는 `라인형 / 박스형 / 테두리형` 세 섹션이 각각 **인증·스탬프·설문·룰렛 + 시작(Start)** 프레임 세트로 구성돼 있다.

---

## 1. 핵심 개념 — 3유형 × 4페이지 상속

- 이벤트 스킨을 **정확히 3가지 템플릿 유형** 중 하나로 규격화한다: **라인형 · 박스형 · 테두리형**.
- 어드민이 **이벤트 추가 시 유형을 1택**하면(➊), 그 유형이 **인증·스탬프·설문·룰렛 4페이지 전체에 상속**된다.
- 유형이 정하는 것 = **면/테두리 처리 방식 · 텍스트 정렬 · 필요한 어드민 색상 필드**. 그 외(개수·리워드 수·색·이미지)는 파라미터.

```
어드민: 템플릿 유형 1택 (라인 / 박스 / 테두리)
   └→ 인증 · 스탬프 · 설문 · 룰렛 4페이지에 동일 스킨 상속
        + 시작(Start) · 리워드는 톤만 일치
```

---

## 2. 템플릿 3유형 정의 (Figma 섹션 A·B·C)

| 유형 | 컨셉 (Figma 원문) | 면/테두리 처리 | 텍스트 정렬 |
|---|---|---|---|
| **A. 라인형** (Line) | **"텍스트 가독성·정보 전달"을 최우선으로 하는 미니멀 컨셉** | 면·테두리 없음 (라인/텍스트 위주) | **좌정렬** (읽는 흐름 좌→우) |
| **B. 박스형** (Box/면처리) | 스탬프 요소를 **채움(fill) 박스·원 안에 담아**, 도장 하나하나가 뚜렷한 컨테이너로 서는 컨셉 | **면(fill) 채움** | **중앙정렬** |
| **C. 테두리형** (Box/면처리) | **외곽 테두리로 구간을 나누고** 페이지마다 제목을 붙여, 참여 동선을 따라 읽어 내려가는 **여정형** 컨셉 | **테두리(stroke) 구획** | **중앙정렬** |

> 셋의 차이는 **"면을 채우나(박스) · 테두리로 나누나(테두리) · 아무것도 안 하나(라인)"** 로 갈린다. 이 차이가 곧 **어드민에서 받아야 하는 색상 필드**(§5)를 결정한다.

---

## 3. 유형 × 페이지 매핑

각 유형 섹션은 아래 페이지 프레임을 모두 포함한다.

| 페이지 | 라인형 | 박스형 | 테두리형 |
|---|---|---|---|
| **시작 (Start)** | 공통 `1. Start` (톤만 일치) | 〃 | 〃 |
| **본인인증** | 좌정렬 · 라인 폼 | 면 처리 폼 | 테두리 구획 폼 |
| **스탬프** | 좌정렬 · 라인 셀 | 채움 박스·원 셀 | 테두리 구획 셀 |
| └ 리워드 변형 | **리워드 1개 / 리워드 복수(여러개)** | 〃 | 〃 |
| **룰렛** | 라인 톤 | 면 톤 | 테두리 톤 |
| **설문** | 좌정렬 · 라인 보기 | 면 처리 보기 | 테두리 보기 |

> **스탬프는 리워드 수에 따라 2변형**(`리워드가 1개` · `리워드가 여러개`)이 각 유형마다 존재한다. 복수 리워드는 **디자인만 참고 · 플로우는 [복수 조건 UI 변경]과 동일**.

## 4. 페이지별 규칙 (Figma 주석 반영)

### 4-1. 스탬프
- **텍스트 규칙**: 한 줄 **5글자**까지 · 띄어쓰기 시 다음 줄로 줄바꿈 · **최대 3줄**. (→ [[큐알스탬프 솔루션/2. 작업 가이드/2-1. 페이지 구조/2-1-3. 스탬프.md]] 규칙 상속)
- **테두리형 스탬프 사이 스트록** = **`#C0C0C4` 고정** (= 비활성 스탬프 색상과 동일).
  > ⚠️ 스탬프 문서·CLAUDE 규칙의 비활성값은 `#C0C0C0`. Figma 주석은 `#C0C0C4` → **표기 불일치 확인 필요**(둘 중 하나로 통일).
- **원형(박스형) 스탬프 텍스트 크기 제안**: 버튼 텍스트 대비 원 안 스탬프 텍스트가 커서 **16px로 축소 제안** (제안 · 미확정).
- **복수 리워드**: 디자인만 참고, 플로우는 [복수 조건 UI 변경]과 동일 (`수정전`/`수정후` `Stamp_Multi` 비교 참조).

### 4-2. 룰렛 (라인형 기준 주석)
- **버튼 색 → 룰렛 배경 outline · 구분선 · 핀 색상**으로 파생.
- **룰렛(조각) 색상 = 버튼색의 10%**.
- **⚠️ 버튼 색상이 흰색일 경우 = 예외 처리 필요** (흰색 10%·흰색 outline은 밝은 배경에서 사라짐 → 별도 fallback). → 조각 색상 상세 규칙 [[큐알스탬프 솔루션/2. 작업 가이드/2-1. 페이지 구조/2-1-5. 룰렛.md]] §8-3.
- 룰렛 배경 이미지는 **다른 페이지와 달리 별도 설정**(§5-4 근거).

### 4-3. 설문
- **설문조사 라디오 버튼 색상**을 어드민에서 별도 지정(공통 어드민 항목).
- 답변 보기 배경은 유형 스킨을 따름(라인=라인 / 박스·테두리=면·테두리). → [[큐알스탬프 솔루션/2. 작업 가이드/2-1. 페이지 구조/2-1-6. 설문지.md]]

### 4-4. 본인인증
- DS 폼 구성요소 고정 · 유형 스킨(정렬·면/테두리)과 **본문 텍스트 색상 · 버튼 색상**만 상속.

## 5. 어드민 규격 (Figma 「어드민 추가」 섹션)

### 5-1. 이벤트 추가 시 — 템플릿 유형 1택 (게이트)
- **➊ 라인형 / 박스형 / 테두리형 중 하나 선택** = 최상위 선택. 이 선택이 아래 색상 필드의 **활성 여부를 결정**(조건부).

### 5-2. 템플릿 공통 어드민 항목 (유형 무관 · 항상)
1. **본문 텍스트 색상**
2. **페이지 공통 배경 이미지** (인증 · 스탬프 · 설문)
3. **설문조사 라디오 버튼 색상**

### 5-3. 템플릿별 추가 색상 (조건부 활성)

| 필드 | 활성 조건 | 필수 |
|---|---|---|
| **본문 · 텍스트 색상** | 항상 | ✅ 필수 |
| **박스 · 면(fill) 색상** | **박스형 선택 시만** | 박스형일 때 필수 |
| **박스 · 테두리(stroke) 색상** | **테두리형 선택 시만** | 테두리형일 때 필수 |

> **각 유형에 맞는 상황일 때만 필드 활성화.** 예) 라인형을 고르면 **면 색상·테두리 색상을 입력할 수 없음**(비활성). → 조건부 활성/비활성으로 무의미한 입력·유령 데이터 방지.

**유형별 "어드민에서 필요한 정보" 요약**

| 유형 | 필요 정보 |
|---|---|
| **라인형** | 페이지 공통 배경 이미지(인증·스탬프·설문) · 본문 텍스트 색상 · 설문 라디오 버튼 색상 |
| **박스형** | 위 + **박스(프레임)별 Fill 색상**(인증·스탬프·설문) |
| **테두리형** | 위 + **박스(프레임)별 Stroke 색상**(인증·스탬프·설문) |

### 5-4. 배경 이미지 설계 근거 (Figma 메모)
- **공통 배경(인증·스탬프·설문)으로 묶은 이유**: 세 페이지는 목적이 **정보 전달용**이라, 배경을 따로 설정하는 **개발 공수를 줄이고 편함**. → 단, **페이지별 유연 대처는 불가**(트레이드오프).
- **룰렛만 배경 별도인 이유**: 룰렛은 정보 전달 구조가 아니라 **룰렛 자체가 주인공** → 강조 배경을 따로 두는 게 임팩트 있음 · **이미 배경 별도 설정으로 개발돼 있음**.

> [!note] 어드민 배경 설정 위치·방식은 별도 검토 중
> "공통 배경" 대신 **각 페이지가 자기 배경을 갖는 페이지별 설정안**과, 설정 진입 UI(인라인 블록 / 별도 "디자인 설정" 화면)를 별도로 디자인·검토 중이다. 확정 시 §5-2·§5-4를 갱신한다.

### 5-5. 어드민 화면
- **어드민_대시보드_디자인**: 위 색상·배경·유형 설정 화면.
- **어드민_설문_수정/삭제**: 설문 문항 수정·삭제 + 라디오 버튼 색상 설정.

## 6. 원칙 요약
- **스킨 = 라인형 / 박스형 / 테두리형 3유형 중 정확히 하나** (어드민 1택 → 4페이지 상속).
- **차이의 축 = 면/테두리 처리**: 라인(없음) · 박스(면 fill) · 테두리(stroke). 이 축이 곧 **어드민 색상 필드**(면=박스형 / 테두리=테두리형)를 결정.
- **정렬**: 라인형 = 좌정렬 / 박스·테두리 = 중앙정렬.
- **공통 어드민** = 본문 텍스트 색상 · 페이지 공통 배경(인증·스탬프·설문) · 설문 라디오 버튼 색상. **유형별 추가** = 박스형 면색 / 테두리형 테두리색 (**조건부 활성**).
- **룰렛**: 버튼색 → outline·구분선·핀 · 조각색 = 버튼색 10% · **흰색 버튼 예외** · 배경 별도.
- **스탬프**: 텍스트 5글자·3줄 · 테두리형 사이 스트록 `#C0C0C4`(=비활성, `#C0C0C0`과 표기 통일 필요) · 리워드 1개/복수 2변형.
