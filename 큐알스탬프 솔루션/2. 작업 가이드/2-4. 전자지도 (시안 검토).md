## 2. 스탬프 크기 (아이콘 + 텍스트)

| 크기 | 규격 | 쓰는 곳 |
|---|---|---|
| **L 100** | 원 100 · 아이콘 24 + 이름 15px **원 안** · 번호 배지 22 | 기존 2열 그리드 (S1 · S1-B) |
| **M 64** | 원 64 · 아이콘 22 · 이름 14px **원 아래**(폭 84) · 배지 20 | 3열 그리드 · 지도 위 배치 · 캐러셀 · 라인형 경로 (S2 · S4 · S5 · S1-C) |
| **S 44** | 원 44 · 아이콘 18 · 이름은 행 텍스트로 | 리스트 행 · 선택 장소 카드 (S3 · S4) |
| 핀 30×38 | 숫자 = 스탬프 번호 배지 | 시작 = 메인색 / 적립 = 메인색+체크 / 미적립 = `#C0C0C0` |

- 원이 작아져도 **이름은 14–15px 하한**(2-1-3 §2-6). 원 64 이하면 이름을 원 밖(아래)으로 뺀다.
- **지도↔스탬프 연결 = 번호.** 스탬프 좌상단 배지 숫자 = 지도 핀 숫자(1:1). 기존 그리드에 없던 요소라 새로 정해야 한다.

## 3. 템플릿별 지도 처리

> 지도 컨테이너는 **그 유형의 「스탬프 칸 처리」를 그대로 상속**한다(새 규칙을 만들지 않음).

| 유형 | 지도 컨테이너 | 정렬 | 시안 |
|---|---|---|---|
| **기본형** | 지도 단독(면·선 없음 · r8) | 타이틀·범례 좌정렬 | S1 · S4 |
| **박스형** | 보조색 면 박스(`#1A2A40` · r16 · 패딩 12) 안에 지도 r10 | 중앙 | S1-B · S2 · S5 |
| **라인형** | 메인색 1px 라인 박스(r20) 안에 지도 + 스탬프 경로/리스트를 함께 | 중앙 | S1-C · S3 |

## 4. 지도 크기

| 위치 | 크기 | 메모 |
|---|---|---|
| 시작 · 미리보기 | 295×180(카드 안) · 275×160(이미지 대체) · 327×240(탭) | 높이 160~240 |
| 스탬프 · 미리보기 | 327×200(기본) · 303×170~300(박스) · 375×260(풀블리드) | 범례(적립/미적립/내 위치) 함께 |
| 스탬프 · 지도 보드 | 327×520 이상 | 장소 8곳 이하일 때만 |
| 전체 화면 | 375×812(헤더 제외 약 660) | 「크게 보기」 / 「지도 보기」로 진입 |

- **최소 높이 160** — 핀(38) + 라벨 + 위아래 여백. 비율 16:10 ~ 4:3.
- **스크롤 충돌**: 페이지 속 지도는 페이지 스크롤과 지도 드래그가 부딪힌다 → 미리보기는 정적(탭하면 전체 화면), 확대·이동은 전체 화면에서.

## 5. 정해야 할 것 (미결)

- [ ] **어드민**: 「전자지도 사용」 on/off · 노출 위치(시작 / 스탬프 / 둘 다) · 표시 형태(미리보기 · 탭 · 보드) · 스탬프마다 주소(위경도) 입력
- [ ] **지도 API·스타일**: 네이버/카카오 중 선택 · 다크 테마 이벤트에서 커스텀(다크) 스타일 가능 여부 — 안 되면 라이트 지도를 카드로 감싸 분리
- [ ] **내 위치**: 위치 권한 요청 시점(전체 화면 진입 시 권장) · 거부 시 내 위치·거리 숨김
- [ ] **핀 겹침**: 가까운 장소는 클러스터 · 10곳 이상이면 리스트형(S3)
- [ ] **길찾기**: 외부 지도 앱 딥링크
- [ ] **번호 배지**를 기존 스탬프(지도 미사용 이벤트)에도 둘지

## 6. 추천 조합

- **기본 추천**: 시작 **T5**(버튼) 또는 **T1**(카드) + 스탬프 **S5**(미니맵 + 3열) — 페이지 길이 유지 · 3유형 모두 적용 쉬움
- **장소 중심 투어형**: 시작 **T3**(탭) + 스탬프 **S3**(리스트)
- **몰입형(장소 8곳 이하)**: 시작 **T4**(히어로) + 스탬프 **S4**(지도 보드)

## 9. 어드민 고려사항 (시작 + 스탬프 S4 기준)

### 9-1. 이벤트 단위 설정

|---|---|
| **전자지도 사용** on/off | off = 기존 그대로(시작에 지도 없음 · 스탬프는 기존 그리드) |
| **스탬프 판 표시 방식** | `그리드(기존)` / `지도(S4)` — 스탬프 페이지 `디자인` 섹션 |

| 템플릿별 지도 처리 | **자동**(입력 없음) — 기본형 단독 · 박스형 보조색 박스 · 라인형 메인색 테두리 |
| 색상 | **자동** — 마커 적립·시작 = 메인 색상 · 미적립 = `#C0C0C0` 고정 · 박스형 지도 박스 = 보조 색상 |

### 9-2. 거점(스탬프)별 입력 — `스탬프 목록` 섹션에 추가

| 필드 | 필수 | 규칙 |
|---|---|---|
| 스탬프 이름 | ✅ (기존) | 스탬프 판·지도 공통 |
| **지도 표시명** | 선택 | 비우면 스탬프 이름 사용 · **6자 이하 1줄 / 7~12자 2줄(어절)** · 12자 초과 경고 |
| **위치(주소 → 좌표)** | ✅ (지도 사용 시) | 주소 검색 → 위경도 저장 · **지도에서 핀 드래그로 미세 조정** · 좌표 없으면 저장 불가(지도에서 빠짐) |
| **마커 아이콘** | ✅ | **아이콘 라이브러리에서 선택**(지하철·왕릉·사찰·빌딩 …) 권장 / 업로드 시 **단색 SVG**만 → 메인색·회색 자동 적용(사진·컬러 PNG는 색 변환 불가) |

| 표시 순서 | — | 지도엔 순서 없음(번호·연결선 없음). 그리드 사용 시에만 의미 |

### 9-3. 지도 동작 (어드민 입력 없이 자동이 좋은 것)

- **초기 화면 = 전체 맞춤(fit bounds)** — 모든 거점이 한 화면에. 중심·줌을 어드민이 고르게 하지 않음(이벤트마다 틀어짐)
- **지도 높이** = 시작 300 · 스탬프 450 고정(거점 6곳 기준) → 거점 수가 많으면 「높이 ≈ 70 × 줄 수 + 90」으로 자동 증가 또는 프리셋(6곳 이하 / 7~10곳)
- 지도 스타일 = **라이트 고정** · 「© OpenStreetMap」 출처 **항상 표시**(숨김 옵션 ❌ — 라이선스)
- 내 위치 버튼 · 「크게 보기」 전체 화면 · X 닫기 = 공통 기능(설정 없음)

### 9-4. 검증·경고 (어드민 미리보기)

- [ ] 좌표 없는 거점 → 「지도에 표시되지 않아요」
- [ ] **거점끼리 너무 가까움**(마커 겹침) → 경고 + 개발 측 클러스터 처리
- [ ] 지도 표시명 12자 초과 → 말줄임 경고
