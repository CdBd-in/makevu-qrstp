> **"정의 ↔ 실행"을 잇는 다리.** 토큰·컴포넌트의 *값·용도 정의*는 [[큐알스탬프 솔루션/2. 디자인 가이드/2-1. 공통 디자인 시스템.md]]에 있고,

## 1. 원칙

1. 변수·컴포넌트는 **새로 만들지 않는다** — 아래 주소록의 것을 인스턴스화해 재사용.
2. 색·폰트 값 **하드코딩 금지** → Figma **변수명**으로 적용 (값은 2-1 참고).
3. 새 화면 = **기존 컴포넌트 인스턴스 배치 + 변수 적용 + 콘텐츠 교체**.
4. 주소록에 없는 요소가 필요하면 → 임의 생성 대신 **4절 "신규 리소스 제안"에 기록 후 합의**.

## 3. 클로드 작업 규약 (How Claude uses this)

**입력 → 출력 흐름**
```
[단계 가이드(2-2~2-5) + 토큰·컴포넌트 정의(2-1) + 본 주소록(3)]  →  클로드(Figma MCP)  →  [Figma 화면·컴포넌트]
```

**산출 절차**
1. 만들 단계의 가이드(2-2~2-5)에서 **화면·상태·콘텐츠** 확인.
2. 본 주소록에서 **기준 프레임** 복제 또는 **필요 컴포넌트** 인스턴스 배치.
3. **2-1의 변수**로 색·타이포 적용 (하드코딩 금지).
4. 콘텐츠(텍스트·이미지)만 가이드대로 교체.
5. 상태(variant)·분기(본인인증 유무, 단일/다중)를 가이드대로 반영.

**MCP 참고**: `get_variable_defs`(변수) · `get_metadata`(구조/위치) · `get_design_context`(구현) · `get_screenshot`(확인) → 기존 컴포넌트 **재사용 우선**.
