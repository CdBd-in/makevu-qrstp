# ✅ 4. 검수 체크리스트

> **이벤트명·이벤트 내용**을 받아 **커스텀 디자인**을 제작한 뒤, 이 목록으로 점검한다.
> 핵심은 두 가지: **공통(고정) 요소는 규격대로** 지켰는가 + **이벤트별 가변 요소는 커스텀이 제대로 반영**됐는가.
> 디자인 기준: [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] · 제작 흐름: [[큐알스탬프 솔루션/3. 워크플로우.md]]

> [!note] 고정(공통) vs 이벤트 커스텀
> - **고정**: 레이아웃 골격 · 타이포 램프 · 공통 컴포넌트 규격(버튼·카드·스탬프·필드·체크박스)
> - **커스텀**: 메인 컬러 · 배경색 · 스탬프 칸 수(n)·배치 · 리워드/로고 이미지 · 배경 비주얼
> 아래 수치 중 **고정으로 명시되지 않은 값은 "기본/권장"** 이며, 이벤트 컨셉에 맞게 커스텀할 수 있다.

> [!tip] 신규 제작은 **검증된 템플릿 복제**로 시작
> 처음부터 그리지 말고 **`수정후` 표준 템플릿(BTS SEOUL CONCERT 9프레임 · Figma `6236:2288`)** 을 복제해 테마·콘텐츠만 교체한다. (→ [[큐알스탬프 솔루션/3. 워크플로우.md]] Step 3) — 이 템플릿은 위 항목들이 이미 반영된 상태다.

## ⚠️ 특히 자주 놓치는 항목 (실제 누락 사례)

> 과거 제작에서 실제로 빠졌던 부분 — 매번 먼저 확인할 것.

1. **스탬프 화면에 CTA 버튼 누락** — 모든 스탬프 상태에 "리워드 받기" 버튼이 있어야 함 (미완성 = 비활성 → 완성 = 활성).
2. **본인인증 후 개인화 텍스트("{이름}님") 누락** — 인증 이후 화면(스탬프·리워드)에 이름이 들어가야 함.
3. **스탬프를 공통 컴포넌트로 안 만듦** — 스탬프는 공통 `stamp` 컴포넌트(2열 점선 그리드)를 **인스턴스로 사용**하고, **칸 수(n)** 가 요청값과 맞는지 확인.
4. **폰트 사이즈가 DS 램프 밖** — 램프에 없는 임의값(24·lh 30/34 등) 사용 금지.
5. **텍스트 노드 겹침/덮어쓰기** — 제목/본문이 겹치지 않는지.
6. **메인 컬러 미적용(기본 블루 잔존)** — 복제 원본의 `#4B73FF` 등이 남으면 **버튼·강조어·스탬프 채움·스탬프 라벨·핀라벨·타이틀**을 전부 이벤트 메인 컬러로 치환했는지.
7. **스탬프를 컴포넌트로 안 만듦 + 그리드 미준수** — `stamp` 컴포넌트(active/inactive)로 배치하고 **그리드 정밀 사양(2-1-3 §2-4)**(100×100·구분선 위치)을 지켰는지.
8. **스탬프 헤더 줄바꿈** — `홍길동님, / 스탬프 N개를 모으고 / 리워드를 받으세요!` **3줄 고정**(어절 단위)인지.
9. **비활성 버튼 = 활성 버튼 opacity 30%** — 색만 옅게가 아니라 **버튼 통째로 30%**. 보조 버튼(인증번호 받기/재전송)도 동일.
10. **Start 이벤트명↔일시카드 간격 40** — 이름이 1줄이든 2줄이든 **간격 40 유지**(이름 높이에 카드 위치 하드코딩 ❌).
11. **설명/안내문 어절 줄바꿈** — Start 설명·Reward 안내문은 **너비 327 고정·높이 hug**, 어절 중간에서 끊지 않기.
12. **⭐ 스탬프 칸 디자인을 커스텀 안 함(기본 컴포넌트 그대로 사용)** — 스탬프 칸 안 비주얼은 **이벤트마다 매번 커스텀**이다. 기본 `stamp` 컴포넌트(숫자 원)를 그대로 두지 말고, **4유형 후보(텍스트만 / 이미지+텍스트 / 이미지만 / 이미지+하단텍스트)를 제작해 사용자에게 제시 → 1개 선택 → 전 스탬프 통일**했는지. (→ [[큐알스탬프 솔루션/2. 작업 가이드/2-1. 페이지 구조/2-1-3. 스탬프.md]] §2-6 · [[큐알스탬프 솔루션/3. 워크플로우.md]] Step 2.5 §2-1) — *리소스가 없어 후보를 못 만드는 경우에만 기본 컴포넌트(숫자/이름) 유지하며, 이때도 사용자에게 고지한다.*
13. **⭐ 스탬프 4유형 후보 보드를 삭제** — 제작·선택에 쓴 **4유형 후보 보드(적립 전/후 한 쌍씩)** 는 작업이 끝나도 **지우지 말고 같은 이벤트 페이지 한쪽에 그대로 보관**한다. (디자인 근거·재선택·후속 수정의 출처) → 선택 안 된 3유형도 함께 남긴다.
14. **⭐ 오토레이아웃·상하 여백 미준수** — 로고·콘텐츠 블록을 **오토레이아웃 흐름(insertChild)** 으로 넣었는지(좌표 하드코딩·absolute ❌ → 겹침/밀림 발생). **프레임 높이 = 콘텐츠 hug**(템플릿 복제 후 남은 **고정 높이 그대로 두면 하단 여백 과다** ❌), **상단 34 · 하단 40** 유지. 비균일 간격(예: 리워드 안내문→카드 30 / 카드→CTA 40)은 **블록 그룹핑**으로 구현. (→ [[큐알스탬프 솔루션/2. 작업 가이드/2-1. 페이지 구조/2-1-1. 시작.md]] §4-1 · [[큐알스탬프 솔루션/2. 작업 가이드/2-1. 페이지 구조/2-1-4. 리워드.md]] §2-1)
15. **⭐ 배경 가독성 미흡** — 배경(패턴·모자이크·일러스트)이 **텍스트·카드 가독성을 해치지 않는지**. 색점·고채도 노이즈로 글자가 묻히면 **저채도화·중앙 비움·오버레이(딤)** 또는 **그라데이션**으로 교체. (배경 = 가독성 최우선 → [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-4. 이미지.md]] · [[큐알스탬프 솔루션/3. 워크플로우.md]] Step 2.5)

## 1. 레이아웃 (고정)
- [ ] 375 폭 · 좌우 여백 24 · 콘텐츠 327
- [ ] CTA는 하단 고정
- [ ] 배경색은 **흰색 고정이 아니라 이벤트 팔레트 배경색**(메인 컬러와 한 쌍) 적용
- [ ] **Start 이벤트명↔일시카드 간격 40 유지** (이름 1~2줄 무관)
- [ ] Start 설명·Reward 안내문 = **너비 327 고정·높이 hug·어절 줄바꿈**
- [ ] **오토레이아웃 흐름 준수** — 로고·콘텐츠 블록은 좌표가 아니라 **오토레이아웃 자식(insertChild)** 으로 배치(absolute·좌표 하드코딩 ❌)
- [ ] **상단 34 · 하단 40 여백** 유지 + **프레임 높이 = 콘텐츠 hug** (템플릿 복제 시 남은 고정 높이로 **하단 여백 과다 ❌**)
- [ ] 비균일 블록 간격(예: 리워드 안내문→카드 30 / 카드→CTA 40)은 **그룹핑으로 구현**(단일 gap로 못 맞추면 블록 묶기)

## 2. 타이포 — DS 램프만 사용 (고정)
- [ ] 허용 스타일만: `Display 48/58` · `Title_L 28/44` · `Sub_L 18/26` · `Field txt_L 22/26` · `Body 14/22~26` · `Button Text 20/26` · `Caption 12` · `link_ul 14/22`
- [ ] 램프에 없는 사이즈/행간 **금지** (필요하면 DS 2-2-1에 스타일을 먼저 추가)
- [ ] 색·타이포는 **변수명으로 적용**(하드코딩 금지)

## 3. 컬러 — 이벤트 메인 컬러 테마 (커스텀)
- [ ] 메인 컬러는 **이벤트별 지정/추론값** 사용 (기본 `#4B73FF`)
- [ ] **활성 버튼·강조어·스탬프(active) 채움·스탬프 라벨·핀 라벨·타이틀**이 메인 컬러로 통일 (보조 버튼 "인증번호 받기/재전송" 포함)
- [ ] **미적립(inactive) 스탬프 = `#C0C0C0` 고정** (메인 컬러 30% ❌ · 단일 테마의 유일한 예외)
- [ ] 비활성 버튼 = **활성 버튼 전체 opacity 30%** (주 CTA·보조 버튼 모두)

## 4. 구조 — 4단계 기준 프레임 (이벤트에 맞게 가감)
- [ ] `1. Start`
- [ ] `2-1. LOGIN-Default` · `2-2. LOGIN-Filled` (본인인증 사용 시 / 미사용 시 생략)
- [ ] `3-x. STAMP` 상태들 (Default · 적립중 · 완료 · RewardDone)
- [ ] `4-1. REWARD-Default` · `4-2. REWARD-Done` — **Done은 Default 복제 + 하단 CTA 상태만 변경**(레이아웃 동일, 별도 확인화면 ❌)

> 프레임 **개수는 고정이 아니다** — 본인인증 유무, 스탬프 단일/다중 등 이벤트 구성에 따라 달라진다.

## 5. 스탬프 (컴포넌트 골격 고정 / 칸 안 디자인·칸 수 커스텀)
- [ ] **⭐ 칸 안 디자인 = 이벤트마다 커스텀** — 4유형 후보 제작 → **사용자 선택** → 전 스탬프 통일 (기본 숫자 원 그대로 ❌ · 예외: 리소스 전무 시 고지 후 기본 유지) → 2-1-3 §2-6
- [ ] **4유형 후보 보드를 페이지에 보관** — 선택 후에도 4유형(적립 전/후) 보드를 **삭제하지 않고 같은 이벤트 페이지에 남겼는지**(선택 안 된 유형 포함)
- [ ] **칸 디자인은 이벤트별 커스텀**(매번 새로 디자인)이되, 공통 `stamp` 컴포넌트(`6189:13747`)를 **골격 기준(그리드·라벨·active/inactive)으로** 따랐는가 (개별 원·텍스트 즉석 배치 ❌) — 칸 안 비주얼만 커스텀 · **active = 메인 컬러 / inactive = `#C0C0C0` 고정**
- [ ] **그리드 정밀 사양(2-1-3 §2-4)** 준수 — 100×100 · 2열 · 점선 **세로선=전체높이(안 자름)·가로선=327** · 각 사이 **정중앙**(31.75 / 20)
- [ ] **스탬프 프레임(페이지) 높이 = 가변**(n에 맞춰 hug)
- [ ] **스탬프 라벨** = active 메인 컬러 / inactive `#C0C0C0` (이름 없으면 숫자 1~n)
- [ ] **칸 수(n)** 가 요청값과 일치 (예: 16 · 3 · 6 · 4)
- [ ] `active`(적립) / `inactive`(미적립) 상태 구분
- [ ] **헤더 3줄 고정** — 개인화 / 스탬프 N개를 모으고 / 리워드를 받으세요!
- [ ] **모든 스탬프 화면에 CTA 버튼** (미완성 비활성 → 완성 활성)

## 6. 개인화 / 분리
- [ ] 본인인증 후 화면에 **개인화 텍스트("{이름}님")** 표시
- [ ] **배경에 버튼·가변요소 미포함** — 버튼·스탬프는 분리 레이어

## 7. 리소스 반영 (커스텀)
- [ ] **배경 가독성 확보** — 배경(패턴·모자이크·일러스트)이 **텍스트·카드를 묻히게 하지 않는지**(저채도·중앙 비움·딤). 애매하면 **그라데이션**. 패턴이 글자 위로 노이즈 ❌
- [ ] 리워드/배경 이미지가 **이벤트 무드(메인 컬러)와 톤 일치** — 안 맞으면 색상 보정(HSV)·교체. 교체 후 **스크린샷으로 실제 반영 확인**(해시만 믿지 말 것)
- [ ] 리워드 이미지: 정보 있으면 **thiings.co**에서 받아 적용, 없으면 `#D9D9D9` placeholder 유지
- [ ] 단일 아이콘으로 부족한 리워드는 **thiings 2개+ 합성**(예: 포토카드 = photo+card · 같은 톤끼리)
- [ ] 로고: 있으면 배치(**비율 유지 · 긴 방향을 프레임 같은 변에 맞춤**), 없으면 `#EDEDED` placeholder
- [ ] 어두운 배경에서 로고 = **`#FFFFFF` 마스크로 흰색 녹아웃** 적용했는가
