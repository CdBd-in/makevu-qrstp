## ⚠️ 특히 자주 놓치는 항목 (실제 누락 사례)

> 아래는 과거 제작에서 실제로 빠졌던 부분 — 매번 먼저 확인할 것.

1. **스탬프 화면에 CTA 버튼 누락** — 모든 스탬프 상태에 "리워드 받기" 버튼이 있어야 함 (미완성 = 비활성 → 완성 = 활성).
2. **본인인증 후 개인화 텍스트("{이름}님") 누락** — 인증 이후 화면(스탬프·리워드)에 이름이 들어가야 함.
3. **스탬프 점선 그리드 누락** — DS 스탬프는 **2열 그리드 + 점선 구분선**.
4. **스탬프 사이즈 DS 미준수** — 기준 **100×100**.
5. **폰트 사이즈가 DS 램프 밖** — 24·lh 30/34 등 임의값 사용.
6. **배경 이미지에 버튼이 베이크됨** — 버튼·가변요소는 **분리 레이어**.
7. **텍스트 노드 겹침/덮어쓰기** — 제목/본문이 겹치지 않는지.

## 1. 레이아웃
- [ ] 375 폭 · 좌우 여백 24 · 콘텐츠 327
- [ ] CTA는 하단 고정

## 2. 타이포 — DS 램프만 사용 (임의 사이즈 금지)
- [ ] 허용 스타일만: `Title_L 28/44` · `Title_S 14/26` · `Field txt_L 22/26` · `Input Text 14/26` · `Button Text 20/26` · `link_ul 14/22` · `Tip 12/26`
- [ ] 24·30·34 등 **램프에 없는 사이즈/행간 금지** (필요하면 2-1에 스타일을 먼저 추가)
- [ ] 색·타이포는 **변수명으로 적용**(하드코딩 금지)

## 3. 컬러
- [ ] DS 토큰만 사용
- [ ] 이벤트 컨셉 적용 시 **모든 버튼(주 CTA + 보조 "인증번호 받기" 등)** 메인 컬러로 통일

## 4. 구조 — 표준 9-프레임
- [ ] `1. Start`
- [ ] `2-1. LOGIN-Default` · `2-2. LOGIN-Filled` (본인인증 없으면 생략)
- [ ] `3-1. STAMP-Default` · `3-2. STAMP-1/n` · `3-3. STAMP-n/n` · `3-4. STAMP-RewardDone`
- [ ] `4-1. REWARD-Default` · `4-3. REWARD-Done`

## 5. 스탬프
- [ ] **100×100, 2열 그리드 + 점선 구분선** 포함
- [ ] 4상태(Default·1/n·n/n·RewardDone) + 빈/채움 구분
- [ ] **모든 스탬프 화면에 CTA 버튼** (미완성 비활성 → 완성 활성)

## 6. 개인화 / 분리
- [ ] 본인인증 후 화면에 **개인화 텍스트("{이름}님")** 표시
- [ ] **배경에 버튼·가변요소 미포함** — 버튼·스탬프는 분리 레이어
