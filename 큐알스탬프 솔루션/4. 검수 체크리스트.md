# ✅ 4. 검수 체크리스트

> **이벤트명·이벤트 내용**을 받아 **커스텀 디자인**을 제작한 뒤, 이 목록으로 점검한다.
> 핵심은 두 가지: **공통(고정) 요소는 규격대로** 지켰는가 + **이벤트별 가변 요소는 커스텀이 제대로 반영**됐는가.
> 디자인 기준: [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] · 제작 흐름: [[큐알스탬프 솔루션/3. 워크플로우.md]]

> [!note] 고정(공통) vs 이벤트 커스텀
> - **고정**: 레이아웃 골격 · 타이포 램프 · 공통 컴포넌트 규격(버튼·카드·스탬프·필드·체크박스)
> - **커스텀**: 메인 컬러 · 배경색 · 스탬프 칸 수(n)·배치 · 리워드/로고 이미지 · 배경 비주얼
> 아래 수치 중 **고정으로 명시되지 않은 값은 "기본/권장"** 이며, 이벤트 컨셉에 맞게 커스텀할 수 있다.

---

## ⚠️ 특히 자주 놓치는 항목 (실제 누락 사례)

> 과거 제작에서 실제로 빠졌던 부분 — 매번 먼저 확인할 것.

1. **스탬프 화면에 CTA 버튼 누락** — 모든 스탬프 상태에 "리워드 받기" 버튼이 있어야 함 (미완성 = 비활성 → 완성 = 활성).
2. **본인인증 후 개인화 텍스트("{이름}님") 누락** — 인증 이후 화면(스탬프·리워드)에 이름이 들어가야 함.
3. **스탬프를 공통 컴포넌트로 안 만듦** — 스탬프는 공통 `stamp` 컴포넌트(2열 점선 그리드)를 **인스턴스로 사용**하고, **칸 수(n)** 가 요청값과 맞는지 확인.
4. **폰트 사이즈가 DS 램프 밖** — 램프에 없는 임의값(24·lh 30/34 등) 사용 금지.
5. **텍스트 노드 겹침/덮어쓰기** — 제목/본문이 겹치지 않는지.

---

## 1. 레이아웃 (고정)
- [ ] 375 폭 · 좌우 여백 24 · 콘텐츠 327
- [ ] CTA는 하단 고정
- [ ] 배경색은 **흰색 고정이 아니라 이벤트 팔레트 배경색**(메인 컬러와 한 쌍) 적용

## 2. 타이포 — DS 램프만 사용 (고정)
- [ ] 허용 스타일만: `Display 48/58` · `Title_L 28/44` · `Sub_L 18/26` · `Field txt_L 22/26` · `Body 14/22~26` · `Button Text 20/26` · `Caption 12` · `link_ul 14/22`
- [ ] 램프에 없는 사이즈/행간 **금지** (필요하면 DS 2-2-1에 스타일을 먼저 추가)
- [ ] 색·타이포는 **변수명으로 적용**(하드코딩 금지)

## 3. 컬러 — 이벤트 메인 컬러 테마 (커스텀)
- [ ] 메인 컬러는 **이벤트별 지정/추론값** 사용 (기본 `#4B73FF`)
- [ ] **활성 버튼·강조어·스탬프 채움·핀 라벨·타이틀**이 메인 컬러로 통일 (보조 버튼 "인증번호 받기" 포함)
- [ ] 비활성 = **메인 컬러 30%**

## 4. 구조 — 4단계 기준 프레임 (이벤트에 맞게 가감)
- [ ] `1. Start`
- [ ] `2-1. LOGIN-Default` · `2-2. LOGIN-Filled` (본인인증 사용 시 / 미사용 시 생략)
- [ ] `3-x. STAMP` 상태들 (Default · 적립중 · 완료 · RewardDone)
- [ ] `4-x. REWARD` (Default · Done)

> 프레임 **개수는 고정이 아니다** — 본인인증 유무, 스탬프 단일/다중 등 이벤트 구성에 따라 달라진다.

## 5. 스탬프 (컴포넌트 고정 / 칸 수·배치 커스텀)
- [ ] 공통 `stamp` 컴포넌트(`6189:13747`) **인스턴스 사용** — 2열 점선 그리드 · 채움색 메인 컬러
- [ ] **칸 수(n)** 가 요청값과 일치 (예: 16 · 3 · 6 · 4)
- [ ] `active`(적립) / `inactive`(미적립) 상태 구분
- [ ] **모든 스탬프 화면에 CTA 버튼** (미완성 비활성 → 완성 활성)

## 6. 개인화 / 분리
- [ ] 본인인증 후 화면에 **개인화 텍스트("{이름}님")** 표시
- [ ] **배경에 버튼·가변요소 미포함** — 버튼·스탬프는 분리 레이어

## 7. 리소스 반영 (커스텀)
- [ ] 리워드 이미지: 정보 있으면 **thiings.co**에서 받아 적용, 없으면 `#D9D9D9` placeholder 유지
- [ ] 로고: 있으면 배치, 없으면 `#EDEDED` placeholder

## 8. 품질

- [ ] 텍스트 겹침·잘림 없음
- [ ] 단계 전환·상태 표현이 가이드대로
