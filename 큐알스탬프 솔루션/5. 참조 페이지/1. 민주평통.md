## 2️⃣ 본인인증 (인증 / LOGIN)

| 상태 | 화면 | node-id |
|---|---|---|
| Default | `2-1.LOGIN-Default` | `5864:1658` |
| Filled | `2-2.LOGIN-Filled` | `5864:1677` |

- 헤드라인: **"휴대폰번호 인증 한 번으로 이벤트에 참여하세요"**
- 입력 필드 3종 (디자인 시스템 컴포넌트 **인스턴스 재사용**):
  - `Field_Name` (이름)
  - `Field_Phone` (휴대폰번호 + "인증번호 받기")
  - `Field_Verification` (인증번호)
- 보조 링크: "인증번호 문자가 오지 않을 때"
- 필수 동의 체크박스 2개: **수집·이용 동의(필수)** / **처리업무 위탁 동의(필수)** — 각 "자세히"
- CTA `button` "시작하기"
- **상태 전환**: Default(비활성) ↔ Filled(입력 완료 시 활성)

## 📌 제작 시 참고 패턴

1. 각 단계는 **여러 상태(state) 화면**으로 구성된다 (Default/Filled · default/1·16/완료 · Default/Collect/Done).
2. 본인인증 입력 필드는 **디자인 시스템 컴포넌트를 인스턴스로 재사용** (새로 만들지 않음 → 3. 제작 프로세스 원칙).
3. 단계 전환 트리거가 명확하다: **화면 탭 → 다음** / **스탬프 완료 시 버튼 플로팅** / **CTA → 구글폼**.
4. 본 이벤트의 아트보드 기준은 **393 폭** (단계 기준 프레임 복제 시 폭 확인).
