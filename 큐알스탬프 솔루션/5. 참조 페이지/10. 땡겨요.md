# 🍜 참조 이벤트 — 땡겨요 (땡겨요랜드 @ 스타필드)

> **신한 배달앱 "땡겨요" × 스타필드(Starfield) "땡겨요랜드" QR 스탬프 이벤트.** 스타필드 내 각 체험존(부스)에서 QR을 스캔하면 해당 존 스탬프가 찍히고, **체험존 5곳** 스탬프를 모두 모으면 **리워드 룰렛**을 돌려 QR주문 할인 혜택/경품(수저세트 등)을 받는다.
> **룰렛(뽑기) 리워드 케이스** — 다른 참조 이벤트의 "고정 단일 리워드"와 달리, 스탬프 완성 후 **6분할 룰렛**을 돌려 당첨 결과에 따라 리워드가 갈린다(Reward1~5 분기).
> **거의 전체가 플랫 비트맵(이미지) 화면** — bg/버튼/스탬프/캐릭터가 모두 `자산@4x`·`Asset@2x` 이미지로 굳어져 있어, Figma 텍스트/컬러 토큰이 없다(재현 시 이미지 재제작 또는 텍스트·도형 재구성 필요).
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

- **아트보드**: 393 폭 · 675/677 고정 높이(스크롤 없음)

- **폰트**: 로고·헤드라인은 **커스텀 레터링(이미지)** / 본문은 Pretendard 계열로 추정

## 1️⃣ 시작 (Start) · `5798:937`
- 상단 **"땡겨요랜드"** 커스텀 레터링 로고(위에 작게 `테이블에서 바로 주문하는`) + 서커스 텐트 줄무늬 배경.
- 중앙 **땡겨요 마스코트 캐릭터 군집** 일러스트 + 말풍선 배너 **"QR 주문이 온다~!"**.
- 하단 `Starfield × 땡겨요` 브랜드 락업 + 안내문:
  - **"고르고 땡기고 주문하고 먹고! 땡겨요랜드에서 스탬프를 모아 리워드 받고 맛있는 주문하세요~!"**
- 레드 pill CTA **"체험 시작"**.

## 2️⃣ 스탬프 (Stamp) — 체험존 캐릭터 얼굴 스탬프
- 상단 텐트 배너 아래 헤드라인: **"고르고! 땡기고! 주문하고! 먹고!"** + 서브 **"모든 미션을 성공하고 룰렛을 돌리면 리워드가 달라진다!"** + **"스탬프를 모아 QR주문 할인 혜택을 받아보세요."**(강조어 레드).
- 안내: **"각 체험존에 해당하는 스탬프를 눌러주세요!"**
- **스탬프 5칸** — 화이트 카드 위 **3(상단) + 2(하단)** 배치. 각 칸 = **캐릭터 얼굴 실루엣**.
  - 존 라벨(각 스탬프 하단): **골라요 · 땡겨요 · 주문해요 · 먹어요 · 앱설치 인증** (5개 미션존).
  - **미적립(before)** = 라이트 그레이 얼굴 실루엣 / **적립(after)** = 컬러 캐릭터 얼굴(존별 마스코트, 파랑/화이트/베이지 등).
  - 스탬프는 **컴포넌트가 아니라 이미지 애셋**(`자산 20~24@4x` = 얼굴 실루엣, `자산 27@4x` 등으로 상태 교체).
- **스탬프 클릭 인터랙션(2종 화면)**:
  - 미적립 클릭(`5798:976`) → **회색 "골라요" 도장 미리보기** + 상단 "돌아가기"(`03-bt`) — "이 존을 방문해 QR을 스캔하세요" 안내.
  - 적립 클릭(`5798:996`) → **레드 "골라요" 도장(적립 완료)** 표시.

## 3️⃣ 룰렛 (Roulette) — 스탬프 완성 뽑기
- 레드 배너 **"스탬프 완성 리워드 룰렛"**.
- **6분할 원형 룰렛**(레드/주황 교차 슬라이스) + 상단 고정 삼각 포인터. 슬라이스 상품:
  - **스트레스볼 · 5천원 할인권 · 3천원 할인권(×2) · 스크래치볼(?) · 3천원 할인권** 등(할인권/굿즈 혼합).
- 하단 우측 여우 마스코트 + 레드 pill CTA **"룰렛 돌리기"**.
- **2종 상태**:
  - `3.2-Roulette1`(`5835:254`) = **스탬프 5개 완성** → 룰렛 활성(돌리기 가능).
  - `3.2-Roulette2`(`5835:264`) = **스탬프 1~4개(미완성)** → 다른 상태(완성 유도/비활성 안내).
  - `3.1-Roulette_start`(`5798:8833`) = 룰렛 진입 시작 화면.

## 🤖 디자인 자동화 재현 포인트

- **테마 색** = 땡겨요 **레드 `#E8341C` 계열** + 주황 서브. 밝은 배경(화이트/옐로우) 위 다크 본문, 강조어만 레드. 버튼은 전부 **레드 pill(캡슐)**.
- **배경 모티프** = **빨강/주황 세로 줄무늬 서커스 텐트** + 땡겨요 마스코트 군집. 놀이공원("~랜드") 팝업 무드가 핵심 아이덴티티.
- **폰트** = 로고/헤드라인은 **커스텀 레터링(이미지로 처리)**, 본문은 Pretendard 계열. 재현 시 로고는 이미지 애셋으로, 본문만 폰트 편집.
- **스탬프 = 5칸(3+2 배치)**, 모티프는 **체험존별 마스코트 캐릭터 얼굴 실루엣**. before=그레이 실루엣 / after=컬러 얼굴. 존 라벨: 골라요·땡겨요·주문해요·먹어요·앱설치 인증.
- **스탬프는 컴포넌트가 아닌 이미지 애셋** — 상태 전환은 이미지 교체(그레이↔컬러, 회색 도장↔레드 도장).
- **단계 구조 = 4단계 변형**: 시작 → 스탬프 → **룰렛(뽑기)** → 리워드. **본인인증 없음**이 특이점(다른 참조 이벤트와 대비).
- **룰렛 = 6분할 뽑기 리워드** — 스탬프 5개 완성 시 활성(Roulette1), 1~4개면 미완성 상태(Roulette2). 당첨 결과에 따라 **리워드 화면 5종(Reward1~5) 분기**.
- **스탬프 클릭 인터랙션 2종** — 미적립 클릭(회색 도장 미리보기 + "돌아가기") / 적립 클릭(레드 도장). 존 상세 페이지 개념.
- **리셋 규칙** — 리워드 화면의 "스탭 확인 버튼" → 첫 화면으로 이동하며 내용 초기화(데모/체험 반복용).
- **주의** — 화면이 전부 플랫 이미지라 라이브 텍스트·컬러 토큰이 없다. 자동 재현 시 (a) 이미지 애셋 재활용 또는 (b) 텍스트/도형/룰렛을 벡터로 재구성해야 하며, hex는 스크린샷 컬러픽으로 확정할 것.
