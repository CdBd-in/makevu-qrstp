# 🥃 참조 이벤트 — The Glen Grant (더 글렌그란트 전시)

> **싱글몰트 위스키 브랜드 "The Glen Grant" 전시 부스 QR스탬프 + 향미 취향 진단(설문·미션) 이벤트.** 전시장을 돌며 QR을 스캔해 **스탬프 4개**를 모으고, 그 사이 **8문항(4미션) 설문**을 통해 "나의 위스키 취향 유형"을 진단받아, **유형별 추천 제품 결과 + 쿠폰**을 받는다.
> **설문/진단(퀴즈) 변형 케이스** — 일반 스탬프 랠리에 **미션(설문) → 결과(유형 진단·제품 추천)** 흐름이 결합된 하이브리드. 스탬프 완주 자체보다 **취향 유형 진단 결과 + 쿠폰**이 리워드를 대신한다.
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

- **아트보드**: 393 폭 · 세로 가변 (시작 739 / 로그인 739 / 스탬프 734 / 미션 1039~1087 / 결과 988~1198)
- **구성**: 본인인증 **있음** · **스탬프 4칸(2×2)** · **설문 미션 8문항(4프레임)** · **취향 유형 진단 결과 3종 + 쿠폰** · **리워드 전용 화면 없음**(결과 화면의 쿠폰이 보상)
- **폰트**: 영문 헤드라인 **SangBleu OG Sans**(밑줄 있는 브랜드 서체) / 국문·본문 **Bookk Gothic**(부크크 고딕)

- 브랜드 타이틀(밑줄 서체, 3줄): **"The Glen Grant / Single Malt Scotch Whisky / Distilled for Pairing"** (SangBleu OG Sans · `#2C5258`).

## 2️⃣ 본인인증 (Login) · `5796:1763` / `5796:1791`
- 헤드라인 **"휴대폰번호 인증 한 번으로 이벤트에 참여하세요"**.
- DS 폼 그대로: `이름` / `휴대폰번호`(+ "인증번호 받기" → Filled 시 "재전송") / `인증번호`(+ "인증되었습니다") · 보조 팁 · 필수 동의 2종(개인정보 수집·이용 / 처리업무 위탁, 각 "자세히").
- CTA **"시작하기"** — Default(비활성) ↔ Filled(활성).

## 3️⃣ 스탬프 (Stamp) — 2×2 향미 엠블럼 씰
- **2열 × 2행 = 4칸** (칸 96×140 · 좌우 60.5/236.5 · 상하 270/474).
- 각 칸 = **원형 스캘럽 엠블럼 씰 이미지**(브랜드 심볼 모티프) · `stamp-before`(그레이) / `stamp-after`(그린-틸 컬러).
- 헤더(3줄, 남은 개수만 변동 · 강조 숫자 시안 `#3AC7E4`):
  - Default: "홍길동님, / **4**개의 스탬프를 더 모으고 / 리워드를 받으세요"
  - 1Done: "홍길동님, / **3**개의 스탬프를 더 모으고 / 리워드를 받으세요"
  - 4Done: "홍길동님, / 스탬프를 모두 모았어요 / 리워드를 받으세요"
  - RewardDone: "홍길동님, / 축하합니다! / 리워드 수령을 완료했어요"
- 헤더 아래 **"리워드 받기"** CTA(미완료 시 opacity 0.3 비활성 → 완료 시 활성).

## 4️⃣ 미션 (Mission) — 8문항 취향 설문 · `5796:2147` 외

  - Q1 "전시 중 가장 인상 깊게 느껴진 더 글렌그란트의 모습은?"
  - Q2 "전시를 둘러본 후 더 글렌그란트를 한 문장으로 표현한다면?"

## 5️⃣ 미션 결과 (Result) — 취향 유형 진단 + 추천 제품 + 쿠폰
- 설문 응답 → **취향 유형 3종** 중 하나로 진단(위스키 병 배경 이미지 위에 표시):
  - RESULT1: **"감각적인 일상 탐험가"** — "작은 것에서 특별함을 발견하고, 오늘의 순간을 누구보다 생생하게 즐기는 당신은 삶의 매 순간을 페어링하는 감각적인 일상 탐험가"
  - RESULT2: **"우아한 순간 수집가"** — "고급스럽고 향긋한 것에서 남다른 깊이를 발견하는 당신은 평범한 하루도 특별하게 만드는 우아한 순간 수집가"
  - RESULT3: **"깊이를 음미하는 탐닉가"** — "복잡하고 묵직한 것 안에서 진짜 가치를 발견하는 안목을 가진 당신은 음미할수록 빛나는 깊이를 탐닉하는 감각의 소유자"
- 상단 반투명 카드(30% 화이트) 안 **"홍길동님은 / [유형명]"** (유형명 = 플럼 `#5F498B` Bold 24px) + 설명 3줄.
- 하단 안내 **"홍길동님에게 어울리는 더 글렌그란트는"** + **추천 제품 카드**(예: RESULT1 = **The Glen Grant 12YO** · Light-Fruity·Orchard fruits·ABV 43%).
- 하단 CTA 2버튼: **"저장"**(작은 버튼 104px, 결과 이미지 저장) + **"쿠폰 사용하기"**(221px, before → 사용 후 after) → `5-5.RESULT-Done`은 **"쿠폰 사용 완료"**(비활성) 상태.
- 부속: `5-4.RESULT-IMG`(저장용 이미지 캡처 프레임).

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **스탬프 + 설문/진단 하이브리드** — 표준 스탬프 랠리에 **미션(8문항 설문) → 결과(유형 진단·제품 추천·쿠폰)** 블록이 추가. 스탬프는 "참여 인증" 역할, 실제 보상 훅은 **취향 진단 결과 + 쿠폰**.
2. **분기(진단) 결과 = 유형 N종 프레임 복제** — RESULT1/2/3을 동일 레이아웃으로 만들고 **유형명·설명·추천 제품 이미지만 교체**. (설문 응답 로직으로 3종 중 분기)
3. **리워드 화면 없음** — 별도 REWARD 프레임 대신 **결과 화면 하단의 "쿠폰 사용하기/사용 완료"** 로 보상 처리. 스탬프에도 `RewardDone` 상태 내장.
4. **브랜드 서체 = 이미지 아닌 웹폰트** — 헤드라인 **SangBleu OG Sans**(밑줄 데코) + 국문 **Bookk Gothic**. Pretendard가 아니므로 리테마 시 폰트 확정 필수.
5. **페이퍼 텍스처 배경** — 각 프레임 `*-bg` 이미지가 크림 페이퍼 질감 풀블리드. 카드는 30% 반투명 화이트로 가독성 확보.
6. **강조 색이 다중** — 메인 그린-틸(`#2C5258`) 외에 **결과 유형명 = 플럼 `#5F498B`**, **스탬프 남은 개수 = 시안 `#3AC7E4`** 로 포인트 컬러가 분리됨. 텍스트 교체 시 강조 색 재적용 주의.

## 🤖 디자인 자동화 재현 포인트

- **테마색**: 메인 `#2C5258`(딥 그린-틸) · 배경 크림 페이퍼 `#F3F3F3` · 포인트 플럼 `#5F498B`(결과 유형명) · 시안 `#3AC7E4`(스탬프 남은 개수) · 카드 `rgba(255,255,255,0.3)`.
- **폰트**: 영문 헤드라인 **SangBleu OG Sans**(밑줄) + 국문/본문 **Bookk Gothic** (Bold/Light). ⚠️ Pretendard 아님 — 확정 후 적용.
- **스탬프**: **4칸(2×2)** · 96×140 원형 스캘럽 엠블럼 씰(브랜드 심볼 모티프) · before(그레이)/after(그린-틸).
- **단계 구조**: 시작 → 본인인증(Default/Filled) → 스탬프(Default/1Done/4Done/RewardDone) → 미션 설문 Q1~Q8(4+Filled 프레임, 문항당 라디오 4지선다) → 결과 진단(유형 3종 + 저장 + 쿠폰 before/after) → 쿠폰 사용 완료.
- **특이사항**:
  - 스탬프 랠리에 **설문·취향 진단(퀴즈형) 결합** — 결과가 **N종 분기 프레임 복제**로 구성.
  - **리워드 전용 화면 없음** → 결과 화면 "쿠폰 사용하기"가 보상. 스탬프에 RewardDone 상태 내장.

  - 강조 색이 3계열(그린틸/플럼/시안)로 분리 → 텍스트 편집 후 강조 색 리적용 필요.
  - 배경은 페이퍼 텍스처 이미지 풀블리드, 브랜드 로고는 mix-blend-multiply로 합성.
