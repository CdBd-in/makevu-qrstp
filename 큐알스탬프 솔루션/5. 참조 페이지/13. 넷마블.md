# 🎮 참조 이벤트 — 넷마블 (Netmarble 8주년 부스 랠리)

> **넷마블 게임 IP 오프라인 행사 "8주년" QR스탬프 랠리.** 행사장 각 부스(입구·포토존·미션존 등)의 QR을 스캔하면 해당 부스 **엠블럼 스탬프**가 찍히고, **6개 부스**를 모두 방문하면 **굿즈 교환소**에서 현장 굿즈를 수령한다.
> **게임 IP 키비주얼 케이스** — 시작/스탬프 화면을 게임 캐릭터 일러스트 + **다크 네이비 × 골드 문장(紋章)** 풀블리드 이미지로 구성하고, 스탬프도 텍스트가 아닌 **골드 엠블럼(월계관+리본배너) 이미지 애셋**으로 제작했다.
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

## 1️⃣ 시작 (Start) · `3853:2164`
- **풀블리드 키비주얼 이미지**(`START-BG`) — 다크 네이비 배경 + 골드 장식 프레임 + 상단 **8주년 로고(원형 "8" 엠블럼)** + 중앙 **게임 캐릭터 8인 콜라주 일러스트**.
- 카피(이미지에 포함): 타이틀 **"✦ QR 스탬프 이벤트 ✦"** · 안내 **"부스 속 QR을 스캔해 스탬프를 모아보세요!"**
- 하단 골드 리본형 CTA **"QR 스탬프 시작하기"**(`BUTTON-Start`, 이미지).
- 최하단 저작권: `©TNPPOP / ©Netmarble Corp. All Rights Reserved`.

## 2️⃣ 본인인증 (Login) · `3853:2278` / `3853:2297`
- 표준 DS 화이트 폼 그대로. 헤드라인 **"휴대폰번호 인증 한 번으로 이벤트에 참여하세요"**(Pretendard SemiBold 28/44).
- 필드: `이름`(홍길동) / `휴대폰번호`(01012345678 + "인증번호 받기"→Filled 시 **"재전송"**, `#0C1041` 40%) / `인증번호`(123456 + "인증되었습니다").
- 보조 링크 "인증번호 문자가 오지 않을 때" · 필수 동의 체크박스 2종(개인정보 수집·이용 / 처리업무 위탁, 각 "자세히").
- CTA **"시작하기"** — Default(비활성) ↔ Filled(**`#0C1041`** 네이비·활성, 흰 글씨).

![[큐알스탬프 솔루션/attachments/netmarble-login-filled.png]]

## 3️⃣ 스탬프 (Stamp) — 부스 엠블럼 랠리
- **풀블리드 다크 네이비 배경**(`STAMP-BG`) + 상단 8주년 로고. 헤더 문구(3상태):
  - Default: **"마스터님! / 카메라로 QR을 스캔해주세요."**
  - 6/6 완료: **"굿즈 교환소에서 / 화면을 보여주세요!"**
- **스탬프 그리드**: `Frame 121`(폭 320, top 215) · **2열 × 3행 = 6칸** · 각 칸 **153×124** · 가로 gap 14 / 세로 gap 15 (wrap 오토레이아웃).
  - 각 칸 = **골드 엠블럼 이미지** — 다크 네이비 원형 방패 + **골드 월계관 테두리** + 중앙 **초승달(문장) 심볼** + 하단 **골드 리본 배너**(부스명).
  - **부스명 6종**: ① 입구 게이트 · ② 네컷부스 · ③ 개념예장 진화미션 · ④ 스톰포드 확득미션 · ⑤ 8주년 키비주얼 포토존 · ⑥ 마스터의 화실.
  - 스탬프는 **부스명이 박힌 이미지 애셋**(`STAMPn-before`=저채도 미적립 / `STAMPn-after`=골드 발광 적립). 텍스트 노드가 아니라 이미지로 고정.
- 하단 **`BUTTON-Reward` "굿즈 수령하기"**(206×47) — before/1Done에서는 opacity 40% 비활성, 6Done에서 활성.
- 상태 진행: Default(0/6) → 1Done(1개 적립) → 6Done(6/6 전부 골드).

## 4️⃣ 리워드 — 별도 화면 없음
- 리워드/경품 전용 프레임이 **존재하지 않는다.** 보상은 **"굿즈 교환소에서 화면을 보여주세요"**(현장 수령)로 대체.
- 운영 규칙(Frame 132 메모): **현장 관리자 비번 입력 → 수령 완료 → 데이터 삭제(초기화) & 시작 페이지 복귀**.
- 즉 이 이벤트는 **스탬프 완주 = 목표**이며, 최종 화면은 `STAMP-6Done`(굿즈 수령하기 버튼 활성).

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **게임 IP 키비주얼 = 풀블리드 이미지** — 시작·스탬프 화면 배경을 게임 캐릭터 콜라주 + 골드 장식 프레임 **이미지 한 장**으로 처리. 타이틀·안내문·CTA·로고까지 이미지에 굳어져 있어 **텍스트 편집이 아닌 이미지 교체**가 필요.
2. **스탬프 = 부스명 박힌 골드 엠블럼 이미지** — 월계관+초승달 문장+리본배너 엠블럼을 부스별로 제작(before 저채도 / after 골드발광 2벌). 부스 추가/변경 시 이미지 세트 교체.
3. **3단계(리워드 화면 생략)** — 굿즈 현장 수령형이라 리워드 프레임 없이 스탬프 화면 하단 **`굿즈 수령하기` 버튼**(완료 시 활성)으로 대체. WORLD PASSPORT의 4단계 리워드 구조와 대비.
4. **다크 × 골드 프리미엄 톤** — 메인 `#0C1041` 네이비에 골드 그라데이션 문장. 로그인 폼만 표준 DS 화이트로 유지(가독성).
5. **운영 초기화 플로우** — 완료 후 현장 관리자 비번 → 수령 처리 → **데이터 초기화 & 시작 페이지 복귀**(현장 부스 공용 기기 재사용 시나리오).

## 🤖 디자인 자동화 재현 포인트

- **테마색**: 메인 `#0C1041`(딥 네이비) · 골드 그라데이션(장식/스탬프) · 선택·링크 `#4B73FF` · 폼 배경 화이트 · 텍스트 `#212529`/`#737D87`.
- **폰트**: 전체 **Pretendard**(헤드라인 SemiBold 28/44, 본문 Medium). 화면 카피는 골드 이미지 애셋에 포함(폰트 재현보다 이미지 재현이 핵심).
- **스탬프 칸수/모티프**: **6칸(2열 × 3행)**, 153×124, gap 14×15. 모티프 = **다크 네이비 방패 + 골드 월계관 + 초승달 문장 + 리본배너(부스명)**. before(저채도) / after(골드 발광) 2상태 이미지.
- **단계 구조**: 시작 → 본인인증(Default/Filled) → 스탬프(Default / 1Done / 6Done) = **3단계**. 리워드 화면 없음, 굿즈 수령 버튼으로 대체.
- **특이사항**:
  - 시작·스탬프 배경은 **풀블리드 키비주얼 이미지**(코드/컴포넌트가 아닌 이미지 교체 방식).
  - `BUTTON-Reward`는 미완료 시 **opacity 40%**, 6/6 완료 시 활성.
  - 리워드 = **현장 굿즈 교환소 수령** + 관리자 비번 → 수령완료 → **데이터 초기화 & 시작 복귀** 운영 플로우.
  - 로그인 화면만 공용 DS 화이트 폼 재사용(테마 미적용, `#0C1041` 버튼만 반영).
