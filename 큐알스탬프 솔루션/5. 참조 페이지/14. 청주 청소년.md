# 🌱 참조 이벤트 — 청주시 청소년의 날 (YOUTH LAND)

> **청주시 주최 "청소년의 날 · YOUTH LAND" 부스 방문 QR스탬프 이벤트.** 청소년광장 행사장 각 부스에서 QR을 스캔하면 해당 **부스 스탬프**가 적립되고, **누적 개수 구간**에 따라 리워드(스탬프 2개=팝콘 / 5개=간식 쿠폰)를 받는다.
> **본인인증이 없는 오픈 참여형 케이스** — 시작하기 → 바로 스탬프 화면으로 진입한다. 또한 **단일 완주형이 아니라 "구간 다중 리워드"** 구조(2개/5개 두 개의 보상 단계).
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

- **Figma**: `QR 스탬프` · fileKey `n8YIkPdm2svezJYjePHn1u` · 페이지 `청주 청소년` (`5671:466`)
- **아트보드**: 393 폭 · 시작 **717** / 스탬프 **1776**(세로 스크롤) / 리워드 **714**
- **구성**: 본인인증 **없음** · **스탬프 17칸(2열 그리드)** · **다중 리워드**(2개·5개 두 단계, 리워드 전용 화면 있음)
- **폰트**: 디스플레이·헤드라인 **Sokcho Bada Dotum TTF**(손글씨풍) / 본문·버튼 **Pretendard**(SemiBold/Bold/Regular)

## 1️⃣ 시작 (Start) · `5676:5426`
- 상단 핑크 라벨 **"QR 스탬프 · 리워드 이벤트"**(Sokcho Bada Dotum, `#FFA7BC`).
- 디스플레이 타이틀 **"청주시 / 청소년의 날"**(화이트, 51.84px, 드롭섀도) + **"YOUTH LAND"**(라임 `#8AC181`, 35.52px).
- **일시 카드**(연녹 배경·상하 그린 테두리): 라벨 "일시"(핑크) + **`2026. 5. 23. [토] 14:00 ~ 18:00`**(딥 그린).
- **안내 카드**: 리워드 표 2줄 — **"스탬프 2개 리워드 · 팝콘"** / **"스탬프 5개 리워드 · 간식 쿠폰"**(라벨=딥그린, 값=다크) + 안내문 **"행사장 내 QR코드를 스캔하면 스탬프가 적립됩니다! 스탬프를 적립하고 리워드를 받아보세요."**
- 하단 그린 CTA **"이벤트 참여하기"**(→ 인증 없이 바로 스탬프 화면).

## 2️⃣ 스탬프 (Stamp) — 부스 방문 그리드
- **헤더**(3줄, 상태별 숫자만 변동): default "스탬프 2개를 더 모으고 리워드를 수령하세요" → 진행 "**2**개를 모았어요! / 리워드 받으러 가세요"(강조 숫자에 딥그린 `#579C66`).
- 헤더 아래 **버튼 3종**(그린, Pretendard SemiBold 20px): **"부스 안내도 바로가기"** / **"2개 적립 리워드 신청하기"** / **"8개 적립 리워드 신청하기"** — 미달성 버튼은 **opacity 35%로 비활성**.
- **스탬프 그리드**: `34` 좌우 여백 · 컨테이너 폭 326 · **2열** · 세로 스크롤(그리드 높이 ~1355) · 총 **17칸**.
  - 각 칸 = **110×115 그린 스탬프**(`stamp-bg-4` 이미지) + 중앙 흰색 **"부스명"** 텍스트(Sokcho Bada Dotum 15px).
  - 칸 사이 **세로 구분선**(Line 계열) + 행 사이 **가로 구분선**으로 격자(파선/실선 혼용) 표현.
  - 적립 전(before) = 동일 애셋 **opacity 35%** / 적립 후(after) = opacity 100%.
- 상태 진행: default(0) → 1/2 → 2/2(2개 달성 → 리워드 분기) → 2/8 → 8/8.

- **5개 달성**: 안내문 **"청소년광장의 운영본부에 방문하여 해당화면을 보여주세요!"** + **간식(과자+음료) 이미지** + 라벨 "스탬프 5개 리워드 · 간식 쿠폰".

## 4️⃣ 수령 후 (After the rewards) · `5676:4836`
- 헤더 **"리워드를 다 받았어요! 다른 스탬프도 모아보세요!"** + 동일 버튼 3종 + 스탬프 그리드 재노출.
- 완주가 목표가 아니라 **구간 리워드 수령 후에도 계속 부스를 모으도록** 유도하는 재참여 화면.

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **본인인증 없음(오픈 참여)** — 로그인/휴대폰 인증 프레임이 아예 없다. `이벤트 참여하기` → 곧바로 스탬프 화면. (개인정보 수집 없이 현장에서 즉시 참여하는 축제형.)
2. **구간 다중 리워드** — 단일 완주형이 아니라 **누적 2개=팝콘 / 5개=간식 쿠폰** 두 구간. 스탬프 화면 상단에 "N개 적립 리워드 신청하기" 버튼을 구간 수만큼 두고, **달성 전에는 opacity 35% 비활성**으로 표현.
3. **스탬프 = 그린 배경 씰 이미지 + 흰 "부스명"** — 씰 자체는 공용 `stamp-bg-4` 애셋 재사용, active/inactive를 **opacity 100/35로만 구분**(별도 그레이 애셋 불필요). 부스명은 텍스트 노드라 편집 가능.
4. **디스플레이 폰트 = Sokcho Bada Dotum(손글씨풍)** — 타이틀·라벨·스탬프명에 사용해 청소년 축제 무드. 본문·버튼은 Pretendard. (리테마 시 헤드라인 폰트 = 이벤트 톤에 맞춘 디스플레이체 선택이 핵심.)
5. **밝은 초록 배경 위 가독성** — 잔디 일러스트 배경 위에 **연녹 카드(`#F0FFED`) + 상하 그린 테두리**로 정보 블록을 띄우고, 강조 숫자는 딥그린 `#579C66`.
6. **리워드 화면이 구간별로 분기** — 리워드 프레임을 구간 수만큼 복제(2개용/5개용) + 안내문·이미지·라벨만 교체. 프레임 이름의 `8/8`은 레거시 표기이며 **실 내용은 "스탬프 5개 리워드"**임에 주의.
7. **수령 후 재모집 화면 포함** — 리워드 수령 후에도 스탬프 그리드를 다시 보여주는 `after the rewards` 프레임으로 지속 참여 유도.

## 🤖 디자인 자동화 재현 포인트

- **테마색**: 메인 `#77AE6E`(프레시 그린) · 서브 `#8AC181`/`#579C66` · 포인트 `#FFA7BC`(핑크) · 카드 `#F0FFED` · 본문 `#212529`. 그린 위 텍스트는 화이트.
- **폰트**: 헤드라인/디스플레이 **Sokcho Bada Dotum TTF**(손글씨풍) · 본문/버튼 **Pretendard**(SemiBold 20 버튼 / Bold 라벨 / Regular 본문).
- **스탬프**: **2열 × ~9행 = 17칸** 세로 스크롤 그리드. 칸 = 110×115 그린 씰 이미지(`stamp-bg-4`) + 흰 "부스명". active/inactive = **opacity 100% / 35%**. 격자 구분선(세로+가로).
- **단계 구조**: 시작 → (인증 생략) → 스탬프(default/1·2/2·2·8/8/8) → **리워드 2단계(2개=팝콘 / 5개=간식쿠폰)** → 수령 후 재모집. `has_auth: false`, `has_reward_screen: true`.
- **특이사항**:
  - 본인인증 없는 오픈 참여형 → 로그인 프레임 생성하지 말 것.
  - 리워드는 **구간(threshold) 다중** → 스탬프 화면 CTA를 구간 수만큼, 미달성분은 opacity 35% 비활성.
  - 스탬프 active/inactive는 별도 그레이 애셋 없이 **투명도만으로** 구분.
  - 프레임명 `stamp-8/8`·`Reward(8/8)`은 레거시 라벨 — 실제 상위 구간 리워드는 **스탬프 5개(간식 쿠폰)**.
  - 리워드 이미지 = 실물 모티프(팝콘·간식) 3D/사진 애셋 중앙 배치.
