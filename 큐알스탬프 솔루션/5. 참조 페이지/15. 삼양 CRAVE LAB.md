# 🌶️ 참조 이벤트 — 삼양 CRAVE LAB (Samyang Global Roadshow)

> **삼양식품 해외 로드쇼 "CRAVE LAB" 디지털 스탬프 이벤트.** 삼양의 대표 브랜드(불닭 · Tangle · MEP)를 주제로 **퀴즈 → 설문 → SNS 인증**을 거치며 **브랜드 스탬프 5개**를 모으면 정보 데스크에서 기프트를 수령한다.
> **글로벌 다국어 + 참여형(퀴즈·설문) 케이스** — 본인인증(휴대폰) 대신 **언어선택(태국어/중국어/영어)** 으로 시작하고, 스탬프 획득 조건이 **퀴즈 정답 · 설문 완료 · SNS 인증**으로 게이팅된다. 스탬프는 **브랜드 로고 원형 씰**을 **콜라주(스태거드) 배치**로 구성.
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

## 2️⃣ 퀴즈 (Quiz) · `5605:1302` 외
- 화이트 카드 3장(문항 3개) · 각 카드에 질문 + 4지선다(라디오). 정답순서 = **1, 3, 3**(swicy / protein / Kick).
  1. "This word is a compound of 'Sweet' and 'Spicy'… Samyang's new Buldak product?" → **Swicy** / Twicy / Smicy / Hotcy
  2. "Tangle Pasta by Samyang is made with chickpeas, making it exceptionally rich in this nutrient?" → Gelatin / Vitamin / **Protein** / Melatonin
  3. "MEP ramyeon provides 'this' to awaken your dull taste buds?" → Pick / Sick / **Kick** / Click
- 상태 프레임: default / **1 stamp**(정답 시 스탬프 1개 획득 `2-1`) / 1 correct / incorrect(오답) / all correct.
- 텍스트 색: 질문 `#111` · 보기 번호/텍스트 `#ec631a` (Pretendard Variable Medium/Bold).

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **본인인증 없음 → 언어선택이 진입 게이트** — 휴대폰 인증 폼 대신 **다국어 선택(태국어/중국어/영어)** 으로 시작. 해외 로드쇼/부스형에서 인증 대신 언어분기 채택.
2. **다국어 = 프레임 세트 병렬 복제** — 동일 8스텝 플로우를 언어별로 1벌씩 복제(캔버스에 3세트). 콘텐츠(텍스트·배경 이미지)만 언어별 교체, 레이아웃·컬러 동일.
3. **참여형 게이팅(퀴즈+설문+SNS)** — 스탬프 5칸이 자동이 아니라 **퀴즈 정답(1,3,3) · 설문 완료 · SNS 해시태그 인증** 성과로 채워짐. 5번째 스탬프는 SNS 인증 전용.
4. **스탬프 = 브랜드 로고 원형 씰 · 콜라주 배치** — 정형 격자가 아니라 좌열/우열을 top 98/188로 어긋낸 **스태거드 콜라주**. 씰마다 로고가 이미지로 고정(before/after 2벌) → 브랜드 추가/변경 시 이미지 교체.
5. **설문 B2B/B2C 분기** — 첫 문항 응답으로 상단 주관식(회사정보) 노출 여부가 달라지는 **조건부 폼**.
6. **리워드 = 오프라인 코드 수령** — 온라인 리워드 지급이 아니라 **정보 데스크에서 스태프가 인증코드 발급** → 모달 입력. 별도 완료 화면 + 재접속 시 "already participated".
7. **영상 embed 스텝** — 리워드 후 브랜드 소개 YouTube 영상 4개를 embed하는 콘텐츠 스텝 존재(부스 체류/브랜딩 목적).
8. **브랜드 워터마크 배경** — 크림 베이지 위 불닭/tangle/MEP 로고 반복 패턴 + 오렌지 프레임 테두리로 브랜드 톤 유지.

## 🤖 디자인 자동화 재현 포인트

- **테마색**: 메인 `#ec631a`(삼양 오렌지) · 다크 UI `#323232` · 배경 크림 베이지(≈`#f5ece0`) + 브랜드 로고 워터마크 패턴 · 오렌지 프레임 테두리.
- **폰트**: 전체 **Pretendard / Pretendard Variable**(Bold/SemiBold/Medium) — 다국어(태국·중국·영문) 모두 Pretendard 계열, 별도 헤드라인 폰트 없음.
- **스탬프**: **5칸** · **2열 스태거드 콜라주**(좌열 top98 / 우열 top188, 약 144×144 원형 링 씰) · 모티프 = **브랜드 로고 5종**(Buldak·tangle·MEP·CRAVE LAB·Samyang) · before(그레이)/after(컬러) 이미지 애셋 · **5번째 = SNS 인증 전용**.
- **단계 구조**: 8스텝 **언어선택 → 시작 → 퀴즈(3문항) → 설문(B2B/B2C 분기) → 스탬프(5칸) → 리워드(코드모달) → 영상(YouTube embed) → 완료**. 본인인증 없음, 리워드 화면 있음.
- **특이사항**:
  - 본인인증 대신 **언어선택 진입 게이트**, 다국어 **3세트 프레임 병렬 복제**(EN 기준으로 정의 후 언어별 콘텐츠 교체).
  - 스탬프 획득이 **퀴즈/설문/SNS 참여로 게이팅**(자동 아님) · 퀴즈 정답 **1,3,3**.
  - 리워드는 **오프라인 코드 수령**(정보 데스크 → `#323232` 인증코드 모달 → Confirm).
  - **완료/재접속 방지 화면**("you've already participated") + **영상 embed 스텝** 포함 — 표준 4단계 템플릿에 없는 확장 스텝.
  - 배경·시작·스탬프 텍스트가 대부분 **이미지 애셋에 베이크됨**(퀴즈/설문만 실제 텍스트 노드) → 자동 재현 시 이미지 교체 vs 텍스트 편집 구분 필요.
