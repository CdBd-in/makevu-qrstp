# ⌚ 참조 이벤트 — 티쏘 (TISSOT · Gentleman 38mm Popup)

> **티쏘(TISSOT) "Gentleman 38mm" 팝업스토어 미션형 럭키드로우 이벤트.** 스탬프를 여러 칸 모으는 방식이 아니라, **2개의 미션(MISSION 1·2)** 을 순서대로 수행하면 **100% 당첨 럭키드로우 티켓**을 받아 현장 스태프에게 보여주고 경품에 참여하는 구조.
> **스탬프 그리드가 없는 변형 케이스** — 격자·씰 대신 **MISSION 스텝 UI**로 구성된다. MISSION 1 = 개인정보 입력+본인인증, MISSION 2 = 카카오 채널 추가. 완주 시 리워드(럭키드로우 티켓) 화면 노출.
> **다크 럭셔리 테마** — 블랙 배경 + Tissot 레드 포인트 + 브랜드 폰트(Tissot Sans)로 시계 브랜드 톤을 재현.
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

## 2️⃣ 미션 1 (Mission 1) — 정보 입력 + 본인인증 · `5239:6364`
- 상단 **레드 밑줄 라벨 "MISSION 1"** (Tissot Sans · uppercase · 레드 + 하단 레드 보더).
- 서브 안내: **"미션 참여를 위해 아래 정보를 입력해주세요. (*필수)"**
- **수집 폼**(DS 인풋): `이름` · `성별`(드롭다운 Chevron) · `생년월일`(YYYY / MM / DD 3분할) · `휴대폰번호`(010 + "인증번호 받기" 레드 버튼) · `인증번호`(+ "인증번호 문자가 오지 않을 때" 링크).
- **필수 동의 3종**: 개인정보 수집·이용 / 개인정보의 마케팅 활용 / 개인정보 취급 위탁 (각 "자세히").
- 하단 레드 CTA **"마지막 미션 참여하기"** · 최하단 주석 "*필수정보 수집∙이용에 동의하셔야만 본 이벤트에 참여하실 수 있습니다."
- 상태 6종: Default → Focus → Verification Enabled(인증번호 받기 활성) → Verification Sent(발송) → Filled(입력완료) → Error(인증 오류·레드).

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **스탬프 없는 미션형** — 격자/씰 그리드 대신 **MISSION 1·2 순차 스텝**. "스탬프 N개" 헤더·플로팅 버튼·완주 카운트가 전부 없다. 참여 완료 = 미션 2개 수행.
2. **본인인증 = MISSION 1에 통합** — 별도 LOGIN 단계가 아니라 정보 수집 폼(이름·성별·생년월일·휴대폰) + 인증번호를 하나의 MISSION으로 묶음. 인증 상태 6종(Default~Error)을 폼 안에서 처리.
3. **다크 럭셔리 테마** — 블랙 배경 + 차콜(`#232323`) 카드 + Tissot 레드 포인트. 진한 메인 컬러라 **레드 버튼 위 텍스트는 화이트**(JINAIR 라임 케이스와 반대 처리).
4. **브랜드 폰트 이원화** — 미션/이벤트명 라벨은 **Tissot Sans(uppercase, 밑줄+레드)**, 국문 본문·헤더는 **Pretendard**. 브랜드 전용 폰트가 있는 케이스.
5. **완료(Done) = 딤 오버레이 잠금** — 참여 후에는 화면 전체를 화이트 85%로 덮고 "1회만 참여 가능합니다"를 노출해 재참여 차단. Default/Done은 동일 레이아웃 + 오버레이 유무 차이.
6. **리워드 = 럭키드로우 티켓** — 실물/이미지 리워드가 아니라 **모바일 티켓을 현장 스태프에게 제시** → 오프라인 100% 당첨 럭키드로우 연계. "참여 확인" 링크는 직원 확인용.
7. **메인 컬러 = DS 변수 재사용** — Tissot 레드가 공통 DS의 `System/Danger/Danger Primary #FC2C19`와 동일 값. 에러색과 브랜드 포인트색을 겸용.
