# 🏇 참조 이벤트 — 대상경주 (KRA 2026 대상경주 모바일 스탬프 투어)

> **한국마사회(KRA) "2026년 대상경주 모바일 스탬프 투어".** 대상경주(5경주 · G1 경마) 관람 현장에서 QR코드를 스캔하면 해당 경주 스탬프가 적립되고, **G1 대상경주 스탬프 5개**를 모두 모으면 아이패드 에어·삼성 타이블릿 **경품 추첨**에 응모할 수 있다.
> **스탬프 클릭 → 정보 팝업 케이스** — 각 스탬프가 곧 개별 대상경주(G1)이며, 적립 전/후 상관없이 **스탬프를 누르면 해당 경주의 연혁·의의·전년 우승마 정보 팝업**이 뜬다. 스탬프 자체가 콘텐츠 진입점 역할을 하는 것이 이 케이스의 핵심.
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

## 1️⃣ 시작 (Start) · `5228:3`
- 상단 **KRA(한국마사회) 로고** + 상단 배너 **"스탬프 적립할수록 당첨 확률 UP!"**.
- 디스플레이 타이틀 **"2026년 대상경주 / 모바일 스탬프 투어"**(크림, Gmarket Sans Bold) — 경마장 트랙 일러스트 배경.
- **참여방법 카드**(다크): 헤드 **"대상경주(5경주)를 관람하고 🐎 QR코드를 스캔하고 스탬프를 적립해 보세요!"**
  - 안내: "이번에 주요 대상경주(5경주)를 관람하고 현장에서 QR코드를 통해 스탬프를 적립 후, 그랑프리 대상경주 당일(12.6.)경품 추첨 응모"
  - 3스텝 아이콘: **① 스탬프 적립 → ② 응모/리워드 수령 → ③ 경품 응모**.
- **추첨경품 카드**: 아이패드 에어(1등, 2명) / 삼성 타이블릿 32인치(2등, 3명) + 이미지. 주석 "경품 사양·수량은 변경될 수 있으며, 변경시 별도 고지".
- **적립 장소 카드**: "스탬프투어 이벤트 안내 테이블 운영 (닉네임 1등 고객센터 앞/메인 앞 놀이공원 앞)" + 유의사항 3줄.
- 하단 오렌지 CTA **"투어 시작하기"** (`#FE7F2D`, 크림 텍스트).

## 2️⃣ 본인인증 (Login) · `5228:2730` / `5228:2731`
- 헤드라인 **"휴대폰번호 인증 한 번으로 이벤트에 참여하세요"**.
- DS 폼 그대로: `이름`(Field_Name) / `휴대폰번호`(Field_Phone + "인증번호 받기") / `인증번호`(Field_Verification).
- Filled 상태: 인증번호 입력값·Tip·`very_success`("인증되었습니다") 노출.
- 필수 동의 체크박스 2종(개인정보 수집·이용 / 처리업무 위탁, 각 "자세히") + CTA `button`(Default 비활성 ↔ Filled 활성).

## 3️⃣ 스탬프 (Stamp) — G1 대상경주 5씰
- 헤더(상태별 문구 변동):
  - Default: **"지금까지 총 / 0개의 스탬프를 적립했어요"** (숫자 오렌지 강조)
  - 진행: **"지금까지 총 / 2개의 스탬프를 적립했어요"** (`3-2.STAMP-2Done`)
  - 완료: **"스탬프를 모두 모았어요 / 리워드를 받으세요"** (`3-3.STAMP-5Done`)
  - 수령완료: **"축하합니다 / 리워드 수령을 완료했어요"** (`3-4.STAMP-RewardDone`)
- **리워드 받기** 버튼(오렌지, 175×48) — Default에서는 opacity 40%(비활성), 5Done에서 활성, RewardDone에서 **"리워드 수령완료"**.
- 안내문 **"*각 스탬프를 눌러 대회 정보를 확인해 보세요"** — 스탬프 클릭 → 팝업 유도.
- **스탬프 그리드**(`Frame 134`, 폭 393 · 높이 773): flex-wrap · gap `162px / 37px` · **147×147 원형 씰 5개**, 배치 = **1·2행 2열 + 5번째 중앙 단독**(2-2-1 콜라주형).
  - 각 씰 = 대상경주(G1) 심볼 이미지(before 그레이 / after 컬러): **① 코리안 더비 · ② 농림축산식품부장관배 · ③ 코리아컵&코리아스프린트 · ④ 대통령배 · ⑤ 그랑프리**.
  - 씰은 **이미지 애셋**(`N-before 1`) — 각 경주 로고/엠블럼이 이미지로 굳어짐.
  - 씰 아래(스탬프 화면 상세)에 경주명 + 일시가 붙음: 코리안더비 5.3.(일)10:00~18:00 · 농림축산식품부장관배 6.7.(일) · 코리아컵&코리아스프린트 9.6.(일) · 대통령배 10.11.(일) · 그랑프리 12.6.(일)10:00~15:00.

## 4️⃣ 정보 팝업 (Popup) — 스탬프 클릭 시
> 리워드가 아니라 **각 스탬프(경주) 상세 정보 팝업**. "적립 전/후 상관없이 스탬프N 클릭"으로 진입. 우측 상단 Close Icon(24×24)로 닫음.
- 공통 구조(다크 카드): **경주명 대타이틀(오렌지)** + 부제 + 일시 + **"주요 연혁 및 경주 의의"**(★ 불릿 2~3개) + **"전년 대상경주 우승마"** 표(대상경주명/경주일자/거리, 우승마/기수명/총상금).
- **POPUP1(`5229:3048`)** = 코리안 더비: "단 한번의 도전기회! 최고의 3세마를 가린다 / **코리안 더비(G1)** / 2026.5.3.(일)" · 전년 우승마 오아시스블루(진겸, 1800m, 10억원).
- **POPUP2(`5229:3059`)** = 농림축산식품부장관배.

- **POPUP4(`5229:3114`)** = 대통령배 · **POPUP5(`5229:3116`)** = 그랑프리.

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **스탬프 = 콘텐츠 진입점(팝업 링크)** — 스탬프 5칸 각각이 개별 G1 대상경주이며, 적립 전/후 상관없이 클릭하면 **경주 상세 정보 팝업**이 뜬다. 스탬프가 단순 진행 표시를 넘어 **정보 허브** 역할. (팝업 5종 별도 프레임)
2. **5칸 2-2-1 콜라주 배치** — 4·6·8칸 정형이 아니라 **2열 4개 + 5번째 중앙 단독**(flex-wrap + gap 162/37로 마지막 씰 센터링). 홀수 스탬프 처리 참고 케이스.
3. **탭형 팝업(2-in-1)** — 코리아컵/코리아스프린트가 한 씰(③)에 묶여 상단 pill 탭으로 두 경주를 전환(POPUP3-1/3-2). 한 스탬프에 복수 콘텐츠를 담는 방식.
4. **리워드 화면 없음(3단계형)** — 경품은 오프라인 추첨. "리워드 받기" 버튼은 스탬프 화면 내에서 opacity로 활성/비활성만 전환하고 별도 리워드 프레임 없음. (경기수의컨퍼런스와 동일한 3단계 패턴)
5. **밝은 스탬프 영역 위 다크 텍스트** — 헤더 안내문은 다크 `#233D4C`, 강조 숫자만 오렌지. 배경(`#233D4C`)과 달리 스탬프 콘텐츠 영역이 밝은 이미지라 텍스트 색이 반전됨. 숫자 교체 시 오렌지 강조 재적용 필요.
6. **KRA 브랜드 = 다크 그린/틸 + 오렌지** — 경마장 트랙 키비주얼 배경 + 오렌지 CTA. 씰 모티프는 각 경주 엠블럼(더비/장관배/코리아컵/대통령배/그랑프리 트로피) 이미지.

## 🤖 디자인 자동화 재현 포인트

- **테마색**: 메인 오렌지 `#FE7F2D` · 배경 다크 틸 `#233D4C` · 텍스트/버튼 크림 `#F5FBE6`(=`#F6FBE7`).
- **폰트**: 전체 **Gmarket Sans** (헤드라인·강조 Bold / 본문·버튼 Medium). 영문 헤드라인 별도 없음.
- **스탬프**: **5칸** · **원형 147×147 씰** · 배치 **2-2-1(2열 4개 + 중앙 단독)** · 모티프 = 5개 G1 대상경주 엠블럼 이미지(코리안더비·농림축산식품부장관배·코리아컵&코리아스프린트·대통령배·그랑프리) · before 그레이 / after 컬러.
- **단계 구조**: 시작 → 본인인증(2) → 스탬프(4상태: Default/2Done/5Done/RewardDone) → **스탬프 클릭 시 정보 팝업(5~6종)**. **리워드 전용 화면 없음** · 본인인증 있음.
- **특이사항**:
  - 스탬프가 곧 **정보 팝업 링크**(적립 전/후 무관 클릭 진입) — 스탬프별 팝업 프레임 반드시 세트로 제작.
  - 한 씰(③)이 **2탭 팝업**(코리아컵/코리아스프린트) — pill 탭 전환 구조.
  - "리워드 받기" 버튼은 스탬프 화면 내 opacity 40%↔100%로 상태 전환(별도 리워드 화면 없음).
  - 시작 화면에 참여방법 3스텝·추첨경품·적립장소·유의사항 카드가 모두 포함(정보량 많은 롱 시작 프레임 1690px).
  - 팝업 본문은 "주요 연혁 및 경주 의의" ★불릿 + "전년 대상경주 우승마" 표 포맷 고정.
