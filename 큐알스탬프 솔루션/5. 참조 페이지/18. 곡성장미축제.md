# 🌹 참조 이벤트 — 곡성장미축제 (Gokseong Rose Festival)

> **전라남도 곡성 세계장미축제 "로지와 함께! 스탬프 투어".** 축제장(기차마을) 내 각 명소에 비치된 QR을 스캔하면 해당 **명소 스탬프(로지프렌즈 씰)** 가 적립되고, **7개 스탬프**를 모두 모으면 **로지프렌즈 기념품**을 받는다.
> **캐릭터 IP(로지/로지프렌즈) + 지도 팝업** 케이스 — 마스코트 3D 캐릭터를 시작·리워드 키비주얼로, 명소별 원형 씰을 스탬프 모티프로 사용. 스탬프 화면에 **축제장 지도 팝업**(핀 위치)이 붙는다.
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

## 1️⃣ 시작 (Start) · `5377:10515`
- 크림 배경 풀블리드. 상단 타이틀 **"로지와 함께! / 스탬프 투어"**(레드) + **아치형 장미 게이트 아래 로지프렌즈 3D 캐릭터** 키비주얼.
- **참여방법 안내 카드**: 딥마룬 pill 헤더 **"스탬프 투어 참여방법"** → 아이콘 플로우(**QR 스캔 → 도장 → 선물상자**) + 안내문.
  - 안내문: **"기차마을 내 QR코드를 스캔하면 스탬프가 적립됩니다. 총 7개의 스탬프 적립 시 로지프렌즈 기념품을 드려요! (당일 재고 소진 시 조기 종료)"**
- 하단 레드 CTA **"시작하기"**(`#E24136` · radius 8 · 좌우 30 · bottom 40).

## 2️⃣ 스탬프 (Stamp) — 명소 씰 랠리 + 지도 팝업
- 헤더(상태별 문구 변동, 남은 개수만 변경):
  - Default: **"스탬프 7개를 더 모으고 리워드를 수령하세요"** (`2-1`)
  - 2개 적립: **"스탬프 5개를 더 모으고 리워드를 수령하세요"** (`2-3`)
  - 완료: **"스탬프를 모두 모았어요! / 리워드를 수령하세요"** (줄1 레드 강조) (`2-4`)
  - 수령완료: **"축하합니다! 리워드 수령을 완료했어요"** (`2-5`)
- 헤더 아래 **레드 CTA "리워드 받기"**(항상 노출 · 완료 후 `2-5`에서 "리워드 수령 완료"로) + 딥마룬 pill **"스탬프 위치 자세히 보기 ›"**.
- **스탬프 그리드**: **2열 × 4행 = 7칸**(1~6번 2열, **7번은 중앙 정렬**). 칸 크기 **130×126**, 좌우 여백 42.5.
  - 각 칸 = **원형 씰(배지)** — 상단 아치 텍스트 **"GOKSEONG"** + 중앙 **로지 캐릭터**(장미 마스코트) + 하단 **리본 라벨 배너에 명소명**.
  - 명소(7): **① 생태학습관 · ② 장미여신 · ③ 장미의집 · ④ 잔디광장 · ⑤ 종합안내소 · ⑥ 장미축제 체험존 · ⑦ 요술랜드 도깨비**.
  - **before = 그레이 씰(이미지)** / **after = 레드 씰**(1번 생태학습관만 벡터 컴포넌트로 조립: `_레이어_1` 로지 벡터 + `Group 2` 리본 라벨 `#E47592`/테두리 `#7F191E`, 나머지는 이미지 애셋 before/after 2벌).
- **지도 팝업(`2-2`)**: "스탬프 위치 자세히 보기" 탭 시 **딤 오버레이 + 축제장 항공뷰 지도**(빨간 핀으로 명소 위치 표시) 모달. 상단 **"*좌우로 스크롤해 보세요"** + 닫기(X). Y값 170px 고정.

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **본인인증 없음(2단계 뼈대)** — 시작 → 스탬프 → 리워드. 로그인 폼이 빠진 **가벼운 축제형** 플로우. 대신 스탬프 상태가 5종(Default/MapPopup/2Done/7Done/RewardDone).
2. **지도 팝업 상태 추가** — 명소가 축제장 곳곳에 흩어져 있어 **"스탬프 위치 자세히 보기 → 항공 지도(핀) 모달"** 을 별도 상태 프레임(`2-2`)으로 둔다. 지도 팝업 Y=170px 고정, 좌우 스크롤 힌트.
3. **스탬프 7칸 = 2열 + 마지막 중앙** — 홀수(7) 배치는 **1~6 2열, 7번만 가로 중앙**. WORLD PASSPORT(4칸 2×2)·경기수의컨퍼런스(67칸 3열)와 다른 홀수 처리 예시.
4. **캐릭터 IP 활용** — 로지프렌즈 마스코트를 ⓐ 시작/리워드 3D 키비주얼 ⓑ 스탬프 원형 씰 중앙 캐릭터로 재사용. 씰 = "GOKSEONG" 아치 + 캐릭터 + **명소명 리본 라벨**(핑크 `#E47592`).
5. **씰 = 명소명 박힌 이미지(before/after 2벌)** — 명소 추가/변경 시 텍스트 편집이 아니라 **그레이/레드 씰 이미지 교체**. (1번 씰만 벡터로 조립되어 있어 리본 라벨 색·문구 편집 가능)
6. **콘텐츠 대부분이 배경 이미지에 포함** — 시작/리워드 프레임은 **풀블리드 배경 이미지 + CTA 버튼**만 실제 노드. 타이틀·안내 카드·캐릭터가 배경 PNG에 굳어져 있어 **문구 수정 = 이미지 재작업**.
7. **레드 단색 테마 + 크림 배경** — 메인 `#E24136`(밝은 레드라 버튼 위 텍스트는 화이트 유지) · 강조/테두리는 딥마룬 `#7F191E`로 대비.

## 🤖 디자인 자동화 재현 포인트

- **테마색**: 메인 `#E24136`(장미 레드) · 딥 `#7F191E`(마룬, pill·씰/리본 테두리) · 리본 라벨 `#E47592`(핑크) · 배경 크림/아이보리 · 본문 `#1D1D1D` · 버튼 텍스트 화이트.
- **폰트**: 전체 **Paperlogy** — 헤드라인/버튼 SemiBold(6), 리본 라벨 등 강조는 Bold(7). (다른 이벤트의 Pretendard 아님에 유의)
- **스탬프**: 7칸 · **2열 + 마지막(7번) 중앙 정렬** · 칸 130×126 · 원형 "GOKSEONG" 아치 씰 + 로지 캐릭터 + 하단 리본 라벨(명소명). before=그레이 / after=레드. 명소 7종: 생태학습관·장미여신·장미의집·잔디광장·종합안내소·장미축제 체험존·요술랜드 도깨비.
- **단계 구조**: 시작(744) → 스탬프(1117, 5상태: Default/MapPopup/2Done/7Done/RewardDone) → 리워드(717, Default/Done). **본인인증 없음**.
- **특이사항**:
  - **지도 팝업**(항공뷰 + 빨간 핀 · Y=170 고정 · 좌우 스크롤)이 별도 스탬프 상태로 존재 — 명소 분산형 축제에 유용.
  - 시작·리워드 화면 콘텐츠(타이틀·캐릭터·안내 카드)가 **풀블리드 배경 PNG에 포함** → 문구 변경 시 이미지 교체 필요. 실제 편집 가능한 노드는 CTA 버튼뿐.
  - 헤더 "N개를 더 모으고" 숫자만 상태별로 바꿔 진행 표현(플로팅 없이 상단 CTA 상시 노출).
