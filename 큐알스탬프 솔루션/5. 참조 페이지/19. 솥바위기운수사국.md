# 🕵️ 참조 이벤트 — 솥바위 기운 수사국 (Sotbawi Energy Investigation Bureau)

> **의령 "솥바위(정암) 기운" 테마의 탐정 컨셉 QR스탬프 이벤트.** "대한민국의 반만을 지키는 솥바위의 기운"을 컨셉으로, 방문지에서 QR을 스캔하면 **기운 별 조각(스탬프)** 을 모으고, **3개(3/3)** 를 모두 채우면 **리워드(충전 케이블·셰이커 키링·글리터 키링 중 택1)** 를 받는다.
> **탐정/미스터리 무드 + 지도(map) 배경 스탬프** 케이스 — 스탬프 화면이 격자가 아니라 **의령 지도 위 3개의 위치 핀 마커**로 배치된다. 시작·스탬프·리워드 화면 모두 **일러스트가 통짜 배경 이미지**로 굳어 있고, 스탬프 핀과 CTA만 별도 오버레이 애셋이다.

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **지도(map) 배치 스탬프** — 4~16칸 격자가 아니라 **지역 지도 일러스트 위에 위치 핀 3개를 비정형 배치**. 핀 좌표 = 실제 방문지 위치에 대응. (경기수의컨퍼런스의 그리드, WORLD PASSPORT의 2×2와 대비되는 "지도형" 유형)
2. **통짜 배경 이미지 + 오버레이 애셋** — 시작/스탬프/리워드는 헤드라인·안내문·캐릭터·지도가 **하나의 배경 이미지**로 굳어 있고, 스탬프 핀과 CTA 버튼만 별도 애셋. 문구 수정 시 **텍스트 편집 불가 → 이미지 재제작** 필요.
3. **테마 폰트 = Danjo-bold(단조)** — 헤드라인·CTA에 **손글씨/붓 느낌 단조체** 사용(탐정·빈티지 무드). 폼/본문만 Pretendard. (Pretendard 단일이 아님 — 브랜드 무드 폰트 병행 케이스)
4. **세계관 카피** — 탐정 수사물 톤("검거 할 예정이다", "요원들", "기운 별 조각 수집")으로 이벤트 스토리텔링. 콘텐츠 자체가 컨셉을 만든다.
5. **before/after 씰 교체** — 미적립 회색 핀 → 적립 시 "CLEAR" 컬러 도장 이미지로 교체. 상태 4단계(Default·1Done·3Done·RewardDone).
6. **리워드 화면 존재(4단계)** — 리워드 상품(택1)·수령처·기간을 전용 화면에 명시. 4-1/4-2는 CTA 상태만 차이나게 동기화.

## 🤖 디자인 자동화 재현 포인트

- **테마색**: 메인 **`#CB000B`**(딥레드/버건디) · CTA 텍스트 **`#FFF9E0`**(크림) · 본문 크림/화이트(딥레드 배경) · 로그인만 화이트 배경 다크 텍스트.
- **폰트**: 헤드라인·CTA = **Danjo-bold(단조체)** · 로그인 폼·본문 = **Pretendard**(SemiBold 20 버튼). → 리테마 시 "브랜드 무드 폰트 + Pretendard 병행" 규칙 적용, 헤드라인에 Pretendard를 쓰지 말 것.
- **스탬프**: **3칸 · 지도(map) 위 위치 핀 배치**(격자❌). 각 핀 = 원형 씰 + 위치명 라벨 · before(회색)/after("CLEAR" 컬러) 이미지 교체. 좌표는 실제 방문지 위치에 매핑.
- **단계 구조**: 시작 → 본인인증(Default/Filled) → 스탬프(Default/1Done/3Done/RewardDone 4상태) → 리워드(Default/Done). **본인인증·리워드 화면 모두 있음(4단계)**.
- **특이사항**:
  - 시작/스탬프/리워드는 **통짜 배경 이미지** — 문구 변경 시 텍스트 편집이 아니라 이미지 재작업.
  - 탐정/미스터리 세계관 카피 + 빈티지 종이 프레임 무드.
  - 리워드 = 택1(충전케이블·셰이커 키링·글리터 키링), 수령 = "Staff에게 화면 제시".
  - 로그인 화면만 표준 DS 폼(화이트 배경)으로 분위기 전환됨.
