# 🌸 참조 이벤트 — 고양꽃박람회 (시간 여행자의 정원)

> **고양국제꽃박람회 "시간 여행자의 정원" QR스탬프 이벤트.** 행사장 내 각 정원(작품) 앞 QR을 스캔하면 해당 **작품 스탬프**가 찍히고, **작품 스탬프 6개**를 모두 모으면 홍매실 부스에서 **엽서(호작도·십장생도)** 를 받는다.
> **관람 동선 안내형 케이스** — 스탬프가 단순 카운트가 아니라 **정원 작품 단위**이며, 각 스탬프에 **작품 설명 외부 링크**가 매핑된다(스탬프 상태와 무관하게 클릭 시 새 창). 본인인증 단계는 **없다.**
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

- **아트보드**: 393 폭 · 시작 **705** / 스탬프 **819** / 리워드 **921** (세로 가변)

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **본인인증 생략(3단계 흐름)** — 관람형 이벤트라 시작 직후 바로 스탬프 진입. 단계 번호가 1·2·4로 3(인증)이 빠진다.
2. **스탬프 = 콘텐츠(작품) 단위 + 외부 링크** — 단순 카운트가 아니라 각 정원 작품에 대응. **클릭 시(상태 무관) 작품 설명 페이지가 새 창**으로 열리는 관람 동선 안내형. (링크 매핑은 스탬프별로 필수)
3. **가변 헤더 카피** — 남은 스탬프 수에 따라 헤더 문구를 상태별로 교체(6→4→완료→수령완료). Diphylleia 세리프로 감성 강조.
4. **중명도 퍼플 테마 + 코랄 포인트** — 배경 텍스트는 화이트(`#F3F0FF`), 스탬프 작품명만 코랄(`#EF4D66`)로 대비.
5. **시작·리워드 화면이 통이미지** — START/REWARD 프레임은 단일 이미지로 조판되어, 재현 시 텍스트 편집이 아니라 **이미지 교체 또는 재조판**이 필요.
6. **리워드 = 오프라인 엽서 수령** — 리워드 화면에 수령장소(홍매실 부스)·수령기한 + 네이버지도 임베드를 명시. Default/Done은 CTA 상태만 차이(동기화 필수).
