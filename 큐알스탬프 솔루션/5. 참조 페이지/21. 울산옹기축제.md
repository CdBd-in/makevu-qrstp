# 🏺 참조 이벤트 — 울산옹기축제 스탬프투어 (Ulsan Onggi Festival 2026)

> **울산옹기축제 "스탬프투어" QR스탬프 이벤트.** 축제장 각 스팟에서 QR을 스캔하면 해당 코스 스탬프가 찍히고, **스탬프 5개**를 모두 모으면 **룰렛**을 돌려 경품(미니옹기 / 옹기접시)을 뽑는 **랜덤 리워드형** 이벤트다.
> **룰렛(추첨) 단계가 리워드 앞에 끼어 있는 케이스** — 스탬프 완주 → 룰렛 스핀으로 상품 결정 → 당첨 리워드 화면. 또한 **각 스탬프마다 영상(Vimeo)이 연결**되어, 적립 시 해당 스탬프 스토리 영상이 재생된다.
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

## 🎨 테마 (옹기축제 세이지 그린 + 옹기 브라운)

| 요소 | 값 | 비고 |
|---|---|---|
| **메인 톤** | **세이지/민트 그린** (축제 키비주얼) | 배경 그라데이션·헤드라인·CTA 버튼 · 이미지에 래스터로 baked-in |
| **서브 톤** | **옹기 브라운**(도기 색) | 스탬프 도장·룰렛 상품(미니옹기/옹기접시)·리워드 옹기 이미지 |
| **배경** | 축제 KV 이미지(`START 4` / `STAMP 6` / `ROULLETE 1` / `REWARD 2`) 풀블리드 | 각 화면 배경이 통이미지 |
| **START 리워드 잔여개수 배지** | 배경 `#FFF3C9`(연크림) + 텍스트 `#464543` | Pretendard SemiBold 16 · 유일하게 노드 스타일로 노출된 토큰 |
| **CTA 버튼** | 그린 pill(`START 3`/`ROULETTE 1`/`REWARD 3` 이미지) | 비활성 시 opacity 40%(스탬프 Default의 `REWARD 3`) |
| **미적립/적립 스탬프** | 그레이 도장 ↔ 브라운(active) 도장 | before/after 이미지 애셋 |

> ⚠️ 이 페이지는 **거의 모든 화면이 통이미지(래스터)로 병합**되어 있어 hex가 노드 스타일로 노출되지 않는다. 노출된 토큰은 START 배지(`#FFF3C9` / `#464543`)뿐이며, 나머지 색은 스크린샷 기준 세이지 그린 + 옹기 브라운으로 재현한다.

## 1️⃣ 시작 (Start) · `5082:3`
- 디스플레이 타이틀 **"2026 울산옹기축제 스탬프투어"** + 서브 **"~옹기마을~"**(축제 KV 배경 위).
- 안내: "각 부스(스탬프 스팟)에서 QR을 스캔해 스탬프를 적립하세요" + "스탬프투어 참여방법" 안내 블록.
- **리워드 잔여개수 배지**(연크림 `#FFF3C9`): **`[리워드 잔여개수] 미니옹기 00개 | 옹기접시 000개`** — 실시간 재고를 변수로 표시(`5085:5/6`).
- 하단 그린 CTA **"룰렛 모험 시작하기!"**.

## 2️⃣ 본인인증 (Login) · `5085:1429` / `5085:1449`
- 헤드라인 **"휴대폰번호 인증 한 번으로 이벤트에 참여하세요"**.
- DS 폼 그대로: `Field_Name` / `Field_Phone` / `Field_Verification`(인스턴스) + 필수 동의 체크박스 2종(개인정보 수집·이용 / 처리업무 위탁, 각 "자세히").
- CTA `button` 인스턴스 — Default(비활성) ↔ Filled(활성).

## 3️⃣ 스탬프 (Stamp) — 지도형 코스 5스팟 + 스탬프 영상
- 상단 헤드라인 **"2026 울산옹기축제 스탬프투어"**.
- **상단 대형 영상 영역(검정 박스)** — 가장 최근 적립한 스탬프의 스토리 영상이 재생(컨트롤바 OFF · Autoplay · Loop).
- 안내(★ 2줄): "**스탬프 5개를 모두 모은 후 하단의 [리워드 받기] 버튼을 눌러주세요.**" / "**적립된 스탬프를 누르면 해당 스탬프의 영상을 다시 볼 수 있습니다.**"
- **"리워드 받기" 버튼** — 미완료 시 opacity 40%(비활성·`REWARD 3`), 5/5 완료 시 활성 그린으로 전환.
- **스탬프 배치 = 5칸 2-1-2 스태거드(지도/코스형)** · 87×87 원형 도장 · **점선 경로(dashed)로 스팟을 연결**:
  - 1행(y782): **물의 계곡**(좌) · **첫번째 결투**(우)
  - 2행(y848·중앙): **두번째 결투**
  - 3행(y914): **마지막 결투**(좌) · **옹기의 탄생**(우)
  - 각 도장은 상단 부제(예: `0개적립보상` / `옹기의 집`)+중앙 코스명+하단 별(★★★) 표시가 이미지로 굳어짐.

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **룰렛(추첨) 단계 삽입 = 5단계** — 스탬프 완주 → **룰렛 스핀으로 상품 랜덤 결정** → 결과별 리워드. 표준 4단계에 `4-1.ROULLETE`를 스탬프와 리워드 사이에 끼운다. 룰렛 화면엔 **당첨 확률(옹기접시 93% / 미니옹기 7%)** 을 반드시 표기.
2. **리워드 2종 분기** — 룰렛 결과로 `5-1.REWARD1`(옹기접시) / `5-2.REWARD2`(미니옹기)가 갈리며, 문구·이미지만 다르고 레이아웃 동일. `5-3.REWARD-Done`으로 수렴(수령 처리).
3. **스탬프 = 지도/코스형 스태거드 배치(2-1-2)** — 4×N 격자가 아니라 **점선 경로로 연결된 5개 코스 스팟**. 정형 그리드가 아니므로 좌표를 개별 배치(y782/848/914, x63/153/245).
4. **스탬프별 영상 연동(Vimeo)** — 각 코스에 스토리 영상이 매핑되고, 상단 대형 플레이어에서 **최근 적립 스탬프 영상 Autoplay·Loop·컨트롤바 OFF**. 적립 스탬프를 다시 누르면 재생. (영상 URL은 `5085:1568` 매핑표 참조)
5. **실시간 재고 배지** — 시작 화면에 **"[리워드 잔여개수] 미니옹기 00개 | 옹기접시 000개"** 를 변수로 노출(연크림 `#FFF3C9` 배지). 경품 소진 관리형.
6. **화면 대부분이 통이미지(래스터)** — 배경·안내문·CTA·스탬프 부제가 png로 병합되어 있어 텍스트/색 편집이 **이미지 교체** 필요. 리테마 시 원본 소스(축제 KV) 재출력 전제.
7. **비활성 CTA = opacity 40%** — 스탬프 미완료 시 "리워드 받기" 버튼을 opacity 40%로 딤 처리 → 5/5 완료 시 활성 그린.

## 🤖 디자인 자동화 재현 포인트

- **테마색**: 메인 = 축제 세이지/민트 **그린**(배경 그라데이션·헤드라인·CTA) · 서브 = 옹기 **브라운**(스탬프·상품·리워드) · START 배지 = `#FFF3C9` 배경 + `#464543` 텍스트(유일 노출 토큰). 나머지는 통이미지 baked-in → 스크린샷 기준 재현.
- **폰트**: 전체 **Pretendard** (헤드라인 Bold / 본문 SemiBold). 별도 영문 헤드라인 폰트 없음.
- **스탬프**: **5칸** · 원형 도장 87×87 · **2-1-2 스태거드(지도/코스형)** · **점선 경로로 연결** · 코스명 = 물의 계곡 / 첫번째 결투 / 두번째 결투 / 마지막 결투 / 옹기의 탄생 · before(그레이)↔after(브라운) 이미지 애셋.
- **단계 구조**: 시작 → 본인인증(2) → **스탬프(4상태)** → **룰렛(추첨)** → **리워드(랜덤 2종 + Done)** = 5단계. (본인인증 O / 룰렛 O / 리워드 화면 O)
- **특이사항**:
  - 스탬프-영상(Vimeo) 연동: 상단 대형 플레이어, 최근 적립 영상 Autoplay·Loop·컨트롤바 OFF, 적립 스탬프 재생.
  - 룰렛 추첨 단계 + 당첨확률(93% / 7%) 표기.
  - 리워드 랜덤 2종 분기(옹기접시/미니옹기) → Done 수렴.
  - 시작 화면 실시간 잔여 재고 배지(변수).
  - 화면 대부분 래스터 통이미지 → 문구/색 수정은 이미지 교체 전제.
