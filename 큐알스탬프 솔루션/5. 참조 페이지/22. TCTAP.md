# 🫀 참조 이벤트 — TCTAP (31st TCTAP, 심혈관중재술 국제학회)

> **31st TCTAP "QR STAMP CHALLENGE" — 영문 전용 국제학회 부스 랠리.** 전시 부스를 돌며 QR을 스캔하면 해당 **스폰서(참가업체) 로고 스탬프**가 찍히고, **스탬프 10개**를 모으면 정보를 제출해 **Lucky Draw(경품 추첨)** 에 응모한다.
> **원형 프로그레스 링 케이스** — 스탬프를 격자가 아니라 **중앙 도넛형 진행률 링(%)을 10개 로고 스탬프가 원형으로 감싸는** 배치로 구성. 적립 전=`TCTAP` 플레이스홀더 씰, 적립 후=**실제 스폰서 로고 이미지**로 교체된다.
> **국문이 아닌 영문 이벤트** — 폰트가 Pretendard가 아니라 **Gotham** 패밀리이며, 본인인증 대신 **정보입력 폼(FORM)** 을 사용한다.
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **원형 프로그레스 링 배치** — 4~16칸 격자가 아니라 **중앙 도넛형 %링 + 10개 로고 스탬프 원형 배열**. 링 진행분(퍼플)과 하트 노드가 적립률에 따라 시계방향으로 채워지고, 중앙 `%` 숫자가 함께 갱신(0/30/100).
2. **스탬프 = 스폰서 로고 이미지** — before=`TCTAP` 워터마크 씰 / after=실제 참가업체 로고. 업체 추가·변경 시 **텍스트가 아닌 로고 이미지 교체**(before/after 2벌).
3. **48개 중 10개 규칙** — 실제 스캔 부스는 48개지만 **순서 무관 아무 10개** 채우면 완료. 링/헤더는 항상 **10 기준**(남은 수 = 10−적립).
4. **본인인증 대신 정보입력 FORM** — Name/Institute/Mobile + 동의 1개. 국제학회 특성상 국내 휴대폰 인증이 아니라 **국가코드 포함 자유입력 폼**. 스탬프 완료(10)를 게이트로 FORM 노출.
5. **리워드 화면 생략** — 경품·당첨발표는 시작/폼 카드로 안내(현장 Event Screen + 문자). 앱 최종 화면은 스탬프 RewardDone.
6. **영문 전용 + Gotham 폰트** — 국문 이벤트의 Pretendard와 달리 전체 **Gotham**(Black 디스플레이 / Bold 라벨 / Medium 본문). 리테마 시 폰트 패밀리부터 교체.
7. **debug 테두리 무시** — 캔버스의 `#ff5454`/`#547cff` 4px 사각 테두리는 플로팅·강조 표시용 가이드이므로 UI에 렌더하지 않는다.
8. **사파리 시크릿 모드 안내 변형** — 스탬프 적립이 시크릿 모드에서 불가하므로 `1.START (safari)` 별도 안내 화면 존재.

## 🤖 디자인 자동화 재현 포인트

- **테마색**: 메인 딥 퍼플 `#35236f` · 스탬프 배경 크림 `#fae2be` · 링 accent 오렌지(트랙)+퍼플(진행) · CTA 스카이블루 `#547cff` · 폼 테두리 `#e7e7e7`.
- **폰트**: 전체 **Gotham** — 타이틀/`%`/폼타이틀=**Gotham Black**, 라벨(1.Name 등)=**Gotham Bold**, 헤더문구·본문·placeholder=**Gotham Medium** (⚠️ Pretendard 사용 금지, 영문 이벤트).
- **스탬프 칸수/모티프**: **10칸(48중 10)** · **원형 배치(중앙 도넛 %링 + 8~10시 로고 링)** · 모티프=**참가 스폰서 로고**(before=`TCTAP` 워터마크 씰 → after=실제 로고). 링은 적립률 %로 채워지는 프로그레스, 상단 하트 노드 이동.

- **특이사항**:
  - 진행률·완료 판정은 **링/헤더의 10 기준**(스캔 대상 48개와 별개), 남은 수 = 10−적립.
  - 스탬프 숫자(헤더 "Collect N more")·`%`는 상태별로 **숫자만** 교체.
  - 경품·발표 안내는 **화면 카드**로 처리(리워드 화면 없음).
  - 국제 응모용 **국가코드 포함 전화 자유입력**(휴대폰 인증 아님).
  - 사파리 시크릿 모드 차단 안내 화면 별도.
