# 🚠 참조 이벤트 — 송도해상케이블카 (BUSAN AIR CRUISE · 스탬프 어드벤처)

> **송도해상케이블카(부산에어크루즈) "스탬프 어드벤처" QR스탬프 이벤트.** 케이블카 탑승객이 파크 내 지정 포토스폿(어트랙션) QR을 찍어 스탬프를 모으고, **5개 스탬프**를 모두 모으면 기념품 3종 **최대 47~56% 할인 쿠폰**을 받는다.
> **다국어(4개국어) + 언어선택 화면이 있는 케이블카 관광 케이스** — 본인인증은 없고 **언어선택**이 첫 단계다. 하늘/구름/파도의 밝은 스카이블루 그라데이션 테마 + 각 어트랙션의 실물 썸네일을 시작 화면 카드에 배치.
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

- **아트보드**: 393 폭 · 세로 가변(시작 **1004** / 언어선택 720 / 스탬프 **864** / 리워드 **738**)

## 전체 흐름

```
언어선택 → 시작 → 스탬프(5칸) → 리워드      (본인인증 없음 · 언어선택 있음 · 4개국어)
```

> ⚠️ 표준 4단계와 달리 **본인인증(휴대폰) 단계가 없다.** 대신 **첫 화면이 언어선택**이다. 프레임 이름의 `0-1/0-2. LOGIN-Default`는 로그인이 아니라 **언어선택 화면**("언어를 선택하세요 / Please select your language" + 라디오 4개).

## 0️⃣ 언어선택 (Language Select) · `5044:1606` / `5044:1783`
- 헤드라인 **"언어를 선택하세요"** + 서브 **"Please select your language"**.
- **Radio Menu 컴포넌트 4개**(각 353×66) — 한국어 / English / 中文 / 日本語 선택.
- 하단 블루 CTA **button**(선택 전 disabled → 선택 후 enabled). Default = 미선택, `5044:1783` = 선택된 상태.

## 1️⃣ 시작 (Start) · `5042:1754`
- 상단 대형 타이틀 **"스탬프 어드벤처"**(Paperlogy 48px, 화이트+블루 이중 레이어).
- 안내문 2블록:
  - **"지정된 장소의 QR을 휴대폰으로 찍어 스탬프를 모아보세요!"** (Medium 20px)
  - **"완주 시 기념품 3종에 대해 `최대 56% 할인권`을 드립니다!"** (SemiBold 22px · "최대 56%…" ExtraBold 블루 강조)
- **어트랙션 썸네일 카드**(화이트 반투명 radius 20, "위치" pill 배지 부착) — **5개 포토스폿 실물 사진 썸네일**(150×100) + 이름:
  - **다이노 어드밴처 · 사랑의 자물쇠 · 소원의 용비늘 · 어린왕자의 별 · 모멘트캡슐** (2·2·1 배치)
- 하단 안내 **"◆ 본 이벤트는 케이블카 탑승객을 위한 이벤트입니다."** (그레이).
- 블루 CTA **"스탬프 투어 시작하기"** + 하단 **BUSAN AIR CRUISE / 송도해상케이블카 로고**.

## 2️⃣ 스탬프 (Stamp) — 어트랙션 실루엣 씰 랠리
- 헤더(2상태): 진행 시 상단 pill **"리워드까지 남은 스탬프 개수"** + 카운트 / 완료 시 **"스탬프를 모두 모았어요! 리워드를 받으세요"** + CTA **button**.
- **스탬프 5칸 = 2·2·1 피라미드 배치**(3열 그리드 아님 — 1·2행 각 2개, 3행 중앙 1개). 컨테이너 폭 353.
  - 각 칸 = **원형 스캘럽(톱니 테두리) 씰** + 중앙 **어트랙션 실루엣 아이콘**(블루) + 하단 **이름 라벨**(14px).
  - 5개 모티프: **공룡(다이노 어드밴처) · 자물쇠(사랑의 자물쇠) · 용(소원의 용비늘) · 별(어린왕자의 별) · 캡슐(모멘트캡슐)**.
  - 적립 전(before)=연한/그레이 실루엣, 적립 후(after)=딥 블루 `#004ea2` 실루엣 — 레이아웃 동일.
- 상태 진행: `2-2. STAMP-1Done`(1/5) → `2-3. STAMP-5Done`(5/5 · 전부 블루 + 리워드 CTA 노출).

## 🌐 다국어 처리 (4개국어)
- **한 페이지 = 4개 섹션**으로 통째 복제(레이아웃·컴포넌트 동일, 텍스트만 번역).
- 진입 시 **언어선택 화면**에서 고른 언어로 이후 시작·스탬프·리워드가 해당 섹션으로 분기.
- 스탬프 모티프(실루엣)·컬러·구조는 4개 언어 공통, **텍스트 노드만 번역** 대상.

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **언어선택이 첫 단계 · 본인인증 없음** — 관광/외국인 대상 이벤트라 휴대폰 인증 대신 **언어선택(4개국어)**을 진입 화면으로 둔다. `0-. LOGIN` 프레임 = 로그인 아님, **언어선택**.
2. **4개국어 = 섹션 통째 복제** — `한국어/영어/중국어/일본어` 4개 섹션에 동일 레이아웃 복제 후 텍스트만 번역. 리테마·구조 변경 시 **4개 섹션 동기화** 필수.
3. **스탬프 = 5칸 2·2·1 피라미드** — 정형 그리드가 아니라 마지막 1칸을 중앙 정렬한 피라미드. 각 칸 = 어트랙션 실루엣(공룡·자물쇠·용·별·캡슐) 원형 스캘럽 씰, before 그레이 / after 블루.
4. **폰트 = Paperlogy (Pretendard 아님)** — 헤드라인 Bold/ExtraBold, 본문 Medium/SemiBold. 리테마 시 기본 Pretendard로 되돌리지 말 것.
5. **유리 그라데이션 버튼** — CTA·"위치"·"리워드" pill 모두 `#004ea2→#2295ce` 세로 그라데이션 + 상단 `#d2eaff` inner glow + 미세 노이즈 텍스처. 단색 fill 아님.
6. **리워드 = 절취 COUPON 티켓** — 스캘럽 티켓 형태에 할인율(최대 47%) + 대상 기념품 3종 나열. 오프라인 매표소 제시형.
7. **시작 화면에 실물 썸네일 카드** — 스탬프 로케이션 5곳을 실제 사진 썸네일로 미리 보여줌(스탬프 모티프와 1:1 대응).
