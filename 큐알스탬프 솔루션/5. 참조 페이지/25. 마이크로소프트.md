# 🟦 참조 이벤트 — 마이크로소프트 (Microsoft AI Tour Seoul · 부스존 스탬프 투어)

> **Microsoft "AI Tour Seoul" 부스존 스탬프 투어.** 컨퍼런스 부스존의 각 Microsoft 부스에서 QR을 스캔하면 해당 **제품 로고 스탬프**가 적립되고, **4개 로고 스탬프**를 모두 모으면 STAFF에게 화면을 인증하고 **Microsoft 굿즈(100% 당첨 랜덤 뽑기)** 를 받는다.
> **기업 브랜드 테크 컨퍼런스 케이스** — 스탬프 모티프가 캐릭터/도시가 아니라 **Microsoft 제품군 로고**(Copilot·Azure·Defender·Microsoft)이며, 다크 블루 테크 배경 위 **은은한 라이트블루 그라데이션 텍스트**로 브랜드 톤을 살렸다.
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **본인인증 없음 → 3단계** — LOGIN 프레임을 생략하고 START에서 바로 STAMP로. 대신 START가 참여방법·대상 부스·부스맵·굿즈 리스트를 담은 **초장문 스크롤(1809)** 안내 페이지가 된다.
2. **스탬프 모티프 = 브랜드 제품 로고** — 캐릭터/도시가 아니라 **Microsoft 제품군 로고**(Copilot/Azure/Defender/MS)를 스탬프 칸에 매핑. 부스(존) = 제품군이라는 컨셉. 신규/변경 시 **로고 애셋(컬러/그레이 2벌) 교체**.
3. **폰트 이원화 = SUIT + Pretendard** — 헤드라인·본문·라벨은 전부 **SUIT**(ExtraBold/Heavy/SemiBold/Regular), **CTA 버튼만 Pretendard Bold**. (다른 참조는 Pretendard 단일이 많음 → 혼동 주의)
4. **메인 컬러 = 단색이 아닌 블루 그라데이션** — CTA는 `#003777`→`#1368B1` linear-gradient + inner glow `#D2EAFF`. 타이틀·배지 텍스트도 화이트→`#9CD2F6` bg-clip 그라데이션. 리테마 시 solid fill 치환이 아니라 그라데이션·클립 텍스트를 유지해야 톤이 산다.
5. **STEP 안내 카드 패턴** — 딥 네이비 `#081835` 카드 + 아래 화살표 커넥터로 STEP 1~4를 수직 나열. 참여 규칙을 카드 UI로 시각화(본인인증 대체).
6. **리워드 = 랜덤 뽑기(가챠)** — 단일 고정 리워드가 아니라 "100% 당첨 랜덤 뽑기"(검볼머신 이미지) + 굿즈 5종 리스트. STAFF 화면 인증으로 오프라인 수령.
7. **완료 상태 = 스탬프 그리드 + MISSION COMPLETE 리본** — 4/4 및 리워드 화면에서 완성 그리드 위에 리본 배지를 얹어 성취감 표현.
