# 🧹 참조 이벤트 — 드리미 X60 (Dreame X60 series 런칭 팝업)

> **로봇청소기 "Dreame X60 series" 런칭 팝업 행사장 QR스탬프 이벤트.** 팝업 행사장 부스마다 QR을 스캔하면 **제품 퀴즈**가 뜨고, 정답을 맞히면 **스탬프 1개**가 적립된다. **스탬프 3개**를 모두 모으면 **룰렛**을 돌려 **팝업 한정 굿즈(5종 중 랜덤)** 를 받는다.
> **퀴즈 + 룰렛 복합형 케이스** — 표준 스탬프 랠리에 ①제품 지식 **퀴즈(3문항 + 오답 팝업)** ②당첨 **룰렛(5분할 휠)** ③당첨 경품별 **리워드 5종 화면**이 결합된 프리미엄 캠페인.
> **다크 럭셔리 골드 테마** — 프리미엄 가전 브랜드에 맞춰 검정 배경 + 골드 그라데이션 + 빛기둥(라이트빔) 키비주얼.
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

- **Figma**: `QR 스탬프` · fileKey `n8YIkPdm2svezJYjePHn1u` · 캔버스 `x60` (`4440:33`)
- **아트보드**: 393 폭 · 시작/리워드 **767** · 스탬프/퀴즈 **635** · 룰렛 **847**

- **캔버스 구성**: 상단(y=3734) = **템플릿/스펙 행**(LOGIN·플로우 라벨 포함) · 하단(y=9708) = **완성 디자인 행**(테마·콘텐츠 적용). 두 행은 같은 이벤트.

## 1️⃣ 시작 (Start) · `4509:153`

- 골드 그라데이션 디스플레이 타이틀 **"QR 스탬프 / REWARD EVENT"**(A2Z, 2줄) + **DREAME 로고**(골드).
- 안내문(어절 줄바꿈): **"Dreame X60 series 런칭 팝업 행사장 내 QR 코드를 스캔해 퀴즈에 참여하세요! 스탬프 3개 적립 시 팝업 한정 굿즈를 드립니다!"**
- 유의사항 불릿 3종: 동일 인증 중복 참여 불가 / 스캔한 QR 중복 적립 불가 / 기간 내 미수령 시 지급 취소.

## 2️⃣ 본인인증 (Login) · `4457:11530` / `4457:11549`
- 헤드라인 **"휴대폰번호 인증 한 번으로 이벤트에 참여하세요"**.

## 3️⃣ 스탬프 (Stamp) — 피라미드 3칸 · `4509:166` 외
- **배치 = 피라미드(2+1)**: 상단 2칸(01·03) + 하단 중앙 1칸(02). 표준 격자가 아닌 삼각 배치.
- 각 칸 = **원형 톱니(스캘럽) 씰** — 미적립은 **그레이 아웃라인 링 + 번호(01/02/03)**, 적립 시 **골드 씰 이미지**(`Asset 1@4x`)로 교체.
- 헤더(3줄, 남은 수만 변동): **"홍길동님, / 3개의 스탬프를 더 모으고 / 리워드를 받으세요"** — 남은 숫자에 **골드 강조**.
- 상단 CTA **"리워드 신청하기"**(3개 완주 전 비활성 → 완주 시 활성).
- 하단 골드 **빛기둥(라이트빔)** 그래픽 고정.
- 상태: Default(0/3) → 1Done → 3Done → RewardDone.

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **퀴즈로 스탬프를 적립하는 루프** — QR 스캔 → 제품 퀴즈 정답 → 스탬프 1개. 정형 랠리에 **지식 퀴즈(3문항 + 오답 리트라이 팝업)** 를 삽입. 문항은 실제 제품 스펙(높이 7.95cm / 흡입력 35,000Pa 등)을 활용.
2. **룰렛 = 리워드 분기** — 스탬프 3개 완주 후 **5분할 룰렛**으로 경품이 랜덤 결정 → 당첨 결과별 **리워드 화면 5종**(텀블러·스트링백·머그컵·블루라이트펜·줄자)으로 분기. 리워드가 단일이 아니라 **N종 변형** 케이스.
3. **스탬프 배치 = 피라미드(2+1)** — 4~16칸 격자가 아닌 **삼각 3칸**. 원형 톱니 씰, 미적립=그레이 아웃라인 링+번호, 적립=골드 씰 이미지 교체.
4. **다크 럭셔리 골드 테마** — 프리미엄 가전 브랜드에 맞춘 검정 배경 + 골드 그라데이션(`#e0d1ab→#977648`) + **빛기둥 키비주얼**. 버튼은 반투명 블랙 + 골드 보더 pill.
5. **헤드라인 폰트 = A2Z** — 국문·영문 헤드라인 모두 **A2Z SemiBold**(Pretendard 아님). 본문·버튼·안내 불릿만 Pretendard. ⚠️ 재현 시 헤드라인에 Pretendard를 쓰지 말 것.
6. **캔버스 2행 구조** — 상단 = 플로우 라벨·LOGIN 포함 **스펙/템플릿 행**, 하단 = **완성 디자인 행**. 콘텐츠 참조는 완성 행(y=9708) 기준.
