# 🎮 참조 이벤트 — 킥플립 (Kickflip · "MY FIRST KICK")

> **"킥플립(Kickflip)" 매장 퀘스트형 QR스탬프 이벤트.** 각 공간(매장/구역)에서 미션(퀘스트)을 완수하고 QR을 스캔하면 해당 공간 도장이 찍히며, **6개 공간 스탬프**를 모두 모으면 리워드를 받는다.
> **레트로 8비트/게임보이 픽셀아트 케이스** — 화면 전체가 도트/그런지 그래피티 감성의 **이미지 애셋(플랫 PNG)** 으로 구성된다. 배경·타이틀·버튼·스탬프·CTA가 텍스트/벡터 노드가 아니라 통이미지로 굳어져 있는 점이 최대 특징.
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

- **Figma**: `QR 스탬프` · fileKey `n8YIkPdm2svezJYjePHn1u` · 페이지 `킥플립` (`4852:2`)
- **아트보드**: **393 × 747 고정**(모든 화면 동일 높이) · 세로 스크롤 없음
- **구성**: 본인인증 **없음** · **스탬프 6칸(2열 × 3행)** · **단일 리워드 화면 있음** → 시작(1) + 스탬프(4상태) + 리워드(2상태)
- **폰트**: 헤드라인·버튼·스탬프 라벨은 **픽셀/그런지 스타일 이미지 타이포(폰트 아님, 이미지에 렌더)** · 리워드 안내문 등 본문은 산세리프(Pretendard 계열 추정)

## 전체 흐름

```
시작 → 스탬프(6칸) → 리워드            (본인인증 없음 · 3단계 · 스탬프 4상태 / 리워드 2상태)
```

> ⚠️ 이 이벤트는 **본인인증(LOGIN) 화면이 없다.** 시작 → 스탬프 → 리워드 3단계. 스탬프는 상태별 4프레임, 리워드는 Default/Done 2프레임으로 총 7화면.

| 단계 | 프레임 | node-id |
|---|---|---|
| 1. 시작 | `1. Start-Default` | `4852:1561` |
| 2. 스탬프 | `2-1. STAMP-Default` / `2-2. STAMP-1Done` / `2-3. STAMP-6Done` / `2-4. STAMP-RewardDone` | `4852:1667` / `4854:1838` / `4854:1851` / `4854:1878` |
| 3. 리워드 | `3-1. REWARD-Default` / `3-2. REWARD-Done` | `4852:1686` / `4852:1689` |

> 상단 `Frame 134~141`(`4852:1718` 등)은 플로우 상태 라벨(시작/스탬프/리워드 + Default·1/6·6/6·리워드Done 표기)로, 실제 화면이 아닌 흐름 주석 프레임이다. 실제 화면은 width 393 프레임(`4852:1561` 이하).

## 1️⃣ 시작 (Start) · `4852:1561`
- 상단 그래피티 타이틀 **"MY FIRST KICK"**(검정 도트/그런지 레터링, 픽셀 프레임 안).
- 중앙 **8비트 매장 일러스트** — 구름·가로등·차양(어닝) 상점 정면 + 상호 간판 **"Mart Kick"** + 브랜드 로고 **"KickFlit / Kickflip"**. 도트 픽셀 아트 통이미지.
- 안내문(픽셀 폰트): **"각 공간의 퀘스트를 완수하여 도장을 획득하세요!"**
- 하단 검정 픽셀 CTA **"QUEST START"**(버튼도 이미지 `bt1`).
- 화면 전체(배경 `1. Start-bg`)가 하나의 통 PNG. CTA 버튼만 별도 이미지 노드.

![[큐알스탬프 솔루션/attachments/kickflip-start.png]]

## 2️⃣ 스탬프 (Stamp) — 공간 퀘스트 도장
- **2열 × 3행 = 6칸.** 각 칸 = **가로형 라운드 픽셀 버튼**(160 × 60.5px)에 **공간(퀘스트) 이름**이 도트 폰트로 박힘.
  - 공간명(6개): **KYEHOON · DONGHWA · JUWANG · MINJE · KEIJU · DONGHYEON** (매장/구역 슬롯 이름).
  - 각 버튼은 이미지 애셋 2벌: **`btN-2`=미적립(그레이·화이트 채움)** / **`btN-1`=적립(민트 채움 active)**. (bt6~bt11 = 6칸)
  - 배치: 좌 x≈27 / 우 x≈205, 행 y≈183 / 273 / 363 (약 90px 간격) · 컨테이너 폭 345.
- 상단 헤더는 별도 텍스트 헤더가 아니라 **"MY FIRST KICK" 그래피티 타이틀**(시작과 동일)로 통일.
- 하단 CTA **`GET REWARD!`** — 미완료 시 **그레이 비활성**(`bt2`), 완료(6/6) 시 **`bt3` 활성**으로 교체.
- 하단 데코: **하트/보석/별 3종 픽셀 게이지 아이콘**(HP바 감성) + `KickFlip` 로고.
- 상태 진행: Default(0/6, 전 버튼 그레이) → 1Done(1개 민트 적립) → 6Done(6개 전부 민트 + CTA 활성) → RewardDone(리워드 수령 완료 후 CTA `bt13`).

## 3️⃣ 리워드 (Reward) · `4852:1686` / `4852:1689`
- 타이틀 **"QUEST COMPLETED"**(2줄 도트 픽셀 레터링).
- 리워드 이미지: **원형 씰/캔뱃지 3종 콜라주** — `mart KICK STAFF` 배지 · 중앙 씰 · `KEEP YOUR AWESOME` 배지 (레트로 핀뱃지 감성).
- 리워드 안내(문구 그대로):
  - **"캔버튼 3종 중 랜덤 1종 증정"**
  - **유의사항 및 안내사항**
    1. 해당 이벤트는 1일 1회에 한하여 참여 가능합니다.
    2. 리워드는 미션 완료 후 이벤트 화면 당일에만 지급 가능합니다.
    3. 직원 확인 후 리워드가 증정되오니 캡처본이나 공유된 이미지를 재사용 경우 리워드 지급이 불가합니다.
    4. 리워드 소진 시 해당 이벤트는 조기 종료될 수 있습니다.
  - **"※ [리워드 수령 확인]은 스태프 확인용으로, 버튼을 누르지 않은 채로 해당 페이지의 스태프에게 보여주세요"**
- 하단 검정 픽셀 CTA **"리워드 수령 확인 (직원용)"** — Default(`3-1`) 활성 → Done(`3-2`) 수령완료.

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **전면 이미지(플랫 PNG) 구성** — 배경·타이틀·매장 일러스트·스탬프 버튼·리워드 배지·데코가 전부 이미지 애셋. 텍스트/벡터 편집 노드가 거의 없음. 재현 시 **레이아웃 프레임 + 이미지 슬롯**으로 구성하고, 문구 수정은 텍스트 편집이 아니라 **이미지 재생성/교체**가 필요.
2. **레트로 8비트/게임보이 아트 디렉션** — 민트 단색 배경(`#6DCDC1`) + 검정 도트 잉크 + 하단 체크무늬 픽셀 밴드 + 그래피티 도트 레터링. 컨셉 자체가 "게임 화면"이라 헤더/CTA/스탬프가 픽셀 버튼 톤으로 통일.
3. **스탬프 = 공간 퀘스트 버튼(가로형)** — 원형 도장이 아니라 **공간명 라벨이 박힌 가로 픽셀 버튼 6개(2×3)**. before(그레이)/after(민트) 2벌 이미지로 상태 전환.
4. **본인인증 없는 3단계** — LOGIN 화면 생략, 시작 → 스탬프 → 리워드. (WORLD PASSPORT의 4단계 구조와 대비, 경기수의컨퍼런스처럼 인증 없는 변형)
5. **고정 아트보드 393×747** — 모든 화면 동일 높이. 세로 스크롤/가변 프레임 아님(대량 스탬프 그리드 케이스와 대비).
6. **리워드 = 랜덤 증정 + 직원 확인 방식** — "캔버튼 3종 중 랜덤 1종", 수령 CTA는 사용자 누르지 말고 스태프에게 화면 제시 → 스태프가 `수령 확인` 처리. 리워드 화면 존재하나 오프라인 직원 확인 결합형.

## 🤖 디자인 자동화 재현 포인트

- **테마색**: 메인/배경 **`#6DCDC1`**(게임보이 민트) · 잉크/아웃라인 **`#070506`** · 밝은 민트 하이라이트 `#C8FFF9` · 비활성 CTA 그레이 `#676667`(fill `#DBDDDD`).
- **폰트**: 헤드라인·버튼·스탬프 라벨은 **폰트가 아니라 픽셀/그런지 이미지 타이포**(이미지로 렌더). 본문(리워드 유의사항)만 산세리프(Pretendard 계열 추정). → 재현 시 타이틀·라벨은 도트/그래피티 이미지 애셋으로 처리.
- **스탬프 칸수/모티프**: **6칸 · 2열 × 3행 · 가로형 픽셀 퀘스트 버튼**(공간명 라벨). before(그레이)/after(민트) 2벌 이미지 세트. 모티프 = 8비트 게임 UI(HP게이지·체크픽셀·그래피티).
- **단계 구조**: **3단계(본인인증 없음)** — 시작(1) → 스탬프(Default/1Done/6Done/RewardDone 4상태) → 리워드(Default/Done 2상태). 아트보드 **393×747 고정**.
- **특이사항**:
  - 화면 전체가 **플랫 이미지 애셋** → 문구/스탬프 변경은 이미지 재생성 필요(텍스트 편집 불가).
  - **LOGIN 화면 없음** · 세로 스크롤 없음(고정 높이).
  - 리워드는 **랜덤 1종 증정 + 스태프 확인**(CTA는 직원용, 사용자 클릭 금지 안내).
  - 하단 **체크무늬 픽셀 밴드**는 전 화면 공통 데코 프레임.
