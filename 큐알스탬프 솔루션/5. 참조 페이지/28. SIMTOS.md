# 🏭 참조 이벤트 — SIMTOS 2026 QR 스탬프 투어

> **SIMTOS 2026(서울국제생산제조기술전) "QR 스탬프 투어".** 전시장 내 지정된 **4개 전시관(장소)** 을 방문해 QR을 스캔하면 각 전시관 스탬프가 적립되고, **스탬프 4개**를 모두 모으면 **경품 추첨(갤럭시 탭/워치/버즈)** 에 응모할 수 있다.
> **이미지 플랫 케이스** — 시작·스탬프·리워드 화면 대부분이 **배경 이미지(bg) + 버튼 이미지(bt) + 개별 스탬프 이미지(st)** 로 굳어져 있고, 라이브 텍스트 노드는 스탬프 헤더 문구 정도만 남아 있다. 재현 시 **이미지 교체 중심** 접근이 필요.
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

- **Figma**: `QR 스탬프` · fileKey `n8YIkPdm2svezJYjePHn1u` · 페이지 `SIMTOS` (`4856:2`)
- **아트보드**: **393 × 720 고정**(모든 실화면 동일 크기)
- **구성**: 본인인증 **없음** · **스탬프 4칸(2×2)** · **단일 리워드 화면 있음** → 시작 + 스탬프 4상태 + 리워드
- **폰트**: 라이브 텍스트 = **NanumSquareRound(ExtraBold)** · 로고/타이틀/본문 대부분 이미지 flatten (Pretendard ❌ — 이 케이스는 나눔스퀘어라운드 기반)

```
시작 → 스탬프(4칸, 4상태) → 리워드        (본인인증 없음 · 리워드 화면 있음)
```

## 2️⃣ 스탬프 (Stamp) — 전시관 방문 씰 4칸
- 구조: `STAMP-bg`(배경) + `bt`(CTA 버튼 이미지) + 스탬프 4개 이미지 **`st…@4x`**(각 **114×114**) + 라이브 헤더 텍스트.
- **배치: 2열 × 2행 = 4칸.** 좌표 고정 — st1(58,315) · st2(221,315) · st3(58,469) · st4(221,469). 칸 사이 그레이 점선 구분선.
- **헤더 텍스트(라이브, NanumSquareRound ExtraBold 20px, 남은 개수만 변동)**:

  - 1적립: **"3개의 스탬프를 더 모으고 / 경품 이벤트에 응모하세요."**
  - 완료: **"스탬프를 모두 모았어요! / 경품 이벤트에 응모하세요."**
- **스탬프 모티프 = 전시관별 원형 씰**(상단 리본에 부스 위치, 하단 라벨에 전시관명):

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **이미지 플랫 구조** — 시작·리워드는 통짜 배경 이미지, 스탬프는 배경 + 버튼 + 개별 씰 이미지로 구성. 텍스트 편집이 아닌 **이미지 슬라이스 교체** 중심. 라이브 텍스트는 스탬프 헤더 정도만.
2. **본인인증 없음 (표준 대비 단축)** — 시작 → 스탬프 직행. LOGIN 프레임 부재. (경기수의컨퍼런스는 인증 있음, JINAIR도 있음 — 대비 케이스)
3. **스탬프 = 전시관 원형 씰, before/after 2벌** — 그레이스케일↔풀컬러 별도 애셋. opacity 토글이 아니라 이미지 스왑.
4. **폰트가 Pretendard가 아님** — 라이브 헤더가 **NanumSquareRound ExtraBold**. 대부분 텍스트는 이미지로 굳어 폰트 검출 제한적. 재현 시 나눔스퀘어라운드 확보 필요.
5. **테마색 = 프레시 그린 `#76AF43`** 단색 — 버튼/일시 pill/강조어에 일관 적용. 색이 이미지에 baked라 variable 미노출.
6. **리워드 화면 존재** — 경품 추첨 안내(발표일·확인처) + 3등 경품 내역(탭/워치/버즈)을 별도 화면에 명시. (경기수의컨퍼런스는 리워드 화면 생략 케이스와 대비)

## 🤖 디자인 자동화 재현 포인트

- **테마색**: 메인 그린 **`#76AF43`** (RGB 118·175·67) · 로고/타이틀 차콜 **`#333333`** · 배경 라이트 민트→화이트 그라데이션 · 버튼 텍스트 화이트 · 경고 pill 연핑크.
- **폰트**: **NanumSquareRound (ExtraBold)** 계열 (⚠️ Pretendard 아님). 텍스트가 이미지에 flatten된 부분은 동일 폰트/두께로 재생성.
- **스탬프**: **4칸 2×2 격자** · 각 씰 **114×114** · 좌표 (58/221, 315/469) · 모티프 = **전시관별 원형 씰**(리본=부스 위치, 하단=전시관명) · 적립 전 그레이스케일 / 적립 후 풀컬러 **별도 이미지 2벌**.
- **단계 구조**: 시작(`4857:24`) → 스탬프 4상태(Default/1Done/4Done/RewardDone, `4857:90/98/106/114`) → 리워드(`4857:81`). **본인인증 없음.**
- **콘텐츠 고정값**: 일시 `2026. 4. 13(월)~4. 17(금)` · 장소 4개 전시관 · 발표 `2026. 4. 30(목)` · 경품 1등 갤럭시 탭S11(1) / 2등 워치8(2) / 3등 버즈4(5) · "1인 1회 참여".
- **특이사항**: ① 화면이 **이미지 슬라이스 중심**(bg+bt+st) → 실작업은 이미지 교체가 관건. ② 헤더 문구의 "남은 개수" 숫자만 상태별로 변동(4→3→모두). ③ 스탬프 후보 유형 보드는 이 페이지에 별도 없음(채택 유형 = 이미지+하단라벨 원형 씰).
