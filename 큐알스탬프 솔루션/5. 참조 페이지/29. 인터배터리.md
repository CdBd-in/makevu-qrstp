# 🔋 참조 이벤트 — 인터배터리 (InterBattery · SK ON)

> **인터배터리 전시회 SK ON 전시관 QR스탬프 이벤트.** 전시관 부스에서 QR을 스캔해 **스탬프 6개**를 모으고, **관람 후기 설문**을 작성한 뒤 **룰렛**을 돌려 **경품(6종 중 1)** 을 받는 구조.
> **설문 + 룰렛 결합형** 케이스 — 스탬프 완주가 리워드로 바로 이어지지 않고, "**설문조사 → 룰렛 추첨 → 리워드 당첨**"의 게임형 보상 플로우를 갖는다. 본인인증 화면은 **없음**.
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

## 전체 흐름

```
시작 → 스탬프(6칸) → 설문 → 룰렛 → 리워드(6종/Done)   (본인인증 없음 · 설문+룰렛 결합형)
```

> ⚠️ 표준 "시작→인증→스탬프→리워드" 4단계와 다르다. **본인인증이 없고**, 스탬프 완주 후 **설문 → 룰렛 추첨**을 거쳐 리워드가 결정된다. 리워드는 **경품 6종 중 당첨 1종**을 보여주는 팝업형 프레임 세트.

## 1️⃣ 시작 (Start) · `4387:45`
- `START-BG` 풀블리드 배경 이미지(SK ON 키비주얼) 위에 하단 CTA 1개.
- 하단 CTA **"이벤트 참여하기"** — **블랙 pill + 화이트 3px 테두리 + 화이트 Pretendard Bold 23px**.

![[큐알스탬프 솔루션/attachments/interbattery-start.png]]

## 2️⃣ 스탬프 (Stamp) — 부스 방문 6칸
- 헤더(고정 문구, 숫자만 변동): **"현재 `N`개의 스탬프를 모았어요"** — 숫자 `N`만 **틸 `#0F938D`** 강조, 나머지 `#1E3135` (Pretendard Medium 24px).
  - Default(0) → 1Done(1) → 6Done(6) → RewardDone.
- **스탬프 그리드**: 컨테이너 폭 267 · **2열 × 3행 = 6칸** · 각 칸 **90×90 원형 이미지 애셋** · gap 세로 39 / 가로 67.
  - 미적립 = `STAMP-before`(그레이) / 적립 = `STAMP-after`(틸) — **별도 이미지 애셋 2벌** 교체(opacity 방식 아님).
- 화면 상단 CTA **"설문조사 후 리워드 신청하기"** (틸) — **미완주 시 opacity 20% 비활성**, **6개 적립 시 활성화** → 설문 페이지로 이동.
- `RewardDone` 상태: 헤더 "리워드 수령을 완료했어요" + CTA "리워드 수령 완료".

![[큐알스탬프 솔루션/attachments/interbattery-stamp.png]]

## 3️⃣ 설문 (Survey / Form) · `4387:1162` / `4387:2689`
- 제목 **"관람 후기를 남겨주세요."**(Pretendard SemiBold 24px) + 부제 **"소중한 시간 내어주시면 감사하겠습니다."** · 우상단 닫기(Close Icon).
- 공용 DS 폼(`Field_Name` + `Checkbox`)로 구성 · 체크박스 테두리 **틸 `#0F938D` 1.5px** · `*필수` 라벨 **`#FF6767`**.
- 질문 3개(모두 필수 포함):
  1. **"이용 경험에 점수를 매겨주세요."** `*필수` — ★★★★★ / ★★★★☆ / ★★★☆☆ / ★★☆☆☆ / ★☆☆☆☆
  2. **"이전 인터배터리 전시회에서 SK ON 전시관을 방문하신 적이 있습니까?"** `*필수` — 있다. / 없다.
  3. **"이전 SK ON 전시관에 비해 만족스러웠던 부분은 무엇입니까?"** — 디자인 / 전시품목(기술) / 전시품 설명(응대) / 이벤트 / 방문한 적 없다.
- 하단 **"제출하기"** 버튼 — 틸 20% 비활성 → **필수 질문 응답 시 활성**. `FORM-Filled`은 응답 채워진 활성 상태.

![[큐알스탬프 솔루션/attachments/interbattery-form.png]]

## 4️⃣ 룰렛 (Roulette) · `4387:1128`
- `ROULETTE-BG` 배경 위 **원형 룰렛** — `ROULETTE-back`(341×341 받침) + `ROULETTE-board`(279×279 회전판) + `ROULETTE-pin`(62×66 상단 포인터) 3개 이미지 레이어.
- 하단 CTA **"룰렛 돌리기"** — **블랙 pill + 화이트 3px 테두리**(시작 CTA와 동일 스타일).

![[큐알스탬프 솔루션/attachments/interbattery-roulette.png]]

## 5️⃣ 리워드 (Reward) — 경품 6종
- 룰렛 결과로 당첨된 경품 1종을 보여주는 프레임 세트. 각 리워드는 `*-Default`(닫기 아이콘 + "리워드 받기" 블랙 pill CTA)와 `*-BG`(경품 이미지 + 품명) 2벌로 구성.
- 경품 품명(Pretendard **Black** 23px · `#231816`) + 경품 이미지 애셋:
  - **REWARD1** 블루투스 키보드 · **REWARD2** 모바일 스탠드 · **REWARD3** UV 양우산 · **REWARD4** 버티컬 마우스 · **REWARD5** 포토부스 이용권 · **REWARD6** 커피 교환권
- `5-2. REWARD-Done`(`4387:2795`) = 수령 완료 상태.

## 🤖 디자인 자동화 재현 포인트

- **테마색**: 메인 **틸 `#0F938D`** — 강조 숫자·체크박스 테두리·설문/제출 fill·리워드 포인트. 텍스트: 스탬프 헤더 `#1E3135` / 설문 `#212529` / 리워드명 `#231816` / 필수 `#FF6767`.
- **CTA 스타일 2종**: ⓐ 메인 액션(시작·룰렛 돌리기) = **블랙 pill + 화이트 3px 테두리 + 화이트 텍스트**(radius 99). ⓑ 인라인 액션(설문 신청·제출) = **틸 fill, 비활성 시 opacity 20%**. ⚠️ 밝은 배경 이미지 위 가독성 위해 메인 CTA를 화이트가 아닌 **블랙**으로 처리한 점 주의.
- **폰트**: 전체 **Pretendard** — 헤더 Medium 24 / 설문 제목 SemiBold 24 / CTA Bold 23 / 리워드명 **Black** 23 / 버튼 SemiBold 20.
- **스탬프**: **6칸(2열×3행)** · 90×90 원형 **이미지 애셋** · before(그레이)/after(틸) **2벌 교체**(opacity 아님) · gap 39/67 · 컨테이너 폭 267. 헤더는 "현재 N개…" 숫자만 틸 강조(텍스트 교체 후 강조색 재적용 필요).
- **단계 구조**: **본인인증 없음** · 시작 → 스탬프(6) → **설문(관람후기 3문항)** → **룰렛(추첨)** → **리워드 6종/Done**. 표준 4단계와 다른 **설문+룰렛 결합 게임형** 보상 플로우.
- **특이사항**:
  - 스탬프 완주만으로 리워드 안 됨 → **필수 설문 응답이 게이트**(제출 후 룰렛 활성).
  - 리워드는 확정 1종이 아니라 **룰렛으로 6종 중 당첨** — 리워드 프레임을 6개 세트로 준비.
  - 상태 변화가 주석 라벨로 명시됨(비활성 20% / 6개 시 활성 / 수령 시 버튼명 변경 / 필수응답 시 활성) → 인터랙션 조건 그대로 반영.
  - 배경·경품·룰렛이 모두 이미지 애셋 → 재현 시 텍스트가 아닌 **이미지 교체** 작업 중심.
