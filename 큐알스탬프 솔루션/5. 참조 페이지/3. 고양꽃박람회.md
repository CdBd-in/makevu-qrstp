## 2️⃣ 스탬프 (Stamp)
| 상태 | 화면 | node-id | 안내 문구 |
|---|---|---|---|
| 기본 | `2-1.STAMP-Default` | `5116:5` | "6개의 스탬프를 더 모으고 리워드를 받으세요" |
| 2개 적립 | `2-2.STAMP-2Done` | `5116:491` | "4개의 스탬프를 더 모으고…" |
| 완료(6/6) | `2-3.STAMP-6Done` | `5116:506` | "스탬프를 모두 모았어요! 리워드를 수령하세요" |
| 리워드 도달 | `2-4.STAMP-RewardDone` | `5116:521` | "축하합니다! 리워드 수령을 완료했어요" |

- **2열 × 3행 = 스탬프 6칸**. 각 칸은 작품명: **별과 우주 / 과거 / 현재 / 미래 / 해와 달의 정원 / 물의 리듬** (각 before/after).
- 남은 개수에 따라 상단 안내 문구가 **동적으로 바뀜**.
- **인터랙션(중요)**:
  - 스탬프 클릭 → **작품 설명 페이지가 새 창에서 열림** (스탬프 상태와 무관). 링크: `cdbd.in/ecostyle/goyang?page=1~6` (스탬프1=page1 … 스탬프6=page6).
  - 상단 이미지 클릭 → **네이버지도(일산호수공원 주제광장)** 열림.
  - 보조 문구: "*스탬프 클릭 시 작품 설명을 확인할 수 있습니다."

## 📌 민주평통/솥바위 대비 특징
- **본인인증 단계가 없음** — 시작 직후 바로 스탬프로 진입(단계 번호도 1·2·4로 3 생략).
- 스탬프가 단순 카운트가 아니라 **작품(콘텐츠) 단위**이며, 각 스탬프에 **외부 설명 링크**가 매핑됨 → "관람 동선 안내형" 변형.
- 남은 개수에 따른 **가변 안내 카피**가 상태별로 들어감.
