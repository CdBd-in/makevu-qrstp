# 🐻 참조 이벤트 — 올리브영 X 망곰이 (OLIVE YOUNG × Mangomee)

> **올리브영 홍대타운 "망곰이의 특별한 하루" 팝업 QR스탬프 이벤트.** 아기천사 망곰이가 잠든 사이 사라진 소중한 친구들을, **1~3층 각 층(스킨케어·메이크업·라이프스타일)의 올리브영 X 망곰이 콜라보 상품**에 숨겨진 힌트를 따라 찾아 **스탬프 3개**를 모두 모으면, 1층 팝업존에서 콜라보 굿즈를 랜덤 증정받는다.
> **캐릭터 IP 콜라보 + 다국어(4개 언어) 케이스** — 배경/일러스트가 파스텔 밤하늘 세계관으로 통일되고, 헤드라인은 라운드 손글씨 디스플레이 폰트로 캐릭터 톤을 살렸다. **본인인증이 없고, 대신 첫 화면이 언어 선택**으로 시작한다.
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

## 전체 흐름

```
언어 선택(2) → 시작 → 스탬프(3칸) → 리워드      (본인인증 없음 · 언어 선택 있음)
```

> ⚠️ 표준 4단계(시작→인증→스탬프→리워드)와 달리 **본인인증 화면이 없고**, 대신 **언어 선택 화면**이 맨 앞에 온다. 팝업 현장 참여형이라 휴대폰 인증 없이 언어만 고르고 바로 시작한다. **4개 언어(KR/EN/CN/JP) 전 세트가 각각 별도 프레임**으로 존재한다.

| 단계 | 프레임(KR) | node-id | 다국어 세트 |
|---|---|---|---|
| 1. 언어 선택 | `1-1. LANGUAGE-Default` / `1-2. LANGUAGE-Selected` | `4085:419` / `4085:1850` | `_EN`·`_CN`·`_JP` |
| 2. 시작 | `2. START` | `4085:1892` | `_EN`·`_CN`·`_JP` |
| 3. 스탬프 | `3-1.STAMP-BG` / `3-2. STAMP-1Done` / `3-3. STAMP-2Done` / `3-4. STAMP-3Done` | `4085:1937` / `4245:4391` / `4245:5568` / `4245:5933` | `_EN`·`_CN`·`_JP` |

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **인증 대신 언어 선택** — 팝업 현장 참여형이라 **본인인증 화면이 없다.** 첫 화면이 **언어 선택(KR/EN/CN/JP)** 이고, 선택 시 CTA가 활성화(`Selected` 상태 하이라이트 테두리).
2. **다국어 4벌 전체 복제** — 언어·시작·스탬프(4상태)·리워드 각 프레임이 **KR + `_EN`/`_CN`/`_JP`** 로 전부 복제되어 있다. 문구 번역본이 프레임 단위로 분리·관리됨.
3. **캐릭터 IP 세계관 통일** — 파스텔 밤하늘 배경 + 손그림 캐릭터(망곰이/유니콘). **스탬프는 3D/사진이 아니라 캐릭터 벡터 일러스트 씰**(컴포넌트 property1 01/02/03, Before=회색·After=컬러).
4. **스토리텔링 = 층별 미션** — "사라진 친구 찾기" 컨셉으로 스탬프 3칸을 **1F 스킨케어 / 2F 메이크업 / 3F 라이프스타일** 매장 층에 매핑. 각 칸 = 층 배지 + 카테고리 라벨.
5. **라운드 디스플레이 폰트** — 헤드라인·버튼에 **Sandoll Odongtong TTF**(라운드 손글씨체)로 캐릭터 톤. 본문·라벨만 **Paperlogy**. (Pretendard 표준 템플릿과 다름 — 브랜드/IP 맞춤 폰트 케이스)
6. **밝은 배경 텍스트 처리** — 라벤더 밝은 배경 위 안내문은 흰색이 아니라 **뮤트 블루 `#436AA2`**, 진한 리워드 배경 영역에서는 **화이트**로 반전.

## 🤖 디자인 자동화 재현 포인트

- **테마색**: 메인 페리윙클 퍼플-블루 `#5B6ECB` 계열(버튼·헤드라인) · 서브/본문 뮤트 블루 `#436AA2` · 배경 = 파스텔 라벤더 밤하늘 그라데이션(별·구름·선물 일러스트 풀블리드).
- **폰트**: 헤드라인·CTA 버튼 = **Sandoll Odongtong TTF**(라운드 디스플레이, 21~24px 화이트) / 본문·카테고리 라벨 = **Paperlogy**(SemiBold 12~13px, Bold 12px). ⚠️ Pretendard 아님.
- **스탬프**: **3칸(1행 3열)** · 모티프 = **층별 캐릭터 일러스트 씰**(유니콘·망곰이 등) · 컴포넌트(`Stamp`/`Component 1`, property1 01/02/03) · Before=회색·After=컬러(별도 애셋). 각 칸 = 층 배지(1F/2F/3F) + 라벨(스킨케어/메이크업/라이프스타일 `#436AA2`).
- **단계 구조**: 언어선택(Default/Selected) → 시작 → 스탬프(Default/1Done/2Done/3Done/STAMPdone) → 리워드(Default/Done). **본인인증 없음**.
- **특이사항**:
  - **언어 4벌(KR/EN/CN/JP)** 전 프레임 복제 — 리테마 시 4개 언어 세트 동기화 필수.
  - 배경·헤드라인·버튼 라벨·일러스트가 **배경 PNG에 구워짐** → 문구 변경 = 이미지 교체.
  - CTA·헤드라인 양옆 **⭐별 장식 아이콘** 반복 모티프.
  - 밝은 배경 = 본문 `#436AA2` / 진한 배경 = 본문 화이트로 반전.
  - 리워드 실물 굿즈 이미지 그리드 + 물음표 선물박스 = 랜덤 증정 표현.
