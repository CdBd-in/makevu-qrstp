# 🔎 참조 이벤트 — 리버스:1999 (Reverse:1999 조사 미션)

> **모바일 게임 "리버스:1999(REVERSE:1999)" IP 콜라보 QR 조사 미션 이벤트.** 스탬프 격자를 채우는 방식이 아니라, 오프라인 곳곳에 숨겨진 **QR을 스캔해 힌트(Hint 1~6)를 열고**, 그 힌트로 **십자말풀이(크로스워드) 6문항**의 정답을 맞춰 미션을 완성하면 **Special Gift(리버스:1999 티켓포스터)** 를 받는 케이스.
> **"스탬프 = 격자 칸" 정형을 벗어난 미션/퀴즈 변형** — 6칸 진행 표현이 스탬프 씰이 아니라 **크로스워드 정답 6개**로 대체된다. 힌트 열람(QR 모달) → 정답 입력(미션 모달) → 6문항 완성 → 리워드의 흐름.
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.


## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **스탬프 격자 대신 크로스워드 미션** — 진행도 6칸을 스탬프 씰이 아니라 **십자말풀이 6문항**으로 표현. "칸=격자 셀"이지만 채움 트리거가 **정답 입력**이다. (스탬프 유형 후보 보드 미적용 · 미션형 변형)
2. **본인인증 생략** — 로그인/휴대폰 인증 화면이 아예 없음. 시작 → 바로 미션. 인증 없는 참여형 케이스.
3. **QR = 힌트 해금 트리거** — QR 스캔이 스탬프를 찍는 게 아니라 **Hint 모달을 여는(Before→After) 트리거**. 힌트로 얻은 단서로 정답을 맞춰야 진행.
4. **모달 중심 상호작용** — 힌트 모달(Before/After) + 정답 모달(Default/Focused/Filled/Fail) 등 **상태 프레임을 모달 단위로 다수 관리**. 각 상태 재현 필요.
5. **명조/세리프 폰트(KoPubWorldBatang Pro)** — 게임 IP의 빈티지/미스터리 톤을 위해 **Pretendard가 아닌 명조**를 전면 사용. 리테마 시 폰트 패밀리 교체 주의.
6. **다크 크림슨 단색 + 틸 서브** — 메인 `#881A23`(CTA·번호·확인) / 서브 `#6ABA9F`(힌트). 비활성은 `opacity 0.3~0.4`로 표현.
7. **상단 314px GIF 배너** — 시작·리워드 상단에 **애니메이션 GIF** 키비주얼(정적 이미지 아님). 애셋 교체 시 GIF 포맷 유지.
8. **콘텐츠 대부분 이미지 baked** — 크로스워드 완성 글자, 리워드 티켓, 안내 문구 상당수가 배경 이미지에 포함. 텍스트 수정 시 이미지 재작업 필요.

## 🤖 디자인 자동화 재현 포인트

- **테마색**: 메인 `#881A23`(다크 크림슨 · CTA/번호타일/확인버튼) · 서브 `#6ABA9F`(틸 · 힌트) · 힌트텍스트 `#11221C` · 크로스워드 빈칸 테두리 `#adadad` · 비활성 `opacity 0.3~0.4`.
- **폰트**: 전체 **KoPubWorldBatang Pro Bold**(명조/세리프) — ⚠️ Pretendard 아님. 게임 IP 톤 유지 핵심.
- **스탬프 칸수/모티프**: 정형 스탬프 격자 **없음**. 대신 **크로스워드 6문항(38×38 셀 십자 배치) + Hint 6개**. 진행도 = 정답 채움.
- **단계 구조**: 시작 → 미션(크로스워드) ⇄ [힌트 모달 Before/After · 정답 모달 Default/Focused/Filled/Fail] → 1Done → 6Done/RewardDone → 리워드(Default/Done). **본인인증 없음 · 리워드 화면 있음.**
- **특이사항**:
  - QR 스캔 = 스탬프 적립이 아니라 **힌트 해금** 트리거.
  - 상태를 **모달 프레임 다수**로 관리(힌트 2 + 정답 4 + 진행 3).
  - 상단 **314px 애니메이션 GIF** 배너(시작·리워드).
  - 리워드 = "리버스:1999 티켓포스터", CTA "스태프 확인"(현장 실물 수령).
  - 콘텐츠(정답 글자·티켓·안내문) 다수가 **배경 이미지에 baked** → 텍스트 편집 = 이미지 재작업.
