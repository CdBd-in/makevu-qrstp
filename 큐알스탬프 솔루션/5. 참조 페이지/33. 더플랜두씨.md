# 🎡 참조 이벤트 — 더플랜두씨 (The Plan Do See · O/X QUIZ STAMP MISSION)

> **"O/X QUIZ STAMP MISSION EVENT"** — 태국 K-콘텐츠 부스 랠리형 퀴즈 스탬프 이벤트. 전시 부스 8곳(K-01~K-08)을 돌며 각 부스 캐릭터/브랜드에 대한 **O/X 퀴즈**를 풀면 해당 부스 스탬프가 찍히고, **8개 스탬프**를 모두 모으면 인포메이션 데스크의 **럭키박스(랜덤 기프트)** 를 받는다.
> **퀴즈형 스탬프 케이스** — 표준 4단계(시작→인증→스탬프→리워드) 대신 **인증(로그인) 화면이 없고**, 스탬프와 리워드 사이에 **O/X 퀴즈 8문항 + 오답 팝업**이 삽입된 변형 구조다. 전체 UI가 **영문(English)** 이고, 화면 대부분이 **풀블리드 이미지 애셋**(배경·안내 카드·퀴즈 카드·지도·리워드 일러스트가 하나의 이미지로 굳어져 있음)으로 구성된다.
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

- **Figma**: `QR 스탬프` · fileKey `n8YIkPdm2svezJYjePHn1u` · 페이지 `더플랜두씨` (`3813:481`)
- **아트보드**: 393 폭 · 시작/스탬프/퀴즈 **699** · 리워드 **800**
- **구성**: 본인인증 **없음** · **스탬프 8칸(3-3-2 그리드)** · **O/X 퀴즈 8문항 + 오답 팝업** · **단일 리워드(럭키박스)**
- **언어**: 전체 **영문** UI
- **폰트**: 영문 디스플레이 헤드라인 **Jalnan 2**(잘난2) / 본문·안내 = 볼드 산세리프 (⚠️ **Pretendard 아님**)

## 전체 흐름

```
시작 → 스탬프(8칸 상태들) → O/X 퀴즈(8문항 + 오답 팝업) → 리워드      (본인인증 없음 · 퀴즈형 변형)
```

> ⚠️ **인증(로그인) 화면이 없다.** 표준 흐름의 2단계(본인인증)가 빠지고, 대신 스탬프↔리워드 사이에 **퀴즈 시퀀스**가 들어간다. 캔버스에는 스탬프 상태(4) · 퀴즈(8) · 오답 팝업(1) · 리워드(2) 프레임이 좌표로 그룹핑되어 있다.

## 1️⃣ 시작 (Start) · `3813:590`
- **방사형 핑크 버스트 배경** 위 상단 디스플레이 로고 타이틀 **"⭕❌ QUIZ · STAMP MISSION EVENT"** (Jalnan 2 계열, O/X를 옐로 알약 심볼로 표현).
- 서브카피: **"Join the Mission and Pick a Gift from the Lucky Box!"**
- **STEP 안내 4단계 카드**(다크 pill 헤더 + 화이트 카드):
  - **STEP 01** — "Scan the QR at the Information Desk"
  - **STEP 02** — "Visit 8 booths and take each O/X quiz"
  - **STEP 03** — "Collect 8 stamps and return to the Information Desk"
  - **STEP 04** — "Pick a gift from the Lucky Box — first come, first served!"
- **보드게임형 지도(map)**: 타원형 트랙 위에 부스 로고들이 배치되고 중앙에 **"K-CONTENT in Thailand"**, `Information Desk`(START) / `RETURN` 노드 표기. → **지도/보드게임 배치** 모티프.

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **퀴즈형 변형(4단계 아님)** — 표준 시작→인증→스탬프→리워드에서 **인증 화면을 제거**하고, **스탬프↔리워드 사이에 O/X 퀴즈 8문항 + 오답 팝업**을 삽입. QR 스캔 → 부스 퀴즈 정답 → 스탬프 적립의 게이팅 구조.
2. **전면 이미지 애셋 구성** — 배경·STEP 안내 카드·퀴즈 카드·지도·리워드 일러스트가 텍스트 노드가 아니라 **디자인이 굳은 풀블리드 PNG**. 문항/문구 수정 시 **텍스트 편집이 아니라 이미지 재생성/교체**가 필요.
3. **전체 영문(English) UI** — 헤드라인·안내·퀴즈·리워드 모두 영어. 국문 참조 이벤트와 달리 다국어(태국 K-콘텐츠 대상) 케이스.
4. **보드게임형 지도 모티프** — 시작 화면에 타원형 트랙 위 부스 로고 배치 + `Information Desk`/`RETURN` 노드. 스탬프 격자와 별개로 **여정(맵) 은유**를 시작 화면에 사용.
5. **밝은 옐로 CTA 처리** — `EVENT START`/`FINISH` 버튼이 레몬 옐로(`#F2E326`)라 **버튼 위 텍스트는 화이트가 아닌 다크/그레이**로. (밝은 서브컬러 위 가독성 규칙)
6. **스탬프 = 부스 로고 각인 스캘럽 씰(8개)** — `K-01`~`K-08` 번호 + 부스 브랜드 로고. before(연핑크)/after(브랜드 컬러) 2벌 이미지. 3-3-2 그리드(3열, 마지막 행 2칸).
7. **상태는 헤드라인 카운트 + 씰 활성**으로 표현 — "RECEIVE N MORE STAMPS…" 남은 수만 바꾸고, 씰을 순차 활성. 6Done에서 "충분히 모음" 문구로 전환, RewardDone에서 완료 문구.

## 🤖 디자인 자동화 재현 포인트

- **테마색**: 메인 마젠타 핑크 `#DB518D`(방사형 버스트 배경) · 서브/CTA 레몬 옐로 `#F2E326` · 화이트 카드 · STEP pill = 다크 네이비. 옐로 버튼 텍스트는 **다크**.
- **폰트**: 디스플레이 헤드라인 **Jalnan 2** · 본문/안내 = 볼드 산세리프. **Pretendard 아님** (전체 영문 표기).
- **스탬프**: **8칸 · 3-3-2 그리드**(3열, 씰 79×79, gap 25/44) · **스캘럽 원형 씰** · `K-01`~`K-08` 번호+부스 로고 각인 · before(연핑크)/after(브랜드 컬러) 이미지 2벌.

- **특이사항**:
  - 인증 단계 제거 + 퀴즈 게이팅 → 표준 흐름의 변형(퀴즈형).

  - 리워드 = **럭키박스(랜덤 기프트)** 컨셉 + **Pickup Location** 부스 로고 그리드(인포메이션 데스크 수령).
