# 🍜 참조 이벤트 — 김포 로컬푸드 미식투어 (Gimpo Local Food Gourmet Tour)

> **김포시 "김포 로컬푸드 미식투어" QR/NFC 스탬프 이벤트.** 김포 관내 투어리스트(맛집·특산물 매장)를 방문해 QR/NFC를 태그하면 스탬프가 찍히고, **스탬프 4개**를 모으면 신세계 상품권 10,000원권(선착순 1,000명)을 받는다.
> **일러스트 포스터형 케이스** — 시작 화면 전체가 김포 캐릭터·지도 일러스트 풀블리드 포스터, 스탬프 화면은 마젠타 단색 배경 위 원형 "GIMPO" 씰 그리드. 배경(START-BG / STAMP-BG)은 편집 불가한 **단일 이미지 애셋**으로 굳어져 있다.
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

- **Figma**: `QR 스탬프` · fileKey `n8YIkPdm2svezJYjePHn1u` · 페이지 `김포미식투어` (`3802:64`)
- **아트보드**: 393 폭 · 시작 **1433**(긴 포스터) / 로그인 852 / 스탬프 **2208**(세로 스크롤) / 리워드 823
- **구성**: 본인인증 **있음** · **리워드 목표 스탬프 4칸** (그리드 슬롯은 2열 세로 스크롤로 여유 배치) · **단일 리워드 화면 있음**

## 2️⃣ 본인인증 (Login) · `3802:145` / `3802:164`
- 헤드라인 **"휴대폰번호 인증 한 번으로 이벤트에 참여하세요"**.
- 공통 DS 폼 그대로: `Field_Name` / `Field_Phone`(인증번호 받기) / `Field_Verification`.
- 필수 동의 체크박스 2종: **"개인정보 수집 이용 동의 (필수)"** / **"개인정보 처리업무 위탁 동의 (필수)"**(각 "자세히" 링크).
- CTA **버튼** — Default(비활성) ↔ Filled(활성). 상태 규칙: **인증&동의 완료 → 시작하기 버튼 활성화**.

## 3️⃣ 스탬프 (Stamp) — 원형 "GIMPO" 씰 그리드
- 프레임 393×2208, 콘텐츠 폭 349(좌우 22 여백), 마젠타 배경 위 세로 스크롤.
- 헤더(3줄 고정, 마젠타 배경 위 화이트, `Pretendard Black`+`Medium`):
  - Default: **"홍길동님, / 4개의 스탬프를 더 모으고 / 리워드를 받으세요"** + `리워드 신청하기` 버튼(비활성)
  - 진행: **"홍길동님, / 3개의 스탬프를 더 모으고 / 리워드를 받으세요"** (`3-2. STAMP-1Done`)
  - 완료: **"홍길동님, / 스탬프를 모두 모았어요! / 리워드를 받으세요"** (`3-3. STAMP-4Done`) → `리워드 신청하기` 버튼 활성화
  - 리워드 후: **"홍길동님, / 미식투어는 끝나지 않았어요 / 계속해서 스탬프를 모아보세요!"** (`3-4. STAMP-RewardDone`)
- **스탬프 그리드**: **2열** × 다행(슬롯 166×166, 열 간격 17 / 행 간격 24) · 세로 스크롤. 리워드 **목표는 4개**지만 슬롯은 여유 배치(수집 지속형).
  - 각 칸 = **원형 스캘럽(톱니) 씰** — 중앙 **`G I M P O`** 레터마크 + 위아래 **별(★) 모티프**. 미적립=화이트/그레이 라인, 적립=마젠타 리컬러(active).
  - 스탬프는 `STAMP-Before` 컴포넌트 인스턴스(적립 시 after 스왑).
- 헤더 버튼 상태: `BUTTON-Stamp-Disabled`(0~진행) → `BUTTON-Stamp-Active`(4Done) → `BUTTON-Stamp-Done`(RewardDone).

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **일러스트 포스터형 시작·배경** — 시작(`START-BG 1`)과 스탬프 배경(`STAMP-BG`)은 **디자이너 제작 단일 이미지 애셋**으로 굳어져 있다. 텍스트/레이아웃이 이미지에 포함되어 있어 문구·색 수정 시 **이미지 재제작**이 필요(Figma 노드 편집 불가).
2. **목표(4)와 그리드 슬롯 수가 다름** — 리워드 조건은 스탬프 4개지만, 스탬프 화면은 2열 세로 스크롤로 **여러 슬롯을 여유 배치**(수집 지속형: RewardDone 이후에도 "계속 모아보세요"). 헤더 카운트("N개 더 모으고")로 목표 진행을 표현.
3. **4단계 표준 구조 + RewardDone 상태 추가** — 스탬프 상태가 Default/1Done/4Done에 더해 **`3-4. STAMP-RewardDone`**(리워드 수령 후 재방문 유도)까지 4상태.
4. **다색 리워드 화면** — 메인 마젠타 배경 위 **시안 타이틀 + 블루 카드 + 오렌지 CTA**의 팝한 다색 조합. 리테마 시 배경(마젠타)만 유지하고 카드/버튼 색은 이미지에 종속.
5. **수령 = 기프티콘 자동발송** — 리워드는 오프라인 수령이 아니라 **신세계 상품권 문자 자동발송**(선착순 1,000명). 캔버스에 `기프티콘 문자 자동발송` 메모 명시.

## 🤖 디자인 자동화 재현 포인트

- **테마색**: 메인 마젠타 **`#E267A5`**(스탬프·리워드 배경). 리워드 서브: 타이틀 시안 `#29A9E0` / 상품권 카드 블루 `#5677B8` / CTA 오렌지 `#F9AE41`. 배경 위 텍스트는 화이트.
- **폰트**: 전체 **Pretendard** — 헤드라인 **Black**, 본문 **Medium/SemiBold**(별도 영문 헤드라인 폰트 없음).
- **스탬프**: 목표 **4칸**, **2열 세로 스크롤 그리드**(슬롯 166×166, 열 gap 17 / 행 gap 24). 모티프 = **원형 스캘럽 "GIMPO" 씰 + 별(★)**. before=화이트/그레이 라인, after=마젠타 리컬러.
- **단계 구조**: 시작(일러스트 포스터) → 본인인증(2) → 스탬프(Default/1Done/4Done/RewardDone 4상태) → 리워드(Default/Done). **본인인증 있음 · 리워드 전용 화면 있음**.
- **특이사항**:
  - 시작·스탬프 배경이 **편집 불가 단일 이미지**(문구 수정 시 이미지 재작업).
  - 리워드 목표(4) ≠ 그리드 슬롯 수(여유 배치, 수집 지속형).
  - 리워드 수령 = **문자 기프티콘 자동발송**(선착순 1,000명), 별도 오프라인 수령 없음.
  - `4-1`/`4-2`는 CTA 상태만 다르고 나머지 100% 동일 → 동기화 필수.
