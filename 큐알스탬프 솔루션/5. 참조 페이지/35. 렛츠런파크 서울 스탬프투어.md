# 🐴 참조 이벤트 — 렛츠런파크 서울 스탬프투어 (KRA Let's Run Park Seoul)

> **한국마사회(KRA) "렛츠런파크 서울" 투어 QR스탬프 이벤트.** 경마공원 내 **5개 투어 코스**(놀라운지 · 예시장 · 중문광장 트리 · 하마대 · 말박물관)를 돌며 QR 스캔/NFC 태그로 스탬프를 적립하고, **5개 모두 적립하면 스타벅스 카페라떼(TALL) 기프티콘**을 받는다.
> **캐릭터 마스코트 스탬프 케이스** — 스탬프 5칸이 각각 **다른 포즈의 조랑말(경주마) 캐릭터 이미지**(선글라스·당근·하트안경·마카롱·응원술)로 구성된 귀여운 컨셉. 국문 타이틀에 **손글씨 계열 WAGURI(와구리)** 폰트를 사용.
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

## 1️⃣ 시작 (Start) · `3774:207` — 긴 세로 스크롤 안내 페이지
- 상단 **KRA 한국마사회 로고** + 디스플레이 타이틀 **"렛츠런파크 서울 / 스탬프투어"**(오렌지 · WAGURI).
- 일시: **`2025.11.21.~12.28.`** · 부가 **`*토, 일만 운영합니다.`**
- 리드 안내문: "사계절 내내 즐거운 이벤트가 가득한 렛츠런파크 서울에서 투어 장소를 돌아다니며 스탬프를 적립해 보세요! 추억을 만들고 선물도 받을 수 있어요!"
- **참여 방법**(1~4 스텝): ① 시작하기 누르고 본인인증 → ② 투어장소 방문 후 QR 스캔 혹은 NFC 태그 → ③ 스탬프 5개 모두 적립 → ④ 기프티콘 받기.
- **QR 스탬프 코스 안내**(1~5, 지도 일러스트 + 번호 핀):
  1. **놀라운지** — 경주관람 명당, 2040 관람존! 초보경마교실에서 키링도 받아가세요~
  2. **예시장** — 경주마의 모습을 가까이서 보자!
  3. **중문광장 트리** — 중문앞 트리에서 트리와 함께 인증샷 찍자!
  4. **하마대** — 결승선을 통과한 경주마들의 집결장소!
  5. **말박물관** — 마문화에 대해 알아보자!
- **유의사항**: 렛츠런파크 서울 방문 고객 전원 대상 / 1인 1회 참여 / 모든 코스 방문·스탬프 필수(순서 무관) / 완주 시 경품 자격 / 경품 선착순·조기소진 가능 / 한국마사회 임직원 참여 불가.
- 하단 오렌지 CTA **"시작하기"**.

## 2️⃣ 본인인증 (Login) · `3774:2556` / `3774:2575`
- 헤드라인 **"휴대폰번호 인증 한 번으로 이벤트에 참여하세요"**.
- DS 폼 그대로 + 오렌지 테마링. 필수 동의 체크박스 2종: **개인정보 마케팅 활용 동의(필수)** / **마케팅 SMS 수신 동의(필수)**, 각 "자세히".
- CTA **"시작하기"** — Default(비활성) ↔ Filled(인증&동의 완료 시 활성). 라벨: "인증&동의 완료 → 시작하기 버튼 활성화".

## 3️⃣ 스탬프 (Stamp) — 조랑말 캐릭터 컬렉션
- **2열 그리드 · 5칸**(2·2·1 배치 · 컨테이너 폭 288 · 셀 **120×120** · gap 24 · 6번째 슬롯은 opacity 0 placeholder로 좌측 정렬 유지).
- 칸 사이 **세로 구분선**(Line 2) + 행 사이 **가로 구분선**(Line 7~) 점선 격자.
- **칸 디자인 = 이미지 애셋(캐릭터)** — 각 스탬프가 서로 다른 조랑말(경주마) 마스코트 이미지:
  - 1 선글라스 조랑말 · 2 당근 든 조랑말 · 3 하트안경 조랑말 · 4 마카롱 조랑말 · 5 응원술(폼폼) 조랑말.
  - `스탬프_N` rounded-rectangle에 이미지 fill. 미적립=그레이 톤 / 적립=풀컬러(별도 애셋).
- 헤더(고정 문구, 남은 개수만 변동, 강조 숫자 오렌지):
  - Default(0/5): **"홍길동님, 5개의 스탬프를 더 모으고 리워드를 받으세요"**
  - 1Done(1/5): **"홍길동님, 4개의 스탬프를 더 모으고 리워드를 받으세요"** (`3-2`)
  - 5Done(5/5): **"홍길동님, 스탬프를 모두 모았어요! 리워드를 받으세요"** (`3-3`)
  - RewardDone: **"홍길동님, 축하드려요! 리워드 수령을 완료했어요"** (`3-4`)
- 헤더 하단 CTA **"리워드 받기"**(미완료 시 opacity 40 비활성 → 완료 시 활성).

## 4️⃣ 리워드 (Reward) · `3774:3467` / `3774:3949`
- 상단 KRA 로고 + **"렛츠런파크 서울 / 스탬프투어"**(오렌지 · WAGURI) + **"참여해 주셔서 감사합니다!"**(다크 · WAGURI).
- 축하 일러스트: **폼폼(응원술) 든 조랑말 마스코트 + 색종이(confetti) + 당근/큐브 장식**(원형 옐로 배경 ellipse 위).
- 리워드 카드(옐로 반투명 radius 24): **"스타벅스 카페라떼 (TALL)"**(오렌지 WAGURI) + **카페라떼 컵 이미지**.
- 하단 오렌지 CTA — Default: "리워드 받기" / Done(`3774:3949`): "리워드 수령 완료"(비활성). 우상단 Close Icon.
- ※ 별도 "리워드 수령처/기한" 핀라벨 텍스트 노드는 없음(수령 안내는 시작 화면 유의사항 + 기프티콘 방식으로 처리).

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **캐릭터 마스코트 스탬프(칸마다 다른 애셋)** — 5칸이 동일 모티프가 아니라 **포즈·소품이 전부 다른 조랑말 캐릭터 5종**. 신규/변경 시 캐릭터 이미지 교체(before 그레이 / after 풀컬러 2벌).
2. **국문 디스플레이 타이틀 = WAGURI(와구리)** — 타이틀·리워드명·감사문에 손글씨 계열 **WAGURI**(Pretendard 아님)를 사용해 친근한 톤. 본문·버튼은 Pretendard. ⚠️ 타이틀 재현 시 폰트 혼동 주의.
3. **시작 화면이 긴 세로 스크롤 안내 페이지(2635)** — 참여 방법 스텝 + 번호 지도 코스 안내(5개) + 유의사항까지 시작 화면에 전부 담김. (다른 이벤트의 카드형 시작 대비 정보량 많음)
4. **NFC 태그 병행** — 참여 수단이 "QR 스캔 **혹은 NFC 태그**". 코스 안내·참여 방법에 NFC 명시.
5. **밝은 크림 배경 + 오렌지 단색 테마** — 배경 `#FEFFEA` 위 오렌지 `#EC692C` 강조. 헤더 강조 숫자만 오렌지(텍스트 교체 시 색 재적용 필요).
6. **2열 5칸 + placeholder 슬롯** — 홀수(5)를 2열 그리드에 배치할 때 6번째 셀을 opacity 0로 두어 좌측 정렬 유지.

## 🤖 디자인 자동화 재현 포인트

- **테마색**: 메인 오렌지 `#EC692C` · 배경 크림 `#FEFFEA` · 본문 `#212529`/`#262626` · 그레이(미적립) `#C0C0C0` · 리워드 카드 `rgba(249,237,172,0.8)`.
- **폰트**: 디스플레이 타이틀 = **WAGURI(와구리) Regular** (렛츠런파크 서울 / 스탬프투어 / 참여해 주셔서 감사합니다! / 스타벅스 카페라떼) · 본문·버튼·헤더 = **Pretendard**(SemiBold/Bold).
- **스탬프**: **5칸 · 2열 그리드**(2·2·1 + opacity 0 placeholder 1) · 셀 120×120 · gap 24 · 점선 격자. 모티프 = **조랑말(경주마) 캐릭터 5종**(선글라스·당근·하트안경·마카롱·폼폼), 이미지 애셋(before 그레이 / after 풀컬러).
- **단계 구조**: 4단계 — 시작(긴 스크롤 안내) → 본인인증(Default/Filled) → 스탬프(Default/1Done/5Done/RewardDone 4상태) → 리워드(Default/Done). 본인인증·리워드 화면 **모두 있음**.
- **콘텐츠 핵심**: 기간 `2025.11.21.~12.28.`(토·일만 운영) · 코스 5개(놀라운지/예시장/중문광장 트리/하마대/말박물관) · 리워드 = **스타벅스 카페라떼(TALL) 기프티콘** · 참여 수단 QR+NFC.
- **특이사항**: ① 국문 타이틀 WAGURI 폰트 필수 ② 칸마다 다른 캐릭터 애셋 ③ 시작 화면에 참여방법·지도 코스·유의사항 모두 포함(세로 2635) ④ 헤더 강조 숫자만 오렌지 ⑤ 리워드 수령처 핀라벨 없음(기프티콘형).
