# 🥃 참조 이벤트 — 맥캘란 (THE MACALLAN 360 POP-UP STORE)

> **맥캘란(THE MACALLAN 360) 팝업스토어 방문 QR스탬프 투어 이벤트.** 팝업스토어 내 QR을 스캔하면 스탬프가 1개씩 적립되고, **[THE MACALLAN 360 Consumer Journey]** 를 따라 진행하며 **Six Pillars 스탬프 6개**를 모두 모으면 **100% 당첨 가챠(가챠 참여권)** 이벤트에 참여할 수 있다.
> **위스키 프리미엄 브랜드 케이스** — 맥캘란 로고에서 메인 컬러(크림슨 레드)를 추출하고, 스탬프는 위스키 아로마/노트를 상징하는 **6종 라인아트 아이콘(Six Pillars)** 으로 구성했다.
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

## 1️⃣ 시작 (Start) · `3777:4308`
- 배경 이미지(`START-BG 1`)에 **모든 카피가 이미지로 굳어져 있음** — 상단 **맥캘란 360 로고** + 타이틀.
- 타이틀: **"THE MACALLAN 360 POP-UP STORE / 스탬프 투어 이벤트"**.
- 안내문(불릿 3):
  - "팝업스토어 내 QR 코드를 스캔하면 스탬프가 1개씩 적립됩니다."
  - "진행 스탬프 안내에 따라 순서대로 [THE MACALLAN 360 Consumer Journey]를 완주해 주세요."
  - "스탬프 총 6개 중 4개 이상을 획득하면 100% 당첨되는 가챠 이벤트에 참여할 수 있습니다."
- 하단 **블랙 CTA "이벤트 참여하기"** (333×50 · radius 5 · Pretendard Bold 20 · bottom 40).

## 2️⃣ 본인인증 (Login) · `3777:5296` / `3777:5315`
- 헤드라인 **"휴대폰번호 인증 한 번으로 이벤트에 참여하세요"** (Pretendard, 2줄).
- DS 폼 그대로: `이름` / `휴대폰번호`(+ "인증번호 받기") / `인증번호` · 보조 링크 "인증번호 문자가 오지 않을 때".
- 필수 동의 체크박스 2종(개인정보 수집·이용 / 처리업무 위탁, 각 "자세히").
- CTA **"시작하기"** — Default(그레이·비활성) ↔ Filled(활성). 컨테이너 padding 상단 64.

## 3️⃣ 스탬프 (Stamp) — Six Pillars 아로마 라인아트
- 헤더(24 좌우 · 72 top · 폭 345): 고정 카피 + 강조 숫자만 변동. (텍스트 `#231F20`, 강조 숫자 크림슨 `#B20D2C`)
  - Default: **"홍길동님, / Six Pillars 스탬프 `4`개 더 획득하고 / 100% 당첨 가챠 참여권을 획득하세요!"**
  - 1Done: 강조 숫자 **`3`** ("3개 더 획득하고")
  - 4Done: **"…스탬프를 모두 모았어요 / 100% 당첨 가챠 참여권을 획득하세요!"** (강조 숫자 없음)
  - RewardDone: **"홍길동님, / 축하드려요! 이벤트 참여를 완료했어요"**
- 헤더 하단 **"참여권 받기"** 버튼(345×50 · 블랙 · radius 5). 스탬프 목표 미달 시 **opacity 40%(비활성)**, RewardDone 상태에서는 **"이벤트 참여 완료"** 로 문구 변경.
- **스탬프 그리드**: 컨테이너 `Frame 48098723`(폭 312 · top 257) · 오토레이아웃 wrap · **gap 30(행) × 60(열)** · **2열 × 3행 = 6칸**.
  - 각 칸 = **126×126 원형 라인아트 씰** — 위스키 아로마/노트를 상징하는 **6종 서로 다른 모티프**(향 그래프 곡선 · 포도송이 · 코(후각) · 오크통 문양 · 맥캘란 M 로고 등).
  - 스탬프는 **이미지 애셋**(`STAMPn-before`=그레이 라인 / after=크림슨 라인). 텍스트가 아니라 라인아트 아이콘 이미지.
  - 적립 진행: Default(0/6 전부 그레이) → 1Done(1개 크림슨) → 4Done(4개 크림슨) → RewardDone(전부 크림슨 + 버튼 완료).

## 4️⃣ 리워드 (Reward) · `3777:4711` / `3777:5489`
- 배경 이미지(`REWARD-BG 1`)에 카피·비주얼이 굳어져 있음. 우상단 **닫기(X) 아이콘**(20×20).
- 타이틀 **"축하합니다!"** (크림슨) + 안내문 **"스탬프에 해당 화면을 제시하고 / 100% 당첨 가챠 키오스크 이벤트에 참여하세요."**
- 리워드 비주얼: **크림슨 가챠(캡슐 뽑기) 3D 볼** — 맥캘란 M 로고가 새겨진 가챠 머신 모티프.
- 하단 **블랙 CTA "이벤트 참여하기"** (333×50 · bottom 40).
- Done(`3777:5489`) = Default 복제 + 상태만 차이("리워드 수령 완료"). **4-1·4-2 동일 처리**(배경·아이콘·여백·폰트).

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **시작·리워드 = 배경 이미지에 카피 포함** — 시작 화면 타이틀/안내 불릿, 리워드 타이틀/안내문/가챠볼이 모두 **`START-BG`/`REWARD-BG` 배경 이미지에 굳어져 있음**. 카피 수정 시 텍스트 편집이 아니라 **이미지 교체** 필요. (경기수의컨퍼런스의 반투명 카드 방식과 대비)
2. **스탬프 = 6종 라인아트 아이콘(Six Pillars)** — 4~16칸 격자에 위스키 브랜드의 6개 기둥(향·노트) 컨셉을 서로 다른 라인아트로 표현. before(그레이)/after(크림슨) 2벌 이미지 애셋.
3. **CTA = 블랙 버튼** — 메인 컬러가 크림슨이지만 버튼은 **블랙 배경 + 화이트 텍스트**로 처리. 비활성은 블랙 opacity 40%.
4. **강조 = 크림슨 숫자** — "N개 더 획득하고"의 남은 개수 숫자만 `#B20D2C` 강조. ⚠️ 텍스트 교체 시 강조 색이 초기화되므로 숫자 수정 후 반드시 크림슨을 다시 입힌다.
5. **완주 목표 4/6 + 가챠 참여권** — 안내상 "4개 이상"이면 참여 가능하나 헤더는 6개 완주 흐름으로 구성. 리워드는 **100% 당첨 가챠 참여권**(현장 키오스크).

## 🤖 디자인 자동화 재현 포인트

- **테마색**: 메인 크림슨 **`#B20D2C`** · 텍스트 **`#231F20`** · CTA 버튼 블랙 `#000000`(비활성 opacity 40%) · 스탬프 배경 화이트.
- **폰트**: 전체 **Pretendard**(헤더 SemiBold 20 / CTA Bold 20 · line-height 1.3~26px · tracking -0.04).
- **스탬프**: **6칸 · 2열 × 3행 · 126×126 원형 라인아트** · 오토레이아웃 wrap · gap 30(행) × 60(열) · 컨테이너 폭 312. 모티프 = **Six Pillars 위스키 아로마/노트 6종**(향 곡선·포도·코·오크·M로고 등) · before 그레이 / after 크림슨 2벌 이미지.
- **단계 구조**: 4단계(시작 → 본인인증 2 → 스탬프 4상태 → 리워드 2). 본인인증 **있음** · 리워드 화면 **있음**(가챠 참여권).
- **레이아웃 값**: 프레임 393폭 · 스탬프 헤더 left 24 / top 72 / 폭 345 · 그리드 top 257 · CTA 하단 40 · 로그인 폼 padding-top 64.
- **특이사항**:
  - 시작·리워드 화면 카피/비주얼이 **배경 이미지에 굳어져 있음** → 콘텐츠 변경 = 이미지 교체.
  - 스탬프 헤더 강조 숫자는 **크림슨 색을 별도로 유지**(텍스트 편집 시 초기화 주의).
  - CTA 버튼은 메인 컬러가 아닌 **블랙** 사용(프리미엄 톤).
  - 운영 메모: 스탬프 적립/참여권은 **현장 관리자 비밀번호 입력** 기반, 리워드는 **키오스크 가챠**로 수령.
