# 🎡 참조 이벤트 — 2025 SONAX FESTA (소낙스페스타 · STAMP MISSION)

> **소낙스(SONAX) 창립 75주년 기념 "2025 SONAX FESTA" QR스탬프 미션 + 룰렛 경품 이벤트.** 행사장 부스에서 QR을 스캔해 스탬프 미션을 완료하면, **룰렛(랜덤 추첨)** 을 돌려 8종 경품 중 하나에 당첨된다.
> **룰렛(휠) 추첨형 케이스** — 4~16칸 정형 스탬프 그리드가 아니라, 스탬프 미션 완료 → **8분할 룰렛 휠**을 돌려 경품을 뽑는 구조. 당첨 결과에 따라 **리워드 화면이 8종(REWARD1~8)** 으로 분기하며, 각 참여자에게 **추첨번호(럭키드로우 번호)** 를 부여한다.
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

## 전체 흐름

```
시작 → 본인인증(2) → 스탬프 미션(스캔) → 룰렛(추첨) → 리워드(8종 분기 + 럭키드로우)
                                          (본인인증 있음 · 리워드 화면 있음)
```

> 표준 4단계(시작→인증→스탬프→리워드)에 **룰렛(추첨) 단계가 추가**된 5단계 변형. 스탬프 미션 완료가 곧 룰렛 참여 자격이며, 룰렛 결과로 리워드가 8종 중 하나로 결정된다.

- 안내문(퍼플 배경 위 화이트): **"행사장 내 스탬프 미션을 완료하고 QR 코드를 스캔하면 스탬프 획득! 모든 스탬프를 모으세요!"** / **"선착순 룰렛 게임 참여를 통한 경품 증정 및 럭키드로우 번호를 제공해드려요!"**

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **룰렛(추첨) 단계 추가 = 5단계** — 표준 스탬프 그리드 대신 **스탬프 미션 완료 → 8분할 룰렛 휠 → 경품 분기** 구조. 룰렛은 `Board`(휠) + `Pin`(포인터) 2애셋으로 구성, 회전 인터랙션 상정.
2. **리워드 8종 분기** — 당첨 경품에 따라 REWARD1~8 화면이 각각 존재. 각 화면 = 동일 레이아웃(축하 타이틀 + 경품 이미지 카드 + LUCKY DRAW 번호)에서 **경품 이미지만 교체**. "꽝"(REWARD8)도 동일 프레임 구조로 처리.
3. **럭키드로우(추첨번호) 시스템** — 리워드 화면 하단 `00` 대형 숫자 = 참여 순서대로 부여되는 추첨번호. 행사 종료 전 별도 추첨(오프라인)과 연계.
4. **배경 = 풀블리드 키비주얼 이미지** — START/ROULETTE/축하 모두 퍼플 코스믹 이미지를 프레임 전체 fill. 인터랙션 버튼만 딥 인디고 `#221D49` 단색 pill.
5. **75주년 브랜딩** — 상단 "1960–2025 75TH ANNIVERSARY EDITION" 러닝헤드 + 원형 엠블럼 + 협찬사 로고 바(소낙스/BMW/제휴사) 반복 배치.

## 🤖 디자인 자동화 재현 포인트

- **테마색**: 버튼/인터랙션 = **딥 인디고 `#221D49`**(pill·라운드 999·화이트 22px 텍스트) · 포인트/키비주얼 = **마젠타·퍼플 `#D345C7`** 코스믹 배경 · 리워드 카드 = 화이트 radius 12.
- **폰트**: 전체 **Pretendard Bold**(별도 영문 헤드라인 폰트 없음 — "STAMP MISSION"·"LUCKY DRAW"도 키비주얼 이미지/Pretendard).
- **스탬프**: 정형 그리드 칸수 없음 → **"스탬프 미션 완료 = 룰렛 참여 자격"** 모델. 대신 **8분할 룰렛 휠(Board 345×345 + Pin 61×61)** 이 핵심 인터랙션.
- **단계 구조**: 시작 → 인증 → 스탬프 미션 → **룰렛(추첨)** → 리워드(8종 분기 + 럭키드로우 번호) → 수령 완료. **본인인증 있음 · 리워드 화면 있음(8종)**.
- **특이사항**:
  - 리워드 8종은 **동일 템플릿 + 경품 이미지만 교체**(꽝 포함). 당첨 화면(3-1) / 상세 화면(REWARDn) / 수령완료(3-2 Done) 3상태.
  - **럭키드로우 번호(`00`)** = 참여 순서 기반 추첨번호. 리워드 하단 마젠타 "LUCKY DRAW" 밴드에 대형 표기.
  - 배경은 전부 **풀블리드 이미지 fill** — 리테마 시 색상 토큰이 아닌 이미지 애셋 교체가 핵심.
  - 이 캔버스에서 **인증·스탬프 프레임은 라벨/자리표시**(검은 프레임+텍스트)로만 존재 → 표준 DS 폼·스탬프 템플릿을 별도 적용해야 함.
