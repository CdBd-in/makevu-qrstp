# 🌾 참조 이벤트 — 강진군청 갈대축제 (가우도 십이몬을 잡아라!)

> **강진군(강진품애ON군민) 주최 "마량미항 갈대축제" QR스탬프 이벤트.** 축제장 각 부스/포인트에서 QR을 스캔하면 강진 캐릭터 **"십이몬"(가우도 12마리 고양이 마스코트)** 스탬프가 채집되고, **12개 캐릭터**를 모으면 마일리지·경품을 받는다.
> **캐릭터 컬렉션(도감) 케이스** — 스탬프가 도장/씰이 아니라 **지역 캐릭터 IP 12종**이다. 시작 화면은 12마리를 **콜라주(겹침·회전)** 로, 스탬프 화면은 **3열 도감 그리드**로, 미적립=흑백 아웃라인 / 적립=풀컬러로 표현한다.
> **본인인증이 없는 3단계 플로우**(시작→스탬프→리워드). 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

- **Figma**: `QR 스탬프` · fileKey `n8YIkPdm2svezJYjePHn1u` · 페이지 `강진군청` (`3528:51734`)
- **아트보드**: 393 폭 · 시작 **852** / 스탬프 **1122** / 리워드 **899**

- **폰트**: 헤드라인·CTA **Hakgyoansim Dotbogi(학교안심 돋보기)** / 본문 **Pretendard**

## 1️⃣ 시작 (Start) · `3528:52439` / `START-BG 3577:1344`
- 상단 헤더: **강진 갈대축제 로고** + **강진품애ON군민** 로고(투명·좌우 배치).
- 타이틀 2줄:
  - **"갈대축제에 놀러온"** (Hakgyoansim Dotbogi · 28px · `#3e805e`)
  - **"가우도 십이몬을 잡아라!"** (Hakgyoansim Dotbogi · 38px · **글자별 멀티컬러**)
- **일시/운영시간**(Pretendard, 라벨 Bold `#16534d`):
  - `행사기간  |  10. 25.(토) ~ 11. 2.(일) / 9일간`
  - `행사부스 운영시간  |  10:00 ~ 17:30`
- **12 캐릭터 콜라주**: 시작 화면 중앙에 십이몬 12마리 이미지를 **겹치고 살짝 회전(±5~20°)** 시켜 무리지어 놓은 키비주얼(격자 아님).
- 하단 유의사항 카드(크림 반투명): "• 이미 스캔한 QR코드로 중복 적립이 불가합니다. • 중복 및 부정 참여 확인 시 리워드 지급이 취소될 수 있습니다."
- 하단 딥그린 CTA **"시작하기"**(`button` `3528:52455`).

## 2️⃣ 스탬프 (Stamp) — 십이몬 캐릭터 도감 · `3529:56087` 외
- **상단 "리워드 안내" 섹션**(스탬프 화면 상단 고정): 헤드라인 "리워드 안내"(`#3e805e`) + `#f6ebbd` 카드 2블록:
  - **성인**(그린) — "스탬프 1개당 1,000마일리지 지급" / *12개 스탬프 모두 적립 시 20,000마일리지*
  - **어린이**(블루 `#547dbb`) — "스탬프 10개 이상 적립 시 키링 등 경품 지급" / *일 선착순 50명*
- **스탬프 그리드**: 컨테이너 `16` 좌우 여백 · 폭 360 · **3열 × 4행 = 12칸** · 각 칸 **120×140**.
  - 각 칸 = **십이몬 캐릭터(에그형 고양이 마스코트) 이미지** + 하단 **캐릭터 이름 라벨**.
  - 12캐릭터 순서/이름: `1-자(모지)` `2-축(우니)` `3-인(보미)` `4-묘(라지)` `5-진(라고니)` `6-사(화란)` `7-오(마론)` `8-미(메이)` `9-신(나나)` `10-유(꼬꼬)` `11-술(메로)` `12-해(파비)` — 십이지(자·축·인·묘…해) 네이밍.
  - 스탬프 애셋 = **before(흑백 아웃라인 + 이름 라벨) / after(풀컬러, 이름 라벨 없음)** 2벌 이미지. 텍스트 노드가 아니라 **캐릭터가 이미지로 굳어져 있음**(신규 캐릭터 = 이미지 교체).
- **상태 진행**: Default(0/12 전부 before) → 1Done(2-축만 after) → 12Done(전부 after) → RewardDone.
- CTA(`button`): 스탬프 화면에도 **"리워드 바로 받기"**(비활성 opacity 40% → 1개 이상 적립 시 활성). RewardDone 상태에선 **"리워드 수령 완료"**.

## 3️⃣ 리워드 (Reward) · `3529:56703` / `3529:56759`
- 상단: 십이몬 캐릭터 5마리 일렬 + 꽃/장식 벡터.
- 타이틀(REWARD-Default): **"축하합니다! 00개의 스탬프를 모았습니다!"** (모은 개수 동적 삽입).
- 안내문: **"강진품애ON군민 부스에서 마일리지와 상품을 받으세요!"** (부스 로고 인라인).
- **리워드 수령처 지도 카드**: 축제장 **일러스트 지도**(`지도 1`) + 위치 핀 라벨 — `리워드 수령처`(강조) · `범선 전망대` · `푸드트럭` · `향토음식관` · 화장실 아이콘. → 오프라인 수령 위치 안내.
- 하단 갈대 실루엣 장식 + CTA **"리워드 바로 받기"**.
- **REWARD-Done**(`3529:56759`) = Default 복제 + 타이틀 "축하합니다!" 계열 + CTA만 **"리워드 수령 완료"**(비활성). *현장 관리자가 비밀번호 입력하여 수령 완료 처리*(플로우 라벨 명시).

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **스탬프 = 지역 캐릭터 IP 도감** — 도장/씰이 아니라 **강진 십이몬 12마리**. 미채집=흑백 아웃라인+이름라벨 / 채집=풀컬러(라벨 제거). "도감 채우기" 게이미피케이션.
2. **시작 화면 = 캐릭터 콜라주** — 12마리를 격자가 아니라 **겹침·회전 무리** 로 배치해 활기·수집욕 자극. 스탬프 화면에서만 3열 도감 그리드로 정렬.
3. **본인인증 없음(3단계)** — LOGIN 프레임 자체가 없다. 시작→스탬프→리워드 3단계. (JINAIR·경기수의컨퍼런스의 인증 有 케이스와 대비)
4. **리워드는 대상별 2트랙** — 성인(마일리지 누적형) / 어린이(10개↑ 경품·선착순) 규칙을 스탬프 상단 카드에 상시 노출.
5. **리워드 수령 = 일러스트 지도 + 관리자 승인** — 축제장 지도에 "리워드 수령처" 핀, 현장 관리자 비밀번호 입력으로 Done 전환.
6. **폰트 = Hakgyoansim Dotbogi(놀이감 헤드라인) + Pretendard(본문)** — 헤드라인/CTA/섹션 타이틀에 학교안심 돋보기, 본문·수치는 Pretendard. (표준 Pretendard 단일과 다른 케이스)

- **폰트**: 헤드라인·CTA·섹션타이틀 = **Hakgyoansim Dotbogi / DotbogiOTF**(학교안심 돋보기), 본문·일시·마일리지 = **Pretendard**(Bold/Medium/Regular). 타이틀 "가우도 십이몬…"은 글자별 멀티컬러.
