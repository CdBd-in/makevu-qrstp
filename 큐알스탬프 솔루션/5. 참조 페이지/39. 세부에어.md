# ✈️ 참조 이벤트 — 세부에어 (Cebu Pacific 해피스토어 QR 스탬프)

> **세부퍼시픽(Cebu Pacific) "해피스토어" 팝업스토어 QR스탬프 이벤트.** 행사장 내 각 부스에서 QR을 스캔하면 스탬프가 적립되고, **5개 중 최소 3개**를 모으면 **룰렛을 돌려 선물(항공권/에코백/무릎담요/액정 클리너)** 을 받는다.
> **룰렛(추첨) 단계가 끼어든 케이스** — 스탬프 완주 후 곧바로 리워드가 아니라, **룰렛으로 상품을 랜덤 결정**한 뒤 해당 리워드 화면으로 자동 이동한다. 상품이 4종이라 **리워드 화면도 4벌 + Done 1벌**로 구성된다.
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

- **Figma**: `QR 스탬프` · fileKey `n8YIkPdm2svezJYjePHn1u` · 페이지 `세부에어` (`3502:20`)
- **아트보드**: 393 폭 · 스탬프/룰렛/리워드 **852** · 시작 **920** · 인증 팝업만 **375×812**
- **구성**: 본인인증 **있음**(+ 이메일 필드 추가) · **스탬프 5칸(2+2+1)** · **룰렛 추첨** · **리워드 4종 + Done** → **5단계** 플로우
- **폰트**: 헤드라인 **Gmarket Sans Bold** / 본문·버튼 **Pretendard**

## 1️⃣ 시작 (Start) · `3502:43`
- 상단 **Cebu Pacific 로고**(옐로우 배경 위) + 디스플레이 타이틀 **"세부퍼시픽 해피스토어 / QR 스탬프 이벤트"**(**Gmarket Sans Bold 26px · `#0075C9`**).
- 서브카피 **"최소 3개 스탬프를 모으면 / 꽝 없는 선물 당첨!!"**(Pretendard Bold 18px · `#4BA4DB`).
- 안내문(Pretendard Medium 16px · `#3E69A0`): **"행사장 내 QR 코드를 스캔하면 스탬프가 적립됩니다. 세부퍼시픽 해피 스토어에 방문하셔서 다양한 체험과 선물까지 모두 즐기세요!"**
- 하단 유의사항(Pretendard Regular 12px · `#636463`, 불릿): 중복참여 불가 / 개인정보·초상권 동의 필수 / 굿즈 한정수량 소진 시 종료 / 현장 사정에 따른 변경·조기종료 / 스태프 안내 준수.
- 하단 CTA **"시작하기"**(Pretendard Bold 20px · 화이트).

## 2️⃣ 본인인증 (Login) · `3502:1232` / `3502:1251`
- 헤드라인 **"휴대폰번호 인증 한 번으로 이벤트에 참여하세요"**.
- DS 폼 + **이메일주소 필드 추가**(총 4필드: `이름` / `휴대폰번호` / `인증번호` / `이메일`) — 캔버스 주석 "기존 인증 플로우 + 이메일주소 필드 추가".
- 동의 체크박스 2종(각 "자세히" → 팝업):
  - **"개인정보 수집 이용 및 초상권 사용 동의 (필수)"** → `2-3.Popup1`
  - **"개인정보 처리업무 위탁 동의 (필수)"** → `2-4.Popup2`(수탁업체 **(주)엠카**, 업무 이벤트 진행)
- CTA **"시작하기"** — Default(비활성) ↔ Filled(활성).

## 3️⃣ 스탬프 (Stamp) — Cebby 마스코트 스탬프 랠리
- 헤더(진행도별 문구 변동, Gmarket Sans):
  - Default: **"홍길동님, 3개의 스탬프를 더 모으고 선물을 받으세요"**
  - 1개 적립: **"홍길동님, 2개의 스탬프를 더 모으고 선물을 받으세요"**
  - 5개 적립: **"홍길동님, 스탬프를 모두 모았어요! 선물을 받으세요"**
  - 수령완료: **"홍길동님, 축하합니다! 선물 수령을 완료했어요"**
- **스탬프 그리드**(`Frame 48098847` 297×354): **총 5칸 · 2 + 2 + 1 배치**(1·2행 2칸, 3행 1칸 중앙). 각 칸 **140×102**.
  - 스탬프 = **Cebu Pacific 마스코트(웃는 새/비행기 "Cebby") 이미지** — 라운드 사각 이미지 노드(**컴포넌트/인스턴스 아님**).
  - 미적립 = `STAMP1`~`STAMP5`(옅은 실루엣) / 적립 = `STAMP-after 1`·`STAMP-after 2`(컬러, **2모티프 교차 배치**: after1·after2·after1·after2·after1).
  - **캔버스 규칙: "5개 중 3개 적립 시 리워드 수령 가능"** — 완주(5개) 전이라도 3개면 다음 단계로 진입.
- 버튼: 상태 1~3 **"선물 받기"** / 수령완료 **"선물 수령 완료"**(비활성).

## 5️⃣ 리워드 (Reward) — 상품 4종 + Done
- 공통 헤딩 **"축하드려요!"**(Gmarket Sans Bold 36px · `#0075C9`).
- 배경은 시작/스탬프의 단색 옐로우와 달리 **필리핀 전통 패턴 옐로우 테두리** + 중앙 **보딩패스형 티켓 카드**("Fly is happy, Fly to the Philippines with Cebu Pacific!").
- 리워드명(룰렛 4종과 일치):
  - `5-1` **"세비 핸드폰 액정 클리너"** · `5-2` **"세부퍼시픽 항공권"** · `5-3` **"세부퍼시픽 에코백"** · `5-4` **"세부퍼시픽 무릎 담요"**
  - `5-5.REWARD-Done` = 예시(에코백) + 버튼 **"선물 수령 완료"**(비활성)
- 수령 안내(Pretendard, `#636463`): **"하단의 "선물 받기" 버튼을 누르시면 사용처리 되오니 이용하실 때 직원에게 보여주세요."**
- **캔버스 규칙(Done): "현장 관리자가 비밀번호 입력하여 수령 완료 처리"**.

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **룰렛(추첨) 단계 삽입 = 5단계** — 표준 4단계에 스탬프↔리워드 사이 **룰렛**을 넣는다. 룰렛은 **BackBoard/Board/Center/Pin** 4레이어 라운드 사각 조합 + 4분할 세그먼트(상품명 라벨). "멈춤 → 자동 리워드 이동" 규칙 명시.
2. **상품 다종 → 리워드 화면 다벌** — 룰렛 상품 4종 각각에 **REWARD Default 화면 1벌씩(4벌)** + 공용 **Done 1벌**. 리워드명·티켓만 교체하고 헤딩·안내·버튼은 공통.
3. **스탬프 5칸 · 2+2+1 비대칭 배치** — 4·6칸 정형이 아니라 **마지막 1칸을 중앙 정렬**한 3행 그리드. 스탬프는 **마스코트(Cebby) 이미지**이며 적립본 2모티프를 교차 배치.
4. **부분 완주 허용** — "5개 중 3개 적립 시 리워드 수령 가능". 완주 아닌 **임계값(3)** 도달로 다음 단계 진입하는 로직.
5. **헤드라인 = Gmarket Sans Bold** — 본문/버튼은 Pretendard지만 **타이틀·"축하드려요!"만 Gmarket Sans Bold**(블루 `#0075C9`). 리테마 시 헤드라인 폰트 혼용 주의.
6. **밝은 옐로우 배경 처리** — Cebu 옐로우(`#FFDD00`) 풀블리드 배경 위 텍스트·버튼은 **블루/네이비**로 대비 확보(흰 텍스트는 버튼 위에만).
7. **인증 폼에 이메일 필드 추가** — 표준 DS 폼(이름/휴대폰/인증번호)에 **이메일주소 필드 1개 추가**. 약관 팝업 2종은 **375×812**로 별도(본문만 375).

## 🤖 디자인 자동화 재현 포인트

- **스탬프**: **5칸 · 2+2+1 배치**(마지막 중앙) · 칸 140×102 · 모티프 = **Cebu Pacific 마스코트(Cebby 새) 이미지**(컴포넌트 아님) · before=실루엣 / after 2모티프 교차 · **3개 적립 시 리워드 오픈**.

- **특이사항**:
  - 룰렛 세그먼트 4종 ↔ 리워드 화면 4벌 **1:1 매핑**(항공권/액정클리너/에코백/무릎담요).

  - 수령: 리워드 Done은 **현장 관리자 비밀번호 입력**으로 처리.
