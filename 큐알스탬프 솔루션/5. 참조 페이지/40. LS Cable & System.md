# 🔌 참조 이벤트 — LS Cable & System (QR Stamp Challenge)

> **LS Cable & System 전시부스 "QR Stamp Challenge".** 전시장의 각 **Product Zone(제품 존)**에서 QR을 스캔하면 해당 존의 스탬프가 찍히고, **5개 존을 모두 방문**한 뒤 설문(Survey)을 완료하면 경품(AirPods 4 / Galaxy Buds Pro 3)을 받는다.
> **영문(글로벌) 이벤트 케이스** — 국문이 아니라 **전체 영문 UI**이며 폰트가 Pretendard가 아닌 **Poppins**다. 스탬프 = **원형 씰(seal)**에 **제품 존 이름이 원호를 따라 곡선 배치**되고 중앙에 **LS Cable & System 로고**가 박힌다.
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

- **구성**: 본인인증 **없음** · **스탬프 5칸(2·2·1 배치)** · **리워드 화면 있음** · 설문은 **오프라인(LS 스태프에게 페이지 제시 후 진행)**

```
시작 → 스탬프(5칸) → 리워드          (본인인증 없음 · 설문은 오프라인 · 3단계)
```

- 상단 **LS Cable & System 로고**(화이트) + 디스플레이 타이틀 **"QR Stamp Challenge!"**(Poppins Bold 40px, 2줄, 화이트).
- **안내 카드**(화이트 20% 반투명·화이트 보더·radius 24): 안내문

## 2️⃣ 스탬프 (Stamp) — Product Zone 원형 씰 랠리 · `3467:1299`
- 헤더(Poppins SemiBold 28px): **"Jone Doe, Collect `5` more stamps to claim your reward"** — 남은 숫자 `5`만 **블루 `#4B73FF`** 강조. 완료 상태(`3467:4353`) = **"Jone Doe, All stamps collected! Claim your reward."**
- 헤더 아래 **CLAIM REWARD 버튼**: 딥블루 `#18226E` · radius 5 · **미완료 시 opacity 40(비활성)**.
- 서브 안내(네이비 `#181B67`): **"Collect 5 stamps / In each Product Zone"**.
- **스탬프 그리드**: 컨테이너 폭 350 · **2열 배치 + 열 사이 세로 구분선 + 행 사이 가로 구분선** · **2·2·1 배열**(1·2행 각 2칸, 3행 1칸) = 총 **5칸**.
  - 각 칸 = **136×136 원형 스캘럽(톱니) 씰** — **제품 존 이름이 원호(상단 반원)를 따라 글자 단위로 곡선 배치** + 중앙 **LS Cable & System 로고**.
  - 5개 존: **Data Center Solution · Distribution · Superconducting · CableBus · BusDuct**.
  - OFF(미적립)=그레이(텍스트 `#9FA0A0`), ON(적립)=딥블루 씰 + 화이트. 컴포넌트 세트 `<존명>/OFF`·`<존명>/ON`(180×180)로 관리.

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **영문 전용 이벤트 = Poppins** — 국문 표준 Pretendard가 아니라 **전 화면 Poppins**(Bold/SemiBold/Light/SemiBold Italic). 글로벌·전시 대상 이벤트는 영문 폰트로 리테마.
2. **본인인증 생략 3단계** — 로그인/인증 화면 없이 **시작 → 스탬프 → 리워드**. 참여 장벽을 낮춘 부스 방문형.
3. **설문(Survey)은 오프라인** — "Complete the Survey"는 앱 화면이 아니라 **리워드 페이지를 스태프에게 보여준 뒤 진행**. 리워드 화면 문구가 곧 수령 안내.
4. **스탬프 = 원형 씰 + 로고 + 곡선 텍스트** — 존 이름을 **원호를 따라 글자 단위로 회전 배치**하고 중앙에 LS 로고. 존 추가/변경 시 **OFF/ON 컴포넌트 2벌**을 갈아끼운다.
5. **스탬프 배치 = 2·2·1** — 4칸(2×2)이 아닌 **5칸**이라 마지막 행이 1칸. 열 세로선 + 행 가로선으로 격자 표현.
6. **강조 색 규칙** — 헤더 남은 개수 숫자만 **`#4B73FF`**, 시작화면 핵심 단어만 **`#FFF200`**. 텍스트 수정 시 강조 색 재적용 필요.
7. **CTA 비활성 = opacity 40** — CLAIM REWARD 버튼은 미완료 시 `#18226E`에 opacity 40으로 흐리게. 완료 시 헤더 문구 교체 + 버튼 활성.
