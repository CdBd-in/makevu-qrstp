# 🚗 참조 이벤트 — 현대자동차 재팬 (集めて知って！ ヒョンデ豆知識ハント)

> **현대자동차(ヒョンデ) 일본 전시장 "모아서 알자! 현대 상식 헌트(豆知識ハント)" QR스탬프 이벤트.** 전시장 차량 근처에 숨겨진 QR을 스캔하면 차량별 **깨알 지식 미션**(CTA 열람 or O/X 퀴즈)이 뜨고, 미션을 클리어하면 스탬프가 찍힌다. **스탬프 5개**를 모으면 현장 INFO 데스크에서 경품(한정 굿즈)을 수령한다.
> **미션형(에듀테인먼트) 케이스** — 표준 스탬프 랠리에 **미션 화면(CTA/퀴즈)이 스탬프와 리워드 사이에 삽입**된 변형. 본인인증(휴대폰) 대신 **닉네임 입력**으로 참여를 시작한다.
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

- **아트보드**: 393 폭 · 세로 가변(시작/스탬프/리워드 **852** · 미션 830~896 · 퀴즈 875~878)
- **구성**: 본인인증 **없음**(닉네임 입력 대체) · **스탬프 5칸(2+3 배치)** · **미션 단계(CTA/O·X 퀴즈)** · **리워드 화면 있음**
- **폰트**: 전체 **Hyundai Sans** 브랜드 서체 — 헤드라인 `Hyundai Sans Head JP OTF`(Bold/Medium/Regular) / 본문 `Hyundai Sans Text JP OTF` (⚠️ **Pretendard 아님**, 현대 전용 서체)
- **언어**: 타이틀·CTA는 **일본어**(現地화), 본문 안내·미션·리워드 문구는 **한국어**(제작용 목업 상태 혼용)

## 전체 흐름

```
시작(닉네임) → 스탬프(5칸) → 미션(CTA/OX퀴즈, QR마다 15종) → 리워드      (본인인증 없음 · 미션 삽입형)
```

> ⚠️ 표준 4단계(시작→인증→스탬프→리워드)와 달리 **인증이 없고**, 스탬프와 리워드 사이에 **미션 단계**가 들어간다. QR 하나당 미션 1개(총 15개), 미션 클리어 → 스탬프 1칸 적립.

## 1️⃣ 시작 (Start · 닉네임) · `3399:16600`
- 상단 **현대 심볼(navy)** + 디스플레이 타이틀 **"集めて知って！ / ヒョンデ豆知識ハント"**(2줄, 네이비, Head OTF Regular 24 + Bold 28).
- 안내문(본문): **"부스 곳곳에 숨겨진 QR을 찾아 / 스탬프 모으고 경품을 획득하세요!"**
- **경품 미리보기 카드**(화이트 radius 12) — 경품 파우치 이미지 2점(살짝 회전 배치).
- **닉네임 입력** 블록: 라벨 "닉네임 입력 후 시작" + 인풋(placeholder "닉네임을 입력해 주세요") + "확인" 버튼(입력 전 opacity 40).
- 하단 CTA **"スタート"**(입력 완료 시 활성). Focused/Filled 상태로 인풋 포커스·입력값("john12")·"완료" 표시.

![[큐알스탬프 솔루션/attachments/hyundai-japan-start.png]]

## 2️⃣ 스탬프 (Stamp) — 현대 로고 코인 랠리 · `3399:16961`
- 상단 축소 심볼 + 타이틀 바.
- 헤더(3줄): **"john12 님 / N개의 스탬프를 더 모으고 / 리워드를 받으세요"** — 남은 개수 **N에 강조 블루 `#4191E3`** 적용.
  - Default: "5개…더 모으고" · 1done: "4개…더 모으고" · 5done: **"스탬프를 모두 모았어요! 리워드를 받으세요"** · RewardDone: **"축하합니다! 리워드 수령을 완료했어요"**.
- 서브: **"전시장 내 15개의 QR 중 5개를 스캔하세요!"** + 우상단 **? 도움말 아이콘**.
- CTA **"리워드 받기"**(5개 미충족 시 disabled=네이비 40% / 완료 시 active=네이비 / 수령 후 "리워드 수령 완료" 비활성).
- **스탬프 그리드**: 화이트 카드 안 **5칸** — 1행 2개 + 2행 3개(**2+3 비정형 배치**, `image 1/5` / `image 1/4/6`). 각 칸 **90×90 원형 코인**(그레이 배경 + 화이트 현대 심볼 + **레드 번호 1~5**) = **이미지 애셋**. 하단에 **차량 KV 이미지**(`20250422_INSTER-KV`, 캐스퍼/인스터 SUV) 풀블리드.
- `2-5.STAMP-Help` = 스탬프 화면 위 **"참여 방법" 오버레이**(반투명 딤 + 카드): ➊ 차량 근처 숨은 QR 찾기(*현대 닷컴 로그인 필수) ➋ 깨알 지식 읽고 미션 클리어해 스탬프 획득 ➌ 5개 획득 후 INFO에 리워드 화면 제시.

## 4️⃣ 리워드 (Reward) · `3405:17703`

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **미션 삽입형 4.5단계** — 표준(시작→인증→스탬프→리워드)에 **미션 단계**가 추가. QR마다 콘텐츠가 다른 **15종 미션**을 CTA(열람)형·O/X 퀴즈형 **2템플릿**으로 커버. 퀴즈는 Success/Error 분기 필요.
2. **본인인증 → 닉네임 입력 대체** — 휴대폰 인증 폼 없음. 시작 화면에서 **닉네임 1필드 + 확인**만으로 참여 시작(입력 전 CTA/확인 opacity 40 비활성).
3. **스탬프 = 브랜드 로고 코인** — 90×90 원형 코인(그레이 + 화이트 현대 심볼 + 레드 번호) 이미지 애셋. 적립 전/후는 opacity가 아닌 **별도 상태 애셋(before/after)**.
4. **2+3 비정형 배치** — 5칸을 1행 2개 + 2행 3개로 배치(짝수 그리드 아님). 하단 **차량 KV 이미지 풀블리드**로 브랜드 감성 강화.
5. **? 도움말 오버레이** — 스탬프 화면에 "참여 방법" 3스텝 오버레이(`2-5.STAMP-Help`)를 별도 상태 프레임으로 보관.
6. **리워드 = 콜라주 + 현장 수령** — 온라인 자동 지급이 아니라 **INFO 데스크 화면 제시**형. "버튼 누르지 말고 화면 제시" 경고 필수 + Done에서 **SNS 팔로우 유도**(2차 참여).
7. **폰트 = 현대 전용 서체** — 전체 **Hyundai Sans(Head/Text JP OTF)**. Pretendard 표준과 달리 **브랜드 서체 지정**이 핵심(자동 재현 시 폰트 치환 주의).
8. **일/한 혼용 목업** — 타이틀·CTA는 일본어(現地), 안내·미션·리워드 본문은 한국어 상태. 실서비스 시 전 문구 일본어화 전제.

## 🤖 디자인 자동화 재현 포인트

- **테마색**: 메인 네이비 `#0E2B5C` · 강조 블루 `#4191E3`(헤더 남은개수 숫자) · 배경 `#F5F5F5` · 본문 `#1E1E1E` · 버튼 disabled = 네이비 opacity 40%.
- **폰트**: 전체 **Hyundai Sans Head/Text JP OTF** (헤드라인 Head Bold/Medium, 본문 Text Regular). ⚠️ Pretendard 아님 — 현대 전용 서체 로드 필요.
- **스탬프**: **5칸** · **2+3 비정형 배치** · **현대 로고 코인 모티프**(그레이 코인+화이트 심볼+레드 번호, 90×90) · before/after 별도 애셋.
- **단계 구조**: 시작(닉네임) → 스탬프(5) → **미션(CTA형/OX퀴즈형, QR당 15종)** → 리워드. **본인인증 없음 · 미션 단계 삽입 · 리워드 화면 있음**.
- **특이사항**:
  - 인증 대신 **닉네임 입력** 시작.
  - **미션 화면 2템플릿**(CTA 열람 / O·X 퀴즈+정답·오답 분기)을 QR별로 재사용.
  - 스탬프 화면 **? 참여방법 오버레이** 별도 상태.
  - 리워드는 **현장 INFO 수령형**("화면 제시" 경고) + Done에서 **SNS 4종 팔로우 유도**.
  - 하단 **차량 KV 이미지**로 브랜드 몰입 강화.
  - 캔버스에 화면 세트가 **메인/백업 2줄** 중복 배치(편집 시 두 줄 동기화 유의 또는 메인만 사용).
