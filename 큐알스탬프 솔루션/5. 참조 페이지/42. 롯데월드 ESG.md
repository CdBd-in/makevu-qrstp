# 🎮 참조 이벤트 — 롯데월드 ESG (탄소중립 QR스탬프투어 · SAVE THE LOTTE WORLD)

> **롯데월드 ESG(탄소중립) 캠페인 "탄소중립 QR스탬프투어".** 픽셀/레트로 게임(8비트 RPG) 컨셉으로, 방문객이 "매직에코 요원"이 되어 파크 곳곳의 **그린 미션 지점 3곳**에서 QR을 스캔해 스탬프를 모으고, **탄소중립 실천 퀴즈(3문항)** 를 풀고 **설문(4문항)** 에 응답한 뒤 **리워드(기프트)** 를 받는다.
> **픽셀 게임형 케이스** — 표준 QR스탬프 UI가 아니라 **8비트 도트 그래픽 + 둥근모(DungGeunMo) 픽셀 폰트**로 전면 리스킨. 화면 텍스트(타이틀·퀴즈문항·답안·리워드 안내)는 대부분 **배경/이미지 애셋에 구워져(baked)** 있고, 앱 UI 텍스트 노드는 CTA("시작하기/제출하기") 정도만 존재.
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

## 1️⃣ 시작 (Start) · `3399:9741`
- 픽셀 디스플레이 타이틀 **"탄소중립 QR스탬프투어"**(골드/화이트 도트) + 서브 **"SAVE THE LOTTE WORLD"**.
- 중앙: 그레이스케일 **롯데월드 파크 지도(도트)**.
- 하단 안내(픽셀 캐릭터 아이콘 + 크림 말풍선): **"매직에코 요원이 되어 그린미션을 해결하고 어드벤처를 구해주세요."**
- CTA: 픽셀 라임/그린 버튼 **"시작하기"**(DungGeunMo 20px · 블랙).

## 2️⃣ 스탬프 (Stamp) — GREEN MISSON MAP · 지도 위 위치 배치
- 헤더: **"GREEN MISSON MAP / SAVE THE LOTTE WORLD"** + 우상단 카운터 **`스탬프 0/3`**(골드, 현재수 화이트).
- **3칸 · 격자❌ 지도 배치** — 각 스탬프(85×85 픽셀 씰)를 파크 지도상의 실제 위치에 흩어 배치:
  - **STAMP1** — `롯데트레인 탑승구 오른쪽 벽면`
  - **STAMP2** — `후룸라이드 입구 왼쪽 아래`
  - **STAMP3** — `야간꽃길 트리`(트리 왼쪽 안내도)
  - 각 지점에 **레드 픽셀 마커 박스(120×120 테두리)** + 지시선 + 위치 라벨.
- 상태 진행: Default(0/3) → 1done(-1/-2/-3 = 어느 스탬프를 먼저 찍었는지 3분기) → 2done → 3done → RewardDone.
- 스탬프 = **before/done 2벌 이미지 애셋**(opacity가 아닌 별도 컬러/그레이 씰). `STAMPn-before`(회색) ↔ `STAMPn-done`(컬러).

## 3️⃣ 퀴즈 (Quiz) — 탄소중립 실천 QUIZ · 3문항

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **픽셀/레트로 게임 전면 리스킨** — 표준 QRSTP DS UI를 쓰지 않고 8비트 도트 그래픽 + **둥근모(DungGeunMo)** 폰트로 완전 재도색. 리테마가 아니라 **아트 디렉션 자체가 별개**. 재현 시 폰트를 반드시 DungGeunMo로 지정(Pretendard 금지).
2. **콘텐츠 대부분이 이미지에 baked** — 타이틀·퀴즈 문항/보기·설문 문항·리워드 문구가 텍스트 노드가 아니라 **배경/카드 이미지**로 고정. 수정 = 텍스트 편집이 아니라 **이미지 재생성**. 노출 텍스트 노드는 CTA(시작하기/제출하기)·카운터(`스탬프 0/3`) 정도.
3. **스탬프 = 지도 위 위치 배치(3칸)** — 격자가 아니라 파크 지도 좌표에 흩어 배치 + 레드 픽셀 마커·지시선·위치 라벨(롯데트레인/후룸라이드/야간꽃길). 스탬프는 before(그레이)/done(컬러) 2벌 이미지.
4. **인증 없음 · 4단계 초과 확장** — LOGIN 프레임 부재. 대신 **퀴즈(3문항, 정답/오답 분기)+설문(4문항)** 단계가 스탬프와 리워드 사이에 삽입된 인터랙티브 확장형(총 5단계군).
5. **퀴즈 상태 분기 다수** — 각 퀴즈마다 Default → Filled-O/X → 결과 O/X 로 6+상태, 스탬프도 1done을 3분기(-1/-2/-3)로 관리. 프레임 수가 많음(원본+검수 복제 2행).
6. **색 토큰 부재** — `get_variable_defs` `{}`. 강조색은 사실상 카운터/타이틀의 **골드 `#EDD28A`** 단색. 리테마는 이미지 팔레트 교체가 핵심.

## 🤖 디자인 자동화 재현 포인트
