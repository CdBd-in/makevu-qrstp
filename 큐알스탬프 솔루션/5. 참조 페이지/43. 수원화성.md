# 🏯 참조 이벤트 — 수원화성 어드벤처 '7개의 보물' (Suwon Hwaseong)

> **수원화성 일대 스토리텔링형 보물찾기 QR스탬프 이벤트.** 정조대왕이 내린 "밀지"를 풀어 화성 안 **일곱 장소**를 찾아가고, 각 장소에서 QR을 스캔하면 보물 확보 증표(스탬프)가 찍힌다. **스탬프 7개**를 모두 모으면 **룰렛**을 돌려 등수별 리워드(1~7등)를 받는다.
> **가장 복합적인 변형 케이스** — 표준 시작→인증→스탬프→리워드에 더해 **언어선택 · 미션 팝업(스탬프별 7개) · 룰렛 · 미션완료 · 다등급 리워드(6종)** 가 결합된 사극/보물찾기 테마. 폰트도 Pretendard가 아니라 **전통 서예/명조 계열 3종**을 쓴다.
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

## 전체 흐름

```
언어선택 → 시작(미션 안내) → 본인인증(2) → 스탬프(7칸) ⇄ 미션 팝업(7)
        → 미션완료 → 룰렛 → 리워드(6등급 Default/Done)
```

> 표준 4단계를 크게 확장한 **스토리텔링 + 게임형** 구조. 스탬프 화면에서 각 칸을 누르면 해당 장소의 **미션 팝업**이 뜨고, 7개 완주 후 **룰렛**으로 등수를 정해 등급별 리워드로 분기한다.

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **표준 4단계를 넘어선 복합 게임 플로우** — 언어선택·미션 팝업(7)·룰렛·다등급 리워드가 추가된 **스토리텔링 보물찾기**. 스탬프 탭 → 미션 모달 → 완주 → 룰렛 → 등급 분기 리워드.
2. **폰트가 Pretendard가 아님(테마 서체 3종)** — 헤드라인 **수성혜정**, 버튼 **단조(Danjo-bold)**, 본문 **조선일보명조(Chosun Centennial)**. 사극/고문서 컨셉에 맞춘 전용 서체 조합. (리테마 시 서체 치환 주의)
3. **고문서(한지) 텍스처 배경 + 반투명 화이트 카드** — 전 화면 공통 `BG Texture 1`(베이지 파치먼트, rotate 90) 위에 `rgba(255,255,255,0.3)` 카드로 가독성.
4. **스탬프 = 장소별 먹선 인장 이미지 7종** — 4~16칸 정형이 아니라 7개(2열), 각 칸이 칼/보물상자/마패 등 **개별 브러시 모티프 이미지**(before/after 2벌). 텍스트가 아닌 이미지 교체 방식.
5. **룰렛으로 리워드 등급 결정** — 완주 보상이 단일이 아니라 **1~7등 룰렛 추첨**으로 6등급 리워드 화면(Default/Done)에 분기. 리워드 프레임 수가 많다(12장).
6. **다국어 병렬 세트(KOR/ENG)** — 같은 플로우를 한국어·영어 두 벌로 제작. 언어선택 화면이 진입점.
7. **강조 색 유지 규칙** — 헤더 남은 개수 숫자·소제목("기간/장소/등수")은 `#AC111F`. 텍스트 편집 시 강조색 초기화 주의(공용 규칙).

- **단계 구조**: 언어선택 → 시작(미션 안내·경품/기간/장소) → 본인인증 → 스탬프 ⇄ 미션 팝업(7) → 미션완료 → 룰렛(1~7등) → 리워드(6등급 Default/Done).
- **특이사항**:
  - 스토리텔링(정조대왕 밀지) 사극 컨셉 + 전용 서체 3종.
  - 스탬프 탭 시 **미션 모달 7종** 오버레이(딤+Close).
  - 완주 보상은 **룰렛 추첨 → 등급 분기 리워드**(6등급 × Default/Done = 12프레임).
  - **KOR/ENG 다국어** 병렬 세트, 언어선택이 진입.
  - 수령 규칙: 스탬프 4개 = 스탬프 페이지 제시 / 7개 = 룰렛 페이지 제시(행궁광장 운영부스).
