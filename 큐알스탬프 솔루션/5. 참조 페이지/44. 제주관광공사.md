# 🌊 참조 이벤트 — 제주관광공사 (제주에 스며드는 시간 Slow & Flow)

> **제주관광공사 "2025 가을시즌 제주여행주간 — 제주에 스며드는 시간 Slow & Flow" 스탬프 투어.** 공항·참여 기업에서 QR을 스캔해 제주 지역(공항·제주시·애월·중문·조천) 스탬프를 모으면, **룰렛을 돌려 제주관광공사 중문면세점 이용권(1·2·3만원권)** 을 받는다.
> **룰렛(추첨) 변형 케이스** — 표준 4단계(시작→인증→스탬프→리워드) 사이에 **룰렛 화면(4단계)** 이 삽입되어, 스탬프 완주 후 룰렛으로 리워드 금액이 결정되는 구조다.

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **룰렛(추첨) 단계 삽입 = 5단계** — 시작→인증→스탬프→**룰렛**→리워드. 스탬프 완주가 곧 리워드가 아니라, 완주 후 룰렛으로 리워드 금액(1/2/3만원권)을 추첨한다. 룰렛 결과에 따라 **리워드 화면이 3버전**으로 분기.
2. **스탬프 = 지역 스팟 씰(별도 SVG variant)** — 공항·제주시·애월·중문·조천 5개 제주 명소를 130×130 원형 씰로. 적립 전/후를 opacity가 아닌 **Active/Disable 컴포넌트 세트 교체**로 표현.
3. **헤드라인 폰트 = tvN Enjoystories OTF** — 국문 디스플레이(룰렛 타이틀 52 / "축하합니다!" 80). ⚠️ **Pretendard 아님**. 본문·버튼만 Pretendard, 스탬프 헤더·쿠폰 숫자는 SB AggroOTF.
4. **웜 브라운 단색 테마 + 제주 풍경 사진 배경** — `#A07E63` 버튼/강조 + 사진 위 다크 그라데이션(180deg + 좌우 0.6 알파)으로 화이트 헤드라인 가독성 확보.
5. **남은 개수 강조는 레드 `#C40D23`** — 헤더 "N개의 스탬프를 더 모으고"의 숫자 N만 레드. 텍스트 교체 시 강조 색이 초기화되므로 재적용 필요.
6. **시작 화면 = 긴 세로 스크롤 랜딩(2039)** — 로고/타이틀/기간/티켓 일러스트/스탬프 위치 안내/리워드 등급/유의사항까지 포함한 종합 랜딩. (다른 프레임은 843 고정)
