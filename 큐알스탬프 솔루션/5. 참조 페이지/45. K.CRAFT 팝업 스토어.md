# 🏮 참조 이벤트 — K.CRAFT 팝업 스토어 (K.CRAFT Pop-up Store)

> **'더 공예, 더 현대' K.CRAFT 팝업 스토어 QR스탬프 이벤트.** 단일 QR 랠리가 아니라 **4개의 서로 다른 미션(구매 인증샷 · 퀴즈 맞히기 · SNS 업로드 · +1)** 을 완료해 스탬프를 채우는 **멀티 미션형** 케이스. 특히 **"퀴즈 맞히기" 미션은 별도 퀴즈미션 페이지(빈칸 채우기 + 힌트 + 정오답 판정)** 로 구성된 것이 최대 특징.
> **한국 전통(민화·단청) 테마 케이스** — 시작/리워드 배경에 학·소나무·산수 민화 일러스트, 적립 스탬프는 **단청 화문(꽃 문양) 메달리온** 모티프.
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.


## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **멀티 미션형 스탬프** — 스탬프 4칸이 동일한 "QR 스캔"이 아니라 **각기 다른 미션(구매 인증샷 · 퀴즈 맞히기 · SNS 업로드 · +1)**. 미적립 칸에 **미션명 텍스트**가 들어가고, 적립되면 **공통 문양 이미지**로 덮인다.
2. **퀴즈 서브플로우 내장** — "퀴즈 맞히기" 미션은 **별도 퀴즈미션 페이지**(빈칸 채우기 + 글자수 카운터 + 힌트 팝업 + 정/오답 Filling/Filled 상태)로 구현. 스탬프가 단순 상태 토글이 아니라 **인터랙티브 미션**을 가진 드문 케이스.
3. **적립 스탬프 = 단청 화문 메달리온 이미지** — before(연보라 톱니 원+미션명) / after(컬러 단청 문양) **2벌 이미지 교체** 방식. 텍스트 노드가 아니므로 문양 변경 시 이미지 교체.
4. **이미지 굳힘형 배경** — 시작·리워드 화면 안내문 상당수가 **배경 이미지(START-BG / REWARD-BG)에 포함**. 문구 수정 시 텍스트 편집이 아닌 이미지 재작업 필요.
5. **차등 리워드 수령 규칙** — 리워드가 단일이 아니라 **스탬프 3개=구매 시 증정 / 2개=행사장 출구**로 개수별 차등. 리워드 화면에 수령 조건표를 명시.
6. **테마 = 딥 퍼플 `#4C458E` + 옐로 액션 + 전통 민화** — 메인 UI는 퍼플, 퀴즈 제출 등 강한 액션은 옐로, 브랜드 정체성은 학·소나무·단청 민화 일러스트로 표현.

## 🤖 디자인 자동화 재현 포인트

- **테마색**: 메인 딥 퍼플 **`#4C458E`**(CTA·헤더 버튼) · 강조 블루 **`#4B73FF`**(남은 개수 숫자) · 퀴즈 액션 **옐로(≈`#FFE600`)** · 본문 블랙 `#212529` · 버튼 텍스트 화이트.
- **폰트**: 전체 **Pretendard**(헤드라인/본문 SemiBold 28/44, 버튼 SemiBold 20/26) — 별도 영문 헤드라인 폰트 없음.
- **스탬프**: **4칸 · 2×2 그리드**(120×120, 컨테이너 295×308, 세로/가로 격자선). before=연보라 톱니 원+미션명 텍스트, after=**단청 화문 메달리온 컬러 이미지**로 교체.
- **미션 라벨(칸 콘텐츠)**: 구매 인증샷 · 퀴즈 맞히기 · SNS 업로드 · (+1). → **동일 QR 스탬프가 아닌 미션별 칸**임을 반드시 반영.
- **단계 구조**: 시작 → 본인인증(Default/Filled) → 스탬프(Default/1Done/AllDone/RewardDone) → **퀴즈 서브플로우(Default/Focus/Right·Wrong Filling·Filled/Hint)** → 리워드(Default/Done). 표준 4단계 + 퀴즈 미션 서브플로우.
- **퀴즈 컴포넌트**: 빈칸(□) 문제 + 입력필드 + 글자수 카운터(`0/5자`↔`5/5자`) + Clear(×) + "힌트 다시보기" → 힌트 팝업 + 옐로 "입력 완료" 버튼 + 정/오답 상태 4종.
- **리워드**: 단청 그립톡/그립 랜덤 제공 · **개수 차등 수령(3개=구매 시 / 2개=행사장 출구)** — 수령 조건표를 화면에 명시.
- **특이사항**: ①시작/리워드 안내문이 배경 이미지에 굳어 있음(텍스트 편집 불가) ②적립 스탬프 문양은 이미지 교체(before/after 2벌) ③퀴즈 정답 예시 "디자인 협업", 오답 예시 "더현대팝업" ④페이지에 y≈15654 재배치 복제본 행이 있으니 원본(y≈12957~14114) 기준으로 참조.
