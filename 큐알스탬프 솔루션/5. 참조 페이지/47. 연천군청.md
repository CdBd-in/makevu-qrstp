# 🌱 참조 이벤트 — 연천군청 (관광술래 · 2025 연천군 관광지 스탬프 투어)

> **연천군 "관광술래" QR스탬프 투어.** 연천군 관광지 13곳을 돌며 각 장소의 QR을 스캔하면 스탬프가 적립되고, **5개 적립 → 1차 리워드(주먹도끼 비누)**, **10개 적립 → 2차 리워드(마그넷+키링)** 를 받는 **2단 리워드(마일스톤형)** 이벤트다.

## 3️⃣ 스탬프 (Stamp) — 관광 캐릭터 씰 · `2998:1183`
- 헤더: `홍길동님` + 진행 문구(상태별 변동):
  - Default: **"5개의 스탬프를 더 모으고 다음 리워드를 받으세요"**
  - 3done: **"2개의 스탬프를 더 모으고 다음 리워드를 받으세요"**
  - 5done: **"5개의 스탬프를 더 모으고 다음 리워드를 받으세요"** (10개까지 5개 남음)
  - 10done: **"스탬프를 모두 모았어요! 리워드를 받으세요"**
  - AllDone: **"축하드려요! 모든 리워드를 받았어요"**
- 헤더 아래 **리워드 CTA 버튼 2개**: `5개 적립 리워드 받기` / `10개 적립 리워드 받기` — 미달성=비활성, 달성=활성, 수령 후=**"N개 적립 리워드 수령 완료"**.
- **스탬프 그리드**: 컨테이너 292폭 · **2열** · 각 칸 **130×130** · gap 32 · 총 **13개**(홀수라 마지막 1개 단독 행).
  - 각 칸 = **점선 원 안에 이젠연천 새싹 캐릭터** + 하단 **관광지명**(01-재인폭포, 02-호로고루 … 13-태풍전망대).
  - 미적립(before) = 점선 테두리 + 흐린 캐릭터 / 적립(after) = **딥그린 채움 원 + 캐릭터 + "적립완료"** 라벨.
  - 각 스탬프는 **관광지별 이미지 애셋**(`NN-관광지명-before` / `-after`), 번호+지명이 씰에 포함.
- 상태 진행: Default(0) → 3done → 5done → Reward1-done → 10done → Reward2-done → AllDone.

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **2단 리워드(마일스톤형)** — 5개/10개 두 구간에서 각각 리워드를 지급. 스탬프 화면에 **리워드 CTA 2개**를 두고, 적립 개수·수령 상태에 따라 **7단계 스탬프 상태**(Default/3done/5done/Reward1-done/10done/Reward2-done/AllDone)로 세분화. (단일 리워드 케이스와 대비되는 핵심 차이)
2. **인증 방법 선택 분기** — 휴대폰/이메일 중 택1. `2-0` 방법선택 → `2-1`(휴대폰) 또는 `2-2`(이메일) 폼으로 분기(각 Default/Filled).
3. **스탬프 = 지자체 관광 캐릭터 씰** — 이젠연천 새싹 마스코트를 관광지 13곳에 재활용(번호+지명 라벨). 미적립=점선원+흐린 캐릭터, 적립=딥그린 채움원+"적립완료". before/after 2벌 이미지.
4. **13칸(홀수) 2열 그리드** — 마지막 1칸이 단독 행. 정형 짝수 칸이 아닌 관광지 수 기준.
5. **헤드라인 폰트 = Jalnan 2(잘난체)** — Pretendard가 아닌 여기어때 잘난체를 타이틀/헤드라인에 사용(관광·친근 톤). 본문만 Pretendard. ⚠️ 표준 템플릿(전체 Pretendard)과 다르므로 리테마 시 주의.
6. **밝은 파스텔 배경 + 딥그린 텍스트** — 배경 `#CFFEC6`가 밝으므로 CTA·타이틀은 딥그린(`#10441A`/`#0F6D21`)으로 대비 확보. (밝은 배경 위 흰 텍스트 지양)
7. **정본 vs 작업사본** — 같은 캔버스에 `3054:*` 이전 사본이 별도 존재. 재현 기준은 y=19271의 `2990/2998/3002/3065` 정본 계열.

- **단계 구조**: 시작 → 인증(방법선택→휴대폰/이메일) → 스탬프(7상태) → **리워드 2단(5개/10개 별도 화면 + 각 Default/Done)**. 표준 4단계 + 마일스톤 리워드 확장.
- **특이사항**:
  - **2단 리워드**가 최대 특징 — 스탬프 헤더 문구·CTA·상태가 5/10 두 마일스톤에 맞춰 변동.
  - 본인인증 **방법선택 분기**(휴대폰/이메일).
  - 헤드라인 **Jalnan 2** 사용, "관광술래" 타이틀에 offset 그림자(`4px 5px #75BC4A`).
  - 시작 화면에 **리워드 실물 이미지 카드 2종 + 유의사항 + 수령처**를 모두 노출(정보 밀도 높음).
  - 리워드 수령처·기한: **연천역/전곡역 관광안내소**, **~2025.12.31**. **만족도 조사 후 수령** 조건 명시.
