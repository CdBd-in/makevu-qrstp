# ⛳ 참조 이벤트 — 제주삼다수 마스터스 스탬프 투어 (Jeju Samdasoo Masters Stamp Tour)

> **제주삼다수 마스터스(골프대회) 관람객 대상 "스탬프 투어" QR스탬프 이벤트.** 대회 코스를 따라 각 스테이션(갤러리 플라자·1H TEE·10H TEE·15H 클링 스테이션·18H GREEN)에서 QR을 스캔하면 스탬프가 찍히고, **스탬프 5개**를 모으는 과정에서 **2단계 리워드**(3개 달성 → 썬젤패치 / 5개 달성 → 스크래치 복권)를 받는다.
> **다단계 리워드(멀티 리워드) 케이스** — 하나의 스탬프판(5칸)에서 **적립 개수별로 서로 다른 리워드를 여러 번** 지급하는 구조. 리워드 신청 버튼이 스탬프 화면에 상시 노출되고, 개수 조건 충족 시 활성화된다.
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

## 전체 흐름

```
시작 → 본인인증(2) → 스탬프(5칸·다단계) → 리워드(2종 각 Default/Done + 수령 모달)
                                            (본인인증 있음 · 리워드 화면 있음 · 멀티리워드)
```

> 표준 4단계이되 **리워드가 2종(3개용/5개용)** 으로 갈라지고, 각 리워드마다 **Default(수령 전) / Done(수령 완료)** 2상태 + **현장 관리자 비밀번호로 수령 완료 처리하는 모달** 플로우가 붙는다. 스탬프 화면도 적립 개수·리워드 수령 여부에 따라 6상태로 세분된다.

## 1️⃣ 시작 (Start) · `2953:95`
- 상단 **제주삼다수 마스터스 로고** + 디스플레이 타이틀 **"스탬프 투어"**(도장 아이콘 모티프) — 시작 화면 전체가 라이트 블루 배경 이미지.
- 안내문: **"대회 코스를 따라 / 각 스테이션에서 QR코드를 촬영하고 / 스탬프를 모으면 선물을 드려요!"**
- **2단계 리워드 미리보기 카드**(원형 이미지 2개):
  - **썬젤패치** — "스탬프 3개 달성 시"
  - **스크래치 복권** — "스탬프 5개 달성 시"
- **유의사항 리스트**(회색 소문자): "· 중복 및 부정참여 확인 시 선물 지급이 취소될 수 있습니다. / · 동일 인증 건으로 중복 참여가 불가합니다. / · 이미 스캔한 QR코드도 중복 적립이 불가합니다. / · 선물은 당일 수령하셔야 하며, 미수령시 취소됩니다. / · 경품 재고 소진 시 사전 예고 없이 다른 경품으로 대체될 수 있습니다."
- 하단 블루 CTA **"시작하기"**.

## 2️⃣ 본인인증 (Login) · `2953:202` / `2953:221`
- 헤드라인 **"휴대폰번호 인증 한 번으로 이벤트에 참여하세요"**.
- DS 폼 그대로: `이름`(Field_Name) / `휴대폰번호`(Field_Phone) / `인증번호`(Field_Verification) + 필수 동의 체크박스 2종(개인정보 수집·이용 / 처리업무 위탁, 각 "자세히").
- CTA **"시작하기"** — Default(비활성) ↔ Filled(활성).

## 3️⃣ 스탬프 (Stamp) — 골프 코스 스테이션 스탬프
- 헤더(3줄, 남은 개수만 변동): **"홍길동님, / [N]개의 스탬프를 더 모으고 / 다음 리워드를 받으세요"** — 강조 숫자 **`#4B73FF`**.
  - 완료 문구: **"홍길동님, 스탬프를 모두 모았어요! 리워드를 신청하세요"** (`3-5`), **"홍길동님, 축하드려요! 모든 리워드를 신청했어요"** (`3-6`).
- 헤더 아래 **상시 리워드 신청 버튼 2개**: **"3개 적립 리워드 받기"** / **"5개 적립 리워드 받기"**.
  - 미충족 시 **opacity 40%(비활성)**, 개수 조건 충족 시 활성(블루). 수령 완료 후 텍스트가 **"N개 적립 리워드 수령 완료"** 로 바뀜.
- **스탬프 그리드**: 컨테이너 폭 307 · **2열 × 3행(마지막 행 1칸) = 5칸** · 각 칸 **130×130 원형 씰** · 칸 사이 세로선(Line 2/9/10) + 행 사이 가로선(Line 5/7)으로 격자 표현.
  - 각 씰 = **번호(1~5) + 스테이션명** 이미지 애셋. 스테이션: **1 갤러리 플라자 · 2 1H TEE · 3 10H TEE · 4 15H 클링 스테이션 · 5 18H GREEN**.
  - 미적립 = `stamp_empty`(그레이), 적립 = `stamp_KR`(블루 번호). **텍스트 노드가 아니라 이미지 애셋 교체**(before/after 2벌).
- 상태 진행: Default(0/5) → 1/5 → 3/5(리워드1 조건 충족) → Reward1 Done → 5/5(리워드2 조건 충족) → Reward1&2 Done.

## 4️⃣ 리워드 (Reward) — 2종 다단계 · `2955:2026` 외
- **리워드1(3개 달성 = 썬젤패치)** · **리워드2(5개 달성 = 스크래치 복권)** 각각 전용 화면. 화면 전체가 통이미지 배경(`REWARD1 3`) + 우상단 **Close Icon**(모달 형태).
- 타이틀 **"축하합니다!"** + **"스탬프 3개 달성완료!"**(또는 5개) + 리워드 원형 이미지 + 리워드명("썬젤패치 / 스탬프 3개 달성 완료!").
- **기프트 수령처 안내**: **"기프트 수령처 ▶ 갤러리 플라자 인포부스"** + 유의사항(당일 수령·미수령시 취소 등).
- CTA 2개: 세컨더리 **"선물 수령처 위치 보기"**(블랙 버튼) / 프라이머리 **"리워드 받기"**(블루).
  - **Done 상태**: 프라이머리 버튼이 **"리워드 수령 완료"**(비활성)로 변경. 나머지 100% 동일.
- **수령 처리 플로우**(주석 노드로 명시): 리워드 모달에서 **현장 관리자 비밀번호를 입력하여 수령 완료 처리** → 버튼 텍스트가 `리워드 받기`→`리워드 수령 완료`로 전환. 모달 OFF만 하고 미완료 시 버튼은 `리워드 받기` 유지.

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **다단계(멀티) 리워드 = 개수 임계값별 지급** — 단일 리워드가 아니라 **3개/5개** 두 임계값에 각각 다른 경품. 스탬프 화면에 **리워드 신청 버튼 2개**를 상시 배치하고 opacity 40%↔활성으로 조건 표현. 리워드 화면도 리워드 수만큼(2종 × Default/Done = 4프레임) 필요.
2. **스탬프 상태 = 6단계로 세분** — 적립 개수뿐 아니라 **리워드 수령 여부**까지 상태에 반영(3/5 → Reward1 Done → 5/5 → Reward1&2 Done). 헤더 문구·버튼 텍스트가 상태별로 달라짐.
3. **현장 수령 = 관리자 비밀번호 모달** — 리워드 수령을 **현장 관리자 비밀번호 입력**으로 확정 처리. Default↔Done 전환은 이 모달 결과에 연동(주석 화살표로 상태 전이 명시).
4. **시작·리워드 = 통이미지 배경** — 시작/리워드 화면은 배경 아트가 하나의 이미지로 굳어 있고(`START 2` / `REWARD1 3`), 그 위에 버튼·Close Icon만 라이브 노드로 올림. → 재현 시 **배경 이미지 교체 + 버튼 위치만 유지**.
5. **스탬프 = 번호+스테이션명 원형 씰 이미지** — 골프 코스 스테이션(갤러리 플라자·1H/10H TEE·15H 클링·18H GREEN)을 번호 씰에 이미지로 고정. 스테이션 변경 시 이미지 교체.
6. **강조 카운트 색 분리** — 헤더 "N개" 숫자는 메인 블루(`#0C6EB4`)가 아니라 **`#4B73FF`**. ⚠️ 텍스트 교체 시 강조 색이 초기화되므로 숫자 수정 후 다시 입힐 것.
7. **정본 vs 복제 열** — 캔버스에 정본(상단)과 QA 복제(하단) 2벌 존재. 수정은 정본 열(y≈13665) 기준.
