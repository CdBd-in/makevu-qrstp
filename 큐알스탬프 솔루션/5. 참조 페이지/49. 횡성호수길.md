# 🗺️ 참조 이벤트 — 횡성호수길 (Hoengseong Lakeside Trail 호수요정 스탬프투어)

> **제6회 횡성호수길 호수축제 "호수요정 QR스탬프투어".** 횡성호수길 코스를 걸으며 각 지점에서 QR을 스캔하면 **호수요정 캐릭터 스탬프 5개**가 지도 위에 하나씩 찍히고, 5마리를 모두 모으면 리워드(횡성 한우 등)를 받는다.
> **지도(map) 배치형 스탬프 케이스** — 4~16칸 격자가 아니라 **횡성호수길 실제 지형 지도 이미지 위에 5개 지점(호수요정)을 흩뿌려 배치**한 콜라주형. 각 스탬프 = 코스 지점의 명소 사진 + 호수요정 캐릭터가 든 메달(리본) 씰.
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

- **Figma**: `QR 스탬프` · fileKey `n8YIkPdm2svezJYjePHn1u` · 페이지 `횡성호수길` (`2692:1292`)
- **아트보드**: 393 × 772 (전 화면 고정 높이)
- **구성**: 본인인증 **있음** · **스탬프 5칸(지도 위 산개 배치)** · **리워드 화면 있음(모달형)** · 리워드 소진 상태 포함
- **폰트**: 폼/본문 **Pretendard** · 타이틀("QR스탬프투어" 등)은 **라운드 디스플레이 서체를 이미지로 고정**(배경 일러스트에 포함)

## 1️⃣ 시작 (Start) · `2692:2703`
- 화면 전체가 **단일 일러스트 이미지**(`START` 이미지 애셋) — 지도·물결·캐릭터·타이틀이 하나의 배경으로 렌더.
- 상단: 물결 헤더 + **"제6회 횡성호수길 호수축제"** / **"횡성호수길 호수요정"** / 라운드 타이틀 **"QR스탬프투어"**(그린 외곽선).
- 안내문: **"맑은 공기 마시며 건강도 챙기고, 숨어있는 5명의 호수요정도 찾아보세요!"**
- 하단 안내: **"약 3시간의 힐링 트레킹 코스, QR코드 스캔하고 스탬프 모으면 선물까지 쏙~! 걷고 찾고 즐기고! 건강한 하루를 선물하세요!"**
- 하단 딥블루 CTA **"시작하기"** (`시작하기 1` 이미지 버튼, 30/60 여백 · 333×43).

## 3️⃣ 스탬프 (Stamp) — 지도 위 호수요정 씰 랠리
- **배경 = 횡성호수길 지형 지도**(`STAMP` 이미지). 스탬프판이 곧 지도.
- **5개 스탬프를 지도의 실제 지점 위치에 산개 배치**(격자 아님):
  - `Frame 127` 구방이 (65, 601) / `Frame 128` 부동이 (84, 234) / `Frame 129` 중금이 (18, 371) / `Frame 130` 포동이 (216, 559) / `Frame 131` 화전이 (280, 453). 각 **86×110** 씰.
  - 각 씰 = **원형 명소 사진 + 골드 메달 리본 + 호수요정 캐릭터** 콜라주. 지점명 라벨(예: `부동교`, `망향의동산`, `사방댐`)이 지도상에 함께 표기.
  - 적립 전 `N-before`(저채도) / 적립 후 `N-after`(컬러+골드+요정) 두 벌 이미지 애셋으로 교체.
- 상단 고정 **"리워드 받기"** 버튼(333×43) — 완주 전까지 비활성(투명도 40%), 완주 시 활성(딥블루). 완주 시 강조 하이라이트(`Rectangle 44` 356×65).
- **상태 전환**(같은 화면):
  - `Default`(0/5) → `Collecting`(1/5 적립, 예: 중금이-after만 컬러) → `Done`(5/5 전부 after) → `Reward Received`(수령 완료, 버튼 "리워드 수령 완료") → `Reward Over`(리워드 소진, 버튼 "리워드 소진" 비활성+색·텍스트 변경).

## 4️⃣ 리워드 (Reward · 모달) · `2692:2853` / `2692:2877`
- 스탬프 화면 위에 뜨는 **모달 프레임**(우상단 `Close Icon` 있음).
- 타이틀 **"축하합니다!"** + 안내문 **"호수요정 5명을 모두 찾았어요! 건강도 얻고, 선물도 받고!"**
- 리워드 이미지: **횡성 특산 한우(거사리 한우 등) 패키지 일러스트**(중앙 카드).
- 수령 안내: **"스탬프투어 종점 수령처에서 화면을 보여주세요"**.
- 하단 CTA: **"리워드 받기"** → 수령 후 `REWARD-Received`에서 **"리워드 수령 완료"**(비활성)로 전환.
- **리워드 수량 제한**: 일 500개 소진 시 스탬프 화면 CTA가 **"리워드 소진"** 상태로 바뀜(`5. STAMP-Reward Over`).

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **지도 배치형 스탬프** — 스탬프를 격자가 아니라 **실제 코스 지도 이미지 위 지점 좌표에 절대 배치**. 각 스탬프 프레임을 지형에 맞춰 x/y 수동 위치(구방이~화전이 5좌표 고정).
2. **캐릭터 IP 기반 스탬프** — 5개 스탬프 = **호수요정 마스코트 5종** + 명소 사진 콜라주. 애셋 이름이 곧 캐릭터/지점명(`구방이/부동이/중금이/포동이/화전이`). before/after 2벌.
3. **타이틀·시작화면은 통짜 이미지** — 시작 화면과 타이틀 서체("QR스탬프투어" 라운드 디스플레이)가 **일러스트 이미지로 고정**. 텍스트 재편집 불가 → 문구 변경 시 이미지 재작업 필요(폼/본문만 Pretendard 라이브 텍스트).
4. **단일 스탬프 화면 다상태** — 별도 프레임 아니라 한 STAMP 화면에서 Default→Collecting→Done→RewardReceived→RewardOver 5상태. **리워드는 모달**(REWARD 프레임)로 오버레이.
5. **리워드 수량 소진 상태 별도 관리** — 일 500개 한정 → "리워드 소진" 버튼 상태(색·텍스트 변경, 비활성)를 명시적으로 디자인. (경품 한정 이벤트의 필수 상태)
6. **테마 = 호수축제 청량 팔레트** — 딥블루 `#01408F`(CTA) + 스카이블루 `#7AC1ED`(브랜드/배경) + 그린 `#B2ED9D`(자연) + 골드 `#FFB913`(메달). 물+자연+트레킹 컨셉.

## 🤖 디자인 자동화 재현 포인트

- **테마색**: CTA/버튼 `#01408F`(딥블루) · 배경/브랜드 `#7AC1ED`(스카이블루) · 포인트 `#B2ED9D`(그린) · 스탬프 메달 `#FFB913`(골드). 버튼 텍스트 화이트.
- **폰트**: 폼·본문 **Pretendard**. 타이틀은 라운드 디스플레이(이미지로 고정, 라이브 텍스트 아님) — 재현 시 유사 라운드 서체 + 그린 외곽선.
- **스탬프**: **5칸** · **지도 위 산개 배치**(격자 X) · 모티프 = **호수요정 캐릭터 + 명소 원형 사진 + 골드 메달 리본** · 86×110 씰 · before(저채도)/after(컬러+골드) 2벌 이미지 · 좌표 고정(127~131 프레임).
- **단계 구조**: 시작(통짜 이미지) → 본인인증(2, DS 폼) → 스탬프(단일 화면 5상태) → 리워드(모달, Default/Received). 본인인증 O · 리워드 화면 O.
- **특이사항**:
  - 스탬프판 = **횡성호수길 실제 지형 지도**를 그대로 배경으로 사용(콜라주형).
