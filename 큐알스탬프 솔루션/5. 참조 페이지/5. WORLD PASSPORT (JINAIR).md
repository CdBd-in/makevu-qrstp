# 🛂 참조 이벤트 — WORLD PASSPORT (JINAIR)

> **진에어(JINAIR) "세계 여행 여권" QR스탬프 이벤트.** 각 여행지에서 QR을 스캔하면 여권에 입국 스탬프가 찍히고, **국가 스탬프 4개**를 모두 모으면 일본 항공권을 받는다.
> **브랜드 리소스(로고)가 있는 케이스** — 로고에서 메인 컬러(라임)·스탬프 모티프(나비/비행기 심볼)를 추출해 테마링했다.
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

## 1️⃣ 시작 (Start) · `6388:3`
- JINAIR 로고(**167×73 프레임 contain·중앙**) + **WORLD PASSPORT**(**Bebas Neue**, 2줄) + 일시 카드(2026.08.01~08.03) + 설명 카드[**thiings 3D 비행기 아이콘** + 안내(어절 단위 줄바꿈)] + 라임 CTA "이벤트 참여하기".
- 설명: "세계 여행을 떠나는 것처럼, 각 여행지를 방문해 QR 코드를 스캔하면 여권에 입국 스탬프가 찍힙니다. 국가 스탬프 4개를 모두 모으면 특별한 여행 리워드를 받을 수 있습니다!" (→ **어절 단위 줄바꿈** 적용)

## 2️⃣ 본인인증 (Login) · `6388:24` / `6388:39`
- DS 폼 그대로 + 버튼/체크박스/보조버튼(인증번호 받기)만 라임으로 테마링.

## 3️⃣ 스탬프 (Stamp) — 여권 입국 스탬프 컨셉
- **2열 × 2행 = 4칸** · 헤더 3줄 고정("홍길동님, / 스탬프 4개를 모으고 / 리워드를 받으세요!").
- **칸 디자인 = ④ 이미지+하단라벨** (매번 커스텀 4유형 중 사용자 선택):
  - 링(원형 입국도장 테두리) + **JINAIR 나비/비행기 심볼** + 하단 **도시 라벨 배너**.
  - 도시(목적지) = **TOKYO · OSAKA · BANGKOK · DANANG** (JINAIR 인기 노선).
  - 적립 후(active)=라임 / 적립 전(inactive)=그레이 · 레이아웃 동일.
- 전용 컴포넌트 세트 **`stamp-WORLDPASSPORT`**(`6403:402` · active `6403:400` / inactive `6403:401`) — **공용 stamp 마스터(`6189:13747`)는 미수정**.
- 상태: Default(0/4) → 1/n(TOKYO 적립) → n/n(4/4) → RewardDone.

## 4️⃣ 리워드 (Reward) · `6388:133` / `6388:165`
- 타이틀 "축하합니다!"(라임 · **Pretendard Bold**) + 안내문 "김포공항 진에어 부스에서 항공권을 받아가세요!"
- 리워드 카드: **thiings 3D 비행기 아이콘**(`reward-airplane-jinair.png` · FIT·중앙) + "리워드 일본 항공권" + 핀라벨[수령장소 **김포공항** / 수령기한 **2026.08.01**].
- Done(`6388:165`) = Default 복제 + 하단 CTA만 "리워드 수령완료"(비활성). **4-1·4-2 동일 처리**(로고·여백·이미지·폰트).

## 📌 제작 노트 (재현 포인트)

1. **검증 템플릿 복제 출발** — `수정후`(`6236:2288`) 9프레임을 새 페이지로 복제 후 테마·콘텐츠·칸수만 교체.
2. **브랜드 리소스 활용** — 로고에서 ⓐ 메인 컬러(라임 `#B0F800`) ⓑ 스탬프 모티프(나비 심볼) 추출. (로고 자체는 새로 그리지 않고 크기·투명배경만 가공)
3. **밝은 메인 컬러 처리** — 라임은 밝아서 **라임 배경 위 텍스트(버튼·핀라벨)는 다크**로. (흰색 텍스트는 라임 위에서 안 읽힘) → 리테마 시 "라임 fill을 가진 노드의 자식 텍스트"만 다크로 치환.
4. **퍼플→라임 리매핑** — 템플릿 BTS 퍼플 `#7F5AF0`(솔리드 fill·텍스트 세그먼트)을 라임으로 일괄 치환 + 배경 그라데이션 → 트래블 배경 이미지로 교체.
5. **스탬프 6→4 축소** — 3번째 행·잉여 구분선 제거 + 행별 세로선(100px) 재구성.
6. **리워드 이미지 = thiings 3D 아이콘** — "일본 항공권" → 항공 모티프 **비행기 아이콘**(`reward-airplane-jinair.png`) FIT·중앙. (※ 직접 제작 보딩패스는 폐기 — 아래 수정 이력)
7. **간격 = 문서 기준** — **시작·리워드 상단 52 / 하단 52** · **스탬프 상단 52 / 하단 40** · **로고→타이틀 12** · 리워드 안내문→카드 35 / 카드→CTA 35 (오토레이아웃 padding·gap, 프레임 높이 hug).
8. **검수** → [[큐알스탬프 솔루션/4. 검수 체크리스트.md]] 전 항목 적용.

## 🔧 수정 이력 (검수 후 보정 · 2026-07-01) ⭐

> 최초 자동 제작본의 누락·오류를 워크플로우 기준으로 교정한 내역. **같은 실수 방지용 체크 포인트**.

1. **Step 1(질문) 누락 → 보완** — 제작 전 **폰트·색상 테마**를 먼저 확정해야 한다. 확정값: 색상 = **JINAIR 브랜드(다크+라임)** · 폰트 = **Bebas Neue(영문 헤드라인) + Pretendard(국문·본문)**. `축하합니다!`가 임의의 **G마켓 산스** → **Pretendard Bold**로 교정.
2. **리워드 이미지** — 임의로 가져온 **거울상 보딩패스** → **thiings 3D 비행기 아이콘**(FIT·중앙)으로 교체(시작·리워드 **4-1·4-2 모두**).
3. **줄바꿈** — 시작 설명이 "리워드 / 를"로 어절 중간에서 깨짐 → **어절 단위 수동 개행**.
4. **로고 규칙** — 327×25로 펴진 로고 → **167×73 프레임 contain·중앙**(시작·리워드).
5. **오토레이아웃 상하 여백** — 컨테이너 padding 0(중앙배치) → **시작·리워드 52/52**, **스탬프 52/40** · 프레임 높이 = 콘텐츠 hug(고정 높이 잔류로 인한 하단 과다 여백 제거: 스탬프 726→572).
6. **로고 → 타이틀 간격 = 12**(시작·리워드).
7. **스탬프 헤더 남은 수 + 강조 색** — `3-2.STAMP-1/n`을 1개 적립 기준 **"스탬프 3개"**(n−m = 4−1)로 수정 + 강조 숫자 **"3"에 메인 라임 `#B0F800`** 적용. ⚠️ **텍스트를 교체하면 강조 색(메인)이 초기화**되므로, 숫자 수정 후 반드시 메인 색을 다시 입힌다.
8. **4-1/4-2 동기화** — 리워드 Done(`6388:165`)은 Default(`6388:133`)와 **로고·여백·이미지·폰트까지 100% 동일**(CTA 상태만 차이). 한쪽만 고치지 말 것.
