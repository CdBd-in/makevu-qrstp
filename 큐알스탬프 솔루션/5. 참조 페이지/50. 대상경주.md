# 🐎 참조 이벤트 — 대상경주 (2025 대상경주 모바일 스탬프 투어)

> **한국마사회(KRA) "2025년 대상경주 모바일 스탬프 투어".** 렛츠런파크(경주) 현장에서 **주요 대상경주(6경주) 관람 + 지정 장소 방문** 후 QR을 스캔하면 스탬프가 적립되고, **스탬프 1개당 응모권 1개**(현장 수령) 및 **일부 스탬프는 적립 즉시 별도 리워드** 지급.
> **혼합 리워드 케이스** — 스탬프 11개는 (a)대상경주 6개 + (b)방문/체험 미션 5개가 섞여 있고, 리워드도 **① 응모권(모든 스탬프)** + **② 별도 리워드(코리아컵·대통령배·그랑프리 3종만 즉시 지급)** 로 이원화. 리워드는 **전용 화면이 아니라 팝업 모달(852px)** 로 표현.
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **혼합 스탬프(경주 관람 + 방문/체험 미션)** — 11칸이 동일 성격이 아니라 대상경주 6종 + 미션 5종 혼합. 각 칸에 **경주명/미션명 + 날짜·시간**이 씰 이미지로 부착.
2. **이원 리워드(응모권 + 별도 리워드)** — ⓐ 모든 스탬프 → 응모권 1개(11/29 자동 활성), ⓑ 코리아컵·대통령배·그랑프리 3종만 적립 즉시 별도 리워드. 특정 스탬프 칸 아래에만 `button` 인스턴스를 조건부로 배치.
3. **리워드 = 전용 화면이 아닌 팝업 모달(852px)** — Close 아이콘 포함, 스탬프 화면 위에 오버레이. default ↔ done(버튼 텍스트만 "…받기" → "…받기 완료" 비활성) 2상태.
4. **헤드라인 폰트 = Gmarket Sans** — 다른 참조들(전체 Pretendard)과 달리 **스탬프 헤더 타이틀은 Gmarket Sans(Medium/Bold)**. 본문·버튼·폼만 Pretendard. ⚠️ 리테마 시 헤더 폰트 혼동 주의.
5. **강조 숫자 색 = 메인 퍼플** — 헤더 "N개"만 `#B21EFF`, 나머지 딥 퍼플. 텍스트 교체 시 강조 색 재적용 필요.
6. **퍼플 2단 팔레트** — 강조/버튼 `#B21EFF` + 딥 배경/본문 `#611A86`. 시작·스탬프 배경은 경마 페스티벌 일러스트(bunting·불꽃·러너) 풀블리드.
