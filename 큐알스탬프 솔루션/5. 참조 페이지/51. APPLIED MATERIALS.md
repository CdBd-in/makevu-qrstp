# 💎 참조 이벤트 — APPLIED MATERIALS (PYEONGTAEK NF SUMMIT)

> **어플라이드 머티어리얼즈(Applied Materials) "평택 NF SUMMIT — GRAND OPENING" QR스탬프 투어.** 전시장 각 부스(Space)에서 QR을 스캔하면 다이아몬드형 스탬프가 찍히고, **5개(Space 1~5)** 를 모두 모으면 **기념품 룰렛**을 돌려 프리미엄 굿즈를 받는다.
> **룰렛(추첨 뽑기) 리워드 케이스** — 스탬프 완성 후 리워드 화면이 고정 상품이 아니라 **룰렛을 돌려 6종 중 1개를 획득**하는 구조. 리워드 화면이 룰렛 결과에 따라 **REWARD1~5** 5벌로 분기한다.
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

- **구성**: 본인인증 **있음** · **스탬프 5칸(피라미드 2-1-2)** · **룰렛 뽑기** → **리워드 모달(5분기)**
- **폰트**: 헤드라인·버튼 **Paperlogy**(ExtraBold/Bold) · 본문·DS 폼 **Pretendard**


## 1️⃣ 시작 (Start) · `2469:1013`
- 상단 **Applied Materials 로고** + 디스플레이 타이틀(전부 배경 이미지에 소성):
  - **"PYEONGTAEK NF SUMMIT"** / **"GRAND OPENING"** (대형 세리프·아웃라인 헤드라인)
  - 서브 **"QR 스탬프 투어"** (골드/시안 톤)
  - 안내: **"평택 NF SUMMIT 10곳에 놓여진 5개의 스탬프를 모두 찾으면 기념품을 드립니다!"**
- 하단 화이트 CTA **"이벤트 참여하기"**(`#14627F` 텍스트).
- ※ START-BG는 통 이미지 → 타이틀·안내문이 **텍스트 노드가 아니라 이미지**(문구 수정 시 이미지 교체 필요).

## 2️⃣ 본인인증 (Login) · `2469:1018` 외
- DS 폼 그대로(이름/휴대폰번호/인증번호) · 4상태 관리:
  - `2-0. LOGIN-Error`(오류) · `2-1. default`(기본) · `2-2. Verification Sent`(인증번호 전송) · `2-3. Filled`(시작하기 버튼 활성화).
- 버튼/보조버튼만 브랜드 톤으로 테마링.

## 3️⃣ 스탬프 (Stamp) — Space 다이아몬드 5칸
- 헤더(Paperlogy ExtraBold 31px): **"5개의 스탬프를 모아 / 리워드를 받으세요!"** — 앞 "5개의 스탬프"만 **골드 `#EAD86C`** 강조.
- **피라미드(2-1-2) 배치**: 160×160 칸 5개.
  - 1행: STAMP1(x0) · STAMP2(x185) — 2칸
  - 2행: STAMP3(x92.5, 중앙) — 1칸
  - 3행: STAMP4(x0) · STAMP5(x185) — 2칸
  - 컨테이너 폭 345 · gap 25 · 헤더↔그리드 36.
- 각 칸 = **다이아몬드/보석 아웃라인 스탬프 이미지** — 중앙 **"Space N"** 라벨 + 반짝임(sparkle) 장식. `STAMPn-before`(미적립) / `STAMPn-done`(적립) **이미지 애셋 2벌**(컴포넌트 아님, 텍스트도 이미지에 소성).
- 하단 CTA(화이트) **"기념품 룰렛 돌리러 가기"**.
- 상태: `default`(0/5) → `1of5`(1개 적립) → `5of5`(전부 적립, CTA 활성).

## 4️⃣ 룰렛 (Roulette) · `2469:955`

- 헤더 **"기념품 룰렛"**(Paperlogy) · CTA **"룰렛 돌리기"**(화이트 버튼).

## 5️⃣ 리워드 (Reward) — 모달 5분기 · `2469:1187`~`2469:1203`
- 룰렛 정지 → **리워드 모달 자동 ON**(우상단 Close Icon). 획득 상품에 따라 **REWARD1~5** 중 하나 노출.
- 구성: 타이틀 **"축하드립니다!"** + 안내 **"평택 NF SUMMIT GRAND OPENING QR스탬프 투어 / 〈상품명〉에 당첨되었어요"** + 상품 이미지 + 수령 안내 **"기념품 교환처 담당 직원에게 화면을 보여주세요"** + CTA **"리워드 수령 확인"**.
- 각 상품 모달은 **수령 전(응모 완료)**·**수령 완료** 2상태 → 수령 완료 시 CTA "리워드 수령 완료"(비활성).
- 모달 OFF 동작: 수령 전 닫으면 **응모 완료 상태 스탬프 페이지**로, 수령 후 닫으면 **수령 완료 상태 스탬프 페이지**로 복귀.

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **룰렛(뽑기) 리워드 변형** — 스탬프 완성이 곧바로 고정 상품으로 가지 않고 **룰렛 화면 → 스핀 → 리워드 모달**로 이어진다. 표준 4단계 + **룰렛 단계 추가**.
2. **리워드가 상품별 5분기 모달** — `REWARD1~5`를 룰렛 결과에 매핑. 각 모달은 상품 이미지·명칭만 다르고 레이아웃·수령안내·CTA는 공통. 상품 추가/수정 시 이미지·문구만 교체.
3. **모달 상태·복귀 로직** — 리워드는 오버레이 모달(Close Icon)이며 "수령 전/후"에 따라 복귀 스탬프 페이지 상태(응모완료/수령완료)가 달라진다. 상태 전이를 프레임으로 문서화(캔버스 주석 참조).
4. **스탬프 = 피라미드(2-1-2) 다이아몬드 애셋** — 4~16 격자가 아니라 **5칸을 2-1-2 피라미드**로 배치. 칸은 "Space N" 라벨이 소성된 **다이아몬드 이미지**(before/done 2벌). 텍스트 편집 불가 → 이미지 교체.
5. **타이틀·안내는 배경 이미지에 소성** — START-BG/ROULETTE-BG 등 배경 통이미지에 헤드라인이 포함. 문구 변경 시 텍스트 노드가 아니라 이미지를 다시 만들어야 함.
6. **밝은 버튼 규칙** — 다크 크리스탈 배경 위 버튼은 **화이트 fill + `#14627F` 텍스트**로 대비 확보(WORLD PASSPORT의 "밝은 라임 위 다크 텍스트"와 대칭 케이스).
7. **폰트 = Paperlogy** — 헤드라인·버튼이 **Pretendard가 아닌 Paperlogy**(ExtraBold/Bold). DS 폼(로그인)만 Pretendard. ⚠️ 리테마 시 폰트 패밀리 혼동 주의.

## 🤖 디자인 자동화 재현 포인트

- **테마색**: 메인 `#14627F`(딥 틸/블루) · 강조 `#EAD86C`(골드) · 배경 = 다크 네이비 크리스탈/폴리곤 이미지 · 버튼 = 화이트 fill + `#14627F` 텍스트.
- **폰트**: 헤드라인·버튼 **Paperlogy**(8 ExtraBold 31px 헤드라인 / 7 Bold 24px 버튼) · 본문/로그인 폼 **Pretendard**. (Pretendard 단독 아님)
- **스탬프**: **5칸 · 피라미드 2-1-2 배치** · 160×160 · 모티프 = **"Space N" 다이아몬드/보석 아웃라인** · 적립 전(before)/후(done) **별도 이미지 애셋 2벌**(opacity 아님, 텍스트 소성).
- **단계 구조**: 시작 → 본인인증(4상태) → 스탬프(default/1of5/5of5) → **룰렛(6분할)** → **리워드 모달 5분기(수령 전/후)** → 스탬프-done. 본인인증 있음 · 리워드 화면 있음.
- **리워드 메커닉**: **기념품 룰렛(뽑기)** — 6종 굿즈 중 1개 당첨 → 상품별 모달 → "기념품 교환처 직원에게 화면 제시"로 오프라인 수령.
- **특이사항**: 아트보드 393×852 **고정**(세로 가변 아님) · 헤드라인/안내문/스탬프 라벨이 모두 **이미지 소성**(텍스트 편집 불가) · 리워드 모달은 오버레이+상태별 복귀 로직 존재.
