# ✈️ 참조 이벤트 — 지금제주여행 (Now Jeju Travel · JEJU STAMP TOUR)

> **제주관광공사 "지금 제주여행 / 제주에 폭삭 빠졌수다" 모바일 스탬프 투어 이벤트.** 제주 곳곳의 스팟에서 QR을 스캔하면 **탑승권(보딩패스) 티켓**에 스탬프가 찍히고, **스탬프 3개**를 모으면 **리워드 자동 응모**가 완료된다.
> **여행 보딩패스 컨셉 케이스** — 시작·리워드 화면 전체가 **JEJU STAMP TOUR 항공권 티켓 키비주얼**(BOARDING PASS)로 디자인되고, 스탬프 페이지는 제주 스팟/국가유산/봄꽃축제를 소개하는 **롱 스크롤 콘텐츠형**이다.

## 1️⃣ 시작 (Start) · `2320:168`
- 상단 **"지금 제주여행"** 워드마크 로고.
- 티켓 헤더 카피: **"제주에 폭삭 빠졌수다"** + **"모바일 스탬프 투어 이벤트"**.
- **JEJU STAMP TOUR 보딩패스 티켓** 카드 — `2025. 3.28(금) ~ 4.6(일)` 기간 표기 · `BOARDING PASS / JEJU ISLAND` 라벨.
- **참여안내(How to)** 카드: 캐릭터(제주 감귤/돌 캐릭터) + 이벤트 참여 방법 설명.
- 하단 그린 CTA **"이벤트 참여하기"**.
- ※ 시작 화면은 대부분 **배경 이미지(START-BG)** + CTA 버튼 이미지로 구성 → 텍스트가 이미지에 굳어 있음.

## 2️⃣ 본인인증 (Login) · `2320:258` / `2320:277`
- 헤드라인 **"휴대폰번호 인증 한 번으로 이벤트에 참여하세요"**.
- DS 폼 그대로: `이름`(홍길동) / `휴대폰번호`(+ "재전송") / `인증번호`(+ "인증되었습니다").
- 보조 링크 "인증번호 문자가 오지 않을 때" · 필수 동의 체크박스 2종(개인정보 수집·이용 / 처리업무 위탁, 각 "자세히").
- CTA **"시작하기"** — Default(비활성) ↔ done(그린·활성). 체크박스 체크 = 그린.

## 3️⃣ 스탬프 (Stamp) — 보딩패스 + 제주 콘텐츠 롱 스크롤
- 헤더(고정 문구, 남은 개수만 변동):

  - 진행: 남은 수만 변동(`3-2. STAMP-1/3` = "앞으로 2 개…")
  - 완료: **"축하합니다!🎉 스탬프를 모두 모았습니다!"** (`3-3. STAMP-3/3`) → 응모 시 **"축하합니다!🎉 자동 응모가 완료됐습니다!"** (`5. STAMP-done`)
- **스탬프 배치**: `Frame 110` 컨테이너 폭 292 · **가로 1행 3칸** · 각 칸 **92×91** · gap 8 · 중앙정렬. (세로 스크롤 프레임이지만 스탬프 자체는 상단 1행)
- 각 칸 = **제주관광공사 브랜드 씰 이미지** — 미적립 `제주관광공사-비어있는-스탬프`, 적립 후 `제주관광공사-컬러스탬프-6/9/10`. **컴포넌트가 아닌 이미지 애셋 교체 방식**.

## 4️⃣ 리워드 (Reward) · `2320:180` / `2320:173`
- 시작 화면과 동일한 **JEJU STAMP TOUR 보딩패스** 키비주얼 위 안내: **"축하합니다! 이벤트의 자동 응모 되었습니다"**.
- 우상단 **Close Icon**(모달 닫기, `2320:185`) — 리워드가 **모달** 형태임을 시사(캔버스 주석: "응모 완료 후 리워드 모달 OFF → 응모 완료 상태의 스탬프 페이지").

- 리워드/응모 안내 문구·유의사항은 티켓 하단 배경 이미지에 포함.

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **보딩패스(항공권) 티켓 키비주얼** — 시작·리워드가 공통 **JEJU STAMP TOUR / BOARDING PASS** 티켓 그래픽. 여행 테마 이벤트의 대표 모티프로, 시작·리워드가 배경 이미지 중심(텍스트가 이미지에 포함).
2. **스탬프 = 브랜드 씰 이미지 애셋** — `제주관광공사-비어있는-스탬프`(before) ↔ `제주관광공사-컬러스탬프-N`(after). 컴포넌트가 아니라 **이미지 교체**로 상태 전환.
3. **리워드 = 자동 응모형(모달)** — 스탬프 3개 완주 = 자동 응모 완료. 별도 수령 액션 없이 헤더 문구 전환 + 리워드 **모달**(Close Icon) 노출. `STAMP-done`과 `REWARD` 두 상태로 표현.
4. **스탬프 페이지 = 롱 스크롤 콘텐츠형(1258)** — 상단 3칸 스탬프 아래로 "주요 스팟 / 국가유산 방문 / 봄꽃 축제" 안내를 길게 배치. 스탬프 그리드보다 **관광 콘텐츠 소개**가 비중이 큰 케이스.
5. **강조 숫자 = 그린 ExtraBold 52px** — "앞으로 N 개의 스탬프가 남았습니다!"의 N만 크게·`#016934`. ⚠️ 텍스트 교체 시 강조 색 초기화 주의(재입힘 필요).
6. **초안/정리본 병존** — 같은 캔버스에 번호 없는 초안 + 번호 붙은 최종본이 함께 있음. 채택은 `1.START ~ 5.STAMP-done` 번호본.
