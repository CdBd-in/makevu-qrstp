# ♾️ 참조 이벤트 — 불가리 QR스탬프 (BVLGARI SERPENTI INFINITO)

> **불가리(BVLGARI) "세르펜티 인피니토(SERPENTI INFINITO)" 전시/팝업 연계 QR스탬프 미션 이벤트.** 방문지·SNS 액션마다 QR/미션을 완료하면 뱀(세르펜티) 심볼 스탬프가 찍히고, **미션 스탬프 5개**를 모으면 **엽서 10종 리워드**를 신청, 추가로 **팝업스토어 경험 리워드**까지 받는다.
> **럭셔리 브랜드 미션형 케이스** — 국가/방문지 랠리가 아니라 **카카오 친구추가·네이버 리뷰·불가리 고객등록·팝업스토어 방문** 등 **행동 미션**을 스탬프 칸으로 구성했다. 브랜드 톤(브라운+골드)과 세르펜티(뱀 ∞) 모티프를 전면 사용.
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

- **Figma**: `QR 스탬프` · fileKey `n8YIkPdm2svezJYjePHn1u` · 페이지 `불가리-QR스탬프` (`2091:4`)
- **아트보드**: 393 폭 · 시작 **979** / 로그인 852 / 스탬프 **1289** / 리워드 851
- **구성**: 본인인증 **있음(에러/발송/완료 상태 포함)** · **미션 스탬프 5칸(2열 그리드)** · **리워드 2종(엽서+팝업)** · 팝업(약관3종·인증문자 미수신 안내)
- **폰트**: 헤드라인·스탬프 라벨 **Yoon Gothic 300 Std(윤고딕)** / 본문·폼 **Pretendard**

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **미션형 스탬프(행동=칸)** — 방문지 랠리가 아니라 **SNS/등록/방문 미션**(카카오 친구추가·네이버 리뷰·불가리 고객등록·팝업스토어)을 스탬프 칸으로 매핑. 각 칸 = 링 아웃라인 + 미션명 텍스트, 완료 시 done 이미지 교체.
2. **브랜드 전용 폰트 = 윤고딕(Yoon Gothic 300 Std)** — 헤드라인·스탬프 라벨이 **Pretendard가 아님**. 럭셔리 브랜드 워드마크 톤에 맞춘 국문 세리프성 고딕. 본문/폼만 Pretendard.
3. **세르펜티(∞/뱀) 모티프** — 미적립 스탬프·구분선·done 이미지 모두 **인피니토(∞) 심볼** 기반. 브랜드 심볼을 스탬프 애셋으로 재사용.
4. **리워드 2종(멀티 리워드)** — 표준 단일 리워드가 아니라 **엽서 10종(REWARD1) + 팝업스토어 경험(REWARD2)** 2개 화면. 각각 Default/Done 쌍. 리워드가 모달(Close 아이콘)로 뜬다.
5. **본인인증 5상태 + 약관 3종** — 로그인이 Default/Verification/Sent/Done/Error 5단계로 세분, 약관 팝업도 **브랜드사(불가리) 동의 추가**로 3종. 인증문자 미수신 안내 팝업(통신사별 스팸 해제 가이드) 포함.
6. **럭셔리 무드 = 브라운 단색 + 골드 라인** — 컬러 팝 최소화, `#FFD542` 골드는 **강조 숫자·라인**에만. 스탬프 라벨은 `#D2B874` 탠.

## 🤖 디자인 자동화 재현 포인트

- **테마색**: 메인/강조 **`#FFD542`(골드)** · 스탬프 라벨 **`#D2B874`(탠)** · 배경 **브라운/커피 브라운 단색** · CTA는 브라운 필 + 밝은 텍스트. (럭셔리 = 저채도 브라운 + 골드 라인 포인트)
- **폰트**: 헤드라인·스탬프 라벨 = **Yoon Gothic 300 Std(윤고딕)** — ⚠️ Pretendard 아님 / 본문·폼 = **Pretendard**. 리테마 시 헤드라인 노드 폰트를 윤고딕으로 지정.
- **스탬프**: **5칸 · 2열 그리드 · 미션형**. 미적립 = 골드 아웃라인 **∞(세르펜티) 링 90px + 미션명 텍스트** / 적립 = **채워진 done 이미지 112px**. 칸 이름 = 행동 미션(카카오 친구추가·네이버 리뷰·불가리 고객등록·팝업스토어).
- **단계 구조**: 시작 → 본인인증(**5상태**: Default/Verification/Sent/Done/Error) → 스탬프(3상태) → **리워드1(엽서 10종)** → **리워드2(팝업스토어)**. 리워드는 **모달(Close 아이콘)** 형.
- **특이사항**:
  - 리워드 **2종(멀티 리워드)** — Default/Done 쌍 각각 존재.
  - 약관 팝업 **3종**(개인정보 수집·이용 / 처리업무 위탁 / **불가리** 동의) + 인증문자 미수신 안내 팝업.
  - 강조 숫자("3개")에 골드 `#FFD542` 적용 → **텍스트 교체 시 강조색 재적용 필요**.
  - 세르펜티 **∞ 심볼**을 스탬프·구분선 전반에 브랜드 모티프로 반복 사용.
