# ⚙️ 참조 이벤트 — 현대 HD (2025 서울모빌리티쇼 스탬프 투어)

> **현대(HYUNDAI) × DEVELON "2025 서울모빌리티쇼 스탬프 투어".** 부스 내 체험 프로그램 4개(HYUNDAI Milestone Table / DEVELON Milestone Table / 4D Ride / Digital Graffiti)에 참여하고 각 프로그램 QR을 스캔하면 스탬프가 찍히며, **스탬프 4개**를 모두 모으면 **캡슐 머신 체험(경품 직접 뽑기)** 기회를 얻는다.
> **다크(블랙) 테마 + 현대 브랜드 그린** 케이스 — 배경이 순블랙(`#000000`)이고, 헤드라인·강조·스탬프(active)에 현대 그린(`#34D330`)을 쓴다. 폰트는 **HDHyundai 전용서체**(Pretendard 아님).
> **본인인증 없음 · 리워드 전용 화면 없음** — 대신 완료 후 **스태프 화면 인증**으로 오프라인 캡슐 머신을 체험한다.
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

- **Figma**: `QR 스탬프` · fileKey `n8YIkPdm2svezJYjePHn1u` · 페이지 `현대 HD` (`2258:26`)
- **아트보드**: 393 폭 · 시작 **1053** · 스탬프 **912**(스탬프 BG 헤더 포함) · 리워드 모달 852
- **구성**: 본인인증 **없음** · **스탬프 4칸(2×2)** · **리워드 전용 화면 없음**(캡슐 머신 체험 안내 팝업 + 스태프 인증)
- **폰트**: 전체 **HDHyundai** (Bold / Medium) — 현대 브랜드 전용서체
- ⚠️ 캔버스에 **구버전(좌측)** 과 **`0328 수정` 신버전(우측)** 이 병존 — **본 문서는 신버전(0328 수정) 기준**. 신버전은 스탬프 135×135, 헤더에 그레이디언트 배경(`스탬프 BG`)이 추가됨.

## 전체 흐름

```
시작 → 스탬프(4칸) → (전부 적립 시) 스태프 인증 → 캡슐 머신 체험 안내 팝업 → 체험 완료
      (본인인증 없음 · 리워드 전용 화면 없음)
```

> ⚠️ **본인인증 단계가 없다.** 시작 → 바로 스탬프. 리워드도 별도 화면이 아니라 **모달 팝업 + 오프라인 스태프 인증**으로 처리된다. 표준 4단계(시작→인증→스탬프→리워드)와 달리 **인증·리워드 화면 둘 다 생략**된 경량 플로우.

## 1️⃣ 시작 (Start) · `2434:132`
- 상단 우측 **HD 로고**(그린 화살표 마크 + "HD").
- 디스플레이 타이틀: **"2025 서울모빌리티쇼 / HYUNDAI × DEVELON / 스탬프 투어"** (스탬프 투어=대형 그린 헤드라인).
- **안내문**: "체험 프로그램에 참여하고 **4개의 스탬프**를 모으면 다양한 기념품을 받을 수 있는 **캡슐 머신 체험 기회**를 드립니다." (그린 강조 세그먼트).
- **"체험 프로그램" 카드**(그린 pill 라벨) — 2×2 4개 프로그램: **HYUNDAI Milestone Table · DEVELON Milestone Table · 4D Ride · Digital Graffiti**.
- **"완료 혜택" 카드**(그린 pill 라벨): "경품을 직접 뽑을 수 있는 **캡슐 머신 체험 기회**를 드립니다." + 하단 **선물상자·굴착기 라인아트 일러스트**.
- 각주: "★ 경품 소진 시 스탬프 투어가 조기종료될 수 있습니다."
- 하단 고정 CTA(이미지 버튼): **"스탬프 투어 시작하기 >"** (그린).

## 2️⃣ 스탬프 (Stamp) — 체험 프로그램 씰 랠리 · `2437:48` / `2437:77` / `2437:87`
- 상단 **헤더 그레이디언트 배경**(`스탬프 BG` · 높이 270) 위에 타이틀 3줄 재노출 + 진행 안내문.
- 헤더 안내문(상태별 문구/색 변화):
  - Default(0/4): **"`4개의 스탬프`를 모으고 / 캡슐 머신 체험 기회를 얻으세요!"** ("4개의 스탬프"=그린 Bold)
  - Collecting(1개 적립): **"`3개의 스탬프`를 모으고 …"** (남은 수 n−m = 4−1 = 3, 그린 강조)
  - Done(4/4): **"`스탬프를 모두 모았어요.` / 캡슐 머신 스태프에게 화면을 인증하고 / 캡슐 머신을 체험하세요!"** (첫 줄 그린 Bold 23.5px, 이하 화이트 20px)
- **스탬프 그리드**: `Frame 110` · 폭 314 · **2열 × 2행 = 4칸** · **gap 44** · 각 칸 **135×135**.
  - 각 칸 = **원형 스캘럽(톱니) 씰 이미지** — 중앙 프로그램명(예: `HYUNDAI Milestone Table`) + 상단 "스탬프 투어" + 하단 "2025서울모빌리티쇼" 텍스트가 **이미지로 굳어짐**.
  - `STAMPn-before`(그레이) ↔ `STAMPn-done`(그린) 2벌 이미지 교체 방식(컴포넌트 아님, `<img>`).
- 하단 안내문(Default/Collecting): **"체험 완료 후, 프로그램 스태프로부터 / 스캔 가능한 스탬프 QR을 받아주세요."** (화이트 17px, opacity 90%).
- Done 상태: 하단 안내문 OFF → 우하단 **"스태프 인증 >"** 버튼(`스태프인증 버튼`) ON.

## 3️⃣ 리워드 — 전용 화면 없음 (팝업 + 스태프 인증) · `2259:1348`
- 리워드 전용 페이지가 **없다.** 스탬프 완료 후 **"캡슐 머신 체험 안내" 모달 팝업**이 뜬다.
- 팝업 구성: 우상단 **닫기(X)** · 다크 웨이브 키비주얼 · 타이틀 **"캡슐 머신 체험 안내"** · 안내 **"스태프에게 화면 인증 후 / 캡슐 머신을 체험해 보세요!"**
- 하단 주의: "아래 버튼은 스태프 확인 버튼이니 / 누르지 말고 스태프의 안내를 따라주세요."
- **CTA 버튼**: `REWARD/Default`=활성(딥 그린 `#01AE42`, "캡슐 머신 체험 완료") ↔ `REWARD/Done`=비활성(opacity 50% + 텍스트 `#E6E7E1`).
- 플로우 주석: 스태프 인증 버튼 클릭 → `Done` 페이지 이동 · 체험 완료 이후 URL 재접속 시 시작하기 버튼이 `Done`으로 이동.

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **다크(블랙) 테마 + 브랜드 그린** — 배경 `#000000` 고정(캔버스 주석 "모든 페이지 BG=#000000"), 강조·스탬프 active·라벨은 HD 그린 `#34D330`. 블랙 위 본문은 화이트. → 리테마 시 "그린 fill 노드의 텍스트"는 그대로, 배경/카드는 다크로.
2. **현대 전용서체 HDHyundai** — 전체 폰트가 **HDHyundai Bold/Medium**(Pretendard 아님). 브랜드 이벤트는 자사 전용서체를 쓰는 경우가 있으므로 Step 1(질문)에서 반드시 폰트 확정.
3. **본인인증·리워드 화면 둘 다 생략** — 부스 현장형 체험이라 **인증 단계 없음**, 리워드는 **모달 팝업 + 오프라인 스태프 인증**. 표준 4단계가 아닌 경량 구조(시작→스탬프→팝업/스태프).
4. **스탬프 = 체험 프로그램명 박힌 그린/그레이 씰 이미지** — 원형 스캘럽 씰에 프로그램명이 이미지로 고정. `before`(그레이) / `done`(그린) 2벌 이미지 교체(컴포넌트 아님). 프로그램 변경 시 텍스트 편집이 아니라 이미지 교체.
5. **진행 상태 = 헤더 안내문 남은 수 + 그린 강조** — "N개의 스탬프"의 N(=남은 수)만 바꿔 Default/Collecting/Done 구성. ⚠️ 텍스트 교체 시 그린 강조가 초기화되므로 수정 후 그린을 다시 입힌다.
6. **구·신버전 병존** — 캔버스에 `0328 수정` 신버전(우측)이 최신. 신버전은 스탬프 135×135 + 헤더 그레이디언트 배경 추가. 구버전(좌측, 100×100)은 참고용.

## 🤖 디자인 자동화 재현 포인트

- **테마색**: 메인 그린 `#34D330` · 배경 순블랙 `#000000` · 리워드 CTA 딥그린 `#01AE42` · 본문 화이트 `#FFFFFF` · Done 텍스트 `#E6E7E1`.
- **폰트**: 전체 **HDHyundai** — 헤드라인/강조 **Bold**, 본문/안내 **Medium**. (Pretendard 아님 · 현대 전용서체 필수 확보)
- **스탬프**: **4칸 · 2×2 그리드 · gap 44 · 칸 135×135**(신버전) · 원형 스캘럽 씰 · 모티프=체험 프로그램명(HYUNDAI/DEVELON Milestone Table · 4D Ride · Digital Graffiti) · before(그레이)/done(그린) 이미지 2벌 교체.
- **단계 구조**: 시작(1053) → 스탬프 Default/Collecting/Done(912) → 리워드 팝업(852) → Done. **본인인증·리워드 전용 화면 모두 없음**.
- **특이사항**:
  - 배경 순블랙 다크 테마 + 스탬프 헤더에 그레이디언트 BG(높이 270).
  - 리워드는 화면이 아니라 **모달 팝업 + 스태프 화면 인증**(오프라인 캡슐 머신).
  - 시작 화면에 "체험 프로그램"(4개)·"완료 혜택" 두 개의 그린-pill 라벨 카드 + 선물상자/굴착기 라인아트 일러스트.
  - Done 스탬프 화면 우하단 "스태프 인증" 버튼이 하단 안내문과 토글(OFF↔ON).
  - 캔버스에 구/신(`0328 수정`) 버전 병존 — 신버전 채택.
