# 🐜 참조 이벤트 — ITZY 팝업 (MISSING ITZY)

> **ITZY(있지) 팝업스토어 "MISSING ITZY" QR스탬프 이벤트.** 팝업 공간 곳곳에 숨은 ITZY 멤버(YEJI·LIA·RYUJIN·CHAERYEONG·YUNA)를 QR로 찾아 스캔하면 해당 멤버 스탬프가 찍히고, **멤버 5명(스탬프 5개)** 을 모두 모으면 **MISSING TWINZY 말랑 키링**을 받는다.
> **실종 전단지(Wanted/Missing Poster) 컨셉의 흑백 펑크 케이스** — 개미(ant) 일러스트·거친 볼드 타이포·전단지 하단 절취선(전화번호 태그)을 그대로 스탬프 화면 배경으로 가져온 강한 무드보드형 디자인. 브랜드 컬러 없이 **블랙/크림 단색**으로 밀어붙인다.
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

- **폰트**: 전체 **Paperlogy 9 Black**(초굵은 디스플레이 · 한글/영문 공통) — ⚠️ Pretendard 아님

|---|---|---|

| **배경** | **`#f7f3e9`** 크림/오프화이트 | 전단지 종이 질감 · 모든 프레임 배경 |

## 전체 흐름

```
시작 → 스탬프(5칸) → 리워드        (본인인증 없음 · 3단계)
```

> ⚠️ **본인인증(로그인) 화면이 없다.** 팝업 현장 참여형이라 시작 후 바로 스탬프로 진입한다. 리워드는 **직원 확인용 화면**으로 마무리(WORLD PASSPORT의 4단계와 달리 3단계, 단 리워드 화면은 존재).

## 1️⃣ 시작 (Start) · `3598:4`
- 디스플레이 타이틀 **"MISSING / ITZY"**(초대형 블랙 볼드, 2줄) + **개미(ant) 흑백 일러스트**(실종 = 작게 숨은 존재 은유).
- 반전 강조 카피(블랙 박스·크림 글자): **"ITZY 멤버들을 찾고 / 스탬프를 획득하세요!"**
- 그 아래 **↓↓ CLICK HERE ↓↓** 화살표 + 블랙 CTA **"FIND OUR ITZY"**(시작하기 역할).
- 하단: 전단지 절취선 태그(세로 회전 전화번호 `200-005-026` … `200-312-009`) — 실종 전단지 특유의 "뜯어가는 연락처" 장식.

## 2️⃣ 스탬프 (Stamp) — ITZY 멤버 찾기
- 헤더(고정): 소형 **MISSING ITZY** 로고 + 반전 카피 **"ITZY 멤버들을 찾고 스탬프를 획득하세요!"** + **FIND OUR ITZY**.
- **스탬프 5칸 = 3 + 2 오프셋 배치**(격자 아님):
  - 1행 3개(가로 중앙정렬), 2행 2개(안쪽으로 들여 배치) — 칸끼리 **살짝 겹침**(`mr -4px` / `mb -8px`)으로 도장이 겹쳐 찍힌 느낌.
  - 각 칸 = **124px** · **점선 원(dashed circle)** 위에 **멤버명 회전 라벨** 잉크 스탬프.
  - 멤버 = **YEJI · LIA · RYUJIN · CHAERYEONG · YUNA** (ITZY 5인).
  - before = 점선 빈 원(미공개) / after = 블랙 잉크 멤버명 스탬프(`STAMP1~5-after` 이미지 애셋 · 살짝 기울어짐).
- 하단 CTA: 5개 미완료 시 회색/텍스트 안내, 완료 시 블랙 **"리워드 수령하러 가기"**.
- 상태: Default(0/5) → 1Done(1/5개 적립) → 5Done(5/5개 적립 → CTA 활성) → RewardDone(리워드 수령 완료 · CTA 투명도 40% 비활성).

## 3️⃣ 리워드 (Reward) · `3698:483` / `3698:487`
- 타이틀 **"MISSION / COMPLETE"** + **"THANK YOU FOR FINDING US"**(블랙 볼드, 개미 일러스트 재등장).
- 리워드 카드: **MISSING TWINZY 말랑 키링 5종**(고양이 캐릭터화된 멤버 — KKemEE·Li-Li·RYUJIN·RYeoWOO·NAONE) 키링 이미지 나열.
- 리워드 내용 문구: **"MISSING TWINZY 말랑 키링 5종 중 랜덤 1종 증정"**.
- **유의사항 및 안내사항**:
  1. 해당 이벤트는 1인 1회에 한하여 참여 가능합니다.
  2. 리워드는 미션 완료 후 이벤트 참여 당일에만 지급 가능합니다.
  3. 직원 확인 후 리워드가 증정되오니 캡처본이나 공유된 이미지를 제시할 경우 리워드 지급이 불가합니다.
  4. 리워드 소진 시 해당 이벤트는 조기 종료될 수 있습니다.
- 수령 안내: **"[리워드 수령 확인]은 스태프용이므로 버튼을 누르지 않은 채로 해당 페이지를 스태프에게 보여주세요"**.
- CTA(직원용) **"리워드 수령 확인 (직원용)"** — Default(활성) ↔ Done(투명도 40% 비활성 = 수령 완료).

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **본인인증 없는 3단계** — 팝업 현장 참여형이라 로그인 단계 생략. `시작 → 스탬프 → 리워드`. (리워드 화면은 있으나 auth는 없음 — 플로우 조합의 변형 케이스)
2. **무채색(블랙/크림) 단색 무드보드** — 브랜드 컬러 대신 **블랙 `#000000` + 크림 `#f7f3e9`** 반전으로 강조. 강조가 필요한 카피는 **블랙 박스 + 크림 글자 invert**로 처리.
3. **폰트 = Paperlogy 9 Black(전용 디스플레이)** — 전체를 초굵은 각진 디스플레이 폰트로 통일(⚠️ Pretendard 아님). 전단지/펑크 무드의 핵심.
4. **실종 전단지 그래픽 시스템** — 개미 일러스트·`CLICK HERE ↓↓` 화살표·하단 세로회전 전화번호 절취선을 시작/스탬프 배경에 공통 배치. 스탬프 = "찾은 멤버 도장"으로 컨셉 일치.
5. **스탬프 5칸 = 3+2 오프셋 겹침 배치** — 정격자가 아니라 도장이 겹쳐 찍힌 느낌(`mr -4px`/`mb -8px`). 각 칸 124px 점선 원 → 적립 시 멤버명 회전 라벨 잉크 스탬프.
6. **리워드는 직원 확인용** — 사용자가 버튼을 누르지 않고 스태프에게 화면을 보여주는 오프라인 수령 방식. Done 상태 = CTA 투명도 40% 비활성(수령 완료).

## 🤖 디자인 자동화 재현 포인트

- **테마색**: 메인 `#000000`(블랙) · 배경 `#f7f3e9`(크림) · CTA=블랙박스+크림텍스트. 브랜드 컬러 없음 → **블랙↔크림 invert**로만 강조.
- **폰트**: **Paperlogy 9 Black** 전체 통일(한글·영문 공통, 초굵은 각진 디스플레이). Pretendard 사용 금지 — 무드가 깨진다.
- **스탬프**: **5칸 · 멤버 모티프(YEJI/LIA/RYUJIN/CHAERYEONG/YUNA)** · **3+2 오프셋 겹침**(격자❌) · 칸 124px · before=점선 빈 원 / after=블랙 멤버명 회전 라벨 **이미지 애셋**(텍스트 아님).
- **단계 구조**: **3단계(본인인증 없음)** — `1.START(3598:4) → 2.STAMP 4상태(Default/1Done/5Done/RewardDone) → 3.REWARD 2상태(Default/Done)`. 아트보드 393×857 고정.
- **특이사항**:
  - 실종 전단지 그래픽(개미·CLICK HERE 화살표·세로회전 전화번호 절취선)을 배경 이미지로 공통 사용.
  - 리워드 = **MISSING TWINZY 말랑 키링 5종 중 랜덤 1종**, 수령은 **직원용 버튼**(사용자 미클릭·화면 제시).
  - 완료/비활성 표현 = **투명도 40%**(색 변화 아님).
  - 강조 카피는 블랙 하이라이트 박스 안에 크림 글자로 반전.
