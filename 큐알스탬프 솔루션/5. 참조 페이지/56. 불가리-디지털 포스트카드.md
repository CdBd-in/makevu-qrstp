# 🐍 참조 이벤트 — 불가리 디지털 포스트카드 (BVLGARI Serpenti Infinito)

> **불가리(BVLGARI) "세르펜티 인피니토(SERPENTI INFINITO)" 전시 디지털 엽서(포스트카드) 이벤트.** 전시장 키오스크(아이패드)에서 10종의 아트워크 엽서 중 하나를 골라 **받는 사람·메시지를 편집**하고, **QR을 스캔해 내 휴대폰으로 옮겨 SNS/링크로 공유**하는 플로우.
> **⚠️ 스탬프가 없는 변형 케이스** — 이 페이지는 QR스탬프 랠리가 아니라 **QR 연동 "디지털 엽서 제작·공유" 인터랙션**이다. 본인인증·스탬프 그리드·리워드 화면이 모두 없고, 대신 **엽서 선택 → 편집 → QR 스캔 → 모바일 공유** 4스텝의 모달 플로우로 구성된다. 스탬프 솔루션의 "브랜드 럭셔리 + 이미지 그리드 + QR 브릿지" 응용 사례로 참고한다.
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

- **Figma**: `QR 스탬프` · fileKey `n8YIkPdm2svezJYjePHn1u` · 페이지 `불가리-디지털 포스트카드` (`2108:3454`)
- **아트보드**: 키오스크/데스크톱 **1180×820**(POSTCARDS-*) · 모바일 공유 **393×851**(POSTCARD-Mobile-Share)
- **구성**: 본인인증 **없음** · **스탬프 없음(엽서 10종 5×2 그리드)** · **리워드 화면 없음** · QR로 모바일 공유
- **폰트**: 전체 **윤고딕(YoonGothic OTF)** — 메모 "*모든 페이지에 윤고딕 서체 사용 (otf 파일 전달)". Pretendard는 개발 주석 라벨에만 사용.

## 전체 흐름

```
엽서 그리드(Default) → 엽서 선택(Selected) → 엽서 편집 모달(Edit) → QR 모달(QR) → [모바일] 공유하기 → URL 공유
                                                                      (본인인증 없음 · 스탬프 없음 · 리워드 없음)
```

> ⚠️ 표준 4단계(시작→인증→스탬프→리워드) 구조가 **아님**. 키오스크 화면(1180)에서 모달을 겹쳐 띄우는 **단일 페이지 상태 전이** + QR 브릿지로 넘어가는 **모바일 공유 화면(393)**의 2트랙 구성.

- 인트로 문구(배경 이미지): **"'푸른 별에 세워 올리는 2025년을 맞이하며 「세르펜티 인피니토(SERPENTI INFINITO)」 전시에서 만나 볼 수 있는 디지털 엽서와 함께 소중한 이들을 담아 특별한 사람들에게 전해보세요. 아래에서 작성할 엽서를 골라 주세요."**
- **엽서 그리드**: `Frame 69`(폭 832, 좌우 중앙) · **5열 × 2행 = 10종** · 각 칸 **160×160** 라운드 이미지 · gap 8.
- 좌상단 **새로고침 버튼**(48 원형·`#4A2100`, icons8-refresh) — 페이지 새로고침(편집내용 초기화).

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **스탬프 랠리가 아닌 "디지털 엽서 공유" 인터랙션** — 표준 시작/인증/스탬프/리워드 4단계가 전부 없다. QR스탬프 솔루션의 **QR 브릿지(키오스크→모바일)** 메커니즘만 차용해 엽서 제작·공유에 응용한 변형.
2. **키오스크(1180) + 모바일(393) 2트랙** — 데스크톱/아이패드 폭 1180 프레임에서 선택·편집·QR을 모두 **모달 상태 전이**로 처리하고, QR 스캔으로 393 모바일 공유 화면으로 넘어간다.
3. **엽서 = 10종 이미지 그리드(5×2, 160×160)** — 스탬프 칸이 아니라 **아트워크 이미지 선택 갤러리**. 선택 시 나머지 opacity 50% + 선택본 `#4A2100` 6px 아웃라인으로 표현.
4. **모달 편집 상태를 세분화** — Default / FocusHead(제목 입력) / FocusBody(본문 입력) / Unfocused(선택 해제) 등 인터랙션 상태를 별도 프레임으로 문서화. 스크롤·키보드·버튼 고정 규칙을 메모로 명시.
5. **텍스트 vs 이미지** — 헤더 타이틀·인트로 문구·CTA 라벨은 **`POSTCARDS-BG`·`카드보내기 1` 이미지에 베이킹**됨(텍스트 편집 불가). 편집 가능한 실제 텍스트 노드는 엽서 **To./메시지**뿐.
6. **폰트 = 윤고딕(YoonGothic OTF) 전용** — 메모에 "모든 페이지 윤고딕 사용, otf 파일 전달". Pretendard는 개발 전달용 주석 라벨에만 존재하므로 재현 시 혼동 금지.
7. **파랑/빨강 테두리는 UI 아님** — `#004DFF`(선택한 엽서 이미지·Default 내용 영역 표기), `red`(치수 박스)는 개발자 전달용 **주석 오버레이**. 실제 렌더에는 포함하지 않는다.

## 🤖 디자인 자동화 재현 포인트

- **테마색**: 페이지 배경 **`#FBF3EA`**(크림) · 모달 **`#FFFDFB`** · 텍스트 **`#61584F`** · 강조/테두리 **`#4A2100`**(딥 브라운) · 딤 `rgba(0,0,0,0.5)`. (파랑 `#004DFF`·빨강은 주석이므로 제외)
