# 💇 참조 이벤트 — 다이슨 (DYSON COOL CLUB)

> **다이슨(Dyson) "DYSON COOL CLUB" 팝업스토어 QR스탬프 이벤트.** 팝업 부스에서 QR을 스캔하며 **미션 3개(스탬프 3개)** 를 완료하면 **100% 당첨 룰렛**을 돌리고, 룰렛 결과에 따라 **뷰티 리워드(스크런치 / 스타일링 크림)** 를 수령한다.
> **룰렛(랜덤 경품) 케이스** — 스탬프 완주 후 리워드로 바로 가지 않고 **룰렛 화면을 경유**해 3종 경품 중 하나가 랜덤 배정되는 구조. 리워드 프레임이 경품별로 3벌 존재한다.
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

## 2️⃣ 본인인증 (Login) · `2035:1319` 외 4상태
- DS 폼: `이름` / `휴대폰번호`(+ "인증하기" → 전송 시 "재전송" + 3:00 카운트다운) / `인증번호`(+ "인증완료").
- 동의 체크박스 **4종(전부 필수)**:
  1. 다이슨 코리아 개인정보 이용·수집 동의 (필수)
  2. 개인정보 제3자 제공(계열사·국외 포함) 및 처리 위탁 동의 (필수)
  3. 마케팅 정보 수신 동의 (필수)
  4. **초상권 마케팅 활용 동의 (필수) — "자세히"** → 팝업 오픈

- 부속 **팝업(`2035:1751`)**: "초상권 마케팅 활용 동의 (필수)" — 촬영·SNS 게시물의 홍보 활용 안내문 + Close 아이콘.

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **룰렛 경유 5단계** — 스탬프 완주 → **룰렛(랜덤 경품)** → 리워드. 표준 4단계(시작·인증·스탬프·리워드)에 **룰렛 화면을 삽입**하고, 리워드는 룰렛 결과에 따라 **경품별 프레임을 분기**한다.
2. **리워드 다분기(3종 × 2상태)** — 단일 리워드가 아니라 **스크런치 / 크림4ml / 크림15ml** 3벌. 각각 수령전·수령완료 → **총 6프레임**. 룰렛 판의 섹터 수 = 리워드 종류 수.
3. **스탬프 = 미션 카드형** — 원형·격자 도장이 아니라 **가로 이미지 카드(dyson 배지 + MISSION N + 설명)** 를 세로로 3장 쌓는 "미션 체크리스트" 레이아웃. before/after는 카드 전체 이미지 교체.
4. **폰트 = Noto Sans KR (Bold)** — ⚠️ 이 볼트 다수 케이스의 표준(Pretendard)과 다르다. 재현 시 폰트 확정 단계에서 **Noto Sans KR**로 명시.
5. **밝은 메인 컬러 처리** — 블러시 핑크(`#EDCEC9`) 버튼·타이틀 위 텍스트는 **플럼(`#594D65`) 다크**. (흰색 텍스트 금지)
6. **본인인증 동의 4종 + 초상권 팝업** — 초상권 마케팅 동의가 별도 필수 항목이며 "자세히" → **팝업(`2035:1751`)** 으로 상세 고지. 인증 상태 전이(입력→전송→카운트다운→완료)를 4프레임으로 분리.
