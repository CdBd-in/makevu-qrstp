# 🗺️ 참조 이벤트 — 광주 시민체감형 실증 제품 스탬프 투어

> **광주광역시 "24년 창업기업제품 실증사업 — 시민체감형 실증 제품 스탬프 투어".** 광주 6개 실증 거점(문화·공공시설)을 돌며 각 장소에 배치된 창업기업 제품을 체험하고 QR을 스캔하면 해당 **기업 스탬프**가 찍힌다. **누적 3 / 8 / 12개** 달성 시 3단계 **미션 리워드**를 각각 신청할 수 있다.
> **지도·경로(로드맵) 케이스** — 스탬프를 격자(그리드)가 아니라 **구불구불한 컬러 리본 도로**를 따라 배치하고, 6개 거점을 서로 다른 색으로 구획한 **투어 맵** 형태. 상단에 **3단계 미션 리워드 버튼**을 별도로 둔 **다중 리워드 구조**가 특징.
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

## 1️⃣ 본인인증 (Login) · `1355:796` / `1355:838`
- 헤드라인 **"휴대폰번호 인증 한 번으로 이벤트에 참여하세요"**(Gmarket Sans).
- DS 폼 그대로: `이름` / `휴대폰번호`(+ "인증번호 받기") / `인증번호`(+ 보조 링크 "인증번호 문자가 오지 않을 때").
- 필수 동의 2종: "개인정보 수집 이용 동의 (필수)" / "개인정보 처리업무 위탁 동의 (필수)" (각 "자세히").
- CTA **"시작하기"** — Default(그레이 비활성) ↔ Enabled(그린 `#0E9351` 활성).

## 2️⃣ 스탬프 — 6거점 로드맵 투어 + 3단계 미션 리워드 · `1350:18`
- **상단 타이틀**: 코랄 사업명 라벨 **"24년 창업기업제품 실증사업"** → 그린 서브 **"시민체감형 실증 제품"** → 대형 화이트 디스플레이 **"스탬프 투어"**(Gmarket Sans 32px).
- **미션 리워드 3칸**(88px 원형 버튼): `MISSION 1 = 3개 적립` · `MISSION 2 = 8개 적립` · `MISSION 3 = 12개 적립`, 각 하위 라벨 **"리워드 신청하기"** → 달성·신청 후 **"리워드 신청완료"**(Done 프레임).
- **적립 카운트 헤더**: "지금까지 총 **N개**의 스탬프를 적립했어요" — 숫자만 코랄 `#DD5E6C`로 강조, Default 0개 → Done 13개.
- **투어 맵(로드맵)**: 세로 스크롤 컨테이너(320 폭 · 높이 약 1033) 안에 **구불구불한 컬러 리본 도로**(Vector 이미지 6개)로 6개 거점 구간을 잇는다. 각 거점은 우측/좌측 정렬 라벨 + 구간 색으로 표시:
  1. **국립아시아문화전당 어린이문화원** `#DD5E6C`
  2. **광주광역시 동구청소년상담복지센터** `#9FC51D`
  3. **광주역사민속박물관** `#2B8475`
  4. **광주시립미술관** `#3597A6`
  5. **GIST (광주과학기술원)** `#7F62A8`
  6. **아이플렉스** `#E9569A`
- **기업 스탬프 14개**: 도로 위에 자유 배치된 **80px 원형**. 각 칸 = 흰 원 + **참여기업명 텍스트**(NanumSquareOTF ExtraBold 12px). 씰은 **이미지 애셋이 아니라 텍스트 노드** — 기업명이 텍스트로 들어가 있어 편집 가능.
  - 기업명: (주)서큘러스 · 모션 어드바이저 · 일이육 · 이퓨월드 · 여행가자(주) · (주)넥스브이 · 이퓨월드 · 디어디어(비브멍) · 아이윌 · (주)넥스트테크 · 닥터케이 헬스케어 · (주)이에스티 솔루션 · (주)티슈오피스.
  - 적립 후(active) = 해당 거점 색의 **스캘럽(톱니) 씰**로 변환(스크린샷의 컬러 도장). 미적립 = 흰 원.
- **하단 안내 카드**(`rgba(0,0,0,0.04)` · 회색 텍스트, 실제 문구):
  - "· 어린이문화원 휴관 기간(11.20수 ~ 12.16월) 동안은 어린이창작 실험실에서 스탬프 투어가 진행됩니다."
  - "· 상품은 조건 달성 후 리워드 신청 시, 로그인 시 사용한 휴대폰 번호로 발송됩니다. (신청 후 7~10일 이내 지급)"
  - "· 상품 지급은 매월 선착순으로 지급으로 조기 마감될 수 있습니다."
  - "· 상황에 따라 상품이 변동될 수 있습니다."

## 3️⃣ 리워드 — 별도 화면 없음
- 리워드/경품 전용 프레임이 **존재하지 않는다.** 보상은 스탬프 화면 상단 **3단계 미션 버튼**에서 직접 신청("리워드 신청하기" → "리워드 신청완료")하고, 상품은 **로그인 휴대폰 번호로 발송**(신청 후 7~10일). 즉 이 이벤트는 **스탬프 화면 = 진행+리워드 통합** 구조.

## 🏷️ 스탬프 유형 (채택)
- 후보 88×88 씰 보드(`1348:1224` 등)가 같은 페이지에 보관. 채택 유형 = **텍스트형 원형 씰**(기업명 텍스트 중앙정렬) + **적립 시 거점 색 스캘럽 씰**로 리컬러. 이미지 애셋 교체가 아닌 **텍스트/색상 편집**으로 관리.

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **격자 아님 = 지도/로드맵 배치** — 스탬프를 3열 그리드가 아니라 **구불구불 컬러 도로(Vector) 위에 좌우로 자유 배치**. 거점 6개를 색으로 구획하는 **투어 맵**이 핵심 컨셉.
2. **다중(3단계) 리워드 = 상단 미션 버튼** — 4단계 리워드 화면 대신 스탬프 화면 상단에 **3/8/12개 누적 달성 미션 버튼**을 두고, 각각 신청/완료 상태를 관리(리워드 전용 프레임 없음).
3. **스탬프 = 텍스트 노드(이미지 아님)** — 경기수의컨퍼런스(업체명 이미지 씰)와 달리 **기업명이 텍스트로** 들어감. 기업 추가/수정이 텍스트 편집으로 가능. 적립 표현은 흰 원 → 거점색 스캘럽 씰.
4. **거점별 6색 팔레트** — 거점명·도로 색·해당 구간 씰 색을 하나로 통일(코랄/라임/틸/블루/퍼플/핑크). 브랜드 단색 테마가 아니라 **멀티컬러 구획**.
5. **폰트 = Gmarket Sans + NanumSquareOTF** — 표준 Pretendard 케이스와 다름. 헤드라인/미션은 Gmarket Sans, 스탬프·본문은 NanumSquareOTF ExtraBold.
6. **강조 숫자 색 초기화 주의** — 적립 카운트 "N개"는 코랄 `#DD5E6C` 강조. 숫자 텍스트 교체 시 강조색을 다시 입혀야 함.

## 🤖 디자인 자동화 재현 포인트

- **스탬프 칸수/모티프**: 기업 스탬프 **14개**, 80px 원형 텍스트 씰. 격자 아님 → **컬러 리본 도로 위 자유 배치(투어 맵)**. 6개 거점으로 구간 분할.
