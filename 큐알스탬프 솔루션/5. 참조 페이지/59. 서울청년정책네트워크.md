# 🗺️ 참조 이벤트 — 2024 서울청년정책네트워크 스탬프맵

> **서울시 "서울청년정책네트워크(청정넷)" 연간 활동 참여 QR스탬프맵.** 발대식부터 분과 회의·네트워킹데이·현장방문·캠페인 등 **1년치 청년정책 활동 25개**에 참여(출석)할 때마다 QR로 스탬프가 찍히고, 참여 개수에 따라 리워드 A~H를 **순차 개방(수령 가능 → 수령 완료)** 받는 구조.
> **여정 지도(journey-map) 콜라주 케이스** — 4~16칸 정형 격자가 아니라, **꼬불꼬불한 경로(S자 라인) 위에 25개 스탬프를 불규칙 배치**하고 청년 활동 일러스트를 사이사이 콜라주한다. 스탬프별로 활동명이 다르다(발대식·N차 분과회의·캠페인 등).

## 전체 흐름

```
스탬프맵(25개 여정 지도) + 리워드 A~H 상태 리스트    (본인인증·시작·리워드 화면 없음 · 단일 스크롤)
```

> ⚠️ 표준 4단계(시작→인증→스탬프→리워드) 구조가 **아니다.** 이 캔버스에는 **스탬프 화면 상태 변형 4장만** 존재하며, 시작·본인인증·리워드 전용 프레임이 없다. 리워드는 **같은 스크롤 하단의 인라인 리스트(수령 가능/수령 완료/참여 대기중 3섹션)** 로 표현된다. 진행도는 "적립된 스탬프 수 → 개방되는 리워드 수"로 연동.

## 1️⃣ 스탬프맵 (Stamp Map) — 여정 지도 콜라주

- 상단 타이틀 레터링 **"2024 서울청년정책네트워크 스탬프맵"**(라운드 볼드 디스플레이, 양옆 ✦ 장식).
- **MAP-BG**(`1205:427`, 375×783) 배경 위에 **꼬불꼬불한 경로 라인**(S자로 위→아래 흐름)이 깔리고, 그 위 25개 스탬프가 **불규칙 좌표로 배치**(격자 아님, 좌표 예: STAMP01 `27.6,110`, STAMP02 `111,96.6`, STAMP25 `160,795` …).
- 각 스탬프 **55×55** 원형. **미적립(before)** = 검정 라인아트 도형 안에 활동명 텍스트:
  - **일반 활동** = 흰/크림 **원형 아웃라인** (발대식 · 소모임 · N차 분과 회의 · 네트워킹데이 · 인사이트 특강 · 현장 방문 · 실국 협의회 · 캠페인 …)
  - **특별/마일스톤 활동** = **레드-마젠타 별버스트(뾰족 도형)** (사회 기여 활동 · 서울청년 시민회의 · 6차 분과 회의)
  - **적립(after)** = **옐로 스캘럽(톱니) 씰 + "출석 완료"** 문구로 교체.
- 경로 사이사이 **청년 활동 일러스트 콜라주**(노트북 회의·현장방문·캠페인·발표 등 사람 일러스트) — 배경 이미지 애셋으로 포함(텍스트 아님).
- 스탬프는 대부분 **개별 이미지 애셋**(`imgStamp01`, `imgStamp02` … 다수 스탬프가 동일 소스 공유 = 동일 "소모임" 원형 재사용). 활동명이 다른 칸은 별도 이미지.

## 2️⃣ 리워드 상태 리스트 (인라인, 하단 스크롤)

스탬프맵 아래에 **3개 상태 섹션**이 세로로 놓이고, 각 섹션 헤더는 좌우 아이콘으로 감싼 라벨:

- **★ 수령 가능 ★** (`1225:231`) — 개방되어 수령 가능한 리워드 영역.
- **● 수령 완료 ●** (`1225:230`) — 이미 받은 리워드.
- **○ 참여 대기중 ○** (`1225:229`) — 아직 조건 미달로 잠긴 리워드.
- **리워드 A ~ H (8종)** 캡슐이 각 상태 섹션으로 이동:
  - `Default`: 리워드 A~H 전부 **참여 대기중**(2열 그리드 · 회색 `#E9E9E9` pill).
  - `0 Received`: A~H 전부 **수령 가능**(1열, 폭 307 pill).
  - `1 Received`: 리워드 A만 **수령 완료** 섹션으로, B~H는 수령 가능.
  - `All Received`: A~H 전부 **수령 완료**(2열 그리드).

## 3️⃣ 시작·본인인증·리워드 전용 화면 — 없음
- 이 캔버스에는 START / LOGIN / REWARD 전용 프레임이 **존재하지 않는다.**
- 상태 진행은 스탬프 활성화 + 리워드 pill의 섹션 이동(대기중→가능→완료)만으로 표현된다.

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **여정 지도(journey-map) 콜라주 배치** — 격자가 아니라 **S자 경로 라인 위 불규칙 좌표**로 25개 스탬프를 배치. 좌표를 오토레이아웃으로 잡을 수 없어 **절대 위치(absolute) 수동 배치** + 경로 라인/일러스트는 배경 이미지(MAP-BG)로 굳힘.
2. **스탬프마다 활동명이 다름** — 공통 "소모임" 원은 이미지 재사용하되, 발대식·N차 분과회의·캠페인 등 고유 활동은 개별 이미지 애셋. 활동 추가/변경 = 텍스트 편집이 아니라 **이미지 교체**.
3. **일반 vs 특별 스탬프 2종 모티프** — 일반=흰 원형 라인, 마일스톤=**레드 별버스트**로 시각 위계. before/after(옐로 씰) 상태 세트가 각각 필요.
4. **리워드가 별도 화면이 아니라 인라인 상태 리스트** — "수령 가능 / 수령 완료 / 참여 대기중" **3섹션 + A~H pill**의 소속 이동으로 진행 표현. 4단계 리워드 화면 대신 **단일 스크롤 하단 리스트** 채택.
5. **폰트 = Noto Sans CJK KR** — ⚠️ 볼트 표준(Pretendard)과 다름. 재현 시 폰트 확정 단계에서 명시 필요.
6. **컬러 = 브랜드 단색 아님** — 크림 배경 `#F3F3EC` + 옐로 씰 + 레드 포인트 + 검정 라인아트의 **그림책/일러스트 톤**. 강조색 역할은 스탬프 옐로 씰이 담당.

## 🤖 디자인 자동화 재현 포인트

- **테마색**: 배경/베이스 크림 **`#F3F3EC`** · 미개방 리워드 pill 회색 **`#E9E9E9`** · 라인/테두리/텍스트 **검정 `#000000`** · 강조=**옐로 스캘럽 씰**(적립) + **레드-마젠타 별버스트**(특별 스탬프). 브랜드 단색 없음 → 일러스트 팔레트.
- **폰트**: **Noto Sans CJK KR**(Regular 본문 / Medium 라벨·헤더) 전체. 타이틀 "…스탬프맵"은 라운드 디스플레이 레터링(이미지 애셋). **Pretendard 아님 — 명시할 것.**
- **스탬프**: **25칸** · **여정 지도(S자 경로) 콜라주 배치**(격자❌·절대좌표) · 55×55 원형 · **before=검정 라인 원(일반)/레드 별버스트(특별) + 활동명** → **after=옐로 톱니 씰 + "출석 완료"**. 활동명이 칸마다 달라 이미지 애셋 다수 필요(공통 "소모임"은 재사용).
- **단계 구조**: 표준 4단계 아님. **스탬프맵(25개) + 리워드 A~H 인라인 상태 리스트** 단일 스크롤. 상태 변형 4장(Default / 0 Received / 1 Received / All Received). **시작·본인인증·리워드 전용 화면 없음.**
- **리워드**: 화면 대신 **"수령 가능 / 수령 완료 / 참여 대기중" 3섹션 + 리워드 A~H(8종) pill 소속 이동**으로 진행도 표현. 섹션 헤더는 좌우 ★/●/○ 아이콘 장식.
- **특이사항**: 경로 라인·활동 일러스트는 배경 이미지(MAP-BG)로 고정 → 스탬프는 그 위 절대배치. 재현 시 배경 이미지와 스탬프 좌표를 분리 관리해야 함.
