## 2. 전체 흐름

```
시작 → 본인인증(2) → 스탬프(6칸) → 리워드      (4단계 9프레임)
```

| 단계 | 프레임 | node-id |
|---|---|---|
| 1. 시작 | `1. Start` | `6425:1115` |
| 2. 본인인증 | `2-1. LOGIN-Default` / `2-2. LOGIN-Filled` | `6425:1134` / `6425:1149` |
| 3. 스탬프 | `3-1. STAMP-Default` / `3-2. STAMP-1/n` / `3-3. STAMP-n/n` / `3-4. STAMP-RewardDone` | `6425:1164` / `6425:1184` / `6425:1204` / `6425:1224` |
| 4. 리워드 | `4-1. REWARD-Default` / `4-2. REWARD-Done` | `6425:1243` / `6425:1273` |
| 부속 | 스탬프 4유형 후보 보드(삭제금지) | `6432:558` |
| 부속 | 스탬프 복제본(로고 보물상자 모티프 ×4) | `6444:132` / `6444:180` / `6444:228` / `6444:276` |

- **스탬프 헤더 상태**: 3-1 "스탬프 **6**개" → 3-2 "스탬프 **5**개"(1개 적립) → 3-3 "모두 모았어요!" → 3-4 "축하드려요!" (남은 수·강조 숫자 = 메인 브라운).
- **CTA**: 시작 "탐험 시작하기" / 스탬프·리워드 "리워드 받기" → 수령 후 "리워드 수령완료"(비활성).

## 3. 스탬프 (4유형 후보 → 사용자 선택)

> 모티프 판단 → **4유형 후보 보드 제작(`6432:558`, 삭제금지)** → 사용자 선택 → 6칸 통일. (→ 2-1-3 §2-6)

- **채택 유형 = ④ 이미지 + 하단 리본** · 리본 = **`리본 라벨` 컴포넌트(`6339:4`)** 를 **메인 브라운으로 리컬러** 적용(active) / 회색(inactive).
- **모티프(메인 버전) = 6개 다른 탐험 아이템**(각 여행지에서 다른 아이템 수집): **나침반 · 지도 · 열쇠 · 보석 · 동전 · 보물상자** (thiings 3D 아이콘).
- 적립 후(active)=컬러 / 적립 전(inactive)=흑백(채도 −100%)·반투명.

### 🪙 대안 버전 — 로고 보물상자 단일 모티프 (복제본)
- 브랜드 로고 일러스트에서 **보물상자만 추출**(`stamp-chest-logo.png`, 손그림 세피아 톤) → **6칸 단일 모티프 통일**(번호 1~6).
- **스탬프 프레임을 복제**(`6444:*`)해 적용 → **thiings 6종 버전은 원본 그대로 보존**. (로고 톤과 가장 일치 — 확정 시 메인 9프레임에 반영)
- ※ 로고가 **합성 일러스트**라 나침반·지도·열쇠 등은 서로 겹쳐 개별 추출 불가 → **깔끔히 분리되는 보물상자 1종만** 사용.

## 5. 제작 노트 (재현 포인트)

1. **n=6 템플릿 복제 출발** — `수정후`(`6236:2288`)는 6스탬프 구성 → 새 페이지로 복제 후 리테마. *(제작 당시 표준 · 현재 표준 템플릿은 `6600:18858` → [[큐알스탬프 솔루션/3. 워크플로우.md]] Step 3)*
2. **다크→라이트 리테마** — 배경 다크 이미지 → 양피지 단색 / 메인 퍼플 `#7F5AF0` → 브라운 `#8C7851`(fills+strokes) / 본문 화이트 → 다크 `#020826`. **혼합 텍스트(강조 숫자)는 세그먼트 단위로** 별도 처리.
3. **폰트** — 이벤트명 Playfair Display(영문) · 축하합니다 Pretendard Bold(국문) · 본문 Pretendard.
4. **로고** — 받은 로고는 새로 그리지 않고 **배경 제거 후 167×73 프레임 contain·중앙**. 밝은 배경이라 흰색 마스크 불필요. 타이틀 텍스트는 유지(중복 허용).
5. **배경 그래픽** — Figma 벡터(점선 루트·X·점) 저투명도·여백 위주 → 텍스트 가독성 유지.
6. **오토레이아웃 상하 여백** — 시작·리워드 52/52 · 스탬프 52/40 · 프레임 높이 콘텐츠 hug.
7. **검수** → [[큐알스탬프 솔루션/4. 검수 체크리스트.md]] 전 항목 통과 (로고 미제공 시 `#EDEDED` placeholder였다가, 이후 로고 반영).
