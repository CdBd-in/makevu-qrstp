# 🍪 참조 이벤트 — 쿠키런 X 캐스퍼 (Cookie Run x CASPER)

> **현대자동차 CASPER x 데브시스터즈 "쿠키런" 콜라보 QR스탬프 이벤트.** 캐스퍼 스튜디오 공간 곳곳에 숨은 **"설탕노움"** 캐릭터를 찾아 QR을 스캔하면 스탬프가 찍히고, **설탕노움 4종**을 모두 모으면 **선물 룰렛**을 돌려 소정의 상품을 받는다.
> **IP 콜라보 + 룰렛 변형 케이스** — 표준 4단계(시작→인증→스탬프→리워드) 사이에 **룰렛(랜덤 추첨) 화면**이 추가되어 스탬프 완주 후 룰렛을 돌려야 리워드가 확정된다. 화면 전체가 **쿠키런 IP 배경 일러스트 풀블리드 이미지**로 구성된다.
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

- **아트보드**: 375 폭 · 세로 714~715 고정(시작·스탬프·룰렛·리워드 모두 동일 높이)

- **폰트**: 국문 본문·안내 **Pretendard** / 타이틀은 **쿠키런/캐스퍼 IP 디스플레이 레터링(이미지)**

## 전체 흐름

```
시작 → 본인인증(다상태) → 스탬프(4칸) → [룰렛] → 리워드      (본인인증 있음 · 룰렛 삽입 5단계)
```

> ⚠️ 표준 4단계와 달리 **스탬프 완주와 리워드 사이에 "룰렛" 단계가 삽입**된다. 스탬프 4개를 다 모으면 `STAMP / Done`의 CTA가 활성화 → 룰렛 화면으로 이동 → 룰렛을 돌려 결과가 나오면 리워드 페이지로 **자동 이동**한다.

## 1️⃣ 시작 (Start) · `1032:1062`
- 상단 로고 락업 **`쿠키런 | CASPER`**(콜라보 co-brand).
- 디스플레이 타이틀(IP 레터링 이미지) **"숨은 설탕노움 찾기 / 이벤트"**.
- 나무 팻말 안내 카드(화이트 텍스트):
  - **"캐스퍼 스튜디오 곳곳에 숨은 설탕노움을 찾아보세요!"**
  - **"함께 설탕노움을 찾아온 분들께 소정의 상품을 드립니다."**
- 하단 옐로우 CTA **"지금부터 함께 떠나볼까?!"** — 배경은 설탕노움을 태운 **캐스퍼(레드 카) 일러스트** 풀블리드.

## 2️⃣ 본인인증 (Login) — 다상태 폼 세트 · `1033:1872` 외
- 헤드라인 **"휴대폰번호 인증 한 번으로 이벤트에 참여하세요"**.
- DS 폼: `Field_Name` / `Field_Phone`(인증번호 받기·재전송) / `Field_Verification`(유효시간·Verified·Expired) · 필수 동의 체크박스 2종(개인정보 수집·이용 / 처리업무 위탁, 각 "자세히") · CTA **"참여하기"**.
- **상태 프레임 다수 보유**(교과서적 인증 플로우): Default / Name_Selected·Error / Phone_Selected·Button_Enabled·Button_Re·Error / Veri_Sent·Selected·Filled·Error·Expired / Error_empty / Button_Enabled / **Enabled**(전부 충족·활성).
- 팝업: `AGREE_Popup1`(수집·이용 · 수탁 (주)엠카) / `AGREE_Popup2`(위탁) / `NOMESSEGE_Popup`(인증문자 안 올 때 통신사별 스팸차단·착신전환 안내, 발송번호 `1800-8590`).

## 3️⃣ 스탬프 (Stamp) — 설탕노움 4종 수집 · `1032:1055`~`1032:1123`
- 헤더(IP 레터링) **"FIND YOUR BRAVE"** + 안내 나무 카드 **"서로 다른 설탕노움 4종이 숨어있어요!"**.
- **스탬프 배치 = 1행 4열(가로 4칸)** — `Group 5` 안에 `1~4`번 슬롯(각 ~62.7×54.5), 좌우로 나란히.
  - 각 칸 = **설탕노움 캐릭터 씰**. 미적립 `N-X`(실루엣/그레이) ↔ 적립 `N-O`(컬러 캐릭터).
  - 스탬프는 이미지 위에 얹힌 **캐릭터 애셋**이며 개별 QR로 적립(스캔 순서는 사용자마다 달라 예시와 다른 순서로 채워질 수 있음 — 페이지 주석 명시).
- 상태 진행: `0/4`(전부 X, CTA 비활성 `Button-Disabled`) → `1/4` → `2/4` → `3/4` → `Done`(4개 컬러, CTA `Button-Enabled` "리워드 받기").

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **룰렛(랜덤 추첨) 단계 삽입** — 스탬프 완주가 곧 리워드 확정이 아니라, **`STAMP/Done → ROULETTE → REWARD`** 로 한 단계 더 있다. 룰렛 정지 후 결과에 따라 리워드 배경(`04 결과N`)이 결정되어 자동 이동. (스탬프→리워드 직결인 표준 케이스와 구조가 다름)
2. **화면 = IP 배경 일러스트 풀블리드 이미지** — 하늘·지면·캐릭터·나무 팻말이 통짜 `_0425` 배경 이미지로 굳어져 있음. DS 색 토큰이 비어 있고, 리테마는 **색 치환이 아니라 IP 이미지 세트 교체**. 신규 콜라보 시 배경/캐릭터 애셋을 통째로 갈아끼운다.
3. **스탬프 = 캐릭터 씰(1행 4열)** — 4종의 설탕노움 캐릭터를 가로 한 줄에 배치. before(`N-X` 실루엣) / after(`N-O` 컬러) 2벌 캐릭터 애셋 교체로 적립 표현. (원형 도장·리본 라벨류가 아니라 **IP 캐릭터 자체가 스탬프**)
4. **나무 팻말 UI 언어** — CTA·안내 카드가 공통 버튼 컴포넌트가 아니라 **우드 사인(나무 팻말) 이미지**. 쿠키런 IP 톤(RPG/여정 컨셉)에 맞춘 커스텀 버튼.
5. **다상태 로그인 세트가 매우 상세** — Name/Phone/Veri 각 단계의 Selected·Error·Expired·Sent·Re 상태와 3종 팝업(약관2 + 인증문자 미수신)까지 완비. 인증 플로우 참고용 레퍼런스로 유용.
6. **STAFF 확인 O/X 토글** — 오프라인 상품 수령 검수를 위한 STAFF용 확인 버튼 변형을 리워드에 별도 애셋으로 보유.

## 🤖 디자인 자동화 재현 포인트

- **테마색**: 메인/하늘 `#2A93FF`(스카이 블루) · 지면/옐로우 CTA `#FFCA35~#FFCD46` · 나무 팻말 브라운(`~#8B5A3C`, 밝은면 `#F1B15D`/진한면 `#91433E`) · 타이틀=화이트+다크 아웃라인 IP 레터링.
- **폰트**: 국문 본문·안내 **Pretendard**. 타이틀("숨은 설탕노움 찾기", "FIND YOUR BRAVE", "선물 룰렛", "축하합니다!")은 **쿠키런/캐스퍼 IP 디스플레이 레터링을 이미지로 처리**(폰트 노드 아님).
- **스탬프 칸수/모티프**: **4칸(1행 4열)** · 모티프 = **쿠키런 "설탕노움" 캐릭터** · before `N-X`(실루엣) / after `N-O`(컬러 캐릭터) 애셋 교체.
- **단계 구조**: 시작 → 본인인증(다상태) → 스탬프(0/4~Done) → **룰렛(랜덤 추첨)** → 리워드(+STAFF 확인). 표준 대비 **룰렛 단계 추가**.
- **특이사항**:
  - 화면 전체가 **`_0425` IP 배경 이미지** — DS 변수 정의 없음, 리테마=이미지 교체.
  - 룰렛 정지 → 리워드 **자동 이동**, 결과별 배경 후보 5종(`04 결과1~5`) 보유.
  - 나무 팻말 커스텀 CTA + STAFF 확인 O/X 토글(오프라인 수령 검수).
  - 로고 락업 = `쿠키런 | CASPER` co-brand.
