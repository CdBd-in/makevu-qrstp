## 🧩 제작 노트 (재사용 포인트)

1. **로고 = 포스터에서 벡터 추출** — 공식 포스터(`.ai` → Figma 벡터)의 타이틀 락업 그룹만 복제 → 태그라인·일시·`2026 KOREA…` 제거 → 전 fill 흰색 → `rescale(132/width)` → **132×69.77**(가로 132·세로 70 한도에 동시 적합). 새로 그리지 않음.
2. **배경 = Figma 네이티브 그라데이션 + 별 오버레이 PNG** — 프레임 높이가 페이지마다 달라도(824/1096/832/742) 그라데이션은 자동 대응, 별은 이미지 1장(786×1800)을 `scaleMode FILL`로 재사용.
3. **캐릭터 = 전달받은 시트에서 알파 투영으로 10개체 자동 분할** — 행/열 투영 → bbox 트림 → 개별 PNG 업로드.
4. **리워드 이미지 = 기획서 PDF 제품컷을 flood-fill 키잉**으로 배경 제거 후 합성(그림자 포함). thiings 3D 아이콘 대신 **실물 굿즈**를 썼다.
5. **점선 그리드** — 가로선 = `LINE`(높이 0)이라 오토레이아웃 gap 20+0+20 = **정확히 40**. 세로선 = 폭 1 `RECTANGLE` + `strokeLeftWeight=1` + `dashPattern [3,3]`(행 높이 FILL).
6. **스탬프 = 단일 컴포넌트 세트 2속성**(`zone` × `state`) → 상태 화면은 `setProperties({state})`만으로 전환.
