### 단계 문구 (어절 단위 줄바꿈)
- **1단계** — `공공디자인 거점 리스트를 확인하고` / `원하는 장소를 자유롭게 방문해보세요.`
- **2단계** — `지정된 장소에 도착하면 GPS를 통해` / `현재 위치를 확인합니다. 위치 인증이 완료되면` / `해당 거점의 모바일 스탬프가 자동 적립됩니다.`
  - 주석(#0071CE 10) — `※ 스탬프 적립 화면 접속시에만` / `위치 확인 및 스탬프 인증이 가능합니다.`
- **3단계** — `방문한 거점수에 따라` / `경품 추첨에 참여할 수 있습니다.`

**수정 이력**
1. `v1` — 초안 배치. 세로 총합이 787을 21px 초과 → 리워드 이미지 44→36, 블록 간격 재조정으로 해소.
2. `v2` — 단계 본문 11.5 → **12**(DS Caption 램프)로 상향.
3. `v3` — 단계 뱃지 사이 **점선 커넥터**(1.5px · dash 3/4) 추가. 원본 상세 이미지의 연결선 재현.
4. `v4` — **버그 수정**: `step-*` row 3개와 `divider-참여방법`에 불투명 `#FFFFFF` 기본 fill이 남아 뱃지 뒤 배경이 흰 띠로 가려지고 점선이 묻힘 → fill 제거(`[]`) + clipsContent off.

**⚠️ 가이드 대비 의도적 편차 (사용자 확인 필요)**
- **타이포 램프**: DS 램프(`Display 48/58` … `Caption 12`) 밖의 값 사용 — 리워드 4-up 카드의 마이크로 라벨 `8.5`, 이름 `9`, 주석 `10/10.5`, 구분선 라벨 `17`, 대제목 `30`. 393폭에 상세 이미지 1장 분량을 787px 안에 담기 위한 압축. (기준 `1. Start`도 40/18/16 등 램프 밖 값 사용 중)
- **프레임 높이**: 가이드는 `콘텐츠 hug`이나, **사용자 지정 393×787 고정**. 블록 내부는 전부 오토레이아웃, 블록 간 배치만 고정 캔버스 기준 y좌표.
- **상하 여백**: 가이드 52/52 대신 **상단 20(로고) · 하단 24** — `1. Start`의 실제 값과 동일하게 맞춤.
- **제목 폰트**: `1. Start`의 `LCK SubTitle`이 로컬에 미설치 → **Pretendard ExtraBold**로 대체.
