# 🐾 참조 이벤트 — 경기수의컨퍼런스 (Gyeonggi Veterinary Conference 2026)

> **경기도수의사회 주최 "경기수의컨퍼런스 2026" 부스 방문 QR스탬프 랠리.** 컨퍼런스 전시 부스마다 QR을 스캔하면 해당 **부스(참가업체) 스탬프**가 찍히고, **67개 부스**를 모두 방문하면 **경품 추첨**에 참여할 수 있다.
> **대규모 부스 랠리 케이스** — 스탬프가 4~16칸이 아니라 **참가업체 수만큼(67개) 세로 스크롤 그리드**로 구성된다. 각 스탬프 = 업체명이 박힌 **번호 씰(도장) 이미지**.
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

## 1️⃣ 시작 (Start) · `6500:28`
- 상단 **경기도수의사회 로고** + 디스플레이 타이틀 **"경기수의컨퍼런스 / Gyeonggi Veterinary Conference 2026"**(네이비).
- **QR 스탬프 이벤트 안내 카드**(화이트 반투명) — 네이비 배지 헤더 아래 2블록:
  - **일시・장소**: `2026.7.11(토) ~ 12(일)  |  수원컨벤션센터`
  - **참여 안내**: "컨퍼런스 각 부스에서 QR을 스캔하고 스탬프를 적립하세요. 모든 전시 부스 방문 후 경품 추첨 참여가 가능합니다."
- 하단 네이비 CTA **"시작하기"**.

## 2️⃣ 본인인증 (Login) · `6500:993` / `6500:1012`
- 헤드라인 **"휴대폰번호 인증 한 번으로 이벤트에 참여하세요"**.
- DS 폼 그대로: `이름` / `휴대폰번호`(+ "인증번호 받기" → Filled 시 "재전송") / `인증번호`(+ "인증되었습니다").
- 보조 링크 "인증번호 문자가 오지 않을 때" · 필수 동의 체크박스 2종(개인정보 수집·이용 / 처리업무 위탁, 각 "자세히").
- CTA **"시작하기"** — Default(그레이·비활성) ↔ Filled(네이비·활성).

## 3️⃣ 스탬프 (Stamp) — 부스 방문 씰 랠리
- 헤더(3상태 고정 문구, 남은/모은 개수만 변동):
  - Default: **"홍길동님, 스탬프 0개를 모았어요"**
  - 진행: **"홍길동님, 스탬프 8개를 모았어요"** (`3-2. STAMP-8Done`)
  - 완료: **"홍길동님, 스탬프를 모두 모았어요"** (`3-3. STAMP-AllDone`)
- **스탬프 그리드**: `24` 좌우 여백 · 컨테이너 폭 345 · **3열** · 세로 스크롤(그리드 높이 약 2712) · 총 **67개(1~67번)**.
  - 각 칸 = **88×88 원형 스캘럽(톱니) 씰** — 중앙 **번호**(1,2,3…) + 하단 **참가업체명**(예: `(주)드림케어` · `(주)이글벳` · `그린벳`).
  - 스탬프는 **업체명이 박힌 이미지 애셋**(`N-before 1`=미적립 그레이 / `N-after`=적립 네이비). 텍스트 노드가 아니라 **번호·업체명이 이미지로 굳어져 있음**.
  - 칸 사이 **세로 구분선**(Line 2/3) + 행 사이 **가로 구분선**(Line n)으로 격자 표현.
- 상태 진행: Default(0/67) → 8Done(8개 적립) → AllDone(67/67 전부 네이비).

## 4️⃣ 리워드 — 별도 화면 없음
- 리워드/경품 전용 프레임이 **존재하지 않는다.** 보상은 **"모든 전시 부스 방문 후 경품 추첨"**(오프라인)으로 대체.
- 즉 이 이벤트는 **스탬프 완주 = 목표**이며, 최종 화면은 `STAMP-AllDone`.

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **스탬프 수 = 참가업체 수(대량)** — 4~16칸 정형이 아니라 **67개 업체 스탬프를 3열 세로 스크롤 그리드**로 구성. 프레임 높이가 콘텐츠에 따라 크게 가변(2995).
2. **스탬프 = 업체명 박힌 번호 씰 이미지** — 씰마다 번호+상호가 이미지로 고정. 신규 업체 추가/수정 시 **텍스트 편집이 아니라 이미지 교체**가 필요(before/after 2벌).
3. **4단계가 아닌 3단계** — 참여형 경품 추첨 이벤트는 **리워드 화면을 생략**하고 시작 카드의 "참여 안내"로 보상 규칙을 설명. (민주평통·WORLD PASSPORT 등의 4단계 리워드 구조와 대비)
4. **진행 상태는 헤더 카운트로 표현** — "N개를 모았어요"의 숫자만 바꿔 Default/진행/완료 3상태 구성(플로팅 버튼·리워드 전환 없음).
5. **브랜드 = 딥 네이비 `#003C5E`** 단색 테마 + 컨퍼런스 포스터 배경 위 **반투명 화이트 카드**로 가독성 확보.
