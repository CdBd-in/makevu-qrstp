# 🎮 참조 이벤트 — MSI (MSI 2026 FAN FESTA 스탬프 투어)

> **라이엇 게임즈 "MSI 2026 (Mid-Season Invitational) FAN FESTA" 스탬프 투어.** 대전(Daejeon)에서 열리는 리그 오브 레전드 팬 페스타 현장의 각 부스(정보/스폰서/케스파/아트존/포토부스 등)에서 QR을 스캔하면 부스 스탬프가 찍히고, **12개 중 10개**를 모으면 **설문 참여 → 룰렛(경품 추첨)** 리워드를 받는다.
> **국문/영문 이중언어 · 설문 + 룰렛 리워드 케이스** — 시작 전 언어선택(국문/ENG) 분기가 있고, 리워드 수령 조건이 "완주 후 설문 응답 → 룰렛 추첨"으로 다단계다. 화면 대부분이 **디자인 시스템 컴포넌트가 아닌 풀블리드 이미지 애셋**(그런지·찢긴 종이 MSI 키비주얼)으로 구성된 점이 최대 특징.
> 제작 규약은 [[큐알스탬프 솔루션/3. 워크플로우.md]], 토큰·컴포넌트 정의는 [[큐알스탬프 솔루션/2. 작업 가이드/2-2. 디자인 요소/2-2-1. 공통 디자인 시스템.md]] 참고.

## 📌 제작 시 참고 패턴 (이 케이스의 특이점)

1. **이미지 기반 화면(image-first)** — CTA·타이틀·배경까지 **PSD/AI에서 완성한 통이미지**를 프레임에 얹는 방식. DS 토큰 리컬러로 재현되지 않으므로, 재현 시엔 키비주얼(그런지 블랙 + 라이엇 레드 + 형광 라임)을 이미지로 준비하거나 그에 준하는 레이어를 직접 구성해야 한다.
2. **이중언어(국문/ENG) 미러링** — `2. Language` 분기 후 국문·영문 두 섹션이 동일 프레임 세트를 미러링. 문구 수정 시 **양쪽 모두** 반영.
3. **완주 ≠ 리워드 조건** — 12칸 중 **10개**만 모으면 리워드. 헤더 카운트는 `10 − 적립수`("N개 더 모으고"). 10칸형 완주와 다른 12중 10 부분 달성 규칙.
4. **스탬프 = 흩뿌린 커스텀 씰 콜라주** — 3열 격자가 아니라 배경 위 자유 배치. 각 씰이 부스별 고유 일러스트(색·라인 제각각) → 신규 부스는 씰 이미지 신규 제작.
5. **리워드 = 설문 → 룰렛(경품 추첨)** — 단일 리워드 화면이 아니라 6문항 설문 게이트 후 8분할 룰렛으로 8종 경품 분기(`Reward1~8`) + Done. 참여형·추첨형 하이브리드.
6. **참여 제한/스태프 게이트** — 1일 3회 한도, 초과 시 `7. Limit Notice`로 분기, 재시작은 스태프 비밀번호 인증. 오프라인 부스 운영 전제의 안전장치.
7. **폰트 = LCK SubTitle(브랜드) + Pretendard(본문)** — 헤드라인은 LoL/LCK 전용 서체, 본문·설문·폼은 Pretendard.

## 🤖 디자인 자동화 재현 포인트

- **테마 색**: 메인 = 라이엇 레드 **`#EE3D3D`**(모든 CTA) · 배경 = 블랙 그런지/찢긴 종이 키비주얼 · 본문 텍스트 **`#212529`** · 비활성/설문칩 `#E8E8E8`+`#898989` · 포인트 형광 라임 화살표.
- **폰트**: 헤드라인 **LCK SubTitle**(MSI/LoL 브랜드 서체 — 대체 시 조건부, 반드시 별도 폰트 로드), 국문·본문·폼·설문 **Pretendard**(입력 = Medium 14 / -0.2).
- **스탬프**: **12칸**, 리워드 조건 = **10개 달성**(전부 아님). 헤더 문구 "`N`개의 스탬프를 더 모으고 / 리워드를 받으세요"에서 `N = 10 − 적립수`. 씰은 **격자 없이 배경 위 자유 배치된 부스별 커스텀 도장 12종**(단일 stamp_type, 각기 다른 일러스트).
- **단계 구조**: `언어선택 → 시작 → 인증(2) → 스탬프(0/12·1/12·10/12·RewardDone) → 설문(6문항·start/default/filled/Done/Restart) → 룰렛(start→spin→Reward1~8→Done)`. 표준 4단계 + 언어선택 + 설문 + 룰렛으로 확장.
- **특이사항 1 — 이미지 우선 구성**: 화면 = 풀블리드 통이미지(CTA·타이틀 포함). DS 컴포넌트 리컬러 방식이 아니므로 재현 시 키비주얼 이미지 자산이 선행 필요. 폼(로그인)만 DS 컴포넌트 사용.
- **특이사항 2 — 이중언어**: 국문(`6137:5383`)/영문(`6156:3550`) 섹션 미러링. 두 섹션 동기화 필수.
- **특이사항 3 — 리워드 = 설문+룰렛**: 완주 후 6문항 설문 → 8분할 룰렛 추첨(8종 경품) → Done. 별표 만족도(`Star` 컴포넌트).
